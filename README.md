# 数学自学项目

一个从零开始建设的数学自学内容项目，长期目标是为小学至高中学生提供结构清晰、循序渐进、适合独立学习的数学课程。

## 当前阶段

当前优先建设数学启蒙、小学一年级和小学二年级的知识讲解内容。

当前内容包括：

- 数学概念讲解
- 具体对象、图示和数学符号之间的转换
- 教师演示例子
- 方法和思考过程说明
- 易混淆点和内容总结

当前暂不制作练习、应用题专项内容、测试系统和网站交互功能。

## 教学理念

小学阶段主要参考 Singapore Math，采用“具体—图示—抽象”的讲解路径，重视数感、概念理解、循序渐进和数学表达。

## 内容路线

当前内容按以下顺序建设：

1. 数学启蒙
2. 小学一年级
3. 小学二年级
4. 内容整理与知识图谱
5. 更高年级内容、练习、测试和网站功能

详细路线见 [ROADMAP.md](ROADMAP.md)。
