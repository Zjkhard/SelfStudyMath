# 几何：平面与曲面、组合图形

我们已经认识过一些平面图形：

~~~text
圆形、三角形、正方形、长方形
~~~

生活中还有许多立体物体：

~~~text
球、盒子、圆柱形水杯、圆锥形帽子
~~~

今天，我们观察立体物体的表面，并学习怎样把简单图形组合成新的图形。

## 一、平面和曲面

平面是平平的表面。

例如：

~~~text
书的封面、桌面、墙面
~~~

这些表面看起来是平的，可以放平直的物品。

曲面是弯曲的表面。

例如：

~~~text
球的表面、圆柱形杯子的侧面
~~~

这些表面不是平的，而是弯曲的。

可以用手摸一摸或用直尺贴一贴，帮助判断一个表面是平面还是曲面。

## 二、认识立体物体的表面

立体物体的外表面可能由平面、曲面，或者平面和曲面共同组成。

看一个盒子：

~~~text
    ┌──────┐
   /      /│
  ┌──────┐ │
  │      │ │
  │      │/
  └──────┘
~~~

盒子的表面是平的。它有多个平面，合起来形成一个立体物体。

看一个球：

~~~text
     ◯
~~~

球的表面是弯曲的，没有平的表面。

## 三、常见立体物体的表面

### 正方体

正方体的 6 个表面都是正方形的平面：

~~~text
正方体：6 个平面
~~~

### 长方体

长方体的表面都是长方形或正方形的平面：

~~~text
长方体：平面表面
~~~

### 圆柱体

圆柱体有两个平的圆形表面，还有一个弯曲的侧面：

~~~text
    ┌────┐
  ┌─┴────┴─┐
  │        │
  └─┬────┬─┘
    └────┘
~~~

### 球

球的表面是曲面：

~~~text
球：曲面
~~~

### 圆锥体

圆锥体有一个平的圆形表面和一个弯曲的侧面：

~~~text
    ▲
   / \
  /   \
 └─────┘
~~~

认识物体时，可以问：

- 它有没有平面；
- 它有没有曲面；
- 它的表面由哪些图形组成。

## 四、根据表面判断物体

如果一个物体的所有表面都是平面，它通常容易堆叠：

~~~text
盒子、积木
~~~

如果一个物体有曲面，它可能容易滚动：

~~~text
球、圆柱形罐子
~~~

但是，圆柱体既可以滚动，也可以把平的底面放在桌面上。

表面形状会影响物体的运动方式：

- 平面可以稳定地放在平面上；
- 曲面接触地面的位置会变化，物体可能滚动。

## 五、平面图形和立体物体不同

平面图形只有平的面，可以画在纸上：

~~~text
○   △   □   ▭
~~~

立体物体有一定的厚度，占据空间：

~~~text
球、正方体、圆柱体
~~~

例如：

~~~text
圆形是平面图形；
球是立体物体。
~~~

圆形可以画在纸上，球可以拿在手里。

## 六、用平面图形拼出新图形

两个三角形可以拼成一个正方形：

~~~text
△ + △ = □
~~~

也可以把一个正方形沿对角线分成两个三角形：

~~~text
□ → △ + △
~~~

拼接和拆分的过程改变了图形的组成，但没有改变覆盖的总区域。

## 七、用相同图形拼成更大的图形

看 4 个小正方形：

~~~text
□ □
□ □
~~~

它们可以拼成一个更大的正方形。

也可以排成一行：

~~~text
□ □ □ □
~~~

这时拼出的图形是一个长方形。

同样的小图形，排列方式不同，可能拼出不同的大图形。

## 八、用不同图形拼成一个图形

一个简单的小房子可以由三角形和正方形组成：

~~~text
    △
   △△△
  ┌────┐
  │ □  │
  │    │
  └────┘
~~~

可以把它看成：

- 一个三角形屋顶；
- 一个正方形或长方形房屋；
- 一个小长方形门。

一个复杂的图形，常常可以拆成几个熟悉的基本图形。

## 九、图形的拆分

看一个大三角形：

~~~text
    ▲
   /|\
  / | \
 /__|__\
~~~

从顶点向底边画一条线，可以把它分成两个小三角形：

~~~text
大三角形 → 小三角形 + 小三角形
~~~

看一个长方形：

~~~text
┌──────┐
│      │
└──────┘
~~~

画一条竖线，可以把它分成两个小长方形：

~~~text
┌───┬───┐
│   │   │
└───┴───┘
~~~

拆分后，每一部分仍然是图形的一部分；把它们合在一起，可以还原原来的图形。

## 十、组合图形的边界

多个图形拼在一起后，外面的轮廓会形成一个新的图形。

例如，两个相同的三角形可以组成一个正方形：

~~~text
△ + △ → □
~~~

拼接线在内部，外面的轮廓是正方形的边界。

看两个长方形拼成的图形：

~~~text
┌────┐
│    ├───┐
│    │   │
└────┴───┘
~~~

中间相连的部分是内部线，最外面的线组成整个图形的边界。

观察组合图形时，要区分：

- 图形内部的拼接线；
- 整个图形最外面的轮廓。

## 十一、用积木制作立体图形

平面图形可以拼成新的平面图形，积木也可以拼成立体物体。

用 4 块相同的正方体积木，可以排成一层：

~~~text
■ ■ ■ ■
~~~

也可以堆成两层：

~~~text
■ ■
■ ■
~~~

还可以先排成一排，再向上堆：

~~~text
上层：■ ■
下层：■ ■
~~~

积木数量相同，但摆放位置不同，组成的立体形状也可能不同。

## 十二、从不同方向观察立体图形

同一个立体物体，从不同方向看，看到的平面图形可能不同。

例如一个长方体：

- 从正面看，可能看到长方形；
- 从侧面看，可能看到另一个长方形；
- 从上面看，可能看到长方形。

一个圆柱体：

- 从上面看，可能看到圆形；
- 从侧面看，可能看到长方形。

所以，看到一个平面图形时，还要想一想它可能是哪个立体物体的一个面。

## 十三、组合图形中的图形数量

看下面的图形：

~~~text
    △
   ┌─┐
   │ │
   └─┘
~~~

它可以看成：

- 1 个三角形；
- 1 个正方形或长方形。

再看：

~~~text
┌───┬───┐
│ △ │ △ │
└───┴───┘
~~~

它由 2 个三角形和 2 个小长方形区域组成。

数组合图形时，可以先分辨基本图形，再说明它们怎样连接。

## 十四、完整地看一个例子

用两个相同的长方形和一个三角形组成一面小旗：

~~~text
    △
   ┌─┐
   │ │
   ├─┤
   │ │
   └─┘
~~~

先看组成部分：

~~~text
三角形：1 个
长方形：2 个
~~~

把两个长方形上下连接，再把三角形放在上面，就得到一个新的组合图形。

这个组合图形的外轮廓看起来像一面小旗。

如果把三角形拿掉，就只剩下两个相连的长方形；如果把长方形拆开，又可以看到原来的两个基本图形。

组合和拆分可以帮助我们理解图形是怎样构成的。

## 十五、我们知道了什么

- 平面是平的表面，曲面是弯曲的表面；
- 正方体和长方体主要由平面组成；
- 圆柱体同时有平面和曲面；
- 球只有曲面；
- 平面图形画在纸上，立体物体有厚度并占据空间；
- 基本平面图形可以拼成新的组合图形；
- 一个组合图形也可以拆分成几个熟悉的基本图形；
- 立体物体可以用积木组合，摆放方式不同，形状也可能不同；
- 观察图形时，可以从组成部分、最外轮廓以及平面和曲面来描述。
