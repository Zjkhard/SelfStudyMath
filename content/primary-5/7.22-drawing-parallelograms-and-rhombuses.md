# 画平行四边形与菱形

平行四边形的两组对边分别平行，菱形是四条边都相等的特殊平行四边形。作图时要先辨认已知条件，再选择直尺、三角尺、量角器或圆规，并在完成后检查平行、相等和角度关系。

## 一、作图工具

```text
直尺：画线段和延长线
三角尺：画垂线和平行线
量角器：画出指定角度
圆规：复制长度、画弧和确定相等边
```

单靠目测不能保证两条线平行或两条边相等，应使用工具和作图步骤保持准确。

## 二、作图前读取条件

开始前先标出题目给出的信息：

```text
边长：例如 AB = 6 cm、BC = 4 cm
角度：例如 ∠A = 60°
平行关系：AB ∥ CD、AD ∥ BC
相等关系：菱形四边相等、相等角或相等对角线
```

还要确定顶点名称顺序，避免把对边和相邻边混淆。

## 三、用两组平行线画平行四边形

已知相邻两边 `AB = 6 cm`、`AD = 4 cm`，以及 `∠DAB = 60°`：

1. 画 `AB = 6 cm`。
2. 在 `A` 处画 60° 的射线。
3. 沿射线量取 `AD = 4 cm`，标出 `D`。
4. 过 `B` 画与 `AD` 平行的直线。
5. 过 `D` 画与 `AB` 平行的直线。
6. 两条平行线交于 `C`，连接并标记 `ABCD`。

所得图形满足 `AB ∥ CD`、`AD ∥ BC`。

## 四、用三角尺画平行线

过已知点画平行线时，可以使用两把三角尺：

1. 将一把三角尺的一条边贴在已知直线 `AD` 上。
2. 用另一把三角尺靠住第一把三角尺的一侧。
3. 固定第二把三角尺，平移第一把三角尺到目标点 `B`。
4. 沿第一把三角尺画线，得到过 `B` 且平行于 `AD` 的直线。

平移时要保持参照三角尺不动，否则新线可能发生倾斜。

## 五、用量角器画平行四边形

已知一条边、相邻边和夹角时，也可先画一个三角形，再利用相等和对边平行完成图形。

例如 `AB = 7 cm`、`AD = 5 cm`、`∠A = 70°`：

1. 画 `AB = 7 cm`。
2. 在 `A` 画 70° 的射线，量取 `AD = 5 cm`。
3. 以 `B` 为端点，画与 `AD` 平行的射线。
4. 以 `D` 为端点，画与 `AB` 平行的射线。
5. 交点为 `C`。

检查 `∠B + ∠A = 180°`，并确认对角相等。

## 六、用圆规复制边长

平行四边形的对边相等。若需要复制 `AD` 的长度到从 `B` 出发的边上：

1. 用圆规量取 `AD` 的长度。
2. 保持开口不变，以 `B` 为圆心画弧。
3. 弧与过 `B` 的平行线交点标为 `C`。
4. 这样可以保证 `BC = AD`。

圆规开口改变会使相等边失去准确性。

## 七、用对角线画平行四边形

平行四边形的两条对角线互相平分。已知两条对角线及其交点时，可以按以下步骤作图：

1. 标出对角线交点 `O`。
2. 在一条直线上取 `A`、`C`，使 `OA = OC`。
3. 在另一条直线上取 `B`、`D`，使 `OB = OD`。
4. 依次连接 `A-B-C-D-A`。

由于两条对角线互相平分，所得四边形是平行四边形。

## 八、画菱形：用相等半径

已知菱形边长为 5 cm，可先画一条边，再用相同半径确定另外两个顶点：

1. 画 `AB = 5 cm`。
2. 以 `A` 为圆心、5 cm 为半径画弧。
3. 以 `B` 为圆心、5 cm 为半径画弧，确定一个顶点 `D`。
4. 选择图形另一侧的相应交点 `C`，使 `BC = CD = 5 cm`。
5. 连接四个顶点。

更稳定的方法是先画相邻两边和夹角，再用平行线闭合图形。

## 九、画菱形：已知两条对角线

菱形的两条对角线互相垂直，并且互相平分。已知对角线长度时：

1. 画较长对角线 `AC`，标出中点 `O`。
2. 过 `O` 画 `AC` 的垂线。
3. 在垂线上取 `OB = OD`，使 `BD` 达到指定长度。
4. 连接 `A-B-C-D-A`。

检查 `OA = OC`、`OB = OD`，以及相邻四边是否相等。

## 十、画菱形：已知一边和一个角

已知菱形边长为 6 cm，内角为 50°：

1. 画 `AB = 6 cm`。
2. 在 `A` 处画 50° 的射线，量取 `AD = 6 cm`。
3. 过 `B` 画与 `AD` 平行的线。
4. 过 `D` 画与 `AB` 平行的线。
5. 交点为 `C`。

四条边都等于 6 cm，且 `∠A = ∠C = 50°`，相邻角为 130°。

## 十一、画正方形

正方形既是平行四边形又是菱形。已知边长时：

1. 画 `AB`。
2. 在 `A`、`B` 处分别作与 `AB` 垂直的线。
3. 在两条垂线上量取与 `AB` 相等的长度，标出 `D`、`C`。
4. 连接 `C`、`D`。

检查四边相等、四个角为 90°。

## 十二、画长方形

已知长和宽时：

1. 画长边 `AB`。
2. 在 `A`、`B` 处作垂线。
3. 分别量取宽，标出 `D`、`C`。
4. 连接 `C`、`D`。

长方形的对边相等且平行，四角都是直角。

## 十三、判断作图是否为平行四边形

完成后检查：

```text
AB 是否平行于 CD
AD 是否平行于 BC
AB 是否等于 CD
AD 是否等于 BC
对角是否相等
```

满足两组对边分别平行即可判定为平行四边形；边长和角度可作为进一步检查。

## 十四、判断作图是否为菱形

菱形的检查重点是：

```text
四条边是否相等
两组对边是否平行
对角线是否互相垂直并平分
对角是否相等
```

只画出“看起来像菱形”的图形还不够，至少要用直尺或圆规检查边长。

## 十五、平行四边形与菱形的作图关系

先画平行四边形，再增加条件可以得到菱形：

```text
平行四边形 + 四边相等 = 菱形
平行四边形 + 四个直角 = 长方形
菱形 + 四个直角 = 正方形
```

这说明不同图形的作图步骤可以共享，区别在于最后要满足的额外条件。

## 十六、用角度检查平行线

如果一条截线分别与两条直线相交，可以比较同位角或内错角：

```text
内错角相等 → 两条直线可能平行
同旁内角和为 180° → 两条直线可能平行
```

实际作图中优先使用三角尺或平行线工具保证平行，再用角度关系进行验证。

## 十七、作图中的顶点命名

四边形应按边界顺序命名：

```text
A → B → C → D → A
```

在平行四边形 `ABCD` 中，`AB` 与 `CD` 是对边，`AB` 与 `BC` 是相邻边；对角是 `∠A` 与 `∠C`。

## 十八、综合作图例题

画一个菱形 `ABCD`，边长 5 cm，`∠A = 60°`。

1. 画 `AB = 5 cm`。
2. 在 `A` 处画 60° 的射线。
3. 在射线上量取 `AD = 5 cm`。
4. 过 `B` 画 `AD` 的平行线。
5. 过 `D` 画 `AB` 的平行线，交点为 `C`。
6. 检查 `AB = BC = CD = DA = 5 cm`。
7. 计算另外三个角：对角为 60°，两个相邻角为 120°。

## 十九、常见错误

### 1. 平行线没有真正平行

画线时要用三角尺、直尺或平行线工具，不要只凭目测。

### 2. 把相邻边误当成对边

平行四边形中 `AB` 与 `CD`、`AD` 与 `BC` 才是两组对边。

### 3. 菱形只保证两边相等

菱形必须四边相等；画完要检查四条边，而不是只检查一组对边。

### 4. 量角器刻度读反

让 0°刻度与起始边对应，再读取递增的刻度圈。

### 5. 忘记闭合图形

四个顶点要按顺序连接，不能出现交叉边或漏连边。

## 二十、小结

```text
平行四边形作图：先画一组相邻边，再用平行线闭合
菱形作图：四边相等，可用圆规复制长度或用对角线性质
正方形：四边相等且四角为90°
作图后检查：平行、相等、角度、对角线和顶点顺序
```

画平行四边形与菱形的关键是准确保持平行和相等关系；完成后必须用测量和图形性质验证，而不能只凭外观判断。
