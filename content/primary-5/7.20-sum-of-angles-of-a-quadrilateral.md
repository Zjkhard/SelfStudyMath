# 四边形内角和

四边形是由四条线段首尾相连组成的图形，有四个顶点、四条边和四个内角。任意四边形的四个内角和都是 360°。

## 一、认识四边形的内角

四边形通常用四个大写字母按顺序命名，例如 `四边形ABCD`。

```text
四个顶点：A、B、C、D
四条边：AB、BC、CD、DA
四个内角：∠A、∠B、∠C、∠D
```

命名时要沿着图形边界依次读顶点，不能跳过一个顶点或改变顺序。

## 二、四边形内角和定理

任意四边形的四个内角之和是 360°：

```text
∠A + ∠B + ∠C + ∠D = 360°
```

图形可以是长方形、梯形、平行四边形，也可以是不规则四边形，内角和都相同。

## 三、用对角线分割四边形

从四边形的一个顶点画一条对角线，可以把四边形分成两个三角形。

```text
两个三角形的内角和 = 180° + 180° = 360°
所以四边形内角和 = 360°
```

这说明四边形内角和来自三角形内角和，而不是由边长或图形大小决定。

## 四、已知三个角求第四个角

知道四边形的三个内角时，第四个角等于 360° 减去已知三个角的和。

```text
∠A = 80°，∠B = 95°，∠C = 110°
∠D = 360° − 80° − 95° − 110° = 75°
```

检验：`80° + 95° + 110° + 75° = 360°`。

## 五、已知两个角求另外两个角

如果两个未知角之间还有相等关系，可以先利用关系再使用内角和。

```text
∠A = 70°，∠B = 110°，∠C = ∠D
∠C + ∠D = 360° − 70° − 110° = 180°
∠C = ∠D = 90°
```

没有额外关系时，只知道两个角通常不能唯一确定另外两个角。

## 六、长方形的内角

长方形的四个角都是直角：

```text
∠A = ∠B = ∠C = ∠D = 90°
```

内角和为 `90° × 4 = 360°`。遇到长方形，可以直接使用直角性质，不必每次重新计算。

## 七、正方形的内角

正方形既是长方形，也是特殊的平行四边形。它的四个角都是 90°，四条边相等。

```text
正方形每个内角 = 90°
```

正方形的对角线还会把角分成两个 45°角，这在综合题中很有用。

## 八、平行四边形的角

平行四边形的对角相等，相邻角互补：

```text
∠A = ∠C
∠B = ∠D
∠A + ∠B = 180°
```

例如一个角是 65°，相邻角是 `180° − 65° = 115°`，对角仍是 65°。

## 九、菱形的角

菱形四条边相等，因此它也是平行四边形，具有平行四边形的角性质：

```text
对角相等
相邻角的和为 180°
四个内角和为 360°
```

菱形的对角线还可以把对角平分，但求内角和时仍使用 360°。

## 十、梯形的角

梯形至少有一组对边平行。沿同一条腰的两个内角是同旁内角，和为 180°。

```text
∠A + ∠D = 180°
∠B + ∠C = 180°
```

具体对应关系取决于图形中哪两条边平行，应先找出平行边和两条腰。

## 十一、等腰梯形的角

等腰梯形的两条腰相等，靠近同一底边的两个底角相等。

```text
∠A = ∠B
∠C = ∠D
```

再结合梯形的相邻角互补，可以求出全部四个内角。

## 十二、凹四边形

大多数四边形向外凸出，称为凸四边形；如果有一个角向内凹入，称为凹四边形。

凹四边形的一个内角大于 180°，但四个内角的和仍是 360°。画对角线时，应注意对角线可能落在图形外部，不能直接照搬凸四边形的内部观察方式。

## 十三、用对角线求未知角

在四边形中画对角线后，利用两个三角形的内角和，可以分步求角。

```text
四边形ABCD中，AC为对角线
∠BAC + ∠BCA + ∠ABC = 180°
∠CAD + ∠ACD + ∠CDA = 180°
```

把两组三角形关系合并，就能得到四边形的 360°关系。

## 十四、外角与内角

四边形的一条边延长后，外角与相邻内角组成平角：

```text
外角 + 相邻内角 = 180°
```

逐个取四个外角时，外角总和也为 360°。解题时要确认外角的取向，避免把不相邻的角混在一起。

## 十五、正多边形中的四边形

正方形是边和角都相等的四边形。因为四个内角相等：

```text
每个内角 = 360° ÷ 4 = 90°
```

这个“内角和除以角的个数”方法也能帮助理解其他规则图形，但本阶段重点仍是四边形。

## 十六、判断四个角能否组成四边形

四个角要作为一个四边形的内角，必须满足：

1. 每个角大于 0°且小于 360°。
2. 四个角的和等于 360°。
3. 图形还要能由四条边首尾相连形成。

例如 `80°、90°、100°、90°` 的和是 360°，角度条件满足；若和为 400°，则不能作为同一四边形的四个内角。

## 十七、解题步骤

1. 按顶点顺序找出四个内角。
2. 识别直角、平行线、相等角或对角线等条件。
3. 写出四边形内角和为 360°，或先分成两个三角形。
4. 计算已知角的总和，再求未知角。
5. 用相邻角互补、对角相等或重新相加进行检查。

## 十八、综合例题

一个平行四边形的一个角是 72°。求另外三个角。

```text
对角 = 72°
两个相邻角 = 180° − 72° = 108°
```

因此四个角依次可以是 `72°、108°、72°、108°`，总和为 360°。

## 十九、常见错误

### 1. 把四边形内角和写成 180°

180°是三角形内角和；四边形应分成两个三角形，所以是 360°。

### 2. 漏掉一个内角

列式前按顶点顺序检查 A、B、C、D 四个角，不能只计算图上明显的三个角。

### 3. 混淆对角和相邻角

平行四边形中对角相等，相邻角互补，二者不能互换。

### 4. 只凭外观判断平行或相等

只有题目标记或已知条件才能说明边平行、边相等或角相等。

### 5. 把外角当成内角

延长边形成的角要先用平角关系转换，不能直接加入四边形内角和。

## 二十、小结

```text
四边形内角和 = 360°
四边形可由一条对角线分成两个三角形
长方形、正方形每个角 = 90°
平行四边形对角相等、相邻角互补
梯形同一条腰两端的内角和为 180°
```

求四边形中的未知角时，先识别特殊四边形的性质，再使用 360°内角和；必要时画对角线，把问题转化为两个三角形的问题。
