# 异分母分数加法与减法

同分母分数加减时，分数单位相同，可以直接合并或分离分子：

~~~text
3/8 + 2/8 = 5/8
~~~

异分母分数的分数单位不同。例如 1/2 和 1/3，二分之一与三分之一不是同样大小的部分，不能直接把分子相加。

本单元学习先把分数改写成相同分母的等值分数，再进行加法或减法。

## 一、分母表示分数单位

在分数中：

~~~text
分母表示每一份的大小
分子表示有这样的几份
~~~

例如：

~~~text
3/5 = 3 个 1/5
~~~

要把两个分数相加或相减，就要先让它们使用相同的分数单位。

## 二、为什么异分母不能直接相加

看：

~~~text
1/2 + 1/3
~~~

1/2 是一个二分之一，1/3 是一个三分之一。它们的大小不同，不能把“1 份”和“1 份”直接当成相同单位合并。

错误写法：

~~~text
1/2 + 1/3 ≠ 2/5
~~~

2/5 的分母 5 表示把整体分成 5 份，改变了原来的分数单位。

正确做法是把 1/2 和 1/3 改写成相同分母的等值分数。

## 三、用图形统一分数单位

把同一个长方形同时按 2 份和 3 份观察，可以把它进一步分成 6 个相同的小部分：

~~~text
1/2 = 3/6
1/3 = 2/6
~~~

现在两个分数都用 1/6 作为单位：

~~~text
1/2 + 1/3
= 3/6 + 2/6
= 5/6
~~~

通分的本质，是把不同大小的分数单位改写成相同大小的分数单位。

## 四、通分的基本步骤

计算异分母分数加减时，可以按以下步骤：

1. 找出两个分母的共同倍数，选择合适的共同分母；
2. 把每个分数改写成以共同分母为分母的等值分数；
3. 对同分母分数进行加法或减法；
4. 如果结果可以约分，写成较简单的等值分数；
5. 用估算、图形或相反运算检查结果。

## 五、一个分母是另一个分母的倍数

计算：

~~~text
2/3 + 1/6
~~~

6 是 3 的倍数，所以选 6 作为共同分母：

~~~text
2/3 = 4/6
~~~

再相加：

~~~text
2/3 + 1/6
= 4/6 + 1/6
= 5/6
~~~

只需要改写分母较小的那个分数。

## 六、两个分母互质时寻找共同分母

计算：

~~~text
1/3 + 1/4
~~~

3 和 4 的最小共同倍数是 12：

~~~text
1/3 = 4/12
1/4 = 3/12
~~~

所以：

~~~text
1/3 + 1/4
= 4/12 + 3/12
= 7/12
~~~

结果 7/12 已经不能再约分。

## 七、异分母分数减法

计算：

~~~text
5/6 - 1/4
~~~

6 和 4 的最小共同倍数是 12：

~~~text
5/6 = 10/12
1/4 = 3/12
~~~

统一分数单位后再减：

~~~text
5/6 - 1/4
= 10/12 - 3/12
= 7/12
~~~

减法也必须先通分，不能直接写成 4/2。

## 八、共同分母的选择

共同分母可以是任意共同倍数，但选择较小的共同倍数，计算通常更简洁。

计算：

~~~text
3/8 + 5/12
~~~

8 和 12 的最小共同倍数是 24：

~~~text
3/8 = 9/24
5/12 = 10/24
~~~

所以：

~~~text
3/8 + 5/12 = 19/24
~~~

如果选择 48，也能得到正确结果：

~~~text
3/8 = 18/48
5/12 = 20/48
18/48 + 20/48 = 38/48 = 19/24
~~~

选择 24 可以少做一些计算。

## 九、先约分再通分

有时通分前可以先观察是否能够约分。

计算：

~~~text
6/15 + 4/10
~~~

先把两个分数约成较简单的等值分数：

~~~text
6/15 = 2/5
4/10 = 2/5
~~~

于是：

~~~text
2/5 + 2/5 = 4/5
~~~

先约分不会改变分数大小，有时能使共同分母更容易找到。

## 十、通分后结果需要约分

计算：

~~~text
1/6 + 1/4
~~~

共同分母取 12：

~~~text
1/6 = 2/12
1/4 = 3/12
2/12 + 3/12 = 5/12
~~~

这个结果不能再约分。

再看：

~~~text
1/6 + 1/3
= 2/6 + 1/6
= 3/6
= 1/2
~~~

加减完成后，要检查分子和分母是否有共同因数。

## 十一、异分母分数加法的图形检查

计算：

~~~text
1/2 + 1/4
~~~

把 1/2 改成 2/4：

~~~text
1/2 + 1/4
= 2/4 + 1/4
= 3/4
~~~

图形上，半个整体和四分之一合起来是四分之三，结果应大于 1/2 且小于 1，这与 3/4 相符。

## 十二、异分母分数减法的数轴检查

计算：

~~~text
7/8 - 1/3
~~~

8 和 3 的共同分母取 24：

~~~text
7/8 = 21/24
1/3 = 8/24
21/24 - 8/24 = 13/24
~~~

1/3 大约是 0.33，7/8 大约是 0.88，差大约是 0.55；13/24 大约是 0.54，结果大小合理。

## 十三、加法的交换顺序

分数加法也满足交换律：

~~~text
a/b + c/d = c/d + a/b
~~~

例如：

~~~text
1/3 + 1/4
= 4/12 + 3/12
= 7/12
~~~

交换顺序：

~~~text
1/4 + 1/3
= 3/12 + 4/12
= 7/12
~~~

交换加数不会改变和，但通分过程可能不同。

## 十四、减法不能随意交换

分数减法不满足交换律：

~~~text
5/6 - 1/4 = 7/12
1/4 - 5/6 = -7/12
~~~

在本单元主要处理结果为非负的分数减法。被减数应不小于减数，通分后分子相减才表示剩余的分数单位。

## 十五、连续的异分母分数加法

计算：

~~~text
1/2 + 1/3 + 1/6
~~~

共同分母取 6：

~~~text
1/2 = 3/6
1/3 = 2/6
1/6 = 1/6
~~~

所以：

~~~text
1/2 + 1/3 + 1/6
= 3/6 + 2/6 + 1/6
= 6/6
= 1
~~~

三个分数单位统一后，可以一起合并。

## 十六、连续的异分母分数减法

计算：

~~~text
11/12 - 1/3 - 1/4
~~~

分母 12、3、4 的共同分母就是 12：

~~~text
1/3 = 4/12
1/4 = 3/12
~~~

因此：

~~~text
11/12 - 1/3 - 1/4
= 11/12 - 4/12 - 3/12
= 7/12 - 3/12
= 4/12
= 1/3
~~~

连续减法仍然按从左到右进行。

## 十七、异分母分数和整数相加

整数可以写成分母为 1 的分数。

计算：

~~~text
2 + 3/4
~~~

整数部分和分数部分表示不同的数量单位，可以先保留整数，再写成带分数：

~~~text
2 + 3/4 = 2 3/4
~~~

也可以把 2 写成 8/4：

~~~text
2 = 8/4
8/4 + 3/4 = 11/4
~~~

带分数的系统加减将在下一单元继续学习。

## 十八、结果大于 1 的异分母加法

计算：

~~~text
5/6 + 3/4
~~~

共同分母取 12：

~~~text
5/6 = 10/12
3/4 = 9/12
~~~

相加得到：

~~~text
10/12 + 9/12 = 19/12
~~~

结果是大于 1 的假分数。它可以继续写成带分数：

~~~text
19/12 = 1 7/12
~~~

这里的带分数转换只是表示结果，带分数加减的完整方法在下一单元学习。

## 十九、用除法理解分母变化

分母相同后，分数加减可以直接合并分子，是因为它们都使用同一个分数单位。

例如：

~~~text
4/15 + 7/15 = 11/15
~~~

这相当于把 4 个十五分之一和 7 个十五分之一合并。

异分母通分，就是先把不同的分数单位都换成相同的单位，再使用同分母加减。

## 二十、用相反运算检查

计算：

~~~text
7/10 - 1/4
~~~

共同分母 20：

~~~text
7/10 = 14/20
1/4 = 5/20
14/20 - 5/20 = 9/20
~~~

用加法检查：

~~~text
9/20 + 5/20 = 14/20 = 7/10
~~~

结果加回减数后回到被减数，说明计算关系相符。

## 二十一、用估算检查结果

计算：

~~~text
7/8 - 2/5
~~~

7/8 接近 1，2/5 接近 1/2，差大约接近 1/2。

准确计算：

~~~text
7/8 = 35/40
2/5 = 16/40
35/40 - 16/40 = 19/40
~~~

19/40 接近 1/2，结果大小合理。

## 二十二、用情境理解异分母加法

一条绳子上午用去全长的 1/3，下午用去全长的 1/4。全天用去全长的几分之几？

两个分数都以整条绳子为整体：

~~~text
1/3 + 1/4
= 4/12 + 3/12
= 7/12
~~~

答：全天用去全长的 7/12。

这里先通分，是因为上午和下午的分数单位不同。

## 二十三、用情境理解异分母减法

一桶水原有全桶的 5/6，用去全桶的 1/4，还剩全桶的几分之几？

~~~text
5/6 - 1/4
= 10/12 - 3/12
= 7/12
~~~

答：还剩全桶的 7/12。

被减数和减数都以同一桶水为整体，结果可以直接比较。

## 二十四、容易混淆的地方

### 1. 直接把分子和分母分别相加

~~~text
1/2 + 1/3 ≠ 2/5
~~~

必须先通分。

### 2. 通分时只改变分母

~~~text
1/3 ≠ 1/12
~~~

要保持分数大小，分子和分母必须同时乘相同的数。

### 3. 通分后忘记约分

~~~text
3/6 = 1/2
~~~

结果应尽量写成较简单的等值分数。

### 4. 减法顺序写反

分数减法要保持被减数和减数的顺序，不能像加法一样交换。

### 5. 忘记检查整体是否相同

两个分数只有在表示同一个单位整体时，才能直接进行加减比较。

### 6. 结果大小不合理

正分数相加的结果应不小于每一个加数；从较大分数中减去较小分数，结果应不大于被减数。

## 二十五、小结

- 异分母分数的分数单位不同，不能直接相加或相减。
- 计算前要找共同分母，把分数改写成等值的同分母分数。
- 通分后只加减分子，分母保持不变。
- 计算完成后要约分，并注意结果是否可能大于 1。
- 分数加法可以交换顺序，分数减法不能随意交换。
- 图形、数轴、估算和相反运算都可以帮助检查结果。
- 异分母分数加减的核心是“先统一分数单位，再合并或分离”。
