# 小数加法与减法

小数加法表示把数量合并，小数减法表示从一个数量中取走一部分或比较两个数量的差。

计算小数加减法时，最重要的是让相同数位对齐，也就是让小数点对齐。

## 一、小数点对齐

计算 2.34+1.25：

~~~text
  2.34
+ 1.25
-------
  3.59
~~~

十分位对十分位，百分位对百分位，个位对个位。

## 二、按位值相加

把 2.34 和 1.25 分解：

~~~text
2.34 = 2 + 3/10 + 4/100
1.25 = 1 + 2/10 + 5/100
~~~

相加：

~~~text
(2+1) + (3/10+2/10) + (4/100+5/100)
= 3 + 5/10 + 9/100
= 3.59
~~~

竖式对齐的本质就是相同位值相加。

## 三、小数位数相同的加法

计算 6.47+2.38：

~~~text
  6.47
+ 2.38
-------
  8.85
~~~

百分位 7+8=15，写 5 并向十分位进 1；十分位 4+3+1=8。

## 四、出现进位

计算 3.68+2.57：

~~~text
  3.68
+ 2.57
-------
  6.25
~~~

百分位 8+7=15，向十分位进 1；十分位 6+5+1=12，再向个位进 1。

## 五、整数与小数相加

整数可以在小数点后补 0：

~~~text
  7.00
+ 2.46
-------
  9.46
~~~

所以 7+2.46=9.46。补 0 是为了让小数点和相同位值对齐。

## 六、小数位数不同的加法

计算 4.5+2.37：

先写成 4.50：

~~~text
  4.50
+ 2.37
-------
  6.87
~~~

末尾补 0 不改变 4.5 的数值。

## 七、三项小数相加

计算 1.25+3.4+0.875：

补齐位数：

~~~text
1.250 + 3.400 + 0.875 = 5.525
~~~

也可以先算 1.25+3.4=4.65，再加 0.875 得 5.525。

## 八、小数减法的位值意义

计算 5.86-2.34：

~~~text
  5.86
- 2.34
-------
  3.52
~~~

个位、十分位和百分位分别相减。

## 九、需要退位的减法

计算 7.42-3.68：

~~~text
  7.42
- 3.68
-------
  3.74
~~~

百分位 2 不够减 8，从十分位借 1 个十分之一，变成 12 个百分之一；十分位因此少 1。

## 十、连续退位

计算 5.00-2.76：

~~~text
  5.00
- 2.76
-------
  2.24
~~~

百分位和十分位都需要借位，要从个位逐级借出：5 个一变成 4 个一、10 个十分之一，再把 1 个十分之一换成 10 个百分之一。

## 十一、被减数小数位不足

计算 8.3-2.47：

把 8.3 写成 8.30：

~~~text
  8.30
- 2.47
-------
  5.83
~~~

## 十二、减去整数

计算 6.72-4：

~~~text
  6.72
- 4.00
-------
  2.72
~~~

整数写成带小数点的形式，便于对齐个位。

## 十三、从整数中减小数

计算 10-3.86：

~~~text
 10.00
-  3.86
--------
  6.14
~~~

10.00 补出了十分位和百分位的 0，退位后结果为 6.14。

## 十四、小数加法的交换律

加法交换律仍然成立：

~~~text
2.4 + 1.75 = 1.75 + 2.4 = 4.15
~~~

改变加数顺序不会改变和，可以把容易凑整的数放在一起。

## 十五、小数加法的结合律

计算 1.25+0.75+3.6：

~~~text
(1.25 + 0.75) + 3.6
= 2 + 3.6
= 5.6
~~~

先把 1.25 和 0.75 凑成整数，计算更简便。

## 十六、凑整计算

计算 4.98+2.37：

可以把 4.98 看成 5-0.02：

~~~text
4.98 + 2.37
= 5 + 2.37 - 0.02
= 7.35
~~~

凑整时要记得补回或减去调整的数量。

## 十七、减法的逆运算验算

计算 9.2-4.75=4.45。用差加减数验算：

~~~text
4.45 + 4.75 = 9.20
~~~

结果回到被减数，说明计算正确。

## 十八、加法的逆运算验算

计算 3.68+2.47=6.15。用和减去一个加数：

~~~text
6.15 - 2.47 = 3.68
~~~

## 十九、用估算检查和

估计 19.8+6.2：

~~~text
19.8 ≈ 20，6.2 ≈ 6
20 + 6 = 26
~~~

精确和为 26，和估算相符。

## 二十、用估算检查差

估计 50.3-18.7：

~~~text
50.3 ≈ 50，18.7 ≈ 19
50 - 19 = 31
~~~

精确差为 31.6，接近 31，说明结果大小合理。

## 二十一、长度单位中的小数加法

一根木条长 2.35 米，另一根长 1.8 米，两根共长多少米？

~~~text
2.35 + 1.80 = 4.15（米）
~~~

两根共长 4.15 米。

## 二十二、长度单位中的小数减法

一条绳长 5 米，剪去 1.75 米，还剩多少米？

~~~text
5.00 - 1.75 = 3.25（米）
~~~

## 二十三、货币中的小数加法

一本书 12.50 元，一支笔 3.80 元，一共花费：

~~~text
12.50 + 3.80 = 16.30（元）
~~~

货币通常保留两位小数，末尾 0 不能随意删去其表示的金额位数。

## 二十四、找零问题

付 50 元购买 18.75 元和12.40元的物品：

总价：

~~~text
18.75 + 12.40 = 31.15（元）
~~~

找零：

~~~text
50.00 - 31.15 = 18.85（元）
~~~

## 二十五、质量和容量

一袋米重 2.5 千克，另一袋重 1.75 千克，总重：

~~~text
2.50 + 1.75 = 4.25（千克）
~~~

一桶水有 8 升，用去 2.65 升，剩余：

~~~text
8.00 - 2.65 = 5.35（升）
~~~

## 二十六、单位不同先换算

一条绳长 2 米 35 厘米，另一条长 1.8 米，求总长（米）。

先把 2 米 35 厘米写成 2.35 米：

~~~text
2.35 + 1.8 = 4.15（米）
~~~

## 二十七、多步小数加减应用题

一辆车上午行驶 18.6 千米，下午行驶 24.75 千米，晚上又行驶 6.4 千米。全天行驶多少千米？

~~~text
18.60 + 24.75 + 6.40 = 49.75（千米）
~~~

## 二十八、先加后减

水箱原有 25 升，上午加入 4.5 升，下午用去 8.75 升，现在有多少升？

~~~text
25.00 + 4.50 - 8.75 = 20.75（升）
~~~

按事件顺序计算，也可以先求加入后的总量再减去用去量。

## 二十九、比较两个小数的差

甲绳长 6.25 米，乙绳长 4.8 米，甲比乙长多少米？

~~~text
6.25 - 4.80 = 1.45（米）
~~~

“比……多多少”或“相差多少”通常使用减法。

## 三十、常见错误

### 1. 小数点没有对齐

2.5+1.37 应写成 2.50+1.37，不能把 5 和 3 对齐。

### 2. 忘记补占位 0

整数和小数相加减时，可以写成 7.00、4.00 以保证位值对齐。

### 3. 退位后忘记减少上一位

从十分位借出 1 个十分之一后，个位或更高位要相应减少 1。

### 4. 单位不统一

2 米和 35 厘米不能直接按 2+35 计算，应先换成同一种单位。

### 5. 结果没有估算检查

加法结果应不小于每个加数；减法结果应小于被减数（减数为正时）。

## 三十一、小数加减法的解题步骤

1. 看清题意和单位。
2. 统一长度、质量、容量或货币单位。
3. 把小数点对齐，必要时补末尾 0。
4. 按整数加减法进行进位或退位。
5. 在答案中保留正确的小数点和单位。
6. 用估算或逆运算检查结果。

## 三十二、小结

小数加减法的核心是：

~~~text
小数点对齐 = 相同数位对齐
~~~

计算时可以补占位 0，按照整数加减法处理进位和退位。解决实际问题时，要先统一单位，最后写出单位，并用估算、逆运算和数量关系检查答案是否合理。
