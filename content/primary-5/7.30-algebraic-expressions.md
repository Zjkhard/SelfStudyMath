# 代数式

代数式用数字、字母和运算符号表示数量关系。字母可以代表一个未知数，也可以代表一类会变化的数量。使用代数式能简洁地表示许多相同结构的问题。

## 一、用字母表示数量

当一个数量会变化或还不知道时，可以用字母表示：

```text
小明有 x 本书
每本 6 元的书买 n 本
```

字母可以取不同的数值，但在同一个问题中要明确它代表什么。

## 二、从语言写出代数式

把文字中的数量关系翻译成运算：

```text
x 加 5：x + 5
x 减 3：x − 3
x 的 4 倍：4x
x 除以 2：x ÷ 2 或 x/2
```

“4x”表示 `4 × x`，数字和字母相乘时通常省略乘号。

## 三、代数式的组成

代数式 `3x + 7` 包含：

```text
3x：一项，3 是系数，x 是字母
+7：常数项
```

加号或减号把不同的项分开。`5a − 2b + 4` 有三项：`5a`、`−2b` 和 `4`。

## 四、系数与常数

系数是字母前面的数，常数是不含字母的数。

```text
7y：系数是 7
−x：系数是 −1
z：系数是 1
12：常数项是 12
```

书写 `x` 时，前面的 1 通常省略；`−x` 中的负号表示系数为 −1。

## 五、代数式中的乘号

以下写法表示相乘：

```text
3 × a = 3a
a × b = ab
m × 5 = 5m
```

数字与字母相乘时数字写在前面；字母与字母相乘时可以连写，但不能把两个字母误读成两位数。

## 六、代入数值求代数式的值

把字母换成已知数，再按照运算顺序计算。

例如 `3x + 2` 中 `x = 5`：

```text
3x + 2 = 3 × 5 + 2 = 17
```

代入时要保留乘号的意义，不能把 `3x` 当成 35。

## 七、代入负数或带括号的数

当代入的数是负数时，最好用括号表示：

```text
x − 4，x = −2
= (−2) − 4 = −6
```

括号可以避免把负号和减号混淆。

## 八、代数式的运算顺序

代数式仍遵循先乘除、后加减，有括号先算括号。

```text
2x + 3，x = 4
= 2 × 4 + 3
= 11
```

```text
5(a + 2)，a = 3
= 5 × (3 + 2)
= 25
```

## 九、同类项

字母部分完全相同的项叫同类项：

```text
3x 和 5x 是同类项
2a 和 −7a 是同类项
4x 和 4y 不是同类项
x 和 x² 不是同类项
```

同类项的字母和指数相同，系数可以不同。

## 十、合并同类项

同类项可以把系数相加或相减，字母部分保持不变：

```text
3x + 5x = 8x
9a − 4a = 5a
```

不能把不同字母的项合并：

```text
3x + 2y 不能写成 5xy 或 5x
```

## 十一、含常数项的化简

先合并同类字母项，再合并常数项：

```text
4x + 3 + 2x + 5
= 6x + 8
```

化简时不改变原代数式的值，只是用更简洁的形式表示。

## 十二、括号的简单展开

利用乘法分配律：

```text
3(x + 4) = 3x + 12
5(a − 2) = 5a − 10
```

五年级阶段可先理解“每一项都乘以括号外的数”，并特别注意减号后的符号。

## 十三、提取公因数

合并同类项的逆过程是提取公因数：

```text
6x + 12 = 6(x + 2)
```

括号外的 6 同时乘括号内的每一项，展开后应回到原式。

## 十四、用代数式表示周长

长方形长为 `l`、宽为 `w`：

```text
周长 = l + w + l + w = 2l + 2w
```

若长为 `x + 3`、宽为 `x`：

```text
周长 = 2(x + 3) + 2x = 4x + 6
```

字母表示长度时，最后代入实际数值并写上长度单位。

## 十五、用代数式表示面积

长方形长为 `a`、宽为 `b`：

```text
面积 = ab
```

正方形边长为 `s`：

```text
面积 = s × s = s²
```

` s² `表示 `s × s`，不要把它读成 `2s`。

## 十六、用代数式表示总价

单价为 `p` 元，购买 `n` 件：

```text
总价 = pn 元
```

若每件 8 元，购买 `n` 件：

```text
总价 = 8n 元
```

代入 `n = 6` 得 `8 × 6 = 48 元`。

## 十七、用代数式表示率关系

速度为 `v km/h`，行驶 `t h`：

```text
路程 = vt km
```

单价为 `p 元/本`，买 `n 本`：

```text
总价 = pn 元
```

率的单位与数量相乘后，应得到目标总量的单位。

## 十八、连续整数的表示

如果一个数用 `n` 表示：

```text
下一个数：n + 1
上一个数：n − 1
连续三个数：n − 1、n、n + 1
```

偶数可以表示为 `2n`，相邻的偶数可表示为 `2n` 和 `2n + 2`。这里的 `n` 通常表示整数。

## 十九、等量关系

同一个数量可以用两个代数式表示，它们之间用等号连接：

```text
总数 = 男生人数 + 女生人数
T = b + g
```

等号表示左右两边相等，不是“答案写在右边”的箭头。

## 二十、用代数式解决简单问题

一个长方形长比宽多 3 cm，宽为 `x cm`：

```text
长 = x + 3 cm
周长 = 2(x + 3) + 2x = 4x + 6 cm
```

若 `x = 5`，周长为 `4 × 5 + 6 = 26 cm`。

## 二十一、代数式的值随字母变化

在 `2x + 1` 中：

```text
x = 2 时，值为 5
x = 5 时，值为 11
```

字母变化时，代数式的值也可能变化。可以用表格记录：

| x | 0 | 1 | 2 | 3 |
| --- | ---: | ---: | ---: | ---: |
| 2x + 1 | 1 | 3 | 5 | 7 |

## 二十二、判断代数式是否等价

如果两个代数式对所有允许的字母值都给出相同结果，它们是等价的。

```text
2(x + 3) 和 2x + 6 等价
```

可以用分配律证明，也可以代入几个数值进行检查；代入检查只能提供证据，不能代替一般化的理由。

## 二十三、综合例题

一个班有 `x` 名女生，男生人数比女生多 4 人。求全班人数的代数式，并在 `x = 18` 时求人数。

```text
男生人数 = x + 4
全班人数 = x + (x + 4) = 2x + 4
x = 18 时：2 × 18 + 4 = 40 人
```

## 二十四、常见错误

### 1. 把字母和数字连读成两位数

`3x` 表示 `3 × x`，不是数字 3x。

### 2. 忘记括号中的整体

代入负数或代入到括号内时，使用括号能避免符号错误。

### 3. 合并不同类的项

`3x + 2y` 不能合并成 `5x` 或 `5y`。

### 4. 忽略运算顺序

先算括号，再算乘除，最后算加减。

### 5. 忘记单位

代数式表示长度、面积、总价等具体量时，代入后要写正确单位。

## 二十五、小结

```text
字母可以表示未知量或变化的数量
代数式由数字、字母和运算符号组成
代入求值时遵循运算顺序
同类项可合并，字母不同的项不能直接合并
代数式可以表示周长、面积、总价、路程等数量关系
```

学习代数式时，先明确字母代表什么，再准确翻译数量关系；计算时注意括号、运算顺序、同类项和单位。
