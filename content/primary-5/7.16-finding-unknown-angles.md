# 求未知角

图形中常用字母或问号表示没有标出度数的角。已知其他角的度数和它们之间的关系，就可以利用加法、减法以及整体与部分的关系求出未知角。

## 一、认识未知角

未知角通常用 `x°`、`a°` 或 `?°` 表示。先找出整体角和已知部分角，再决定使用加法还是减法。

```text
已知一个角是 35°，另一个角与它合起来是 90°。
未知角 = 90° − 35° = 55°
```

## 二、角的和与角的差

两个或多个角拼成较大的角时，用加法表示：

```text
大角 = 小角1 + 小角2
```

已知大角和其中部分，求剩余部分时：

```text
未知角 = 大角 − 已知部分之和
```

## 三、直角中的未知角

直角是 90°。直角被分成两个或多个相邻角时，各部分的和仍是 90°。

```text
x° + 28° = 90°
x° = 90° − 28° = 62°
```

两个角的和是 90°，它们互为余角。例如 41° 的余角是 `90° − 41° = 49°`。

## 四、平角中的未知角

平角是 180°。一条直线一侧的相邻角总和为 180°。

```text
x° + 117° = 180°
x° = 180° − 117° = 63°
```

两个角的和是 180°，它们互为补角。例如 72° 的补角是 `180° − 72° = 108°`。

## 五、相邻角的关系

相邻角有共同的顶点和一条公共边，内部没有重叠。若它们组成直角：

```text
a° + b° = 90°
```

若它们组成平角：

```text
a° + b° = 180°
```

解题时观察外侧两条边组成的是直角、平角，还是题目给出的其他整体角。

## 六、三个或多个相邻角

一个直角或平角可以分成三个或更多相邻角。把同一整体内的所有角都列入算式。

```text
24° + 31° + x° = 90°
x° = 90° − 24° − 31° = 35°
```

```text
48° + x° + 67° = 180°
x° = 180° − 48° − 67° = 65°
```

## 七、先求整体角，再求未知角

如果未知角属于一个已知的大角，可以连续减去已知部分：

```text
大角是 125°，已知部分为 46° 和 32°。
x° = 125° − 46° − 32° = 47°
```

也可以先求已知部分的和：`46° + 32° = 78°`，再计算 `125° − 78° = 47°`。

## 八、公共边形成的角

几条射线从同一个顶点出发时，相邻小角可以拼成较大的角。

```text
∠AOC = ∠AOB + ∠BOC
```

若 `∠AOC = 96°`、`∠AOB = 38°`，则 `∠BOC = 96° − 38° = 58°`。先写角的组成关系，能减少看图时认错角的机会。

## 九、同一个顶点周围的角

围绕一个点转一整圈是 360°。只有当所列角正好围绕顶点一周且没有遗漏时，才能使用 360°。

```text
82° + 105° + x° + 73° = 360°
x° = 360° − 82° − 105° − 73° = 100°
```

## 十、对顶角相等

两条直线相交时，互相相对的角叫对顶角，对顶角相等。

```text
一个角是 64°，它的对顶角也是 64°。
相邻角 = 180° − 64° = 116°
```

遇到交叉直线，可先找对顶角，再利用平角关系求其他角。

## 十一、利用相等标记

图中相同的弧线或文字标记表示角相等。例如 `∠A = ∠B` 且 `∠A = 52°`，所以 `∠B = 52°`。

若两个相等角组成平角：

```text
x° + x° = 180°
```

可先把两个相等角看作两份，再求每份的度数。

## 十二、从图形标记读取条件

```text
小方框：表示直角，即 90°
相同弧线：表示角相等
两条边在同一直线上：提示组成平角，即 180°
同一顶点的一周：可能使用 360°
```

这些标记都是已知条件，应和题目给出的数字一起使用。

## 十三、估测与计算互相检查

可以先估计未知角是锐角、直角还是钝角，再计算。若计算结果为 58°，图形应大致接近 60°，而不是接近 120°。图形不按比例时，以已知关系和计算结果为准。

## 十四、求未知角的步骤

1. 找出未知角所在的整体角。
2. 判断整体角是 90°、180°、360°，还是题目给出的其他角。
3. 写出整体等于各部分之和的关系。
4. 计算已知角的总和，再求未知角。
5. 写上 `°`，并检查答案的角度范围。

## 十五、角度范围检查

```text
锐角：0° < 角 < 90°
直角：角 = 90°
钝角：90° < 角 < 180°
平角：角 = 180°
周角：角 = 360°
```

如果图中未知角明显是锐角，计算却得到 132°，应检查整体角、减法顺序和是否漏掉了已知角。

## 十六、综合例题

一条直线的一侧有三个相邻角，分别为 35°、`x°` 和 68°。求 `x`。

```text
35° + x° + 68° = 180°
x° = 180° − 35° − 68°
x° = 77°
```

检验：`35° + 77° + 68° = 180°`，所以未知角是 77°，属于锐角。

## 十七、常见错误

### 1. 随意把整体角看成 90°或180°

只有出现直角标记或两条边形成直线时，才能使用对应的整体角。

### 2. 漏掉一个相邻角

列式前沿着整体角逐个检查小角，确保每一部分都被计算。

### 3. 把减法方向写反

未知部分应等于整体减去已知部分，不能用已知部分减整体。

### 4. 忘记写度数单位

答案应写成 `64°`，而不是只写 `64`。

### 5. 只凭图形大小猜答案

图形可能不是按比例绘制，应以角的关系和计算结果为准。

## 十八、小结

```text
直角 = 90°，平角 = 180°，周角 = 360°
整体角 = 各部分角之和
未知角 = 整体角 − 已知部分之和
对顶角相等
```

求未知角的核心是先辨认整体关系，再用加法或减法列式，最后用角的分类和总和关系检查答案。
