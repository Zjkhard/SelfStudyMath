# 三角形内角和

三角形是由三条线段首尾相连组成的图形。三角形内部的三个角叫作三角形的内角。无论三角形的形状和大小怎样变化，三个内角的和都是 180°。

## 一、认识三角形的内角

一个三角形有三个顶点、三条边和三个内角。通常用大写字母表示顶点，三角形写作 `△ABC`。

```text
△ABC 的三个内角是：∠A、∠B、∠C
```

内角是在三角形内部、由相邻两条边形成的角。不要把三角形外部延长线形成的角误认为内角。

## 二、三角形内角和定理

任意三角形的三个内角之和是 180°：

```text
∠A + ∠B + ∠C = 180°
```

这是求三角形中未知角的主要依据，与三角形是否倾斜、边长是否相等无关。

## 三、用剪拼观察内角和

可以把纸上的三角形三个角剪下来，再把它们的顶点拼在同一点。三个角的边会排成一条直线，形成平角。

```text
三个内角拼成平角
所以：内角和 = 180°
```

折叠、剪拼和测量都能帮助观察这个规律，但计算时应使用精确的 180°。

## 四、已知两个角求第三个角

知道三角形的两个内角时，第三个角等于 180° 减去已知两个角的和。

```text
∠A = 52°，∠B = 67°
∠C = 180° − 52° − 67° = 61°
```

检验：`52° + 67° + 61° = 180°`。

## 五、已知一个角和另一个关系

如果题目给出一个角以及另外两个角的关系，先利用关系求出部分角，再使用 180°。

```text
∠A = 40°，∠B 比 ∠C 大 20°
∠B + ∠C = 180° − 40° = 140°
```

五年级常见题目会通过图形标记或简单的数量关系给出第二步条件。

## 六、锐角三角形

锐角三角形的三个内角都小于 90°，但它们的和仍是 180°。

```text
55° + 65° + 60° = 180°
```

如果已知两个角都是锐角，求出的第三角也应大于 0°，并根据计算结果判断三角形类型。

## 七、直角三角形

直角三角形有一个直角，内角为 90°。另外两个角的和是 90°。

```text
90° + ∠B + ∠C = 180°
∠B + ∠C = 90°
```

例如一个锐角是 34°，另一个锐角为：

```text
90° − 34° = 56°
```

直角三角形中不可能有第二个直角或钝角。

## 八、钝角三角形

钝角三角形有一个大于 90°而小于 180°的内角，另外两个角必须是锐角。

```text
∠A = 112°，∠B = 28°
∠C = 180° − 112° − 28° = 40°
```

一个三角形最多只能有一个钝角，否则内角和会超过 180°。

## 九、等腰三角形中的内角

等腰三角形有两条相等的边，底边两端的两个底角相等。

```text
顶角 = 40°
两个底角和 = 180° − 40° = 140°
每个底角 = 140° ÷ 2 = 70°
```

看到两条相等边或相等角的标记时，可以先写出相等关系，再结合内角和计算。

## 十、等边三角形中的内角

等边三角形的三条边相等，三个内角也相等。

```text
每个内角 = 180° ÷ 3 = 60°
```

因此，等边三角形同时是锐角三角形。

## 十一、利用外角求内角

三角形的一条边延长后，外角与相邻的内角组成平角。

```text
外角 + 相邻内角 = 180°
```

如果外角是 125°，相邻内角为：

```text
180° − 125° = 55°
```

先用平角关系求出相邻内角，再使用三角形内角和求其他未知角。

## 十二、外角与两个不相邻内角

三角形的一个外角等于与它不相邻的两个内角之和。

```text
外角 = 远端内角1 + 远端内角2
```

例如两个远端内角是 48° 和 63°，外角为：

```text
48° + 63° = 111°
```

这个关系可以由平角和内角和共同推导，也可用来检查计算结果。

## 十三、含字母的简单关系

如果两个角相等，可以先把它们看作相同的部分。

```text
三角形的三个角为 50°、x°、x°
50° + x° + x° = 180°
两个 x° 的和 = 130°
x° = 65°
```

解题时先用语言说明“两个角相等”，再进行分配和计算。

## 十四、按图形关系列式

求未知角前，可以按以下方式标记：

```text
直角标记：一个角是 90°
相等弧线：两个角相等
相等边标记：可能提示等腰三角形
延长线：可能形成平角或外角
```

这些信息应与 `三个内角和为 180°` 一起使用。

## 十五、三角形内角和与量角器

可以用量角器分别测量三个内角，再把读数相加。由于画线和读数会有误差，总和可能接近 180°，但不一定恰好等于 180°。

计算题中使用精确关系：

```text
∠A + ∠B + ∠C = 180°
```

## 十六、判断能否组成三角形

三个给出的角要组成三角形，必须满足：

1. 三个角都大于 0°。
2. 三个角的和等于 180°。

例如 `40°、60°、80°` 可以组成三角形；`50°、70°、80°` 的和为 200°，不能作为同一个三角形的三个内角。

## 十七、解题步骤

1. 找出三角形的三个内角。
2. 读取直角、相等角或延长线等标记。
3. 写出三个内角和为 180°。
4. 先求已知角的总和，再求未知角。
5. 检查未知角是否大于 0°，并判断它属于锐角、直角还是钝角。

## 十八、综合例题

在 `△ABC` 中，`∠A = 48°`，`∠B = 2∠C`。求 `∠B` 和 `∠C`。

```text
∠A + ∠B + ∠C = 180°
48° + 2∠C + ∠C = 180°
3∠C = 132°
∠C = 44°
∠B = 88°
```

检验：`48° + 88° + 44° = 180°`。

## 十九、常见错误

### 1. 把外角当成内角

先看角的顶点和两条边是否位于三角形内部，延长线外侧形成的角通常是外角。

### 2. 只看到一个直角就忘记剩余关系

直角三角形的另外两个角之和是 90°，不是 180°。

### 3. 忘记等腰三角形的两个底角相等

出现相等边或相等角标记时，应先利用等腰关系。

### 4. 认为图形大小决定角度

图形可能不是按比例绘制，内角和关系比视觉判断更可靠。

### 5. 计算后不检查

把三个角重新相加，确认总和为 180°，并检查每个角都符合三角形的角度范围。

## 二十、小结

```text
三角形内角和 = 180°
直角三角形的两个锐角和 = 90°
等腰三角形的底角相等
等边三角形每个角 = 60°
三角形的一个外角 = 两个不相邻内角之和
```

求三角形中的未知角时，先辨认图形关系，再使用 180°内角和列式，最后用总和和角的分类进行检查。
