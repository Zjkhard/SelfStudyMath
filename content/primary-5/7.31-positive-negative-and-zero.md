# 正数、负数与零

生活中有些量可以用“增加和减少”“高于和低于”“收入和支出”来表示。正数、负数和零帮助我们记录方向相反或相对某个基准的数量。

## 一、正数

大于 0 的数叫正数。正数前面可以写“+”号，也可以省略：

```text
+5 = 5
+12 = 12
```

正数常表示增加、上升、收入、向前或高于基准等情况。

## 二、负数

小于 0 的数叫负数，前面必须写负号 `−`：

```text
−3、−8、−15
```

负数常表示减少、下降、支出、向后或低于基准等情况。

## 三、零的意义

0 既不是正数，也不是负数。它通常表示没有变化、正好达到基准或两种相反数量相互抵消。

```text
温度 0°C：在摄氏温度的基准点
账户变化 0 元：没有增加也没有减少
海拔 0 m：以规定的海平面为基准
```

## 四、整数的组成

整数包括负整数、零和正整数：

```text
……、−3、−2、−1、0、1、2、3、……
```

本单元重点讨论整数。带小数或分数的正负数将在后续学习中进一步研究。

## 五、数轴

数轴是一条标有等距刻度的直线，用来表示数的位置。

```text
←  −3  −2  −1   0   1   2   3  →
```

数轴的基本特点：

```text
0 是原点
向右数值变大
向左数值变小
相邻刻度之间的距离相等
```

## 六、在数轴上表示整数

在数轴上表示 `−4`：

1. 找到原点 0。
2. 向左移动 4 个单位。
3. 在该位置标出 `−4`。

表示 `+4` 时，从 0 向右移动 4 个单位。

## 七、用数轴比较正数

在数轴上，右边的数总比左边的数大：

```text
3 在 1 的右边，所以 3 > 1
```

正数之间的比较与以前学过的自然数比较相同。

## 八、比较负数

比较负数时，数轴上越靠右的数越大：

```text
−2 在 −5 的右边，所以 −2 > −5
```

虽然 5 比 2 大，但 `−5 < −2`。负号会改变比较关系，不能只看数字部分。

## 九、负数与零比较

任何负数都小于 0，任何正数都大于 0：

```text
−7 < 0 < 4
```

可以在数轴上看到：负数在原点左边，正数在原点右边。

## 十、相反数

只有符号不同、与 0 距离相等的两个数互为相反数。

```text
5 和 −5 互为相反数
−8 和 8 互为相反数
0 的相反数是 0
```

在数轴上，相反数关于原点对称。

## 十一、绝对值的初步认识

一个数到 0 的距离叫作这个数的绝对值，用两条竖线表示：

```text
|5| = 5
|−5| = 5
|0| = 0
```

绝对值表示距离，因此不会是负数。绝对值相等的两个数可能互为相反数，也可能是同一个数。

## 十二、生活中的正负数

| 情境 | 正数 | 负数 | 0 |
| --- | --- | --- | --- |
| 温度 | 零上 | 零下 | 冰点基准 |
| 账户 | 存入 | 支出 | 无变化 |
| 海拔 | 高于基准 | 低于基准 | 基准面 |
| 方向 | 向东或向上 | 向西或向下 | 未移动 |

使用正负号前要先说明基准和正方向。

## 十三、带正负号的温度

如果今天温度从 `−3°C` 上升 5°C：

```text
−3 + 5 = 2°C
```

如果从 `4°C` 下降 7°C：

```text
4 − 7 = −3°C
```

结果的正负表示最终温度在基准的哪一侧。

## 十四、正负数加法：同号

两个正数相加，结果为正；两个负数相加，结果为负，绝对值相加：

```text
(+3) + (+5) = +8
(−3) + (−5) = −8
```

数轴上，同号相加表示向同一方向移动。

## 十五、正负数加法：异号

一正一负相加时，先比较绝对值，用较大的绝对值减较小的绝对值，结果符号跟随绝对值较大的数：

```text
(+8) + (−3) = +5
(−8) + (+3) = −5
```

可以理解为相反方向的数量互相抵消。

## 十六、减去一个数

减法可以看成加上它的相反数：

```text
a − b = a + (−b)
```

例如：

```text
5 − (−2) = 5 + 2 = 7
−4 − 3 = −4 + (−3) = −7
```

遇到减号后面的负数，要特别注意两个符号。

## 十七、连续变化

记录连续变化时，可以把每次增加写成正数，每次减少写成负数。

```text
初始资金 20 元
买东西 −8 元，再收入 +5 元
最终变化 = −8 + 5 = −3 元
剩余 = 20 − 3 = 17 元
```

先明确是“变化量”还是“最终数量”。

## 十八、正负数的乘法初步

在简单规律中：

```text
正 × 正 = 正
负 × 正 = 负
```

例如每小时下降 2°C，经过 3 小时的变化可表示为 `−2 × 3 = −6°C`。更完整的负数乘除法规则将在后续学习中展开。

## 十九、正负数与代数式

代入正数或负数时，建议给负数加括号：

```text
2x + 3，x = −4
= 2 × (−4) + 3
= −8 + 3
= −5
```

括号能清楚表示负号属于整个数，而不是减法运算的一部分。

## 二十、按大小排列正负数

从小到大排列时，数轴上从左向右排列：

```text
−6、−2、0、3、7
```

从大到小排列则反向：

```text
7、3、0、−2、−6
```

## 二十一、求两个数的距离

数轴上两个数之间的距离等于较大数减较小数：

```text
−3 与 4 的距离 = 4 − (−3) = 7
```

如果两个数互为相反数 `a` 和 `−a`，它们之间的距离是 `2a`（当 `a` 为正数时）。

## 二十二、综合例题

某地早晨温度为 `−5°C`，中午上升 12°C，晚上又下降 8°C。求中午和晚上的温度。

```text
中午：−5 + 12 = 7°C
晚上：7 − 8 = −1°C
```

温度从早晨到晚上总变化为 `−1 − (−5) = 4°C`，比早晨高 4°C。

## 二十三、常见错误

### 1. 认为 0 是正数或负数

0 既不是正数，也不是负数。

### 2. 比较负数时只看数字大小

应看数轴位置：越靠右越大，所以 `−2 > −7`。

### 3. 忘记负号

`−5` 和 `5` 不是同一个数，它们在原点两侧。

### 4. 减去负数时符号混乱

可以先改写为加上相反数，例如 `3 − (−4) = 3 + 4`。

### 5. 代入负数不加括号

在代数式中使用 `(−3)`，能减少运算顺序和符号错误。

## 二十四、小结

```text
正数 > 0，负数 < 0，0 既不是正数也不是负数
数轴上越靠右的数越大
相反数到 0 的距离相等、符号相反
正负数加法可用数轴移动或相反量抵消理解
减去一个数等于加上它的相反数
```

学习正数、负数和零时，先确定基准和正方向，再用数轴表示和比较；进行运算或代入时，特别注意负号、括号和单位。
