# 等腰三角形与等边三角形

三角形可以根据边的关系分为不同类型。等腰三角形有两条相等的边，等边三角形有三条相等的边。边的相等会带来角的相等，是求未知角和判断图形的重要依据。

## 一、等腰三角形的组成

等腰三角形有两条相等的边，称为腰；另一条边称为底边。

```text
两条相等的边：腰
不相等或剩下的一条边：底边
腰的夹角：顶角
底边两端的角：底角
```

如果 `AB = AC`，那么 `△ABC` 的底边是 `BC`，顶角是 `∠A`，底角是 `∠B` 和 `∠C`。

## 二、等腰三角形的底角相等

等腰三角形的两个底角相等。这是等腰三角形最重要的性质。

```text
AB = AC
所以 ∠B = ∠C
```

相等的边对应相等的对角。判断底角时，要找出相等边所对着的两个角。

## 三、已知顶角求底角

三角形的内角和是 180°，两个底角相等。因此：

```text
底角 = (180° − 顶角) ÷ 2
```

例如顶角为 40°：

```text
两个底角和 = 180° − 40° = 140°
每个底角 = 140° ÷ 2 = 70°
```

## 四、已知底角求顶角

如果一个底角是 65°，另一个底角也是 65°，所以：

```text
顶角 = 180° − 65° − 65° = 50°
```

也可以先算两个底角的和 `65° × 2 = 130°`，再用 `180° − 130°`。

## 五、已知一个底角求另一个底角

根据底角相等，知道一个底角就知道另一个：

```text
∠B = 72°
所以 ∠C = 72°
```

此时顶角为：

```text
180° − 72° − 72° = 36°
```

## 六、等腰三角形的对称性

当等腰三角形的两腰相等时，从顶点向底边中点画出的线通常把图形分成左右对称的两部分。

```text
两腰相等
两个底角相等
顶点到底边中点的对称线平分顶角和底边
```

在本阶段，重点使用边角相等和内角和计算，不必把所有对称性质都当作新的定理记忆。

## 七、等腰三角形中的直角

如果等腰三角形的顶角是直角：

```text
顶角 = 90°
两个底角和 = 180° − 90° = 90°
每个底角 = 90° ÷ 2 = 45°
```

所以等腰直角三角形的两个锐角都是 45°。

## 八、等腰三角形中的钝角

等腰三角形的钝角只能是顶角，因为两个底角相等，不能同时大于 90°。

```text
顶角 = 120°
每个底角 = (180° − 120°) ÷ 2 = 30°
```

因此，等腰三角形可以是锐角三角形、直角三角形或钝角三角形，取决于顶角的大小。

## 九、等腰三角形的判断

如果一个三角形的两个角相等，那么它们所对的两条边相等，这个三角形是等腰三角形。

```text
∠B = ∠C
所以 AB = AC
```

实际图形中可以根据相等边标记或相等角弧线判断，不要只凭图形看起来“像不像”等腰三角形。

## 十、等边三角形的组成

等边三角形的三条边都相等：

```text
AB = BC = CA
```

等边三角形的三个内角也相等。因此，等边三角形同时具备等腰三角形的底角性质。

## 十一、等边三角形的每个角

三个内角相等，且内角和为 180°：

```text
每个内角 = 180° ÷ 3 = 60°
```

所以等边三角形的三个角都是 60°，它一定是锐角三角形。

## 十二、等边三角形与等腰三角形的关系

等边三角形有三组相等的边，因此也可以看作一种特殊的等腰三角形。

```text
等边三角形：三边相等，三角相等
一般等腰三角形：至少两边相等，两个底角相等
```

在学习和分类时，先看题目采用的定义；等边三角形通常单独列出，因为它的三个角都相等。

## 十三、由角判断等边三角形

如果一个三角形的三个角都是 60°，则三边相等，它是等边三角形。

```text
∠A = ∠B = ∠C = 60°
所以 △ABC 是等边三角形
```

如果只知道两个角都是 60°，第三个角由内角和也必为 60°。

## 十四、利用相等标记列式

图中的短线表示边相等，弧线表示角相等。先把标记翻译成数学关系，再列式。

```text
AB = AC  →  ∠B = ∠C
∠B = ∠C →  两个底角可看成相等的两份
```

例如顶角 50°：

```text
∠B = ∠C = (180° − 50°) ÷ 2 = 65°
```

## 十五、等腰三角形与外角

等腰三角形的一个底角为 70°，对应的外角与它组成平角：

```text
外角 = 180° − 70° = 110°
```

另一个底角也是 70°，所以外角也可以用两个不相邻内角之和检查：

```text
顶角 + 另一个底角 = 40° + 70° = 110°
```

## 十六、周长与等腰、等边关系

知道边长关系时，可以把相等的边合并计算周长。

```text
等腰三角形两腰各 8 cm，底边 11 cm
周长 = 8 + 8 + 11 = 27 cm
```

```text
等边三角形边长 6 cm
周长 = 6 × 3 = 18 cm
```

周长计算与角度计算是不同任务，读题时要先确认要求。

## 十七、画等腰三角形

给定底边和两腰长度时，可以用直尺和圆规画等腰三角形：

1. 画出底边。
2. 以底边两个端点为圆心，分别以腰长为半径画弧。
3. 两弧的交点是顶点。
4. 连接顶点和底边两个端点。

两条腰使用相同半径，能保证它们相等。

## 十八、画等边三角形

给定边长时，可以用以下方法画等边三角形：

1. 画一条指定长度的线段。
2. 以两个端点为圆心、以线段长度为半径画弧。
3. 取两弧的一个交点作为第三个顶点。
4. 连接第三个顶点与原线段两个端点。

三条边都等于指定长度，三个角也都为 60°。

## 十九、综合例题

等腰三角形的一个底角是 68°。求顶角，并判断三角形类型。

```text
另一个底角 = 68°
顶角 = 180° − 68° − 68° = 44°
```

三个角为 68°、68°、44°，都小于 90°，所以它是锐角等腰三角形。

## 二十、常见错误

### 1. 把相等边对应的角找错

相等边所对的角才相等，应先确认每条边的对角位置。

### 2. 忘记两个底角都要计算

求顶角时要从 180° 中减去两个底角，而不是只减去一个。

### 3. 把等腰三角形都当成等边三角形

等腰只保证至少两边相等；只有三边都相等时才是等边三角形。

### 4. 只凭外观判断相等

使用边上的短线、角上的弧线和题目条件，不要依赖图形是否画得对称。

### 5. 忘记单位或关系

角度答案写 `°`，长度答案写 `cm`、`m` 等单位，并区分角度与周长问题。

## 二十一、小结

```text
等腰三角形：两腰相等，两个底角相等
等腰三角形顶角 + 两个底角 = 180°
等边三角形：三边相等，三个角相等
等边三角形每个内角 = 60°
等边三角形是特殊的等腰三角形
```

处理这类问题时，先读取相等边或相等角标记，再结合三角形内角和计算；最后用边角特征检查分类是否正确。
