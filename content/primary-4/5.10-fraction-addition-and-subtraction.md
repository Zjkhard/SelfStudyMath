# 分数加法与减法

我们已经知道，分数表示一个或几个分数单位。

例如：

~~~text
3/5 表示 3 个 1/5
2/7 表示 2 个 1/7
~~~

分数加减的关键是：

~~~text
只有相同的分数单位，才能直接合并或分离
~~~

这和整数加减时相同数位上的数量才能直接相加或相减很相似。

## 一、分数加法表示部分合并

把同一个整体平均分成 8 份。

先取 3 份，再取 2 份：

~~~text
3/8 + 2/8
~~~

两个分数的每一份都是 1/8，所以可以直接合并取出的份数：

~~~text
3 个 1/8 + 2 个 1/8 = 5 个 1/8
~~~

因此：

~~~text
3/8 + 2/8 = 5/8
~~~

## 二、分数减法表示部分分离或比较

同一个整体中原来有 7/9，取走 2/9：

~~~text
7/9 - 2/9 = 5/9
~~~

这里表示：

~~~text
7 个 1/9 - 2 个 1/9 = 5 个 1/9
~~~

减法也可以表示两个分数相差多少：

~~~text
7/9 - 5/9 = 2/9
~~~

## 三、同分母分数相加

同分母表示分数单位相同。

看：

~~~text
2/11 + 5/11
~~~

每一份都是 1/11，只需合并份数：

~~~text
2/11 + 5/11 = 7/11
~~~

所以：

~~~text
分母相同，分子相加，分母不变
~~~

分母不变，是因为每一份仍然是整体的 1/11。

## 四、同分母分数相减

看：

~~~text
8/13 - 3/13
~~~

每一份都是 1/13：

~~~text
8 个 1/13 - 3 个 1/13 = 5 个 1/13
~~~

所以：

~~~text
8/13 - 3/13 = 5/13
~~~

也就是：

~~~text
分母相同，分子相减，分母不变
~~~

## 五、为什么分母不能相加

看：

~~~text
1/4 + 2/4
~~~

合并后是 3 个四分之一：

~~~text
1/4 + 2/4 = 3/4
~~~

整体仍然平均分成 4 份，每一份仍然是 1/4。

如果把分母也相加，写成 3/8，就把每一份变成了 1/8，改变了分数单位。

所以：

~~~text
分母表示每一份的大小
分子表示有这样的几份
合并相同分数单位时，只改变份数
~~~

## 六、结果可以写成更简单的等值分数

计算：

~~~text
1/6 + 3/6 = 4/6
~~~

4 和 6 都能除以 2：

~~~text
4/6 = 2/3
~~~

所以：

~~~text
1/6 + 3/6 = 4/6 = 2/3
~~~

再看减法：

~~~text
7/10 - 3/10 = 4/10 = 2/5
~~~

先完成加减，再把结果写成较简单的等值分数。

## 七、结果等于一个整体

如果合并后的份数和整体的总份数相同，结果就是 1。

例如：

~~~text
3/7 + 4/7 = 7/7 = 1
~~~

再看：

~~~text
5/12 + 7/12 = 12/12 = 1
~~~

这里没有改变整体，只是所有部分刚好合成一个完整的整体。

## 八、异分母不能直接相加

看：

~~~text
1/2 + 1/3
~~~

1/2 的分数单位是 1/2，1/3 的分数单位是 1/3。

~~~text
一个二分之一和一个三分之一
不是两个相同大小的部分
~~~

因此，不能直接把分子相加写成 2/5。

必须先把两个分数改写成分数单位相同的等值分数。

## 九、用图形理解统一分数单位

把同一个长方形分别按二等份和三等份观察。

如果同时画出这两种分割线，长方形会被平均分成 6 份：

~~~text
1/2 = 3/6
1/3 = 2/6
~~~

现在两个分数都以 1/6 为分数单位：

~~~text
3/6 + 2/6 = 5/6
~~~

所以：

~~~text
1/2 + 1/3 = 5/6
~~~

统一分母的本质，是找到共同的分数单位。

## 十、一个分母是另一个分母的倍数

计算：

~~~text
2/3 + 1/6
~~~

6 是 3 的倍数，可以把 2/3 改写成六分之几：

~~~text
2/3 = 4/6
~~~

于是：

~~~text
2/3 + 1/6
= 4/6 + 1/6
= 5/6
~~~

只需改变其中一个分数，就能得到相同的分母。

## 十一、寻找共同分母进行加法

计算：

~~~text
1/3 + 1/4
~~~

3 和 4 的一个共同倍数是 12，因此可以把两个分数都写成十二分之几：

~~~text
1/3 = 4/12
1/4 = 3/12
~~~

再相加：

~~~text
1/3 + 1/4
= 4/12 + 3/12
= 7/12
~~~

7 和 12 没有大于 1 的公因数，结果已经不能再写成分子、分母更小的等值分数。

## 十二、寻找共同分母进行减法

计算：

~~~text
5/6 - 1/4
~~~

6 和 4 的一个共同倍数是 12：

~~~text
5/6 = 10/12
1/4 = 3/12
~~~

现在分数单位相同：

~~~text
5/6 - 1/4
= 10/12 - 3/12
= 7/12
~~~

减法中也必须先统一分数单位。

## 十三、共同分母不只有一个

计算：

~~~text
1/4 + 1/6
~~~

12、24、36 都是 4 和 6 的共同倍数。

选择 12：

~~~text
1/4 = 3/12
1/6 = 2/12
3/12 + 2/12 = 5/12
~~~

如果选择 24：

~~~text
1/4 = 6/24
1/6 = 4/24
6/24 + 4/24 = 10/24 = 5/12
~~~

两种方法得到相同结果。通常选择较小、方便计算的共同分母。

## 十四、从 1 中减去一个分数

计算：

~~~text
1 - 3/8
~~~

一个整体可以写成：

~~~text
1 = 8/8
~~~

所以：

~~~text
1 - 3/8
= 8/8 - 3/8
= 5/8
~~~

一般来说，面对分母为某个数的分数，可以把 1 写成分子、分母相同的分数。

## 十五、连续计算三个分数

计算：

~~~text
1/6 + 1/3 + 1/4
~~~

6、3、4 的一个共同倍数是 12：

~~~text
1/6 = 2/12
1/3 = 4/12
1/4 = 3/12
~~~

于是：

~~~text
1/6 + 1/3 + 1/4
= 2/12 + 4/12 + 3/12
= 9/12
= 3/4
~~~

统一分数单位后，可以像合并相同单位的整数一样合并份数。

## 十六、加法中的交换与组合

分数加法也可以交换加数或改变组合顺序。

看：

~~~text
1/4 + 2/5 + 3/4
~~~

先把能合成 1 的两个分数放在一起：

~~~text
1/4 + 3/4 = 1
~~~

所以：

~~~text
1/4 + 2/5 + 3/4
= 1/4 + 3/4 + 2/5
= 1 + 2/5
~~~

这个结果大于 1。下一单元将学习怎样用假分数和带分数完整表示这种结果。

## 十七、用估算判断结果

计算前，可以用 0、1/2 和 1 判断大致范围。

看：

~~~text
1/3 + 1/4
~~~

1/3 和 1/4 都小于 1/2，它们的和应当小于 1，并且大于 1/2。

准确结果：

~~~text
1/3 + 1/4 = 7/12
~~~

7/12 确实在 1/2 和 1 之间。

再看：

~~~text
5/6 - 1/4
~~~

5/6 接近 1，减去 1/4 后，结果应当大于 1/2：

~~~text
5/6 - 1/4 = 7/12
~~~

7/12 大于 1/2，结果合理。

## 十八、用相反运算验算

加法可以用减法检查。

例如：

~~~text
1/3 + 1/4 = 7/12
~~~

从和中减去一个加数：

~~~text
7/12 - 1/4
= 7/12 - 3/12
= 4/12
= 1/3
~~~

减法可以用加法检查：

~~~text
5/6 - 1/4 = 7/12
~~~

检查：

~~~text
7/12 + 1/4
= 7/12 + 3/12
= 10/12
= 5/6
~~~

结果回到原来的数，说明数量关系相符。

## 十九、找出未知的部分

看：

~~~text
2/5 + ? = 4/5
~~~

未知的部分可以用减法找到：

~~~text
4/5 - 2/5 = 2/5
~~~

所以：

~~~text
2/5 + 2/5 = 4/5
~~~

再看：

~~~text
? - 1/6 = 1/2
~~~

未知的原数等于差加上减去的部分：

~~~text
1/2 + 1/6
= 3/6 + 1/6
= 4/6
= 2/3
~~~

所以：

~~~text
2/3 - 1/6 = 1/2
~~~

## 二十、完整的计算顺序

计算异分母分数加减时，可以依次检查：

~~~text
1. 两个分数是否表示同一个单位整体
2. 分母是否相同
3. 如果不同，寻找合适的共同分母
4. 写出等值分数，统一分数单位
5. 分子相加或相减，分母不变
6. 把结果写成较简单的等值分数
7. 用估算或相反运算检查
~~~

每一步都对应明确的数量关系。

## 二十一、容易混淆的地方

### 1. 分子和分母分别相加

~~~text
1/2 + 1/3
~~~

不能写成 2/5，因为二分之一和三分之一不是相同的分数单位。

### 2. 只改变分母

把 1/2 写成分母为 6 的等值分数时，分子和分母都要乘 3：

~~~text
1/2 = 3/6
~~~

不能写成 1/6。

### 3. 找到共同分母后忘记改分子

分数单位变小后，同一部分所包含的份数也会改变。

### 4. 计算后没有化成较简单的等值分数

例如：

~~~text
4/6 = 2/3
~~~

两个答案大小相同，但 2/3 更容易看清分数关系。

### 5. 减法中把较小的分数减去较大的分数

在这一阶段讨论的非负分数范围内，要先确认被减数不小于减数。

### 6. 把共同分母当作两个分母的乘积

两个分母的乘积通常可以作共同分母，但不一定是最方便的选择。

## 二十二、小结

分数加减的核心是统一分数单位：

~~~text
同分母：直接把相同的分数单位合并或分离
异分母：先写成同分母的等值分数，再计算
~~~

计算时：

~~~text
分子相加或相减
分母保持为共同分母
结果可以写成较简单的等值分数
~~~

一个整体可以根据需要写成：

~~~text
1 = 2/2 = 3/3 = 8/8 = ……
~~~

图形、数轴、等值分数和共同分母都在说明同一件事：只有每一份同样大，份数才能直接相加或相减。
