# 垂线与平行线

观察道路、门框、方格纸和铁轨，会看到直线之间有不同的位置关系：

~~~text
有些直线相交
有些直线相交成直角
有些直线始终不相交
~~~

这一单元学习两种重要关系：垂直和平行。

## 一、直线可以向两端延伸

线段有两个端点，直线可以向两端无限延伸。

~~~text
线段：A●────────●B

直线：←────────────→
~~~

判断两条直线是否相交或平行时，不能只看纸上已经画出的短短一段，还要想象它们继续向两端延伸。

两条线段现在没有接触，它们所在的直线延长后仍可能相交。

## 二、相交线

同一平面内的两条直线如果有一个公共点，就叫作相交线。

~~~text
  │
──●──
  │
~~~

公共点叫作交点。

两条直线相交时，会在交点周围形成角。

相交只说明两条直线碰到了一起，并不说明它们一定形成直角。

## 三、垂直

如果两条直线相交形成直角，就说这两条直线**互相垂直**。

~~~text
    b
    │
    │
a ──□────
    │
~~~

图中的小方框表示直角。

直线 a 与直线 b 相交形成 90°，因此：

~~~text
直线 a 垂直于直线 b
直线 b 也垂直于直线 a
~~~

垂直是两条直线之间的相互关系。

## 四、垂直符号

“垂直于”可以用符号表示：

~~~text
⊥
~~~

如果直线 a 与直线 b 互相垂直，可以写成：

~~~text
a ⊥ b
~~~

读作：

~~~text
直线 a 垂直于直线 b
~~~

符号 ⊥ 的形状也像两条相交成直角的直线。

## 五、垂足

当直线 a 与直线 b 垂直相交于点 P 时：

~~~text
    b
    │
    │
a ──P────
    │
~~~

点 P 叫作垂足。

可以说：

~~~text
从直线 a 上的点 P 作出了直线 b
直线 b 是直线 a 的垂线
P 是垂足
~~~

“垂线”通常是相对于另一条直线来说的。

## 六、相交不一定垂直

看两条倾斜相交的直线：

~~~text
╲  ╱
 ╲╱
 ╱╲
╱  ╲
~~~

它们相交，但交角不一定是 90°。

判断垂直不能只看“像一个十字”，而要确认：

~~~text
交点处是否形成直角
~~~

可以使用直角标记、三角尺的直角或量角器进行判断。

## 七、垂直关系与方向无关

下面的直线虽然倾斜，但仍可能互相垂直：

~~~text
╲
 ╲
  ●
 ╱
╱
~~~

如果它们相交形成 90°，它们就是垂直线。

~~~text
一条水平、一条竖直
~~~

是常见的垂直形式，但不是唯一形式。

把一对垂直线一起旋转，直角大小不变，垂直关系也不变。

## 八、同一点处的四个角

两条直线互相垂直时，交点周围形成 4 个角。

一周是：

~~~text
360°
~~~

4 个角都相等，因此每个角是：

~~~text
360° ÷ 4 = 90°
~~~

所以两条垂直线在交点处形成 4 个直角。

只标出其中一个直角，就足以说明这两条直线互相垂直。

## 九、经过直线外一点画垂线

要经过点 P，画一条垂直于直线 a 的直线，可以使用直尺和三角尺：

~~~text
1. 把三角尺的一条直角边贴住直线 a
2. 移动三角尺，使另一条直角边经过点 P
3. 沿经过 P 的直角边画线
4. 标出垂足和直角记号
~~~

三角尺的两条直角边互相垂直，所以画出的新直线与直线 a 垂直。

## 十、经过直线上一点画垂线

如果点 P 已经在直线 a 上：

~~~text
1. 把三角尺的一条直角边与直线 a 重合
2. 让三角尺的直角顶点对准 P
3. 沿另一条直角边画直线
~~~

画出的直线经过 P，并与直线 a 形成 90°。

无论点在直线上还是直线外，判断结果都要检查直角。

## 十一、点到直线的距离

从直线外一点 P 向直线 a 画垂线，P 到垂足之间的线段叫作点 P 到直线 a 的垂直线段。

这条垂直线段的长度，就是点 P 到直线 a 的距离。

~~~text
P●
 │
 │
 □
──────── a
~~~

从 P 到直线 a 可以画许多不同的线段，其中垂直线段最短。

因此，测量一个点到一条直线的距离时，要沿垂直方向测量。

## 十二、平行线

同一平面内的两条直线，如果无论怎样延长都不相交，就说它们互相平行。

~~~text
a ←────────────────→

b ←────────────────→
~~~

可以说：

~~~text
直线 a 平行于直线 b
直线 b 也平行于直线 a
~~~

平行也是两条直线之间的相互关系。

## 十三、平行符号

“平行于”可以用符号表示：

~~~text
∥
~~~

如果直线 a 与直线 b 互相平行，可以写成：

~~~text
a ∥ b
~~~

读作：

~~~text
直线 a 平行于直线 b
~~~

符号 ∥ 像两条方向相同、互不相交的直线。

## 十四、平行线之间的距离

平行线沿着相同方向延伸，它们之间的垂直距离处处相等。

~~~text
a ─────────────────
  │       │       │
  │       │       │
b ─────────────────
~~~

图中连接两条平行线的短线段都与它们垂直，而且长度相等。

如果两条直线之间一端近、一端远，它们继续延长后就会相交，不是平行线。

## 十五、没有相交不一定平行

纸面上画出的两条短线段可能暂时没有相交：

~~~text
────────
       ╱
      ╱
~~~

但把它们所在的直线继续延长，可能会相交。

因此，不能只根据“眼前没有碰到”判断平行，还要观察：

~~~text
方向是否相同
垂直距离是否保持不变
延长后是否仍不相交
~~~

## 十六、平行关系与长短无关

两条线段可以长短不同，但它们所在的直线仍可能互相平行：

~~~text
────────────

    ──────
~~~

平行描述的是方向和位置关系，不是长度关系。

同样，两条直线倾斜放置也可以平行：

~~~text
╱
 ╱
  ╱

      ╱
       ╱
        ╱
~~~

把一组平行线一起旋转，平行关系不会改变。

## 十七、用直尺和三角尺画平行线

经过点 P，画一条平行于直线 a 的直线，可以这样做：

~~~text
1. 把三角尺的一条边贴住直线 a
2. 用直尺贴住三角尺的另一条边，并固定直尺
3. 让三角尺沿直尺滑动，直到原来的边经过点 P
4. 沿这条边画出经过 P 的直线
~~~

三角尺在滑动时没有转动，所以原来贴住直线 a 的那条边方向不变。

因此，新画的直线与直线 a 平行。

## 十八、同时垂直于同一条直线

看三条直线：

~~~text
a ─────────────────
  │
  │ c
b ─────────────────
~~~

如果：

~~~text
a ⊥ c
b ⊥ c
~~~

那么 a 和 b 都与 c 形成相同方向的直角。

在同一平面内：

~~~text
a ∥ b
~~~

也就是说：

~~~text
同一平面内，两条直线都垂直于同一条直线
这两条直线互相平行
~~~

## 十九、垂直于平行线中的一条

如果：

~~~text
a ∥ b
c ⊥ a
~~~

那么直线 c 与直线 b 相交时，也会形成直角：

~~~text
c ⊥ b
~~~

因为平行线 a 和 b 的方向相同，垂直于其中一条的方向，也垂直于另一条。

这个关系常用于检查方格、长方形和正方形中的边。

## 二十、图形中的垂直和平行

长方形中：

~~~text
相邻的边互相垂直
相对的边互相平行
~~~

~~~text
A────────B
│        │
│        │
D────────C
~~~

可以写成：

~~~text
AB ⊥ BC
AB ∥ DC
AD ∥ BC
~~~

正方形也有相同的垂直和平行关系，只是它的 4 条边还都相等。

## 二十一、生活中的近似与数学中的准确

铁轨、斑马线、方格纸和窗框常帮助我们观察平行或垂直。

但真实物体可能因为弯曲、磨损或绘制误差，只是“看起来接近”平行或垂直。

数学图形中的关系需要依据：

~~~text
直角标记
平行标记
测量结果
已知条件
~~~

不能只凭图形看起来像什么作出准确结论。

## 二十二、容易混淆的地方

### 1. 相交就认为垂直

只有相交角是 90° 时，两条直线才互相垂直。

### 2. 一横一竖才是垂直

倾斜的两条直线也可以互相垂直，关键是相交形成直角。

### 3. 没有看到交点就认为平行

要想象直线向两端延长。延长后相交，就不是平行线。

### 4. 平行线必须一样长

直线没有固定长度；线段长短不同，也不影响它们所在直线的平行关系。

### 5. 用斜线段测量两条平行线的距离

两条平行线之间的距离要沿垂直方向测量。

### 6. 作图时让三角尺发生转动

画平行线时，三角尺只能沿固定直尺滑动，不能改变方向。

### 7. 把符号混淆

~~~text
⊥ 表示垂直
∥ 表示平行
~~~

## 二十三、小结

垂直线相交形成直角：

~~~text
a ⊥ b
交角为 90°
~~~

平行线在同一平面内始终不相交：

~~~text
a ∥ b
两线间的垂直距离处处相等
~~~

判断和作图时：

~~~text
用直角检查垂直
用相同方向和相等距离理解平行
用直尺与三角尺保持准确关系
~~~

垂直和平行还可以互相联系：

~~~text
同一平面内，同垂直于一条直线的两条直线互相平行
一条直线垂直于两条平行线中的一条，也垂直于另一条
~~~

这些关系将帮助我们进一步认识三角形和四边形。
