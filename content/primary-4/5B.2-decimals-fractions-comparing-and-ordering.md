# 小数与分数、大小比较及数的顺序

小数和分数可以表示同一个数量。

例如：

~~~text
0.5 = 5/10 = 1/2
0.75 = 75/100 = 3/4
~~~

把两种写法联系起来，可以帮助我们比较大小、确定数在数轴上的位置，并排列数的顺序。

本单元主要比较非负数。

## 一、分母为 10 的分数与小数

十分之几可以直接写到十分位。

例如：

~~~text
1/10 = 0.1
4/10 = 0.4
9/10 = 0.9
~~~

分母 10 表示把一个整体平均分成 10 份，分子表示有几个十分之一。

~~~text
7/10 = 7 个十分之一 = 0.7
~~~

## 二、分母为 100 的分数与小数

百分之几可以写到百分位。

例如：

~~~text
3/100 = 0.03
28/100 = 0.28
90/100 = 0.90 = 0.9
~~~

3/100 写成 0.03，而不是 0.3：

~~~text
十分位没有十分之一，要写 0 占位
3 写在百分位
~~~

## 三、分母为 1000 的分数与小数

千分之几可以写到千分位。

例如：

~~~text
7/1000 = 0.007
64/1000 = 0.064
528/1000 = 0.528
~~~

小数点后要保留正确的三个数位：

~~~text
十分位、百分位、千分位
~~~

缺少的数位用 0 占位。

## 四、把小数写成分数

看小数最后一个数字所在的数位。

~~~text
0.6 的最后一位在十分位 → 6/10
0.27 的最后一位在百分位 → 27/100
0.405 的最后一位在千分位 → 405/1000
~~~

所以：

~~~text
0.6 = 6/10
0.27 = 27/100
0.405 = 405/1000
~~~

这一步先按小数位值写分数，再观察是否可以化简。

## 五、把分数写成最简形式

看：

~~~text
0.45 = 45/100
~~~

分子和分母都能除以 5：

~~~text
45/100 = 9/20
~~~

所以：

~~~text
0.45 = 45/100 = 9/20
~~~

再看：

~~~text
0.125 = 125/1000
~~~

分子和分母都除以 125：

~~~text
125/1000 = 1/8
~~~

所以：

~~~text
0.125 = 1/8
~~~

## 六、把常见分数化成十分数

看：

~~~text
3/5
~~~

把分母 5 变成 10：

~~~text
3/5
= (3 × 2)/(5 × 2)
= 6/10
= 0.6
~~~

再看：

~~~text
1/2 = 5/10 = 0.5
~~~

如果分母能通过乘一个整数变成 10，就可以先写成十分数，再写成小数。

## 七、把常见分数化成百分数

看：

~~~text
3/4
~~~

把分母 4 变成 100：

~~~text
3/4
= (3 × 25)/(4 × 25)
= 75/100
= 0.75
~~~

再看：

~~~text
7/20
= 35/100
= 0.35
~~~

分母 4、20、25、50 等都可以通过等值分数变成 100。

## 八、把常见分数化成千分数

看：

~~~text
7/8
~~~

把分母 8 变成 1000：

~~~text
7/8
= (7 × 125)/(8 × 125)
= 875/1000
= 0.875
~~~

再看：

~~~text
3/40
= 75/1000
= 0.075
~~~

选择 10、100 还是 1000，要看哪个能成为原分母的倍数。

## 九、带分数与小数

看：

~~~text
2 3/4
~~~

先把分数部分写成小数：

~~~text
3/4 = 0.75
~~~

所以：

~~~text
2 3/4 = 2.75
~~~

反过来：

~~~text
1.375
= 1 + 375/1000
= 1 + 3/8
= 1 3/8
~~~

整数部分保持不变，只转换不足一个整体的部分。

## 十、假分数与小数

看：

~~~text
7/4
~~~

先转换成带分数：

~~~text
7/4 = 1 3/4
~~~

再把 3/4 写成 0.75：

~~~text
7/4 = 1.75
~~~

也可以把 7/4 化成百分数：

~~~text
7/4 = 175/100 = 1.75
~~~

两种方法得到同一个结果。

## 十一、有些分数不能写成有限三位小数

看：

~~~text
1/3
~~~

分母 3 不能通过乘一个整数恰好变成 10、100 或 1000。

~~~text
0.3 = 3/10
~~~

而：

~~~text
1/3 ≠ 3/10
~~~

所以 0.3 不是 1/3 的精确写法。

以后会学习，有些分数写成小数时，数字会不断重复。本单元只处理能够精确写成有限三位以内小数的分数。

## 十二、比较符号与数轴方向

比较大小时使用：

~~~text
>  大于
<  小于
=  等于
~~~

在数轴上：

~~~text
右边的数大于左边的数
左边的数小于右边的数
同一个位置上的数相等
~~~

小数和分数只是数的不同写法，比较的是它们表示的数量。

## 十三、先比较整数部分

比较：

~~~text
4.08 和 3.95
~~~

先看整数部分：

~~~text
4 > 3
~~~

所以：

~~~text
4.08 > 3.95
~~~

整数部分不同时，不需要先比较小数部分。

不能只看 08 和 95，因为它们分别属于不同整数之后的部分。

## 十四、整数部分相同时比较十分位

比较：

~~~text
2.7 和 2.4
~~~

整数部分都是 2，再比较十分位：

~~~text
7 个十分之一 > 4 个十分之一
~~~

所以：

~~~text
2.7 > 2.4
~~~

比较小数时，从最高位开始逐位比较。

## 十五、十分位相同时比较百分位

比较：

~~~text
6.38 和 6.35
~~~

依次比较：

~~~text
整数部分：6 = 6
十分位：3 = 3
百分位：8 > 5
~~~

所以：

~~~text
6.38 > 6.35
~~~

一旦在某个数位发现不同，就由这个数位决定大小。

## 十六、继续比较千分位

比较：

~~~text
0.507 和 0.502
~~~

整数部分、十分位和百分位都相同：

~~~text
0 = 0
5 = 5
0 = 0
~~~

比较千分位：

~~~text
7 > 2
~~~

所以：

~~~text
0.507 > 0.502
~~~

## 十七、小数位数不同怎样比较

比较：

~~~text
3.47 和 3.405
~~~

可以在 3.47 的末尾添 0：

~~~text
3.47 = 3.470
~~~

现在逐位比较：

~~~text
3.470
3.405
~~~

十分位相同，百分位上：

~~~text
7 > 0
~~~

所以：

~~~text
3.47 > 3.405
~~~

补末尾 0 只统一了书写位数，没有改变数的大小。

## 十八、位数更多不一定更大

比较：

~~~text
0.8 和 0.75
~~~

把 0.8 写成：

~~~text
0.80
~~~

比较十分位：

~~~text
8 > 7
~~~

所以：

~~~text
0.8 > 0.75
~~~

0.75 的小数位数更多，但它并不更大。

比较小数不能数数字个数，要比较每个数字所在的位值。

## 十九、占位 0 会影响大小

比较：

~~~text
2.09 和 2.9
~~~

统一写到千分位：

~~~text
2.09 = 2.090
2.9  = 2.900
~~~

十分位上：

~~~text
0 < 9
~~~

所以：

~~~text
2.09 < 2.9
~~~

2.09 中的 0 在十分位，不能删除。

## 二十、比较小数与分数

比较：

~~~text
0.6 和 5/8
~~~

把 5/8 写成小数：

~~~text
5/8 = 625/1000 = 0.625
~~~

把 0.6 写成：

~~~text
0.6 = 0.600
~~~

所以：

~~~text
0.600 < 0.625
~~~

因此：

~~~text
0.6 < 5/8
~~~

也可以把两个数都写成分数，只要统一表示方式即可。

## 二十一、判断相等

比较：

~~~text
1.2 和 6/5
~~~

把 6/5 化成十分数：

~~~text
6/5 = 12/10 = 1.2
~~~

所以：

~~~text
1.2 = 6/5
~~~

写法不同不代表大小不同。图形、分数、小数和数轴位置都可以表示同一个数。

## 二十二、使用 0、1/2 和 1 作基准

常见基准可以帮助快速判断范围：

~~~text
1/2 = 0.5
1 = 1.0
~~~

例如：

~~~text
0.38 < 0.5
0.72 > 0.5
0.995 < 1
1.04 > 1
~~~

基准比较可以先确定大致位置，再用位值进行准确比较。

## 二十三、升序和降序

**升序**表示从小到大排列。

~~~text
小 → 大
~~~

**降序**表示从大到小排列。

~~~text
大 → 小
~~~

排列前要先确认方向，避免大小比较正确却把顺序写反。

## 二十四、排列小数的顺序

排列：

~~~text
0.65，0.605，0.56，0.6
~~~

统一写到千分位：

~~~text
0.650
0.605
0.560
0.600
~~~

从小到大：

~~~text
0.56 < 0.6 < 0.605 < 0.65
~~~

从大到小则相反：

~~~text
0.65 > 0.605 > 0.6 > 0.56
~~~

## 二十五、小数与分数混合排序

排列：

~~~text
1/2，0.45，3/5，0.625
~~~

先都写成小数：

~~~text
1/2 = 0.5
0.45 = 0.45
3/5 = 0.6
0.625 = 0.625
~~~

统一写到千分位：

~~~text
0.500，0.450，0.600，0.625
~~~

从小到大：

~~~text
0.45 < 1/2 < 3/5 < 0.625
~~~

统一表示方式可以让数的顺序更清楚。

## 二十六、在数轴上检查顺序

看下面的顺序：

~~~text
0.4 < 0.45 < 0.5 < 0.55 < 0.6
~~~

它们在数轴上从左到右排列：

~~~text
0.4──0.45──0.5──0.55──0.6
~~~

相邻两个十分位之间还可以放入百分位和千分位小数。

数轴可以帮助检查：

~~~text
数是否位于合理区间
升序是否从左向右
两个不同写法是否位于同一点
~~~

## 二十七、完整的比较方法

比较两个数时，可以依次进行：

~~~text
1. 如果表示方式不同，先考虑统一成小数或分数
2. 比较整数部分
3. 整数部分相同，再比较十分位
4. 继续比较百分位、千分位
5. 位数不同时，可以在末尾补 0
6. 用数轴或基准数检查结果
~~~

比较小数和整数时，也可以把整数写成带小数点的形式：

~~~text
3 = 3.000
~~~

这不会改变整数的大小。

## 二十八、容易混淆的地方

### 1. 把分子直接写到小数点后

3/100 应写成 0.03，不是 0.3。

### 2. 小数写成分数后不看位值

0.45 表示 45/100，不是 45/10。

### 3. 认为所有分数都能写成有限三位小数

像 1/3 这样的分数不能用有限三位小数精确表示。

### 4. 小数位数越多，数就越大

0.75 有两位小数，但小于只有一位小数的 0.8。

### 5. 从最右边开始比较

应从最高位开始：先整数部分，再十分位、百分位和千分位。

### 6. 随意删除中间的 0

2.09 中的 0 是十分位占位符，删除后会变成 2.9。

### 7. 混淆升序和降序

升序从小到大，降序从大到小。

### 8. 用近似值代替准确值

本单元比较的是准确数值。四舍五入会在下一单元学习。

## 二十九、小结

小数与分数可以互相表示：

~~~text
分母为 10、100、1000 的分数，可以按位值写成小数
小数可以根据最后一个数位写成十分数、百分数或千分数
结果还可以利用等值分数化简
~~~

比较小数时：

~~~text
先比较整数部分
再从十分位开始逐位比较
位数不同时，可以在末尾补 0
不能根据小数位数的多少判断大小
~~~

排列数的顺序时，可以统一成分数或小数，再按照数轴上从左到右的位置确定升序；降序则反向排列。
