# 10.15 利用乘法公式因式分解

乘法公式可以正向展开，也可以反向使用。若一个多项式符合熟悉的平方差或完全平方结构，就能把它写成几个因式的乘积。

~~~text
a² − b² = (a + b)(a − b)
a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²
~~~

因式分解是展开的逆过程，结果展开后必须与原式相同。

## 一、因式分解的意思

把一个多项式写成若干个代数式相乘的形式，称为因式分解。

~~~text
x² − 9 = (x + 3)(x − 3)
~~~

右边是两个因式的乘积。因式分解没有改变代数式的值，只是改变了表达形式。

## 二、平方差公式反向使用

平方差公式是：

~~~text
(a + b)(a − b) = a² − b²
~~~

反向使用可得：

~~~text
a² − b² = (a + b)(a − b)
~~~

识别要点是两个平方项相减。将两个平方分别看成 $a^2$ 与 $b^2$，再写成“和乘差”。

## 三、平方差例一

~~~text
x² − 25
= x² − 5²
= (x + 5)(x − 5)
~~~

25 是 $5^2$，所以两项都是平方。因式的次序可以交换，但一个括号用加号、另一个用减号。

## 四、含字母系数的平方差

~~~text
9y² − 4
= (3y)² − 2²
= (3y + 2)(3y − 2)
~~~

平方项 $9y^2$ 的平方根式是 $3y$，而 4 的平方根是 2。不要把 $9y^2$ 误认作 $(9y)^2$。

## 五、完全平方三项式反向使用

完全平方公式：

~~~text
(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
~~~

反向因式分解时，先检查首项和末项是不是完全平方，再检查中间项是否恰好为两平方根乘积的 2 倍：

~~~text
a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²
~~~

中间项的符号决定括号中间使用加号还是减号。

## 六、完全平方例一

~~~text
x² + 10x + 25
= x² + 2×x×5 + 5²
= (x + 5)²
~~~

首项 $x^2$ 是 $x$ 的平方，末项 25 是 5 的平方；中间项 $10x=2×x×5$，所以符合和的完全平方结构。

## 七、完全平方例二

~~~text
x² − 6x + 9
= x² − 2×x×3 + 3²
= (x − 3)²
~~~

首末两项的平方根分别为 $x$ 和 3，中间项是 $-2×x×3$，所以括号中使用减号。

## 八、首项系数不为 1

整个首项要作为一个整体识别平方：

~~~text
4x² − 12x + 9
= (2x)² − 2×(2x)×3 + 3²
= (2x − 3)²
~~~

因为 $(2x)^2=4x^2$，中间项 $-2×2x×3=-12x$，末项为 9。三项都与公式匹配。

## 九、含两个变量的完全平方

~~~text
16a² − 40ab + 25b²
= (4a)² − 2×(4a)×(5b) + (5b)²
= (4a − 5b)²
~~~

中间项同时含有 $a$ 和 $b$，可用首末项平方根的两倍乘积检查：$2×4a×5b=40ab$。

## 十、因式分解前先提取公因数

有时多项式各项先有共同因数。应先提取，再判断剩余部分是否符合特殊公式：

~~~text
3x² + 12x + 12
= 3(x² + 4x + 4)
= 3(x + 2)²
~~~

先提出公因数 3，括号内成为完全平方三项式。提取后仍要检查括号内结构。

## 十一、结合提取公因数与平方差

~~~text
2x² − 18
= 2(x² − 9)
= 2(x² − 3²)
= 2(x + 3)(x − 3)
~~~

先提出 2，再识别平方差。若不先提取，$2x^2$ 与 18 也不是最直接的平方差形式。

## 十二、先看符号与项数

~~~text
平方差：两项相减，如 x² − 16
完全平方：三项，首末项为平方，中间项为两倍乘积
~~~

若两项是相加，例如 $x^2+16$，它不是平方差公式的 $a^2-b^2$ 结构；若三项中间项不符合两倍乘积，也不能套完全平方公式。

## 十三、验证完全平方三项式

要检验 $A^2 \pm 2AB+B^2$ 是否为完全平方，可按下列顺序：

1. 求首项和末项的平方根，分别记作 $A$、$B$；
2. 计算 $2AB$；
3. 核对中间项的绝对值和符号；
4. 写成 $(A+B)^2$ 或 $(A-B)^2$；
5. 展开验证。

任何一项不符合，就不能使用完全平方公式。

## 十四、平方差中两项必须都是平方

~~~text
25x² − 49y² = (5x)² − (7y)²
= (5x + 7y)(5x − 7y)
~~~

只有在每一项都能写成相同数域内的平方时，才能按平方差分解。对通常的实数多项式，正系数项 $25x^2$ 与 $49y^2$ 都符合。

## 十五、因式分解结果不一定只写一种顺序

~~~text
x² − 4 = (x + 2)(x − 2)
= (x − 2)(x + 2)
~~~

乘法因式的顺序可以交换。通常写成结构清楚、没有明显公因数遗漏的形式。

## 十六、检验因式分解

最可靠的检查方法是把所得乘积重新展开：

~~~text
(2x − 3)²
= 4x² − 12x + 9
~~~

展开结果与原式一致，说明因式分解正确。也可代入一个简单数值作辅助检查，但数值检验不能代替恒等式展开。

## 十七、不是特殊结构的例子

~~~text
x² + 5x + 6
~~~

它不是完全平方三项式，因为首末项平方根为 $x$ 和 $\sqrt6$，其中间项并非 $2x\sqrt6$；它也不是平方差，因为它有三项且是加法结构。

这并不表示它不能因式分解，只表示本节的特殊乘法公式不适用。形如 $ax^2+bx+c$ 的因式分解将在下一课学习。

## 十八、完全平方与平方差的易错点

- 把 $a^2+b^2$ 错写成 $(a+b)(a-b)$；平方差要求两平方相减。
- 把 $a^2+2ab+b^2$ 写成 $(a-b)^2$；中间项为正时应为 $(a+b)^2$。
- 因为三项首末项是平方，就忽略中间项必须匹配 $2ab$。
- 对 $4x^2$ 取平方根时写成 $4x$，而不是 $2x$。
- 忘记先提取各项的公因数。
- 分解后不展开检查，漏掉系数或符号错误。

## 十九、展开与因式分解互为逆过程

~~~text
展开：(a + b)² → a² + 2ab + b²
分解：a² + 2ab + b² → (a + b)²
~~~

平方差公式也可双向使用。掌握展开形式有助于识别因式结构；因式分解则为后续解方程和化简提供方便。

## 二十、回顾

利用乘法公式因式分解，主要识别三种结构：

~~~text
a² − b² = (a + b)(a − b)
a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²
~~~

先提取公因数，再核对平方根与中间项；分解后可重新展开验证。不能只凭项数或外观套公式，必须确保每一项都符合对应结构。
