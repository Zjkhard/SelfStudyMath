# 11.4 二次函数图像：$a<0$、开口方向、对称轴、顶点与截距

二次函数 $y=ax^2+bx+c$ 在 $a<0$ 时，图像是一条开口向下的抛物线。它有一条竖直对称轴和一个最高点，最高点称为顶点。对称轴和截距的求法与 $a>0$ 时相同，但顶点由最低点变为最高点，值域方向也随之改变。

~~~text
y = ax² + bx + c，a < 0
图像：开口向下
对称轴：x = −b/(2a)
顶点：对称轴上的最高点
纵轴截距：x = 0 时的 y 值，即 c
~~~

## 一、从最简单的抛物线开始

函数 $y=-x^2$ 是 $y=x^2$ 关于横轴反射后的图像。它关于纵轴对称，顶点在原点 $(0,0)$，并从顶点向左右两侧下降。

~~~text
x     −2   −1    0    1    2
y     −4   −1    0   −1   −4
~~~

$x$ 与 $-x$ 对应相同的函数值，说明图像左右对称；随着 $|x|$ 增大，函数值变小。

## 二、二次项系数 $a$ 与开口方向

在一般式 $y=ax^2+bx+c$ 中，$a<0$ 表示抛物线开口向下。顶点是整条抛物线的最高点。与开口向上的情况相同，在其他条件一致时，$|a|$ 较大，图像较窄；$|a|$ 较小，图像较宽。

~~~text
a > 0：开口向上，有最低点
a < 0：开口向下，有最高点
~~~

## 三、顶点式直接显示顶点

若函数写成 $y=a(x-h)^2+k$，且 $a<0$，由于 $(x-h)^2\ge0$，乘以负数后 $a(x-h)^2\le0$。最大值 $k$ 在 $x=h$ 时取得，因此顶点为 $(h,k)$，对称轴为 $x=h$。

~~~text
y = a(x − h)² + k，a < 0
顶点：(h, k)
对称轴：x = h
最大值：k
~~~

例如 $y=-2(x-1)^2+3$ 的顶点是 $(1,3)$，对称轴为 $x=1$，最大值是 3。

## 四、对称轴两侧的对应点

对称轴左右等距离的两个 $x$ 值，会得到相同的 $y$ 值。对函数 $y=-2(x-1)^2+3$，对称轴为 $x=1$：

~~~text
x = 0：y = −2(−1)² + 3 = 1
x = 2：y = −2(1)² + 3 = 1
~~~

所以 $(0,1)$ 与 $(2,1)$ 关于直线 $x=1$ 对称。绘制图像时可以先求一侧的点，再利用对称轴得到另一侧对应点。

## 五、一般式中的对称轴与顶点

无论 $a$ 为正还是为负，二次函数 $y=ax^2+bx+c$ 的对称轴都是：

~~~text
x = −b/(2a)
~~~

把对称轴的横坐标代回原函数，求出顶点的纵坐标。若 $a<0$，所得顶点就是最大点。

例如 $y=-x^2+4x-3$ 中 $a=-1$、$b=4$、$c=-3$：

~~~text
对称轴：x = −4/[2 × (−1)] = 2
顶点的 y 值：−2² + 4 × 2 − 3 = 1
顶点：(2, 1)
~~~

## 六、纵轴截距

纵轴上的点满足 $x=0$，所以一般式 $y=ax^2+bx+c$ 的纵轴截距点仍是 $(0,c)$，与 $a$ 的正负无关。

~~~text
x = 0 → y = c
纵轴截距点：(0, c)
~~~

例如 $y=-x^2+4x-3$ 的纵轴截距为 $-3$，图像经过 $(0,-3)$。注意开口向下不代表纵轴截距一定为负；截距由 $c$ 决定。

## 七、横轴交点

图像与横轴相交时 $y=0$，所以横轴交点的横坐标是二次方程 $ax^2+bx+c=0$ 的实数解。对于 $y=-x^2+4x-3$：

~~~text
0 = −x² + 4x − 3
  = −(x − 1)(x − 3)
x = 1 或 x = 3
~~~

因此横轴交点为 $(1,0)$ 和 $(3,0)$。顶点 $(2,1)$ 正好位于这两个交点的中间，并在它们上方。

## 八、顶点高度决定横轴交点数量

若 $a<0$，顶点为最高点。观察顶点相对于横轴的位置，可以判断抛物线与横轴的交点个数：

~~~text
顶点在横轴上方：与横轴有两个交点
顶点在横轴上：与横轴有一个交点（相切）
顶点在横轴下方：与横轴没有交点
~~~

这里假设函数定义域包含所有实数。抛物线从最高点向两侧下降，因此顶点的高度决定它能否穿过横轴。

## 九、绘制开口向下的图像

以 $y=-x^2+4x-3$ 为例，先确定对称轴 $x=2$、顶点 $(2,1)$、纵轴截距 $(0,-3)$ 和横轴交点 $(1,0)$、$(3,0)$。再利用对称性得到点 $(4,-3)$。

~~~text
关键点：(0, −3)，(1, 0)，(2, 1)，(3, 0)，(4, −3)
图像关于 x = 2 对称，开口向下
~~~

标记关键点后，用平滑曲线连接；顶点应是曲线最高处，左右两侧呈镜像关系。

## 十、定义域与值域

若没有额外限制，二次函数的定义域为所有实数。若 $a<0$ 且顶点为 $(h,k)$，函数值不会超过 $k$，因此值域为 $y\le k$。

~~~text
定义域：所有实数（若题目没有额外限制）
值域：y ≤ k，其中 (h, k) 是顶点
~~~

实际情境可能限制自变量范围；若顶点不在允许范围内，实际最大值还需结合定义域判断，不能直接套用整条抛物线的顶点结论。

## 十一、实际情境中的最大值

开口向下的二次函数常用于描述有最大值的情境，例如抛出的物体高度随时间变化。若抛物线顶点为 $(h,k)$，则在完整模型中，$x=h$ 时函数值达到最大 $k$。

~~~text
h：达到最大值时的自变量
k：最大函数值
~~~

实际问题还要解释变量代表什么、单位是什么，以及顶点是否落在题目允许的时间或距离范围内。

## 十二、常见错误

- $a<0$ 时仍把抛物线画成开口向上，或把顶点当作最低点。
- 把对称轴公式中的 $a$ 忘记带负号，或把整个 $2a$ 放在分母之外。
- 把一般式中的 $b$ 当作纵轴截距；纵轴截距是 $c$。
- 用顶点式读顶点时忽略括号中的符号，例如 $x+2=x-(-2)$，顶点横坐标是 $-2$。
- 把横轴交点和纵轴截距混淆。
- 依据开口方向判断截距符号；截距由常数项决定。
- 在实际问题中忽略定义域限制，直接把顶点作为实际最大值。

## 十三、回顾

当 $a<0$ 时，二次函数图像是开口向下的抛物线，顶点为最高点。对称轴仍为 $x=-b/(2a)$；纵轴截距为 $(0,c)$；横轴交点由令 $y=0$ 求得。若顶点为 $(h,k)$，且定义域为所有实数，则最大值为 $k$、值域为 $y\le k$。

绘图时先找对称轴和顶点，再标出截距及成对的对称点，最后画出平滑的开口向下曲线，并结合定义域解释图像结论。
