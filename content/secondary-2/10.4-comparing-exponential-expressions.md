# 10.4 比较指数式的大小

比较两个指数式时，不要只看底数或指数哪个大。底数和指数都会影响幂的大小，底数是否大于 1、是否为负数，也会改变比较方法。

本节先把式子化成熟悉的形式，再选用同底数、同指数、倒数关系或估算来判断。

## 一、先确定底数的范围

在比较前先辨认底数是：

~~~text
大于 1：幂随指数增大而增大
介于 0 与 1 之间：幂随指数增大而减小
等于 1：任何指数幂都等于 1
~~~

负底数还要考虑指数奇偶。本节涉及分数指数时，底数取正数，以保证根式在实数范围内有定义。

## 二、同底数且底数大于 1

若底数 $a>1$，指数越大，幂越大。因此比较同底数幂时，只需比较指数：

~~~text
a > 1 且 m > n  ⇒  aᵐ > aⁿ
~~~

例如：

~~~text
3⁵ 与 3⁴ 比较
因为底数 3 > 1，且 5 > 4，所以 3⁵ > 3⁴
~~~

底数大于 1 时，每多乘一个底数，数值就增大。

## 三、同底数且底数在 0 与 1 之间

若 $0<a<1$，每乘一次底数，数值会变小。因此指数越大，幂越小：

~~~text
0 < a < 1 且 m > n  ⇒  aᵐ < aⁿ
~~~

例如：

~~~text
(1/2)² = 1/4
(1/2)³ = 1/8
所以 (1/2)² > (1/2)³
~~~

不能把底数大于 1 时的比较方向直接套用到小于 1 的正底数上。

## 四、同指数且底数为正

若两个正底数使用相同的正指数，底数较大，幂也较大：

~~~text
0 < a < b 且 n > 0  ⇒  aⁿ < bⁿ
~~~

例如：

~~~text
4³ 与 5³ 比较
因为 4 < 5，所以 4³ < 5³
~~~

这个规则也适用于相同的正分数指数，例如 $2^{1/2}<5^{1/2}$，因为平方根函数在正数范围内保留大小顺序。

## 五、把底数改写成共同底数

不同底数的幂可以尝试改写成同一个底数，再比较指数：

~~~text
8⁴ 与 4⁶
8⁴ = (2³)⁴ = 2¹²
4⁶ = (2²)⁶ = 2¹²
所以 8⁴ = 4⁶
~~~

两边都化为同底数同指数后，便可看出它们相等。

## 六、共同底数示例

比较 $16^3$ 与 $8^4$：

~~~text
16³ = (2⁴)³ = 2¹²
8⁴ = (2³)⁴ = 2¹²
~~~

所以 $16^3=8^4$。转化时使用幂的乘方法则，外层指数与底数改写出的指数相乘。

## 七、比较不同指数的幂

如果底数与指数都不同，可分别寻找共同底数或共同指数，或者计算出可比较的精确数值。

例如：

~~~text
3⁵ = 243
5³ = 125
因此 3⁵ > 5³
~~~

若数值较大，不一定要展开全部乘积；可以先寻找幂的改写关系，或用有根据的估算。

## 八、负指数与倒数

负指数表示正整数次幂的倒数。对正数底数，先改写成倒数通常更容易比较：

~~~text
2⁻³ = 1/2³ = 1/8
4⁻² = 1/4² = 1/16
~~~

由于 $1/8>1/16$，所以 $2^{-3}>4^{-2}$。比较正分数时，分子相同为 1，分母较小的分数较大。

## 九、倒数会反转大小关系

若 $0<a<b$，则它们的倒数大小相反：

~~~text
1/a > 1/b
~~~

例如 $2<5$，但 $1/2>1/5$。遇到负指数时，如果化成正数的倒数，必须留意大小方向已经反转。

## 十、指数为负时同底数的变化

对底数 $a>1$，指数越大幂越大，这条规律也适用于负整数指数：

~~~text
2⁻² = 1/4
2⁻¹ = 1/2
~~~

因为 $-2<-1$，所以 $2^{-2}<2^{-1}$。指数从 −2 增加到 −1，数值从 1/4 增加到 1/2。

若底数在 0 与 1 之间，指数增加时幂反而减小；无论指数为正、零或负，都要先判断底数范围。

## 十一、比较分数指数幂

可把分数指数改写成根式，或比较指数本身。对于 $a>1$，指数越大，幂越大；例如：

~~~text
2^(3/2) 与 2^(4/3)
3/2 > 4/3，且底数 2 > 1
所以 2^(3/2) > 2^(4/3)
~~~

也可以化为根式：$2^{3/2}=2\sqrt2$，$2^{4/3}=\sqrt[3]{16}$，再借助已知幂或估算比较。

## 十二、利用熟悉的平方根比较

若两个待比较的数都是正数，可以在保持大小顺序的操作下比较它们的平方。比如比较 $2\sqrt3$ 与 3：

~~~text
(2√3)² = 12
3² = 9
因为 12 > 9，所以 2√3 > 3
~~~

这里两边原本都是正数，平方后大小关系保持。若比较的数可能为负，不能不加判断地平方两边。

## 十三、用乘方夹住数值

若难以精确求根，可以利用相邻整数的幂夹住根，再比较。例如判断 $\sqrt[3]{20}$ 是否大于 2：

~~~text
2³ = 8 < 20
所以 ∛20 > 2
~~~

因为正数的立方随数值增大而增大。类似地，比较正数的 n 次方根时，可以比较它们的被开方数或用整数幂作界限。

## 十四、特殊底数 0 与 1

在指数有定义的范围内：

~~~text
1ᵐ = 1
0ⁿ = 0（n 为正整数）
~~~

以 1 为底的幂不会随指数改变；以 0 为底的正整数次幂为 0。零底数的零指数和负指数不在这些规则的适用范围内。

## 十五、比较前先统一表达

可以按以下顺序选择方法：

~~~text
底数相同 → 比指数，并检查底数与 1 的关系
指数相同、底数为正 → 比底数
底数不同 → 尝试改写为共同底数
出现负指数 → 改写为倒数，检查大小方向
出现根式 → 改写为分数指数或用乘方夹界
仍不明显 → 精确计算或合理估算
~~~

不必对每一题使用同一种方法；选择步骤最少且理由清楚的方法即可。

## 十六、估算与计算器的使用

计算器可以帮助检查不易心算的指数式，但比较时仍要理解结果的来源。输入负底数时应加括号，例如 (-2)^5 与 -2^5 含义不同。

若两个数非常接近，显示的小数位数可能不足以判断大小。可增加精度、改用精确的共同底数关系，或用平方、立方等方法验证，不要只凭四舍五入后的显示值下结论。

## 十七、常见错误

- 只看指数大小，不看底数是大于 1 还是介于 0 与 1 之间。
- 认为底数和指数都较大的式子一定较大。
- 把不同底数的指数直接相加或比较。
- 将负指数误认为负数，或取倒数后忘记大小关系反转。
- 对可能为负的数直接平方比较，却未确认平方保序的条件。
- 输入计算器时忽略负底数的括号。
- 只凭近似小数比较非常接近的数，忽略计算精度。

## 十八、回顾

比较指数式大小时，先看底数和指数的结构。正底数同底数幂比较，要区分底数大于 1 与介于 0、1 之间；同指数的正底数幂可比较底数；不同底数时可改写为共同底数；负指数可改写成倒数，但大小方向要相应检查。

分数指数可以转换为根式，必要时用乘方、估算或计算器辅助验证。每个结论都要注明适用条件，而不能只凭“底数大”或“指数大”判断。
