# 11.10 两点之间的距离

在坐标平面中，两点的横坐标差表示水平方向的距离，纵坐标差表示竖直方向的距离。这两个方向互相垂直，因此可以把它们作为直角三角形的两条直角边，再用勾股定理求两点间的线段长度。

~~~
点 P(x₁, y₁) 与 Q(x₂, y₂)：
水平差：x₂ − x₁
竖直差：y₂ − y₁
距离：d = √[(x₂ − x₁)² + (y₂ − y₁)²]
~~~

## 一、横向与纵向的坐标差

在坐标平面上，从点 $P(x_1,y_1)$ 移动到点 $Q(x_2,y_2)$，横坐标改变 $x_2-x_1$，纵坐标改变 $y_2-y_1$。水平和竖直方向互相垂直。

求长度时，差值的正负表示变化方向；实际长度取差值的绝对值。公式将两个差值平方，因此点的先后顺序不会影响距离。

## 二、从勾股定理得到距离公式

以线段 $PQ$ 为斜边，经过 $P$ 或 $Q$ 作一条水平线和一条竖直线，可以构成直角三角形。两条直角边长分别是 $|x_2-x_1|$ 和 $|y_2-y_1|$。

~~~
d² = |x₂ − x₁|² + |y₂ − y₁|²
d² = (x₂ − x₁)² + (y₂ − y₁)²
d = √[(x₂ − x₁)² + (y₂ − y₁)²]
~~~

这就是两点距离公式。根号取非负值，因为距离是非负长度。

## 三、公式中的点与坐标顺序

设两个点为 $P(x_1,y_1)$ 和 $Q(x_2,y_2)$，则：

~~~
d(P,Q) = √[(x₂ − x₁)² + (y₂ − y₁)²]
~~~

公式中第一个括号比较两个横坐标，第二个括号比较两个纵坐标。只要前后保持一致，交换两点的顺序也会得到相同距离。

## 四、求一般两点间的距离

求 $A(1,2)$ 与 $B(4,6)$ 之间的距离：

~~~
d = √[(4 − 1)² + (6 − 2)²]
  = √[3² + 4²]
  = √25
  = 5
~~~

所以 $AB=5$ 个坐标单位。横向相差 3 个单位，纵向相差 4 个单位，正好构成 $3$、$4$、$5$ 的直角三角形。

## 五、含负坐标的例子

求 $P(-2,1)$ 与 $Q(4,9)$ 之间的距离。先正确计算包含负数的坐标差：

~~~
d = √[(4 − (−2))² + (9 − 1)²]
  = √[6² + 8²]
  = √100
  = 10
~~~

两点间距离为 10 个坐标单位。写成 $4-(-2)$ 时要加括号，避免把减去负数误算成减去正数。

## 六、水平线段与竖直线段

若两点纵坐标相同，线段水平，纵坐标差为 0，距离就是横坐标差的绝对值。若两点横坐标相同，线段竖直，距离就是纵坐标差的绝对值。

~~~
同一水平线上：(x₁, y) 与 (x₂, y)
d = |x₂ − x₁|

同一竖直线上：(x, y₁) 与 (x, y₂)
d = |y₂ − y₁|
~~~

例如 $C(2,-3)$ 与 $D(8,-3)$ 的距离是 $|8-2|=6$；$E(-1,4)$ 与 $F(-1,-2)$ 的距离是 $|-2-4|=6$。

## 七、距离可能是根式

不是所有坐标差都会形成整数边长。求 $M(0,0)$ 与 $N(2,1)$ 之间的距离：

~~~
d = √[(2 − 0)² + (1 − 0)²]
  = √5
~~~

精确距离是 $\sqrt5$ 个坐标单位。若题目要求近似值，可以写成约 2.24 个坐标单位；否则应保留根式。

## 八、用距离公式检查图形信息

距离公式可帮助判断坐标图中线段的长度是否相等。例如求三角形三边长度后，可以检查是否有两边相等，或判断图形是否包含直角条件。若使用直角判定，还应确认比较的是最长边与另外两边平方和。

距离公式给出两点之间的直线段长度，不表示沿折线或道路实际行走的总路程。

## 九、单位与坐标刻度

若坐标轴每个单位代表 1 cm，公式求出的距离单位为 cm；若每格代表 2 km，则坐标差要按实际刻度换算后再求距离，或先在坐标单位下计算并最后乘以比例。

~~~
坐标单位 ≠ 必然等于 1 m 或 1 cm
先读轴的刻度和单位，再解释距离
~~~

若横轴和纵轴使用不同的比例尺，应先换算成同一实际单位，再把水平、竖直实际长度代入勾股定理。

## 十、距离公式的性质

距离具有以下基本性质：

~~~
d(P,Q) ≥ 0
d(P,Q) = d(Q,P)
同一点到自身的距离为 0
~~~

公式中两个坐标差平方后相加，因此不会得到负的距离。交换两点只会同时改变两个差值的符号，平方结果保持不变。

## 十一、常见错误

- 把横坐标差与纵坐标差相加，而不是分别平方后相加。
- 忘记对平方和开平方，误把距离写成距离的平方。
- 负坐标相减时漏掉括号，算错坐标差。
- 混淆 $(x,y)$ 的顺序，把横坐标和纵坐标对调。
- 忽略坐标轴刻度或单位，直接把格数当成实际长度。
- 把直线距离当成沿道路或折线的总路程。
- 对根式擅自取整或过早近似。

## 十二、回顾

两点距离公式由勾股定理得到：水平坐标差和竖直坐标差是直角三角形的两条直角边，线段长度为斜边。因此
$d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$。

代入时先认清每个点的坐标顺序，正确处理负数，并保留精确根式或按要求近似。若坐标代表实际位置，还要结合坐标轴的刻度与单位解释答案。
