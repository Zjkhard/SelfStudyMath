# 10.29 三角形内角与外角

三角形的三个内角之和为 $180^\circ$。把一条边延长后，三角形外部形成的角称为外角；外角与同一顶点的相邻内角互补，并且等于另外两个不相邻内角之和。掌握这两条关系，就能从不同角度求三角形中的未知角。

~~~text
内角和：A + B + C = 180°
相邻内角与外角：外角 + 相邻内角 = 180°
外角定理：外角 = 两个不相邻内角之和
~~~

## 一、三角形的内角和

任意三角形的三个内角之和都是 $180^\circ$。若两个角已知，第三个角可由 $180^\circ$ 减去前两个角的和求出。

~~~text
∠A + ∠B + ∠C = 180°
∠C = 180° − ∠A − ∠B
~~~

例如，若两个内角分别为 $48^\circ$ 和 $67^\circ$，第三个内角为 $180^\circ-48^\circ-67^\circ=65^\circ$。

## 二、为什么三角形内角和是 180°

过三角形一个顶点作与对边平行的直线。根据平行线与截线的角关系，另外两个内角分别与这条直线上的两个角相等；三个角拼在一起构成一条直线上的平角，因此总和为 $180^\circ$。

~~~text
平行线角关系：两底角分别对应到顶点处
直线角：三个相邻角组成 180°
所以三角形内角和 = 180°
~~~

这个论证把前一节的平行线角性质与三角形内角和联系起来。

## 三、利用内角和列方程

一个三角形的三个内角分别为 $x^\circ$、$(x+20)^\circ$ 和 $(2x+10)^\circ$。求三个角。

~~~text
x + (x + 20) + (2x + 10) = 180
4x + 30 = 180
4x = 150
x = 37.5
~~~

三个角分别为 $37.5^\circ$、$57.5^\circ$ 和 $85^\circ$，它们的和为 $180^\circ$。代数求解后，应回到角度意义检查结果。

## 四、三角形外角的定义

把三角形的一条边延长，在顶点处由延长线与另一条边形成的、位于三角形外部的角称为外角。外角与该顶点的内角共用一条边，另外两边组成一条直线，所以它们是一对邻补角。

~~~text
外角 + 相邻内角 = 180°
~~~

例如，若相邻内角为 $125^\circ$，外角为 $180^\circ-125^\circ=55^\circ$。

## 五、三角形外角定理

三角形的一个外角等于两个不相邻内角之和。这两个不相邻内角也称为远内角。

~~~text
外角 = 远内角 1 + 远内角 2
~~~

例如，若两个远内角为 $38^\circ$ 和 $71^\circ$，外角为 $38^\circ+71^\circ=109^\circ$。它也与相邻内角互补，因此相邻内角是 $71^\circ$。

## 六、从内角和推出外角定理

设三角形内角为 $A,B,C$，在 $C$ 处的外角为 $D$。内角和给出 $A+B+C=180^\circ$；邻补角关系给出 $C+D=180^\circ$。两式右边相等，消去 $C$ 后得到：

~~~text
A + B + C = 180°
C + D = 180°
所以 D = A + B
~~~

这说明外角定理与内角和、直线角关系一致。

## 七、用外角关系求未知数

一个三角形的两个远内角为 $(x+15)^\circ$ 和 $(2x-5)^\circ$，相邻内角为 $70^\circ$。求 $x$。

外角与 $70^\circ$ 的内角互补，所以外角为 $110^\circ$；再用外角定理：

~~~text
(x + 15) + (2x − 5) = 110
3x + 10 = 110
3x = 100
x = 100/3
~~~

两个远内角分别为 $145/3^\circ$ 与 $185/3^\circ$，其和为 $110^\circ$；加上相邻内角 $70^\circ$，三个内角之和为 $180^\circ$。角度出现分数并不代表计算错误。

## 八、外角比远内角大

三角形的每个内角都大于 $0^\circ$，所以外角是两个正的远内角之和，必定大于其中任意一个远内角。

~~~text
外角 = 两个远内角之和
因此外角 > 每一个远内角
~~~

这条关系可以用来判断答案是否合理：若算出的外角小于其中一个远内角，通常是列式或计算出错。

## 九、延长不同的边

在同一个顶点延长不同边，会得到位置不同的外角。通常所说的一个外角，是与该顶点内角相邻且组成直线角的角；对应的关系仍是“外角与相邻内角互补”。作图或读图时要明确指出使用的是哪个外角。

~~~text
先识别外角的顶点
再找与它相邻的内角
最后找另外两个远内角
~~~

## 十、综合角度关系

求角时可把三类关系组合使用：三角形内角和、外角与相邻内角互补、外角等于两个远内角之和。必要时还可使用对顶角、平行线角关系。

~~~text
已知内角 → 用内角和求第三角
已知外角与相邻内角 → 用 180° 互补
已知两个远内角 → 用外角定理求外角
~~~

每次使用关系时，都要明确角的顶点和位置，不能只依据图形看起来的大小判断。

## 十一、常见错误

- 把三角形内角和误写为 $360^\circ$。
- 把外角和相邻内角说成相等，而不是互补。
- 使用外角定理时，把相邻内角误当成远内角。
- 把两个远内角相减来求外角，而不是相加。
- 列方程时漏掉角表达式中的括号或单位。
- 得到未知数后没有计算各角并检查内角和。
- 不辨认具体外角，就套用不对应的角关系。

## 十二、回顾

三角形内角和为 $180^\circ$。三角形外角与相邻内角互补，并等于两个不相邻内角之和。求未知角时，可根据已知角的位置选用相应关系，也可以把角的代数表达式代入关系式列方程。

结果应满足角度范围，并能通过内角和、邻补角或外角定理进行检验。
