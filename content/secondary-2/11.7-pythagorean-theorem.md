# 11.7 勾股定理

勾股定理描述直角三角形三边长度之间的关系：两条直角边的平方和等于斜边的平方。斜边是直角所对的边，也是三边中最长的一边。定理只适用于直角三角形。

~~~text
a² + b² = c²
a、b：直角边
c：斜边
~~~

## 一、辨认斜边与直角边

先找出三角形中的直角。构成直角的两条边叫直角边；直角所对的边叫斜边。斜边不一定是图上看起来最长的水平边或竖直边，但它一定是直角三角形最长的一边。

~~~text
直角两侧的边 → 直角边
直角对面的边 → 斜边
~~~

标记字母时通常用 $a,b$ 表示两条直角边，用 $c$ 表示斜边。斜边对应公式右侧的 $c^2$。

## 二、勾股定理

若一个直角三角形的直角边长为 $a$、$b$，斜边长为 $c$，则：

~~~text
a² + b² = c²
~~~

例如直角边长为 3 cm 和 4 cm，则斜边满足 $c^2=3^2+4^2=25$，所以 $c=5$ cm。边长为正，因此取正平方根。

## 三、定理与正方形面积

可以在直角三角形的三条边上分别作正方形。边长为 $a$、$b$、$c$ 的正方形面积分别是 $a^2$、$b^2$、$c^2$。勾股定理说明：

~~~text
两条直角边上正方形的面积和
= 斜边上正方形的面积
a² + b² = c²
~~~

这也是定理名称中“平方”关系的一种几何理解。

## 四、已知两条直角边求斜边

一个直角三角形的两条直角边分别为 6 m 和 8 m。设斜边为 $c$：

~~~text
c² = 6² + 8²
   = 36 + 64
   = 100
c = √100 = 10 m
~~~

答案为 10 m。斜边比任意一条直角边都长，可用来快速检查结果是否合理。

## 五、已知斜边和一条直角边求另一条直角边

若斜边为 13 cm，一条直角边为 5 cm，另一条直角边设为 $x$：

~~~text
x² + 5² = 13²
x² = 169 − 25
x² = 144
x = √144 = 12 cm
~~~

这里应从斜边平方中减去已知直角边的平方。若反过来相加，会得到比斜边还长的直角边，与三角形结构不符。

## 六、何时保留根式

并非所有平方根都是整数。若两条直角边长为 1 和 1，则斜边为：

~~~text
c² = 1² + 1² = 2
c = √2
~~~

$\sqrt2$ 是精确答案。若题目要求小数近似值，可写成 $c\approx1.41$，并按要求的精度取舍。没有要求近似时，不要过早把根式换成有限小数。

## 七、常见整数边长组

满足勾股定理的整数边长组称为勾股数，例如 $(3,4,5)$、$(5,12,13)$ 和 $(8,15,17)$。若一组勾股数的每个数都乘以相同正数，仍满足定理。

~~~text
3² + 4² = 5²
5² + 12² = 13²
8² + 15² = 17²
~~~

熟悉这些数可以帮助估算或检查答案，但解决问题仍应根据已知边建立正确的平方关系。

## 八、把图形信息转化为方程

应用定理前，先确认图形是直角三角形，并把已知长度标在对应边上。再根据直角确定斜边，最后代入公式。

~~~text
确认直角
→ 标出斜边和两条直角边
→ 写 a² + b² = c²
→ 代入边长并求解
→ 检查长度和单位
~~~

即使图形画得不按比例，也应根据直角标记而不是视觉形状判断边的角色。

## 九、长度单位与答案

平方项的单位是面积单位。例如边长以厘米表示时，$a^2$、$b^2$、$c^2$ 的单位都是 cm²；求出边长后，再用 cm 作答案单位。

~~~text
长度：cm
平方后的长度：cm²
最终所求边长：cm
~~~

代入之前应统一长度单位。例如一边用米、另一边用厘米时，先换算成同一单位。

## 十、勾股定理的适用范围

勾股定理的前提是三角形有一个 $90^\circ$ 角。对一般的锐角三角形或钝角三角形，不能直接使用 $a^2+b^2=c^2$。

~~~text
已知是直角三角形 → 可使用勾股定理
没有直角条件 → 不能直接套用该定理
~~~

下一课将学习勾股定理的逆定理，用三边长度判断一个三角形是否为直角三角形。

## 十一、常见错误

- 没有先确认直角三角形，就套用勾股定理。
- 把斜边误认为图上最长的水平边或竖直边，而没有找直角所对的边。
- 把斜边平方放在等式左侧相加，或将直角边误当斜边。
- 求直角边时把两条平方相加，而不是从斜边平方中相减。
- 求平方根后保留负边长，或忘记边长取正值。
- 提前把根式取近似，造成精度损失。
- 混用不同长度单位，或将边长单位和平方单位混淆。

## 十二、回顾

在直角三角形中，若两条直角边为 $a,b$，斜边为 $c$，则 $a^2+b^2=c^2$。已知两条直角边时求斜边，先将平方相加再开平方；已知斜边和一条直角边时求另一边，先用斜边平方减去已知直角边的平方。

使用前确认直角，求解时认清斜边，最后检查边长大小、单位和答案精度。
