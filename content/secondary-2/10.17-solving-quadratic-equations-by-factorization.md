# 10.17 用因式分解法解二次方程

二次方程的未知数最高次数是 2。若方程可以因式分解，常能把它化为两个因式的乘积等于 0，再分别求出未知数。

~~~text
x² − 5x + 6 = 0
(x − 2)(x − 3) = 0
~~~

这一步的关键依据是零乘积性质，而不是把乘积中的两个因式直接“拆开”。

## 一、零乘积性质

若两个数的乘积等于 0，那么至少有一个因数等于 0：

~~~text
AB = 0  ⇒  A = 0 或 B = 0
~~~

因此若 $(x-2)(x-3)=0$，就分别考虑 $x-2=0$ 或 $x-3=0$。

## 二、先整理成等于零的形式

因式分解法要求方程一边是 0。标准形式为：

~~~text
ax² + bx + c = 0，其中 a ≠ 0
~~~

若方程右边不是 0，先把所有项移到一边，再合并同类项。

~~~text
x² = 5x − 6
x² − 5x + 6 = 0
~~~

移项时注意符号变化，并确保等号右边变成 0。

## 三、完整例题：二次三项式

解方程：

~~~text
x² − 5x + 6 = 0
~~~

左边因式分解为：

~~~text
(x − 2)(x − 3) = 0
~~~

由零乘积性质：

~~~text
x − 2 = 0  或  x − 3 = 0
x = 2      或  x = 3
~~~

所以方程的解为 2 和 3。

## 四、将解代回原方程检验

~~~text
x = 2：2² − 5×2 + 6 = 4 − 10 + 6 = 0
x = 3：3² − 5×3 + 6 = 9 − 15 + 6 = 0
~~~

两个值都满足原方程，因此没有漏解或多解。

## 五、系数不为 1 的二次项

解方程：

~~~text
2x² + x − 3 = 0
~~~

先因式分解：

~~~text
(2x + 3)(x − 1) = 0
~~~

分别令因式为 0：

~~~text
2x + 3 = 0  或  x − 1 = 0
x = −3/2    或  x = 1
~~~

解为 $-\frac32$ 和 1。二次方程的解不一定都是整数。

## 六、先提取公因数

解：

~~~text
3x² − 12x = 0
~~~

先提取公因数：

~~~text
3x(x − 4) = 0
~~~

因此：

~~~text
3x = 0  或  x − 4 = 0
x = 0   或  x = 4
~~~

方程有两个解：0 和 4。提取公因数后，两个因式都要分别考虑。

## 七、为什么不能直接除以 x

方程 $3x²-12x=0$ 可以写成 $3x(x-4)=0$。如果直接两边除以 $x$，就会得到 $3x-12=0$，只求出 $x=4$，漏掉了 $x=0$。

因为 $x$ 可能等于 0，不能在不知道 $x\ne0$ 的情况下除以 $x$。应使用零乘积性质，分别求 $3x=0$ 和 $x-4=0$。

## 八、先把右边移到左边再分解

解 $x²+2x=15$：

~~~text
x² + 2x − 15 = 0
(x + 5)(x − 3) = 0
~~~

所以：

~~~text
x + 5 = 0  或  x − 3 = 0
x = −5     或  x = 3
~~~

先整理成等于零，再分解。若直接把 $x²+2x$ 因式分解后令其因式为零，会改变原方程。

## 九、利用平方差公式解方程

解：

~~~text
x² = 9
~~~

先移项，再用平方差公式：

~~~text
x² − 9 = 0
(x + 3)(x − 3) = 0
~~~

因此 $x=-3$ 或 $x=3$。两个解都要保留，因为平方后正数和负数都可能得到 9。

## 十、利用完全平方式解方程

~~~text
(x − 4)² = 0
(x − 4)(x − 4) = 0
x − 4 = 0
x = 4
~~~

这里两个因式相同，得到同一个解 4。有时称它为重根；作为不同的解值，只有一个。

## 十一、因式分解与求解步骤

1. 将方程整理成一边为 0；
2. 合并同类项并提取公因数；
3. 用适当方法将左边完全因式分解；
4. 对每个因式分别列出“因式等于 0”；
5. 解所得的一元一次方程；
6. 检验解是否满足原方程。

因式分解不完整可能造成漏解；方程未整理为零等式就使用零乘积性质，可能得到错误结果。

## 十二、每个因式都要为零的情形

若方程有三个因式：

~~~text
x(x − 2)(x + 5) = 0
~~~

至少一个因式为零，所以：

~~~text
x = 0，或 x − 2 = 0，或 x + 5 = 0
~~~

解为 $x=0$、$x=2$ 或 $x=-5$。有多少个一次因式，就要逐一检查它们对应的方程。

## 十三、因式分解法并非总能直接使用

例如某个二次三项式若不能按已学方法因式分解，就不能强行拼出两个因式。先检查是否有公因数、平方差或完全平方结构，再尝试二次三项式拆项分组。

本单元重点是可因式分解的方程。遇到不能用当前整数因数方法分解的二次方程，应保留原式并学习后续方法时再处理，不要把“无法因式分解”误说成“方程没有解”。

## 十四、检查解的合理性

把每个候选解代回原方程左边，计算是否等于右边。若题目来自实际情境，还要结合情境筛选，例如长度通常为正数，物品数量通常为非负整数。

数学方程的解与情境中可接受的答案可能不同；情境限制不能替代代数求解，但会影响最终解释。

## 十五、常见错误

- 没有把方程整理成一边为 0。
- 将乘积等于某个非零数时错误使用零乘积性质。
- 因式分解后只解一个因式，漏掉其他解。
- 直接除以含未知数的因式，漏掉该因式等于 0 的解。
- 因式中系数不为 1 时求解错误，例如 $2x+3=0$。
- 把完全平方方程的重复因式误认为两个不同的解。
- 将无法因式分解误判为无解。
- 求出结果后不代回检验。

## 十六、回顾

因式分解法利用零乘积性质：若 $A·B=0$，则 $A=0$ 或 $B=0$。先将二次方程化为等于 0 的形式，再因式分解、逐个令因式为零并求解。

不要在未知数可能为 0 时随意除以含未知数的因式；应保留所有因式对应的解，并代回原方程检验。下一课将把二次方程放入实际问题中建模和求解。
