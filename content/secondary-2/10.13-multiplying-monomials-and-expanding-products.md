# 10.13 单项式乘法与代数式乘积的展开

在长方形的长和宽都由代数式表示时，面积等于长乘宽。例如长为 $x+2$、宽为 $x+3$，面积可以先写成 $(x+2)(x+3)$，也可以展开成由若干项组成的代数式。

本节从单项式相乘开始，再用分配律展开代数式的乘积。

## 一、什么是单项式

单项式是数字、字母及其乘积组成的代数式。数字部分叫系数，字母部分表示变量因式：

~~~text
−5x²y：系数是 −5，字母因式是 x²y
3ab³：系数是 3，字母因式是 ab³
7：常数也是单项式
~~~

相乘时，先分别处理系数和字母因式。

## 二、单项式相乘：系数相乘

单项式相乘时，系数按整数乘法计算：

~~~text
4x × (−3y) = −12xy
~~~

正系数乘负系数得负数；负系数乘负系数得正数。先确定符号，再处理字母因式，有助于减少错误。

## 三、同底数幂的指数相加

相同字母的幂相乘时，指数相加：

~~~text
x² × x³ = x⁵
~~~

因为左边共有五个 $x$ 因子。若字母不同，就保留为不同因式：

~~~text
a² × b³ = a²b³
~~~

不能把不同底数的指数合并。

## 四、单项式乘单项式的完整步骤

~~~text
(3x²y)(−2xy³)
= 3×(−2) × x²×x × y×y³
= −6x³y⁴
~~~

系数相乘得到 −6；$x$ 的指数 $2+1=3$，$y$ 的指数 $1+3=4$。

## 五、单项式相乘的更多例子

~~~text
(−4a²b)(3ab³) = −12a³b⁴
(2m³n²)(5mn) = 10m⁴n³
~~~

每个字母分别与相同字母合并；不要把 $m$ 和 $n$ 的指数交叉相加。

## 六、单项式乘以括号：分配律

单项式乘以括号内的每一项：

~~~text
a(b + c) = ab + ac
~~~

例如：

~~~text
3x(2x − 5)
= 3x×2x − 3x×5
= 6x² − 15x
~~~

括号外的 $3x$ 必须乘到括号内两项，不能只乘第一项。

## 七、负号也要分配到每一项

~~~text
−2(3x − 4)
= (−2)×3x + (−2)×(−4)
= −6x + 8
~~~

负数乘括号中的负项会得到正项。可把括号外系数写在每个乘积中，避免漏掉符号变化。

## 八、两个括号相乘的分配过程

两个二项式相乘时，第一括号的每一项都要分别乘第二括号的每一项：

~~~text
(a + b)(c + d)
= ac + ad + bc + bd
~~~

四项分别来自 $a×c$、$a×d$、$b×c$ 和 $b×d$。检查是否每一对都出现一次，是避免漏项的好方法。

## 九、展开两个二项式

~~~text
(x + 2)(x + 3)
= x×x + x×3 + 2×x + 2×3
= x² + 3x + 2x + 6
= x² + 5x + 6
~~~

先分配相乘，再把 $3x$ 和 $2x$ 合并为 $5x$。展开后通常还要整理同类项。

## 十、带有减号的括号乘积

~~~text
(2x − 1)(x + 4)
= 2x×x + 2x×4 − 1×x − 1×4
= 2x² + 8x − x − 4
= 2x² + 7x − 4
~~~

每一项的符号都来自原式中的因数。特别注意减号属于它后面的项。

## 十一、乘以多项式时逐项分配

同一方法可以用于单项式与三项式相乘：

~~~text
2x(x² − 3x + 4)
= 2x×x² − 2x×3x + 2x×4
= 2x³ − 6x² + 8x
~~~

括号中有几项，括号外的单项式就要乘几次。

## 十二、两个多项式相乘

例如把二项式与三项式相乘，每一项都要与另一括号的每一项相乘：

~~~text
(x + 1)(x² − 2x + 3)
= x³ − 2x² + 3x + x² − 2x + 3
= x³ − x² + x + 3
~~~

展开时可先按第一括号的各项分组，最后合并同类项。合并前先确认所有乘积项都已写出。

## 十三、用面积理解括号乘积

边长为 $x+2$ 和 $x+3$ 的长方形，可以拆成四块：$x×x$、$x×3$、$2×x$、$2×3$。

~~~text
总面积 = x² + 3x + 2x + 6
       = x² + 5x + 6
~~~

这与 $(x+2)(x+3)$ 的展开结果一致。面积分割直观说明了每个部分都要计入总乘积。

## 十四、展开后才能合并同类项

展开是把括号乘积写成加减项；整理是把同类项合并。两步不要混淆：

~~~text
(x + 1)(x + 4)
= x² + 4x + x + 4
= x² + 5x + 4
~~~

$x²$ 项不能与 $x$ 项合并，因为字母部分和指数不同。

## 十五、不要把每项只配一次

展开 $(x+2)(x+3)$ 时，不能只把 $x$ 乘 $x$、把 2 乘 3；交叉乘积 $3x$ 和 $2x$ 也必须包括：

~~~text
(x + 2)(x + 3) ≠ x² + 6
~~~

可以用“每项乘另一括号的每一项”逐一检查，或用面积分块验证。

## 十六、乘积顺序与系数

乘法满足交换律，因此同一组因式的顺序可以调整，但每个因式都不能遗漏：

~~~text
2x × 3y = 3y × 2x = 6xy
~~~

整理时通常先写系数，再按习惯排列字母因式，例如 $6xy$。

## 十七、展开不等于因式分解

展开把因式的乘积写成和或差：

~~~text
(x + 2)(x + 3) → x² + 5x + 6
~~~

因式分解则是把和或差反向写成乘积，之后会单独学习。展开时要顺着分配律逐项相乘。

## 十八、常见错误

- 单项式乘法中忘记系数相乘或符号相乘。
- 同底数幂相乘时没有相加指数，或把不同字母的指数合并。
- 括号外的因式只乘到括号中的一项。
- 两个括号相乘时漏掉交叉项。
- 相减展开时没有给括号内每一项改变符号。
- 合并不是同类项的代数式项。
- 将展开与因式分解的方向混淆。

## 十九、回顾

单项式相乘时，系数相乘；相同字母的指数相加。展开括号乘积时使用分配律：括号外的每项要乘括号内的每项；两个多项式相乘时，每一项都要与另一式中的每一项相乘。

展开后再合并同类项，并检查符号、交叉项和每个因式是否都已处理。下一课将学习平方差和完全平方等特殊乘法公式。
