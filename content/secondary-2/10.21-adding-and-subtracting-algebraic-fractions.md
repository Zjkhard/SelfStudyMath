# 10.21 代数分式加法与减法

代数分式的加法和减法与普通分数类似：分母相同时，分母不变，分子相加或相减；分母不同时，先找到公分母并通分，再合并分子。计算结束后可因式分解、约简，并保留原分母所产生的全部禁取值。

~~~text
记录每个原分母的禁取值
→ 找公分母并通分
→ 将分子作为整体相加或相减
→ 化简、因式分解并约简
→ 写出结果及原式限制
~~~

## 一、分母相同的分式相加

若两个分式的分母相同，可以把分子相加，分母保持不变：

~~~text
A/C + B/C = (A + B)/C
~~~

例如：

~~~text
(2x + 1)/(x − 3) + (x − 4)/(x − 3)
= (2x + 1 + x − 4)/(x − 3)
= (3x − 3)/(x − 3)
= 3
~~~

原分母要求 $x\neq3$。约简结果虽然是常数 3，仍需注明原式的限制 $x\neq3$。

## 二、分母相同的分式相减

相减时，减号作用于后一个分子的每一项。可以用括号明确表示整个分子被减去：

~~~text
A/C − B/C = (A − B)/C
~~~

例如：

~~~text
(5x − 2)/(x + 1) − (2x + 3)/(x + 1)
= [(5x − 2) − (2x + 3)]/(x + 1)
= (5x − 2 − 2x − 3)/(x + 1)
= (3x − 5)/(x + 1)
~~~

原分母要求 $x\neq-1$。常见错误是只改变后一个分子的第一项符号，忘记括号内其余各项也要变号。

## 三、分母为常数倍数时通分

两个分母若容易互相扩展成相同的分母，可把分子、分母同乘适当的因数。

~~~text
1/x + 1/(2x)
= 2/(2x) + 1/(2x)
= 3/(2x)，其中 x ≠ 0
~~~

这里公分母可取 $2x$。原分母 $x$ 与 $2x$ 都要求 $x\neq0$。

## 四、分母不同的代数分式相加

计算 $\frac{x}{x-2}+\frac{3}{x+2}$。两个分母的公分母可取 $(x-2)(x+2)$。原分母要求 $x\neq2,-2$。

~~~text
x/(x − 2) + 3/(x + 2)
= [x(x + 2)]/[(x − 2)(x + 2)]
  + [3(x − 2)]/[(x + 2)(x − 2)]
= [x(x + 2) + 3(x − 2)]/[(x − 2)(x + 2)]
= (x² + 5x − 6)/(x² − 4)
= [(x + 6)(x − 1)]/[(x − 2)(x + 2)]
~~~

结果为 $\frac{(x+6)(x-1)}{(x-2)(x+2)}$，没有共同因式可约。限制仍为 $x\neq2,-2$。

## 五、寻找最简公分母

分母有共同因式时，最简公分母中每个不同因式取它出现过的最高次幂。先将分母因式分解，再确定公分母，通常比直接把两个分母相乘更简洁。

例如分母分别为 $x(x-1)$ 和 $x(x+1)$，最简公分母为 $x(x-1)(x+1)$；共同因式 $x$ 只取一次。

~~~text
1/[x(x − 1)] + 1/[x(x + 1)]
= (x + 1)/[x(x − 1)(x + 1)]
  + (x − 1)/[x(x − 1)(x + 1)]
= 2x/[x(x − 1)(x + 1)]
= 2/[(x − 1)(x + 1)]
~~~

原分母要求 $x\neq0,1,-1$。约去 $x$ 后，仍须保留 $x\neq0$。

## 六、通分时乘以缺少的因式

通分不是只改变分母。分母乘了什么因式，分子也必须乘同一个因式，分式的值才保持不变。

~~~text
1/(x + 2) = (x − 1)/[(x + 2)(x − 1)]
~~~

这个等式要求 $x\neq-2$，并且右边写出的形式还要求 $x\neq1$；若原式并不排除 $x=1$，这种人为引入的限制会改变定义范围。因此选择公分母和通分形式时，应优先使用原分母因式组成的最简公分母，避免无必要地引入额外禁取值。

## 七、分母含二次式时先因式分解

计算 $\frac{1}{x^2-1}+\frac{1}{x+1}$。先分解 $x^2-1=(x-1)(x+1)$，便能看出最简公分母。

~~~text
1/(x² − 1) + 1/(x + 1)
= 1/[(x − 1)(x + 1)] + (x − 1)/[(x − 1)(x + 1)]
= x/[(x − 1)(x + 1)]
~~~

原分母要求 $x\neq1,-1$。因式分解不但帮助找到公分母，也让原式的限制一目了然。

## 八、减法通分时括号不可少

计算 $\frac{2}{x-1}-\frac{1}{x+1}$。原分母要求 $x\neq1,-1$。

~~~text
2/(x − 1) − 1/(x + 1)
= [2(x + 1) − (x − 1)]/[(x − 1)(x + 1)]
= (2x + 2 − x + 1)/[(x − 1)(x + 1)]
= (x + 3)/[(x − 1)(x + 1)]
~~~

减号必须作用于第二个分子的全部项，所以 $-(x-1)=-x+1$。漏掉括号或变号不完整，都会改变结果。

## 九、分子也可能需要整理

通分后，应先正确合并分子同类项，再检查是否能因式分解或约分。不要在合并分子之前跨越加减号约分。

~~~text
1/x − 1/(x + 1)
= (x + 1)/[x(x + 1)] − x/[x(x + 1)]
= 1/[x(x + 1)]
~~~

原分母要求 $x\neq0,-1$。分子中的 $(x+1)-x$ 化简为 1，因此不能与分母中的某个因式约分。

## 十、关于定义范围的提醒

答案的禁取值由原式决定。通分或约简时出现的中间形式，不应无意中缩小原式的定义范围；约去共同因式也不应扩大原式的定义范围。

~~~text
原式每个分母 ≠ 0
约简后仍排除原式的所有禁取值
~~~

如果为了通分而乘上原分母中没有的字母因式，须确认没有额外排除原式原本允许的取值。最简公分母通常能避免这种问题。

## 十一、常见错误

- 分母不同时没有通分，就直接把分子、分母分别相加或相减。
- 通分时只扩充分母，没有对分子乘同一个因式。
- 减法时没有用括号括起后一个分子，导致符号错误。
- 忘记把因式分解后的分母为零的取值记录下来。
- 约去加减式中的一项，而不是约去完整的共同因式。
- 约简后只根据新分母写限制，漏掉原式的禁取值。
- 选用了不必要的公分母，额外引入原式没有的取值限制。

## 十二、回顾

代数分式加减的核心是先通分。分母相同时，分母不变、分子按整体相加或相减；分母不同时，先因式分解并寻找最简公分母，再把各分式改写成同分母形式。

合并后整理分子，必要时因式分解并约简。整个过程中都要记录原分母的禁取值，并确保减号作用于后一个分子的每一项。
