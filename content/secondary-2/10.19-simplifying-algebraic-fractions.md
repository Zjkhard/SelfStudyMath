# 10.19 约简代数分式

分数可以约去分子、分母的共同因数；代数分式也可以约去分子、分母的共同因式。关键是先把多项式分解成因式，再约去完整的共同因式。同时，原分式的分母不能为零，因此约简后也要保留原来的禁取值。

~~~text
找出原分母为零时的取值限制
→ 分解分子与分母
→ 约去共同因式
→ 写出约简结果和原式的限制
~~~

## 一、什么是代数分式

形如两个整式相除的式子称为代数分式，例如 $\frac{x+2}{x-3}$。分母中含有字母时，分母不能等于零；使分母等于零的取值不属于原式的定义范围。

~~~text
分式：  5/8
代数分式： (x + 2)/(x − 3)
~~~

在 $\frac{x+2}{x-3}$ 中，$x-3\neq0$，所以 $x\neq3$。这个限制在开始化简时就应记录下来。

## 二、约分的依据

若分子和分母都含有同一个非零因式 $A$，则可以同时除以 $A$：

~~~text
(A × B)/(A × C) = B/C，前提是 A ≠ 0
~~~

分式约分本质上是分子、分母同时除以相同的非零因式。这里“非零”很重要：如果某取值会让被约去的因式为零，它仍然可能是原分式的禁取值，不能因为因式已经消失就把它加回定义范围。

## 三、先分解，再约分

约简含多项式的代数分式时，通常要先因式分解。只有出现在分子和分母乘积中的共同因式才能约去。

~~~text
(x² − 9)/(x² + 3x)
~~~

先看原分母：$x^2+3x=x(x+3)$，因此 $x\neq0$ 且 $x\neq-3$。再分解分子：

~~~text
(x² − 9)/(x² + 3x)
= [(x − 3)(x + 3)]/[x(x + 3)]
= (x − 3)/x
~~~

约简结果是 $\frac{x-3}{x}$，但原式仍要求 $x\neq0,-3$。特别是 $x=-3$：它使原分母为零，即使约简式在该处有意义，也不属于原式的定义范围。

## 四、单项式中的共同因式

约分也适用于含系数和字母的单项式。系数先约分，同一字母的幂按较小的指数约去。

~~~text
6x²y/(9xy²)
= (6/9) × (x²/x) × (y/y²)
= 2x/(3y)
~~~

原分母 $9xy^2$ 不得为零，因此 $x\neq0$ 且 $y\neq0$。约简后虽然 $x$ 不再出现在分母中，仍须保留 $x\neq0$；而 $y$ 仍在分母中，所以 $y\neq0$ 也必须保留。

## 五、用因式分解识别隐藏的公因式

共同因式有时藏在二次式中。应用已学过的平方差公式、完全平方公式或分解二次三项式的方法，把分子、分母分别分解后再观察。

~~~text
(x² + 5x + 6)/(x² + 4x + 3)
= [(x + 2)(x + 3)]/[(x + 1)(x + 3)]
= (x + 2)/(x + 1)
~~~

原分母 $(x+1)(x+3)$ 不得为零，因此 $x\neq-1,-3$。最终答案为 $\frac{x+2}{x+1}$，并附上这两个原式限制。

## 六、不能约去加减项

不能把分子或分母中的一部分项当作因式约去。约分只针对整个乘积中的共同因式，不能对加法或减法中的单独一项进行约分。

~~~text
错误： (x + 2)/x 约去 x，得到 2
~~~

这个做法把分子中的 $x$ 项误当成了整个分子的因式。事实上 $x+2$ 是一个和，不能拆成因式 $x$ 与 $2$。例如取 $x=2$，原式为 $\frac{4}{2}=2$；取 $x=1$，原式为 $3$，不可能恒等于 2。

若有共同因式，应先提取或分解：

~~~text
(x² + 2x)/x
= [x(x + 2)]/x
= x + 2，原式要求 x ≠ 0
~~~

## 七、负号与数值因数

负号可以看作因式 $-1$。约简时注意负号的位置，最后通常把负号写在分式前或分子前。

~~~text
(−6x²)/(9x)
= −(6x²)/(9x)
= −2x/3，原式要求 x ≠ 0
~~~

可以在分子、分母同时提出负号而不改变分式：$\frac{-A}{-B}=\frac{A}{B}$。只改变分子或只改变分母的符号，则整个分式会改变符号。

## 八、零作分子的情形

若分子恒为零且分母在允许取值下不为零，分式的值就是零。但原分母的禁取值仍然不能忽略。

~~~text
0/(x − 2) = 0，条件是 x ≠ 2
~~~

这里不是说 $x=2$ 时分式也等于零；$x=2$ 会使原分母为零，原式没有定义。

## 九、约简结果与定义范围

约简是把原分式改写成在允许取值范围内与它相等的较简单形式。若约去的因式在某些取值为零，原分式在那里无定义，因此不能只看约简后分母来判断完整的定义范围。

~~~text
原式：   [(x − 3)(x + 3)]/[x(x + 3)]，x ≠ 0, −3
约简式： (x − 3)/x
~~~

两式在 $x\neq0,-3$ 时相等。若把约简式单独看作新表达式，它在 $x=-3$ 有定义；但若它表示原分式的约简结果，仍需注明原式限制 $x\neq-3$。

## 十、约简的完整格式

书写过程时，先记录原分母的限制，再分解、约分并把限制写在答案旁边。

~~~text
约简 (x² − 4)/(x² − x − 2)

原分母：(x − 2)(x + 1)，所以 x ≠ 2, −1。
(x² − 4)/(x² − x − 2)
= [(x − 2)(x + 2)]/[(x − 2)(x + 1)]
= (x + 2)/(x + 1)，其中 x ≠ 2, −1。
~~~

虽然约简式的分母只排除了 $x=-1$，原式还排除了 $x=2$，所以答案中要一并保留 $x\neq2,-1$。

## 十一、常见错误

- 没有先因式分解，就试图约去多项式中的某一项。
- 只约分子的一部分或分母的一部分，而没有确认它们是共同因式。
- 约去含字母因式后，忘记该因式为零时原分母可能为零。
- 只依据约简后分母写限制，漏掉原分母产生的禁取值。
- 处理负号时只改变分子或分母的符号，导致结果符号错误。
- 把分子、分母中的系数约分后，漏掉字母因式或写错指数。

## 十二、回顾

约简代数分式的核心步骤是：先找出原分母为零时的禁取值，再将分子和分母分解因式，最后约去共同因式。加减式中的项不能直接约分；只有完整的共同因式才能约去。

约简不会改变原分式在其定义范围内的值，也不会取消原分母带来的限制。写出结果时，应同时给出约简式和原式的禁取值。
