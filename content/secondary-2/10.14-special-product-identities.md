# 10.14 平方差公式与完全平方公式

上一课用分配律展开两个代数式的乘积。有几种常见结构反复出现，可以把展开结果记成公式，帮助快速计算和整理。

~~~text
(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
(a + b)(a − b) = a² − b²
~~~

这些公式都来自分配律。本节先推导，再学习识别结构与应用。

## 一、完全平方公式从哪里来

平方表示一个式子乘以自身：

~~~text
(a + b)² = (a + b)(a + b)
~~~

使用分配律，将每一项分别相乘：

~~~text
(a + b)(a + b)
= a² + ab + ab + b²
= a² + 2ab + b²
~~~

两个交叉乘积都是 $ab$，合起来得到 $2ab$。这就是和的完全平方公式。

## 二、和的完全平方公式

~~~text
(a + b)² = a² + 2ab + b²
~~~

结果由三项组成：第一个数的平方、两数乘积的 2 倍、第二个数的平方。

中间项的符号为正，因为两个交叉乘积 $ab$ 和 $ba$ 都为正号。

## 三、差的完全平方公式

~~~text
(a − b)² = (a − b)(a − b)
~~~

展开并合并中间项：

~~~text
(a − b)(a − b)
= a² − ab − ab + b²
= a² − 2ab + b²
~~~

因此：

~~~text
(a − b)² = a² − 2ab + b²
~~~

首项和末项都是平方，因此为非负项；中间项为 $-2ab$。平方后末项 $b^2$ 仍是正号。

## 四、完全平方的面积理解

边长为 $a+b$ 的正方形，可以按边长 $a$ 与 $b$ 切分成四块：

~~~text
面积：a² + ab + ab + b²
总面积：(a + b)²
因此：(a + b)² = a² + 2ab + b²
~~~

两块长方形的面积都是 $ab$，所以中间项出现两次。面积图也说明为什么不能漏掉交叉项。

## 五、平方差公式的推导

将和与差相乘：

~~~text
(a + b)(a − b)
= a² − ab + ab − b²
= a² − b²
~~~

中间的 $-ab$ 与 $+ab$ 抵消，因此得到平方差公式：

~~~text
(a + b)(a − b) = a² − b²
~~~

它表示“和乘差”等于“两数平方之差”。

## 六、平方差的面积理解

当 $a>b>0$ 时，一个边长为 $a$ 的正方形去掉边长为 $b$ 的小正方形，剩余面积是 $a^2-b^2$。这块剩余区域可以重新拼成边长分别为 $a+b$ 与 $a-b$ 的长方形，因此：

~~~text
a² − b² = (a + b)(a − b)
~~~

这提供了平方差公式的几何直观。代数公式对变量值的适用不只限于此图的正数情形，但拼图解释以 $a>b>0$ 为前提。

## 七、展开一个代数式的平方

展开 $(x+4)^2$：

~~~text
(x + 4)²
= x² + 2×x×4 + 4²
= x² + 8x + 16
~~~

把 $a$ 对应为 $x$，把 $b$ 对应为 4，再逐项代入完全平方公式。

## 八、系数也要平方

展开 $(2x+3)^2$：

~~~text
(2x + 3)²
= (2x)² + 2×(2x)×3 + 3²
= 4x² + 12x + 9
~~~

首项是 $(2x)^2=4x^2$，不是 $2x^2$；中间项是两个括号交叉乘积的和。

## 九、展开差的平方

~~~text
(3x − 5)²
= (3x)² − 2×(3x)×5 + 5²
= 9x² − 30x + 25
~~~

最后一项为正数，因为 $(-5)^2=25$。负号只出现在中间项。

## 十、利用平方差展开

~~~text
(y + 7)(y − 7)
= y² − 7²
= y² − 49
~~~

两个括号的首项相同，第二项大小相同、符号相反，符合平方差结构。

## 十一、系数形式的平方差

~~~text
(3a + 2b)(3a − 2b)
= (3a)² − (2b)²
= 9a² − 4b²
~~~

使用公式时应把整个首项和次项分别视作 $A$ 与 $B$，再计算 $A^2-B^2$。

## 十二、识别三个公式的结构

~~~text
(A + B)² → A² + 2AB + B²
(A − B)² → A² − 2AB + B²
(A + B)(A − B) → A² − B²
~~~

平方公式的两个括号完全相同；平方差公式的两个括号相差第二项的符号。先看括号结构，再选公式。

## 十三、用公式简便计算

~~~text
49 × 51
= (50 − 1)(50 + 1)
= 50² − 1²
= 2499
~~~

把 49 和 51 看成 50 两侧相差 1 的数，平方差公式使计算简便。

## 十四、接近整十、整百的平方

~~~text
102²
= (100 + 2)²
= 100² + 2×100×2 + 2²
= 10,404
~~~

~~~text
98²
= (100 − 2)²
= 100² − 2×100×2 + 2²
= 9,604
~~~

估算可先判断结果约为 10,000，再检查展开的中间项和末项。

## 十五、完全平方公式与平方差公式的区别

~~~text
(a − b)² = a² − 2ab + b²
(a + b)(a − b) = a² − b²
~~~

左式是一个差的平方，展开有三项；右式是和与差相乘，交叉项抵消后只剩两项。两者不能混用。

## 十六、常见错误：漏掉中间项

~~~text
(a + b)² ≠ a² + b²
(a − b)² ≠ a² − b²
~~~

完全平方时两个交叉乘积不会抵消，而会合并成 $+2ab$ 或 $-2ab$。只有和与差相乘时，交叉项才抵消。

## 十七、常见错误：平方整个首项

~~~text
(2x + 3)² ≠ 2x² + 12x + 9
~~~

正确的首项是 $(2x)^2=4x^2$。括号里的每个部分都要按公式中 $A$、$B$ 的整体处理。

## 十八、常见错误：末项符号

差的平方末项仍为正：

~~~text
(a − b)² = a² − 2ab + b²
~~~

因为 $(-b)×(-b)=b²$。不要把末项写成 $-b²$；也不要因为括号中有减号，就把展开式所有项都写成负数。

## 十九、先检查是否符合公式形状

公式只能用于对应结构。例如：

~~~text
(x + 2)(x + 5) 不是平方差结构
(x + 2)² 是完全平方结构
(x + 2)(x − 2) 是平方差结构
~~~

第一式仍可用一般分配律展开；不能因为两个括号相似，就直接把它当作和差乘积。

## 二十、常见错误

- 把 $(a+b)^2$ 写成 $a^2+b^2$，漏掉 $2ab$。
- 把 $(a-b)^2$ 的中间项写成正号或末项写成负号。
- 把平方差与差的平方混淆。
- 系数或整个代数式没有整体平方。
- 在括号结构不符合时套用特殊公式。
- 用公式后没有合并同类项或检查结果。

## 二十一、回顾

从分配律得到三条常用公式：

~~~text
(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
(a + b)(a − b) = a² − b²
~~~

完全平方公式有中间项，平方差公式的交叉项相互抵消。使用前先识别括号结构，并把括号中的整个代数式作为 $a$、$b$ 代入；下一课将学习这些公式如何反向用于因式分解。
