# 10.16 分解因式 ax²+bx+c

二次三项式常见的形式是 $ax^2+bx+c$。因式分解时，要把它改写成两个一次式的乘积。

首项系数为 1 时，可以寻找和与积符合条件的两个数；首项系数不为 1 时，可以把中间项拆成两项，再分组提取共同因式。

## 一、先回顾二次三项式

~~~text
ax² + bx + c
首项：ax²
中间项：bx
常数项：c
~~~

这里 $a,b,c$ 是常数，且 $a\ne0$。因式分解通常寻找两个一次因式；展开它们后应重新得到原三项式。

## 二、首项系数为 1 的形式

考虑：

~~~text
x² + bx + c
~~~

寻找两个数 $m,n$，使它们满足：

~~~text
m + n = b
mn = c
~~~

若找到这样的数，就有：

~~~text
x² + bx + c = (x + m)(x + n)
~~~

因为右侧展开后是 $x²+(m+n)x+mn$。

## 三、例：常数项为正

分解 $x²+7x+12$。寻找乘积为 12、和为 7 的正整数对：3 与 4。

~~~text
3 + 4 = 7
3 × 4 = 12
~~~

因此：

~~~text
x² + 7x + 12 = (x + 3)(x + 4)
~~~

展开检验：$x²+4x+3x+12=x²+7x+12$。

## 四、常数项为正且中间项为负

分解 $x²-9x+20$。积为 20 且和为 −9 的两个数都是负数：−4 与 −5。

~~~text
(−4) + (−5) = −9
(−4)(−5) = 20
~~~

所以：

~~~text
x² − 9x + 20 = (x − 4)(x − 5)
~~~

两个负数相乘得到正的常数项；两个负数相加给出负的中间项。

## 五、常数项为负

常数项为负时，两个整数因数一正一负。分解 $x²-x-12$：

~~~text
4 × (−3) = −12
4 + (−3) = 1
~~~

这组和为 1，不是 −1；应改选 3 与 −4：

~~~text
3 × (−4) = −12
3 + (−4) = −1
~~~

因此：

~~~text
x² − x − 12 = (x + 3)(x − 4)
~~~

检查中间项：$-4x+3x=-x$。

## 六、用展开检查首项系数为 1 的结果

如果候选因数为 $(x+m)(x+n)$，展开后：

~~~text
(x + m)(x + n)
= x² + (m+n)x + mn
~~~

因此必须同时核对中间项系数和常数项。只让两个数乘积等于 $c$ 还不够，它们的和也必须等于 $b$。

## 七、一般形式的关键条件

对 $ax²+bx+c$，若可写成 $(px+q)(rx+s)$，则：

~~~text
pr = a
qs = c
ps + qr = b
~~~

展开后首项由 $prx²$ 得到，常数项是 $qs$，两个交叉项合并成 $(ps+qr)x$。一般情形下直接猜四个数可能不方便，因此使用拆分中间项。

## 八、拆分中间项的方法

寻找两个数 $m,n$，使：

~~~text
m + n = b
mn = ac
~~~

把 $bx$ 写成 $mx+nx$，再把四项分成两组，分别提取公因式。两组应得到相同的括号。

## 九、例：分解 2x²+7x+3

先计算 $ac=2×3=6$。寻找积为 6、和为 7 的数 6 与 1，将中间项拆开：

~~~text
2x² + 7x + 3
= 2x² + 6x + x + 3
~~~

分组提取公因式：

~~~text
= 2x(x + 3) + 1(x + 3)
= (2x + 1)(x + 3)
~~~

两个组都含有 $(x+3)$，因此可以提出共同的括号。

## 十、再验算一般形式

~~~text
(2x + 1)(x + 3)
= 2x² + 6x + x + 3
= 2x² + 7x + 3
~~~

展开结果与原式完全一致，所以因式分解正确。

## 十一、例：首项系数大于 1，常数项为负

分解 $6x²+x-2$。先算 $ac=6×(-2)=-12$，寻找积为 −12、和为 1 的数 4 与 −3：

~~~text
6x² + x − 2
= 6x² + 4x − 3x − 2
~~~

分组提取：

~~~text
= 2x(3x + 2) − 1(3x + 2)
= (3x + 2)(2x − 1)
~~~

展开检验：$6x²-3x+4x-2=6x²+x-2$。

## 十二、例：负的中间项

分解 $3x²-10x+8$。$ac=3×8=24$，要找和为 −10、积为 24 的两数 −6 与 −4：

~~~text
3x² − 10x + 8
= 3x² − 6x − 4x + 8
= 3x(x − 2) − 4(x − 2)
= (3x − 4)(x − 2)
~~~

注意第二组提取 4 时，括号内应为 $(x-2)$；因为 $-4(x-2)=-4x+8$。

## 十三、首项系数为负时先提取负号

例如：

~~~text
−2x² − 7x − 3
= −(2x² + 7x + 3)
= −(2x + 1)(x + 3)
~~~

先提取 −1，使括号内首项系数为正，再按熟悉的方法分解。最后不要漏掉提取出的负号。

## 十四、先提取所有项的公因数

因式分解前先检查各项是否有共同因数：

~~~text
4x² + 14x + 6
= 2(2x² + 7x + 3)
= 2(2x + 1)(x + 3)
~~~

先提出 2，括号内的 $ac=2×3=6$，拆项分组后得到 $(2x+1)(x+3)$。提取公因数通常能简化后续数字。

## 十五、分组时括号必须一致

拆项分组的目标是制造相同的二项式因子：

~~~text
2x² + 6x + x + 3
= 2x(x + 3) + 1(x + 3)
~~~

若分组后得到的括号不一致，先检查拆分的两数是否满足和为 $b$、积为 $ac$，再检查符号和提取的公因数。

## 十六、常数项为零时先提出 x

若 $c=0$，二次式前两项都含有 $x$，可以直接提取 $x$：

~~~text
ax² + bx = x(ax + b)
~~~

例如：

~~~text
5x² − 15x = 5x(x − 3)
~~~

先提出所有项的最大公因数，再检查括号内能否继续分解。

## 十七、何时不能用整数因数对分解

若找不到整数 $m,n$ 满足和为 $b$、积为 $ac$，就不能用本节的整数拆项法分解成整数系数的一次因式。

例如 $x²+x+1$ 中，整数因数对乘积为 1 只有 $(1,1)$ 或 $(-1,-1)$，它们的和分别为 2 和 −2，都不是 1。因此它不能按首项系数为 1 的整数因数对方法分解。

这不等于所有二次式都必能用整数系数因式分解；是否存在所需因数结构，要由系数决定。

## 十八、拆项法与特殊公式的关系

有些三项式也能用前一课的完全平方公式快速分解，例如：

~~~text
x² + 6x + 9 = (x + 3)²
~~~

拆项法也可以找到 3 和 3，因为和为 6、积为 9。特殊公式是结构更明显的快捷方法；选择清楚且不易出错的方法即可。

## 十九、分解因式的检查步骤

1. 检查是否已提取最大公因数；
2. 检查首项、常数项与中间项的符号；
3. 对首项系数为 1 的式子，核对两数之和为 $b$、积为 $c$；
4. 对一般形式，核对两数之和为 $b$、积为 $ac$；
5. 分组后确认括号相同；
6. 将结果展开，检查是否还原为原式。

## 二十、常见错误

- 只找乘积正确的因数对，忘记核对和。
- 一般形式中误用 $c$，没有计算 $ac$。
- 中间项拆分后某一项的系数或符号写错。
- 分组提取公因式时，负号处理不当。
- 没有先提取整体公因数。
- 两组没有相同括号，仍强行提出。
- 分解后不展开检验。

## 二十一、回顾

对 $x²+bx+c$，寻找和为 $b$、积为 $c$ 的两数；对一般的 $ax²+bx+c$，寻找和为 $b$、积为 $ac$ 的两数，将中间项拆成两项后分组提取公因式。

分解时先提取公因数，仔细处理符号，并以展开检验结果。若不存在所需的整数因数对，就不能使用本节的整数拆项方法。
