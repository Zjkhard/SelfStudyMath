# 11.26 直方图

直方图用相连的矩形柱表示连续数值数据在各个区间内的频数。横轴表示连续的数值区间，柱的宽度对应区间宽度；在组宽相同的常见情形中，柱高表示该组频数。它能帮助我们观察数据集中在哪些范围、分布是否对称以及哪些区间最常见。

~~~
连续数据 → 分组区间 → 统计各组频数 → 画相连的柱形
~~~

## 一、直方图表示连续数据

身高、时间、质量和长度等连续量可以在一定范围内取中间值。数据较多时，常把数值范围分成连续区间，再统计每个区间的数据个数。

~~~
区间：0 ≤ x < 10，10 ≤ x < 20，20 ≤ x < 30
频数：每个区间内实际落入的数据个数
~~~

直方图显示的是分组后的分布；单凭某根柱，通常不能知道区间内每个原始数据的具体数值。

## 二、区间边界与组宽

每个区间都应清楚标明下限和上限。通常将左端点包含在该组、右端点不包含在该组，这样相邻组既连续又不重叠。

~~~
0 ≤ x < 10
10 ≤ x < 20
20 ≤ x < 30
~~~

这些区间的组宽都是 10。数据恰好等于 10 时，按上述规则计入第二组，而不是第一组。

## 三、直方图中的柱形相连

横轴的区间首尾相接，表示连续数值可以从一组过渡到相邻组，所以柱形之间通常没有空隙。柱宽表示组宽，柱高在等组宽情况下表示频数。

~~~
直方图：连续区间，柱形相接
柱宽：区间宽度
柱高：组频数（各组组宽相等时）
~~~

柱形相接不是为了美观，而是表达数值区间连续这一信息。

## 四、由分组频数表绘制直方图

一组测量数据整理成以下频数表：

~~~
区间（单位）      0 ≤ x < 10   10 ≤ x < 20   20 ≤ x < 30
频数                    3              4              3
~~~

绘制步骤如下：

~~~
1. 横轴标出连续区间及单位；
2. 纵轴标出频数并设置均匀刻度；
3. 按每组区间宽度确定柱宽；
4. 按相应频数确定柱高；
5. 各柱相接，并补上标题和轴标签。
~~~

因为三组宽度都为 10，可以直接用柱高 3、4、3 表示频数。中间区间 $10\le x<20$ 的数据最多。

## 五、阅读直方图

先看标题、横轴区间、纵轴频数刻度和单位，再比较柱高或柱面积。可读出某区间内有多少数据、哪个区间频数最大，以及数据主要集中在哪些范围。

~~~
频数最高的组 → 众数组（不能据此确定组内的确切众数）
柱形较集中 → 数据多落在对应区间
柱形分布范围 → 粗略反映数据跨度
~~~

若只知道分组数据，不能据此断定组内某一个确切数值最常见；只能描述区间层面的分布。

## 六、直方图与条形图的区别

条形图主要比较彼此分开的类别；直方图表示连续数值的分组区间。条形图各柱通常留空，类别顺序可按情境安排；直方图的区间必须按数值次序排列，柱形通常相连。

~~~
条形图：类别，柱间有间隔
直方图：连续数值区间，柱形相接
~~~

例如“上学方式”适合条形图；“学生身高按区间分组”适合直方图。

## 七、相同组宽时比较频数

若所有区间宽度相同，频数较大的组画得更高，柱面积也相应较大，因此可以直接比较柱高判断各组数据数量。

~~~
组宽相同：柱高 ∝ 频数
~~~

画图时仍要依照频数轴刻度定位，不能只按柱高看起来大约多少来估计。

## 八、组宽不同时的注意事项

若各区间宽度不同，直接把柱高设为频数会使较宽的组视觉上占据更大面积，可能误导比较。规范直方图通常使柱形面积代表频数，此时柱高使用频数密度：

~~~
频数密度 = 频数 / 组宽
柱形面积 = 组宽 × 频数密度 = 频数
~~~

本阶段优先使用组宽相同的分组，柱高可直接表示频数；遇到不等组宽的直方图，先查看纵轴标的是频数还是频数密度。

## 九、频数与相对频数

有时纵轴表示相对频数或百分比，而不是频数。相对频数等于组频数除以总数；使用百分比时，各组百分比总和应约为 100%。

~~~
相对频数 = 组频数 / 总频数
~~~

图表应清楚标明纵轴含义。频数和相对频数虽然都能比较分布，但表示的量不同。

## 十、从直方图估计分布特征

直方图可以展示数据的整体形状，例如数据主要集中在哪一段、两侧是否大致对称、是否有多个高峰或较长尾部。由于数据已分组，判断通常是近似的。

~~~
观察：
数据集中范围
频数最高的区间
分布是否大致对称
是否有明显稀疏区或尾部
~~~

不同的分组起点和组宽可能改变图形外观，因此解释时应同时查看原始分组设置。

## 十一、常见错误

- 把直方图画成柱间有空隙的条形图。
- 区间有重叠或空档，导致数据重复计数或遗漏。
- 横轴区间没有按数值顺序排列。
- 忽略组宽，误以为不等宽柱形的高度总是频数。
- 忘记标明纵轴表示频数、相对频数还是频数密度。
- 从某个分组区间直接推断组内精确数据值。
- 使用不均匀刻度或遗漏单位，造成读数错误。
- 只凭图形外观作过强结论，不说明分组造成的不确定性。

## 十二、回顾

直方图将连续数值分组后用相连柱形表示频数分布。横轴表示按顺序排列的连续区间，柱宽反映组宽；组宽相同时，柱高可以直接表示频数。

制作和读取时检查区间边界、刻度、单位和纵轴含义。若组宽不相等，应确认柱高是否表示频数密度；不要把直方图与用于比较类别的条形图混淆。
