# 10.25 平移、旋转与组合变换

平移是把图形上每一点沿相同方向移动相同距离；旋转是使图形绕一个固定点转过指定角度。它们和反射一样，都是刚性变换：保持长度和角度不变，因此变换前后的图形全等。多个变换连续进行时，必须按题目给出的顺序逐步追踪图形。

~~~text
平移：指定方向与距离（或平移向量）
旋转：指定中心、方向与角度
组合：依次执行每一步，前一步的像成为下一步的原图
~~~

## 一、平移的描述

平移由移动方向和距离决定。平面直角坐标系中，也可以用向量 $(a,b)$ 表示横向移动 $a$ 个单位、纵向移动 $b$ 个单位。

~~~text
平移向量 (a, b)：
横坐标加 a，纵坐标加 b
(x, y) → (x + a, y + b)
~~~

例如点 $P(2,-1)$ 按向量 $(3,2)$ 平移后，得到 $P'(5,1)$。每个顶点都按相同的向量移动，连结对应顶点即可画出平移后的多边形。

## 二、在方格纸上作平移

作图时，先数出规定的水平和竖直移动格数，再把每个顶点移动相同格数，最后依照原来的顺序连线。

~~~text
平移 4 格向右、2 格向下：
(x, y) → (x + 4, y − 2)
~~~

平移不会改变边的长度、边的方向、角度或顶点顺序。若图形移动后变大或变小，所做的就不是平移。

## 三、旋转的要素

描述一次旋转需要指出旋转中心、旋转方向和旋转角。若没有特别说明，平面几何中通常把逆时针作为正方向，顺时针作为反方向。

~~~text
一次旋转：绕中心 O，按指定方向转过 θ°
点到旋转中心的距离保持不变
~~~

作图时，对每个顶点分别连到旋转中心，保持该点到中心的距离不变，并按相同方向转过相同角度，再连结新的顶点。

## 四、绕原点旋转的坐标规则

在坐标平面中，点 $(x,y)$ 绕原点逆时针旋转 $90^\circ$ 后变为 $(-y,x)$；顺时针旋转 $90^\circ$ 后变为 $(y,-x)$；旋转 $180^\circ$ 后变为 $(-x,-y)$。

~~~text
逆时针 90°：(x, y) → (−y, x)
顺时针 90°：(x, y) → (y, −x)
旋转 180°：(x, y) → (−x, −y)
~~~

例如点 $A(3,1)$ 逆时针旋转 $90^\circ$ 后为 $A'(-1,3)$；顺时针旋转 $90^\circ$ 后为 $A'(1,-3)$。可以在方格纸上检验：旋转前后到原点的距离相同。

## 五、绕其他中心旋转

若旋转中心不是原点，先观察点相对于旋转中心的位置。可把旋转中心暂时看成坐标原点，旋转点与中心的相对向量，再把旋转后的向量加回中心位置。

例如中心为 $C(2,1)$，点 $P(4,2)$ 相对于 $C$ 的向量是 $(2,1)$。绕 $C$ 逆时针旋转 $90^\circ$ 后，相对向量变为 $(-1,2)$，所以像点为 $P'(1,3)$。

~~~text
P − C = (4 − 2, 2 − 1) = (2, 1)
(2, 1) 逆时针旋转 90° → (−1, 2)
P′ = C + (−1, 2) = (1, 3)
~~~

像点到旋转中心的距离仍为 $\sqrt{5}$，与原点 $P$ 到 $C$ 的距离相同。

## 六、变换图形并标记对应点

对多边形进行平移或旋转时，每个顶点都遵循同一个变换规则。可在原顶点名称上加撇号表示像点，例如 $A'$、$B'$、$C'$，并保持连接顺序。

~~~text
△ABC 的像为 △A′B′C′
A → A′，B → B′，C → C′
~~~

因为变换保持形状与大小，所以 $AB=A'B'$、$BC=B'C'$、$CA=C'A'$，对应角也相等。

## 七、组合变换

组合变换是连续进行两个或多个变换。每一步都作用于上一步得到的像，而不是重新作用于最初图形，除非题目明确如此说明。

~~~text
原图形 → 第一步的像 → 第二步的像 → 最终像
~~~

例如点 $P(1,0)$ 先向右平移 1 个单位，再绕原点逆时针旋转 $90^\circ$：

~~~text
(1, 0) → (2, 0) → (0, 2)
~~~

最终像为 $(0,2)$。每个箭头代表一次变换；把坐标逐步写出，可避免把变换顺序弄反。

## 八、变换顺序可能影响结果

不同变换的顺序通常不能随意交换。仍取 $P(1,0)$：

~~~text
先右移 1，再逆时针旋转 90°：
(1, 0) → (2, 0) → (0, 2)

先逆时针旋转 90°，再右移 1：
(1, 0) → (0, 1) → (1, 1)
~~~

两个顺序得到的像点不同。因此读题时要标明“先……再……”，并按指定次序执行。

## 九、变换后的性质

平移和旋转都是刚性变换，所以变换前后对应边、对应角、周长和面积均相等。图形的位置或方向可能改变，但不会被拉伸、压扁或翻转成不同大小。

~~~text
长度不变，角度不变
周长不变，面积不变
位置或朝向可以改变
~~~

若一个操作改变了图形大小，它就不是平移或旋转；若使图形镜像翻转，则涉及反射。

## 十、如何描述一次变换

描述清楚变换时，尽量说明对象、变换类型和必要参数：

~~~text
将 △ABC 向右平移 3 个单位、向下平移 2 个单位。
将图形绕点 O 顺时针旋转 90°。
先关于 y 轴反射，再按向量 (2, 1) 平移。
~~~

坐标变换中也可以直接写出点的映射规则，例如 $(x,y)\mapsto(x+2,y-1)$。对旋转而言，旋转中心和方向不可省略，否则描述不完整。

## 十一、常见错误

- 平移时不同顶点移动了不同的方向或距离。
- 旋转时只改变坐标符号，却没有确认旋转中心和方向。
- 把顺时针与逆时针的 $90^\circ$ 规则混淆。
- 绕非原点旋转时，直接套用绕原点的坐标公式。
- 组合变换中第二步仍作用于原图，而不是第一步得到的像。
- 交换了变换次序，导致最终像的位置错误。
- 作出像后没有按对应顶点顺序连接，造成图形边交叉或错连。

## 十二、回顾

平移由方向和距离确定，坐标形式是 $(x,y)\mapsto(x+a,y+b)$。旋转由中心、方向和角度确定；绕原点旋转 $90^\circ$ 或 $180^\circ$ 时，可使用相应坐标规则。

平移和旋转保持长度、角度、周长与面积。进行组合变换时，逐步记录每一步的像，并严格按照给定顺序执行。
