# 10.2 零指数与负整数指数

上一课学习了同底数幂相除时指数相减。例如，当 $a ≠ 0$ 时：

~~~text
a³ ÷ a³ = 1
~~~

如果用指数相减表示，右边也可以写成 $a^{3-3}=a^0$。因此，对非零底数，零指数的定义必须与已有的除法规律一致：$a^0=1$。同样的思路还能解释负整数指数。

## 一、零指数的意义

任何非零数除以自身都等于 1。对非零数 $a$，有：

~~~text
a⁴ ÷ a⁴ = a⁰
a⁴ ÷ a⁴ = 1
~~~

因此规定：

~~~text
a⁰ = 1（a ≠ 0）
~~~

这表示零指数幂的值为 1，而不是 0。条件 $a ≠ 0$ 必须保留。

## 二、用指数规律理解零指数

观察同底数幂逐次相除：

~~~text
2⁴ ÷ 2¹ = 2³
2⁴ ÷ 2² = 2²
2⁴ ÷ 2³ = 2¹
2⁴ ÷ 2⁴ = 2⁰ = 1
~~~

每增加一个相同因数作为除数，指数就减少 1；当分子分母完全约去时，剩下的数值是 1。零指数与同底数幂除法保持一致。

## 三、零指数的例子

~~~text
7⁰ = 1
(-5)⁰ = 1
(3x)⁰ = 1（3x ≠ 0）
~~~

最后一个式子要求整个底数 $3x$ 不为零，也就是 $x ≠ 0$。底数可以是负数或代数式，只要它不为零，零次幂就等于 1。

## 四、零底数的特别限制

零指数规则要求底数非零，因此本节不把 $0^0$ 定义为 1。它不属于 $a^0=1$（$a≠0$）这条规则的适用范围。

负整数指数也不能以 0 为底，因为改写后会出现以 0 为分母：

~~~text
0⁻² = 1/0²
~~~

分母不能为零，所以 $0^{-2}$ 无意义。处理零底数时，必须先检查指数和定义条件。

## 五、从除法规律走向负指数

仍以底数 2 为例，逐步扩大除数的指数：

~~~text
2³ ÷ 2¹ = 2² = 4
2³ ÷ 2² = 2¹ = 2
2³ ÷ 2³ = 2⁰ = 1
2³ ÷ 2⁴ = 2⁻¹ = 1/2
~~~

最后一步中，分子分母约去三个 2 后，分母还剩一个 2，所以结果是 $1/2$。这提示 $2^{-1}$ 应等于 $1/2$。

## 六、负整数指数的定义

对非零底数 $a$ 和正整数 $n$，规定：

~~~text
a⁻ⁿ = 1/aⁿ（a ≠ 0）
~~~

负指数表示取正整数次幂的倒数，不表示结果一定是负数。

~~~text
2⁻³ = 1/2³ = 1/8
~~~

因为 $2^3=8$，它的倒数是 $1/8$。

## 七、负指数与倒数互化

负指数幂可以改写为分数；非零分数的倒数也可以写成负指数形式：

~~~text
a⁻ⁿ = 1/aⁿ
1/aⁿ = a⁻ⁿ（a ≠ 0）
~~~

例如：

~~~text
5⁻² = 1/5² = 1/25
1/3⁴ = 3⁻⁴
~~~

互化时，指数的绝对值不变，只把幂移到分数线的另一侧，并改变指数的正负。

## 八、分子分母都含幂

~~~text
2³/2⁵ = 2³⁻⁵ = 2⁻² = 1/2² = 1/4
~~~

同底数相除时指数相减。若指数差是负数，就用负指数定义把结果化成正指数幂的倒数。

反过来：

~~~text
7²/7⁵ = 1/7³
~~~

计算最后可选择保留负指数形式或写成分数；若题目要求正指数形式，应改写为倒数。

## 九、含字母的负指数

~~~text
x⁻³ = 1/x³（x ≠ 0）
~~~

例如：

~~~text
4a⁻² = 4/a²（a ≠ 0）
~~~

系数 4 不随负指数移动；只有带指数的因式 $a^{-2}$ 改写为 $1/a^2$。

## 十、负底数与负指数

负底数和负指数是两件不同的事：底数前的负号影响正负，指数前的负号表示取倒数。

~~~text
(-2)⁻³ = 1/(-2)³ = -1/8
(-2)⁻² = 1/(-2)² = 1/4
~~~

先按定义把负指数改为倒数，再判断负底数的奇偶次幂符号。

## 十一、括号决定负号是否属于底数

~~~text
(-3)⁻² = 1/(-3)² = 1/9
-3⁻² = -(3⁻²) = -1/9
~~~

第一式中底数是 $-3$；第二式中底数是 3，前面的负号在幂运算之后作用。括号会改变表达式的含义。

## 十二、负指数与同底数幂法则

指数扩展到整数后，同底数幂的乘除规律仍保持一致，但底数必须非零：

~~~text
aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ（a ≠ 0）
~~~

例如：

~~~text
3⁻² × 3⁵ = 3³ = 27
~~~

用乘法规律可以将指数相加；也可先把 $3^{-2}$ 改写为 $1/9$，再计算。两种方法结果一致。

## 十三、幂的乘方与积的乘方

前一课的幂法则也适用于整数指数，但出现负指数时仍需满足底数非零等条件：

~~~text
(aᵐ)ⁿ = aᵐⁿ
(ab)ⁿ = aⁿbⁿ
~~~

例如：

~~~text
(2⁻¹)² = 2⁻² = 1/4
(ab)⁻² = 1/(a²b²)（a ≠ 0，b ≠ 0）
~~~

涉及分母时，要检查其中每个底数都不为零。

## 十四、把答案写成正指数形式

~~~text
3x⁻² = 3/x²
5a²b⁻³ = 5a²/b³
4/(m⁻²) = 4m²（m ≠ 0）
~~~

负指数因式移过分数线时变成正指数。最后一个例子中，$m^{-2}=1/m^2$，除以 $1/m^2$ 等于乘以 $m^2$。

## 十五、分数化成负指数形式

~~~text
1/2⁵ = 2⁻⁵
3/4³ = 3 × 4⁻³
~~~

只有分母中的幂改写为负指数，分子系数仍保持原位。若分子中也有幂，可以分别处理：

~~~text
a²/b⁴ = a²b⁻⁴（b ≠ 0）
~~~

## 十六、运算顺序

负指数不改变运算顺序，仍先处理括号与幂，再做乘除加减：

~~~text
2 + 2⁻² = 2 + 1/4 = 9/4
~~~

不能先把底数 2 与加数 2 相加再取负指数。指数只作用于它所属的底数或括号。

## 十七、常见错误

- 把 $a^0$ 当作 0；正确规则是 $a^0=1$，且 $a≠0$。
- 把 $a^{-n}$ 当作 $-a^n$；负指数表示倒数。
- 忘记负指数底数不能为零，导致分母为零。
- 将 $2^{-3}$ 算成 $-8$，混淆负指数与负底数。
- 把 $(-a)^{-n}$ 与 $-a^{-n}$ 混为一谈。
- 改写负指数时忘记指数绝对值不变。
- 移动分数线上的因式时没有改变指数符号。
- 忘记指数只作用于紧邻的底数或括号。

## 十八、回顾

对非零底数 $a$：

~~~text
a⁰ = 1
a⁻ⁿ = 1/aⁿ（n 为正整数）
~~~

零指数幂等于 1；负整数指数幂等于正整数次幂的倒数。负指数不代表负数，负底数也不代表负指数。运算时先检查底数是否非零、看清括号和指数作用范围，再按指数法则化简。
