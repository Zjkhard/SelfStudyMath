# 10.22 含代数分式的方程

含代数分式的方程中，未知数可能出现在分母里。解题时不能只按普通方程运算：先找出使原分母为零的禁取值，再用各分母的最简公分母消去分母，解所得方程，最后把候选解代回原方程检验。

~~~text
找出原方程的禁取值
→ 确定最简公分母
→ 方程两边同乘最简公分母
→ 解所得方程
→ 排除禁取值并代回原方程检验
~~~

## 一、为什么必须先记录禁取值

分母不能为零。例如方程 $\frac{2}{x-1}=3$ 只在 $x\neq1$ 时有意义。因此求解前要先从原方程的每个分母找出禁取值。

~~~text
分母 x − 1 ≠ 0
所以 x ≠ 1
~~~

这些限制属于原方程。后续即使某个分母因约分或乘法而消失，原限制仍然有效。

## 二、两边同乘最简公分母

解方程 $\frac{2}{x-1}=\frac{3}{x+1}$。

原分母要求 $x\neq1,-1$。最简公分母为 $(x-1)(x+1)$，方程两边同乘它：

~~~text
2/(x − 1) = 3/(x + 1)
2(x + 1) = 3(x − 1)
2x + 2 = 3x − 3
x = 5
~~~

$x=5$ 不在禁取值之中。代回原方程：左边为 $2/4=1/2$，右边为 $3/6=1/2$，成立。因此方程的解为 $x=5$。

## 三、方程中有整式项

解 $\frac{2}{x-1}=1+\frac{3}{x-1}$。

原分母要求 $x\neq1$。最简公分母是 $x-1$，两边同乘后：

~~~text
2/(x − 1) = 1 + 3/(x − 1)
2 = (x − 1) + 3
2 = x + 2
x = 0
~~~

$x=0$ 满足限制。代回原方程，左边为 $2/(-1)=-2$，右边为 $1+3/(-1)=-2$，所以解为 $x=0$。

整式项也要乘以最简公分母。例如上式的 $1$ 乘以 $(x-1)$ 后变为 $x-1$，不能仍写成 1。

## 四、含多个不同分母

解 $\frac{1}{x}+\frac{1}{x+2}=\frac{3}{x+2}$。

原分母要求 $x\neq0,-2$。最简公分母为 $x(x+2)$：

~~~text
1/x + 1/(x + 2) = 3/(x + 2)
(x + 2) + x = 3x
2x + 2 = 3x
x = 2
~~~

$x=2$ 满足限制。代回原方程，左边为 $1/2+1/4=3/4$，右边为 $3/4$，所以解为 $x=2$。

## 五、解出来的值若是禁取值

方程变形得到的候选值不一定是原方程的解。若候选值使原分母为零，原方程在该值处没有定义，必须排除。

解 $\frac{x+1}{x-2}=2+\frac{3}{x-2}$。

原分母要求 $x\neq2$。两边同乘 $x-2$：

~~~text
(x + 1)/(x − 2) = 2 + 3/(x − 2)
x + 1 = 2(x − 2) + 3
x + 1 = 2x − 1
x = 2
~~~

得到的候选值 $x=2$ 正是禁取值，因此原方程无解。不能把它写成解，也不能将它代入原方程，因为原式的分母会变成零。

## 六、等式两边同乘时为何要检验

在允许的取值范围内，最简公分母不为零，因此两边同乘它会保留等式关系。但所得方程可能带有原方程不允许的候选值；检验可确保答案满足最初的限制和方程。

~~~text
候选解满足所得方程
不一定满足原方程的定义限制
所以最终答案必须经过检验
~~~

尤其当消去分母后，原来分母中的字母因式不再明显时，更要回看一开始记录的禁取值。

## 七、最简公分母的选择

先把各分母因式分解，再取每个因式出现的最高次数，组成最简公分母。这样通常能避免展开过大的乘积，并能看清禁取值。

~~~text
分母：x(x − 1)，(x − 1)(x + 2)
最简公分母：x(x − 1)(x + 2)
限制：x ≠ 0, 1, −2
~~~

同乘最简公分母后，每一项都要乘上它缺少的因式；被消去的分母因式应逐项约去，不能漏项。

## 八、检查运算过程

消去分母时，可以逐项检查每个分子实际乘了什么：

~~~text
(A/B) × M = A × (M/B)
~~~

其中 $M$ 是最简公分母。若某项原本是整式 $P$，则该项变成 $P\times M$；若原本是 $A/B$，则变成 $A\times(M/B)$。写清这一步有助于避免漏乘或错误约分。

## 九、常见错误

- 求解前没有从原分母列出禁取值。
- 两边同乘最简公分母时，忘记整式项也要乘它。
- 将除以一个代数式误当作可以随意乘回去，而没有考虑该式为零的情形。
- 通分或消去分母时漏掉某项应乘的因式。
- 得到候选解后不代回原方程检验。
- 候选值使原分母为零，仍把它当作方程的解。
- 只检验消去分母后的方程，没有检查原方程是否有定义。

## 十、解题书写格式

含代数分式方程建议按以下顺序呈现：

~~~text
解：原方程的分母不能为零，所以……
方程两边同乘最简公分母……
解所得方程，得到候选值……
检查候选值是否违反限制，并代回原方程验证。
答：……
~~~

若全部候选值都违反限制，应明确写出“原方程无解”，并说明原因。

## 十一、回顾

解含代数分式的方程，先确定原分母不为零的取值范围，再用最简公分母消去分母并求候选解。最后排除禁取值，并把保留的值代回原方程检验。

“解出一个数”只是计算过程的一部分；它只有在原方程有定义并且等式成立时，才是原方程的解。
