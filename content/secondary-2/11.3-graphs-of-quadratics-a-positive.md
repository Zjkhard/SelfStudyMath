# 11.3 二次函数图像：$a>0$、开口方向、对称轴、顶点与截距

二次函数通常写成 $y=ax^2+bx+c$，其中 $a\neq0$。当 $a>0$ 时，图像是一条开口向上的抛物线；它有一条竖直对称轴和一个最低点，最低点称为顶点。本课学习如何从公式、表格和图像识别这些特征。

~~~text
y = ax² + bx + c，a > 0
图像：开口向上
对称轴：x = −b/(2a)
顶点：对称轴上的最低点
纵轴截距：x = 0 时的 y 值，即 c
~~~

## 一、从最简单的抛物线开始

函数 $y=x^2$ 的图像是开口向上的 U 形曲线，称为抛物线。它关于纵轴对称，顶点在原点 $(0,0)$。

~~~text
x    −2   −1    0    1    2
y     4    1    0    1    4
~~~

表格中 $x$ 与 $-x$ 对应相同的函数值，因此图像左右对称。随着 $|x|$ 增大，$y$ 增大，原点是最低点。

## 二、二次项系数 $a$ 与开口方向

在 $y=ax^2+bx+c$ 中，若 $a>0$，抛物线开口向上；若 $a<0$，抛物线开口向下。系数 $a$ 的绝对值还影响图像的宽窄：在其他条件相同的情况下，$|a|$ 较大，图像较窄；$|a|$ 较小，图像较宽。

~~~text
a > 0：开口向上，有最低点
a < 0：开口向下，有最高点（下一课学习）
~~~

本课只讨论 $a>0$ 的情形。

## 三、顶点式能直接显示顶点

若二次函数写成 $y=a(x-h)^2+k$，且 $a>0$，则平方项 $(x-h)^2$ 最小为 0，发生在 $x=h$。因此函数的最低值为 $k$，顶点为 $(h,k)$，对称轴为 $x=h$。

~~~text
y = a(x − h)² + k，a > 0
顶点：(h, k)
对称轴：x = h
最小值：k
~~~

例如 $y=2(x-1)^2+3$ 的顶点是 $(1,3)$，对称轴为 $x=1$，最小值是 3。系数 2 大于 0，所以图像开口向上。

## 四、顶点式图像的对称点

在对称轴左右等距离的位置，函数值相同。对于 $y=2(x-1)^2+3$，对称轴为 $x=1$，因此 $x=0$ 与 $x=2$ 的函数值相同：

~~~text
x = 0：y = 2(−1)² + 3 = 5
x = 2：y = 2(1)² + 3 = 5
~~~

点 $(0,5)$ 和 $(2,5)$ 关于直线 $x=1$ 对称。利用这种对称性，可以少算一半的点来绘制图像。

## 五、一般式中的对称轴与顶点

一般式 $y=ax^2+bx+c$ 的对称轴位置为：

~~~text
x = −b/(2a)
~~~

先求对称轴的 $x$ 坐标，再代入原函数求顶点的 $y$ 坐标。由于 $a>0$，该顶点是最低点。

例如 $y=x^2-4x+3$ 中 $a=1$、$b=-4$、$c=3$：

~~~text
对称轴：x = −(−4)/(2 × 1) = 2
顶点的 y 值：2² − 4 × 2 + 3 = −1
顶点：(2, −1)
~~~

## 六、纵轴截距

纵轴上的点满足 $x=0$。把 $x=0$ 代入一般式，得到 $y=c$，所以二次函数 $y=ax^2+bx+c$ 的纵轴截距点是 $(0,c)$。

~~~text
x = 0 → y = c
纵轴截距点：(0, c)
~~~

例如 $y=x^2-4x+3$ 的纵轴截距为 3，图像经过 $(0,3)$。纵轴截距可以帮助确定抛物线在纵轴上的位置。

## 七、横轴交点

图像与横轴相交处满足 $y=0$。因此横轴交点的横坐标是方程 $ax^2+bx+c=0$ 的实数解。一个抛物线可能与横轴相交两次、相切一次，也可能不相交。

对于 $y=x^2-4x+3$，可以因式分解：

~~~text
0 = x² − 4x + 3
  = (x − 1)(x − 3)
x = 1 或 x = 3
~~~

所以图像与横轴交于 $(1,0)$ 和 $(3,0)$。若当前方法不能方便地求出方程的根，可先根据表格或图像估计交点；后续课程将继续学习其他求解方法。

## 八、绘制一般式的图像

绘图时先找对称轴和顶点，再找纵轴截距、横轴交点或其他成对的对称点。以 $y=x^2-4x+3$ 为例，已知对称轴 $x=2$、顶点 $(2,-1)$、纵轴截距 $(0,3)$ 和横轴交点 $(1,0)$、$(3,0)$。

~~~text
关键点：(0, 3)，(1, 0)，(2, −1)，(3, 0)，(4, 3)
图像关于 x = 2 对称，开口向上
~~~

用平滑曲线连接这些点，不能用折线代替抛物线。点 $(4,3)$ 可由 $(0,3)$ 关于对称轴 $x=2$ 得到。

## 九、横轴交点的数量与顶点位置

当 $a>0$ 时，顶点是最低点。观察顶点相对于横轴的位置，可以判断横轴交点的数量：

~~~text
顶点在横轴下方：与横轴有两个交点
顶点在横轴上：与横轴有一个交点（相切）
顶点在横轴上方：与横轴没有交点
~~~

这是针对整条抛物线开口向上的情况。抛物线从顶点向两侧上升，因此顶点高度决定它是否会穿过横轴。

## 十、定义域与值域

在纯数学图像中，二次函数的自变量通常可取任意实数。若 $a>0$ 且顶点为 $(h,k)$，函数值不会小于 $k$，所以值域为 $y\ge k$。

~~~text
定义域：所有实数（若题目没有额外限制）
值域：y ≥ k，其中 (h, k) 是顶点
~~~

在实际情境中，自变量可能有额外限制，例如时间不能为负数；此时应按情境缩小定义域。

## 十一、常见错误

- 看到二次函数就认为开口方向固定；方向由 $a$ 的正负决定。
- 把 $b$ 当成纵轴截距；一般式中的纵轴截距是 $c$。
- 将对称轴写成点坐标，或漏掉等式 $x=-b/(2a)$ 中的负号。
- 只求出顶点的横坐标，没有代回函数求顶点坐标。
- 把横轴交点与纵轴截距混淆；横轴交点满足 $y=0$，纵轴截距满足 $x=0$。
- 绘图时没有使用对称点，或用折线连接抛物线上的点。
- 将顶点的函数值误认为最大值；$a>0$ 时它是最小值。

## 十二、回顾

当 $a>0$ 时，二次函数 $y=ax^2+bx+c$ 的图像是开口向上的抛物线，有最低点。一般式的对称轴为 $x=-b/(2a)$；把这个横坐标代入函数，得到顶点坐标。纵轴截距为 $(0,c)$，横轴交点由令 $y=0$ 求得。

绘制图像时，先确定开口方向、对称轴和顶点，再标出截距及对称点，并用平滑曲线连接。图像的顶点位置也能帮助判断最小值和值域。
