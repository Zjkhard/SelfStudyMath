# 11.13 棱锥的认识

棱锥由一个多边形底面和若干个三角形侧面组成，所有侧面都在同一个顶点处相接。棱锥根据底面的边数命名：三角形底面的棱锥叫三棱锥，正方形底面的棱锥叫四棱锥。本课认识棱锥的各部分，并区分垂直高和侧面斜高。

~~~
一个 n 边形底面
+ 一个顶点
→ n 个三角形侧面
→ n 边形棱锥
~~~

## 一、棱锥的组成部分

棱锥的多边形面称为底面；其余三角形面称为侧面。各侧面相交于同一个顶点，底面边称为底棱，顶点与底面各顶点相连的边称为侧棱。

~~~
底面：一个多边形
侧面：若干个三角形
顶点：所有侧面共同相交的顶点
底棱：底面的边
侧棱：顶点连到底面顶点的边
~~~

例如四棱锥有一个四边形底面、四个三角形侧面、一个锥顶。侧面与底面的交线是底棱，相邻侧面的交线是侧棱。

## 二、按底面边数命名

棱锥按底面多边形的边数命名，而不是按侧棱数或顶点总数命名。

~~~
三角形底面 → 三棱锥
四边形底面 → 四棱锥
五边形底面 → 五棱锥
n 边形底面 → n 棱锥
~~~

三棱锥也称四面体，因为它一共有四个三角形面。名称“棱锥”中的边数指底面的边数。

## 三、棱锥的面、棱和顶点数量

若棱锥底面是 $n$ 边形，则有 $n$ 个三角形侧面和 1 个底面：

~~~
面数：n + 1
顶点数：n + 1
棱数：2n
~~~

例如五棱锥有 6 个面、6 个顶点和 10 条棱：5 条底棱与 5 条侧棱。

## 四、认识棱锥的垂直高

棱锥的高是锥顶到包含底面的平面的垂直距离。高必须与底面所在平面垂直；一条侧棱通常不是棱锥的高。

~~~
棱锥高 h：锥顶到底面平面的垂直距离
侧棱：连接锥顶与底面顶点的线段
~~~

若棱锥是直棱锥，垂足在底面中心；一般棱锥的垂足不一定在底面内部。判断“高”时要看垂直关系，而不能只看图中哪条线画得竖直。

## 五、垂直高与侧面斜高

规则棱锥的侧面常有一条从锥顶到某条底棱中点的垂线，这条线段是该侧三角形的高，称为侧面斜高。它位于侧面内，与棱锥的垂直高不是同一条线段。

~~~
垂直高：垂直于底面所在平面
侧面斜高：位于一个侧面内，是该侧三角形的高
侧棱：从锥顶到一个底面顶点
~~~

规则棱锥的侧面斜高将用于计算侧面三角形面积；棱锥体积公式使用的是垂直高。

## 六、正棱锥

若底面是正多边形，且锥顶位于底面中心的正上方，棱锥称为正棱锥。正棱锥的垂直高落在底面中心，侧面是全等的等腰三角形，侧棱长度相等，侧面斜高也相等。

~~~
正棱锥：
底面是正多边形
锥顶在底面中心正上方
各侧面全等
~~~

一般棱锥的底面不一定是正多边形，锥顶的垂足也不一定位于底面中心，侧面可能大小不同。

## 七、棱锥与棱柱的区别

棱柱有两个互相平行且全等的多边形底面，侧面通常是平行四边形；棱锥只有一个多边形底面，三角形侧面汇聚于同一个锥顶。

~~~
棱柱：两个平行全等底面，侧面不汇聚于一点
棱锥：一个底面，三角形侧面共用锥顶
~~~

看清底面数量和侧面形状，就能区分这两类立体图形。

## 八、从实物或立体图识别棱锥

观察实物或示意图时，先找唯一的底面，再追踪各侧面是否都汇聚于同一点。立体图中的虚线表示被遮挡的棱，不代表不存在。

~~~
识别步骤：
1. 找到底面多边形；
2. 找到侧面共同的顶点；
3. 数底面的边数并命名；
4. 区分底棱、侧棱和高。
~~~

## 九、棱锥展开图的预备认识

把棱锥表面沿一些棱剪开并展开到平面上，会得到一个底面多边形和与底面边数相同的三角形侧面。展开图中的三角形要能沿对应底棱折回，并在同一个锥顶相接。

~~~
n 边形棱锥的展开图：
1 个 n 边形底面 + n 个三角形侧面
~~~

下一课将进一步学习如何判断展开图，并计算棱锥表面积。

## 十、结构与后续公式的联系

棱锥的表面积由底面和所有侧面面积组成；体积则取决于底面积与垂直高。认识不同的面和高度，才能正确选用后续公式。

~~~
表面积：底面面积 + 各侧面面积
体积：与底面积、垂直高有关
~~~

不要把侧面斜高或侧棱误代入体积公式。

## 十一、常见错误

- 按棱锥的总顶点数命名，而不是按底面边数命名。
- 把所有棱锥都看成正棱锥，认为各侧面必定相同。
- 把侧棱当成垂直高，忽视高必须垂直于底面。
- 把侧面斜高与棱锥垂直高混为一谈。
- 认为立体图中被遮挡的虚线棱不存在。
- 把棱锥与有两个底面的棱柱混淆。
- 数面数时漏掉底面，或把底棱重复计入侧棱。

## 十二、回顾

棱锥有一个多边形底面，三角形侧面都汇聚于同一个锥顶。底面有 $n$ 条边的棱锥有 $n$ 个侧面、$n+1$ 个面、$n+1$ 个顶点和 $2n$ 条棱。

棱锥的垂直高是锥顶到底面平面的垂直距离；侧面斜高是侧三角形内的高。后续计算体积要用垂直高，计算侧面面积则需要相应侧面的斜高。
