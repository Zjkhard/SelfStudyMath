# 10.3 正数的 n 次方根与分数指数

平方根和立方根分别是二次方根、三次方根。我们可以把这个想法推广到更高的次数，并用分数指数把开方记号与幂统一起来。

本节先讨论正数底数，避免根式取值范围带来的额外困难。核心关系是：分数指数的分母表示开几次方，分子表示再乘方几次。

## 一、从平方根和立方根开始

因为 $3^2=9$，所以 3 是 9 的平方根；因为 $2^3=8$，所以 2 是 8 的立方根。

~~~text
√9 = 3
∛8 = 2
~~~

符号 $\sqrt{\ }$ 表示平方根，$\sqrt[3]{\ }$ 表示立方根。根号内的数叫作被开方数；根号左上方的小数字叫作根指数。

## 二、正数的 n 次方根

若正数 $a$ 的正数 $b$ 满足 $b^n=a$，那么 $b$ 称为 $a$ 的正 n 次方根，记作：

~~~text
ⁿ√a = b    当且仅当    bⁿ = a，且 b > 0
~~~

这里 $n$ 是大于或等于 2 的整数，$a>0$。例如，因为 $2^4=16$，所以 $\sqrt[4]{16}=2$。

## 三、根指数的写法

平方根的根指数 2 通常省略；其他根指数要写在根号左上方：

~~~text
平方根：√a
立方根：∛a
四次方根：⁴√a
~~~

例如，$\sqrt[5]{32}=2$，因为 $2^5=32$。根指数说明要找几次方后得到被开方数，不是被开方数的乘数。

## 四、根号表示主要的正根

对正数 $a$，符号 $\sqrt[n]{a}$ 表示正的 n 次方根。要区分根号的值与方程的所有解：

~~~text
√25 = 5
x² = 25 的解是 x = 5 或 x = −5
~~~

根号 $\sqrt{25}$ 只表示非负的平方根 5；方程 $x^2=25$ 则有两个解。不能把根号符号直接理解成“正负两个值”。

## 五、用乘方验证根

求根后可以用乘方检查：把候选根乘方到指定次数，看是否得到被开方数。

~~~text
⁴√81 = 3，因为 3⁴ = 81
⁵√32 = 2，因为 2⁵ = 32
~~~

若乘方结果不等于被开方数，候选值就不正确。

## 六、完全 n 次幂

若一个正整数可以写成某个整数的 n 次方，就称它为完全 n 次幂。例如：

~~~text
25 = 5²，是完全平方数
27 = 3³，是完全立方数
16 = 2⁴，是完全四次幂
~~~

认识完全 n 次幂能帮助我们较快地求一些常见根，也能用来检查根式结果。

## 七、引入分数指数

整数指数表示重复乘方；分数指数把乘方与开方联系起来。对正数 $a$ 和正整数 $n≥2$，定义：

~~~text
a^(1/n) = ⁿ√a
~~~

例如：

~~~text
16^(1/2) = √16 = 4
27^(1/3) = ∛27 = 3
~~~

分数指数 $1/n$ 对应 n 次方根。

## 八、分数指数分母表示根指数

在 $a^{1/n}$ 中，分母 $n$ 表示开 n 次方：

~~~text
64^(1/3) = ∛64 = 4
81^(1/4) = ⁴√81 = 3
~~~

可用乘方验证：$4^3=64$，$3^4=81$。计算时先认出分母所代表的根指数。

## 九、分数指数分子表示乘方次数

若分数指数的分子大于 1，先取根再乘方，或先乘方再取根，结果相同：

~~~text
a^(m/n) = (ⁿ√a)^m = ⁿ√(a^m)
~~~

其中 $a>0$，$m,n$ 为正整数，$n≥2$。例如：

~~~text
8^(2/3) = (∛8)² = 2² = 4
~~~

这里分母 3 表示立方根，分子 2 表示平方。

## 十、再看几个分数指数

~~~text
16^(3/4) = (⁴√16)³ = 2³ = 8
32^(2/5) = (⁵√32)² = 2² = 4
~~~ 

先计算容易识别的根，再做分子表示的乘方，通常较简洁。也可以先处理根号内的乘方，只要运算条件允许。

## 十一、根式写成分数指数

根式可以改写成分数指数：

~~~text
√a = a^(1/2)
∛a = a^(1/3)
⁴√(a³) = a^(3/4)
~~~

例如：

~~~text
⁵√(x²) = x^(2/5)（x > 0）
~~~

转换时，根指数成为分母，被开方数的幂指数成为分子。

## 十二、分数指数写成根式

反过来，正数底数的分数指数也可改写为根式：

~~~text
a^(3/2) = √(a³) = (√a)³
~~~

例如：

~~~text
25^(3/2) = (√25)³ = 5³ = 125
~~~

根号与分数指数表示同一个数，可以选择更方便的形式计算。

## 十三、等价的计算顺序

对于正数底数，先开根后乘方与先乘方后开根得到相同结果：

~~~text
64^(2/3) = (∛64)² = 4² = 16
64^(2/3) = ∛(64²) = ∛4096 = 16
~~~

通常选择中间数较容易计算的一种顺序。两种写法来自同一个定义，不应改变分子、分母的作用。

## 十四、分数指数可以约分

同一个有理数指数可以用等值分数表示。例如 $2/6=1/3$，因此对正数 $a$，两种记法给出相同的值：

~~~text
a^(2/6) = a^(1/3)
~~~

具体计算前可先约分指数，以简化根式。例如：

~~~text
64^(2/6) = 64^(1/3) = ∛64 = 4
~~~

## 十五、正底数是本节的重要条件

本节的分数指数定义限定底数 $a>0$。正底数的任意正整数次方根都能在正实数范围内确定，因此分数指数表示清楚。

~~~text
(-16)^(1/2) 不属于本节正底数范围
16^(1/2) = 4
~~~

负底数的偶次方根涉及实数范围内是否有定义以及不同教材的约定，本节不扩展处理。做题时不要在未确认底数范围前随意套用分数指数规则。

## 十六、不要混淆根指数和分数指数分子

在 $a^{m/n}$ 中，分母 $n$ 对应根指数，分子 $m$ 对应乘方次数。例如：

~~~text
27^(2/3) = (∛27)² = 9
~~~

不是先开平方再取立方，也不是把 2 和 3 当作底数。每个位置都有明确的作用。

## 十七、常见错误

- 把 $a^{1/n}$ 误读成 $a÷n$。
- 把分母当作乘方次数、分子当作根指数。
- 忘记分数指数底数的范围条件。
- 把 $\sqrt{25}$ 写成 $±5$；根号表示主要的非负平方根。
- 只对分数指数分子的数字乘方，忽略分母对应的根。
- 将 $\sqrt[n]{a^m}$ 改写成 $a^{n/m}$，把分子和分母颠倒。
- 计算后不使用乘方验证结果。

## 十八、回顾

正数 $a$ 的正 n 次方根是满足 $b^n=a$ 的正数 $b$，记作 $\sqrt[n]{a}$。分数指数把根式写成幂：

~~~text
a^(1/n) = ⁿ√a
a^(m/n) = (ⁿ√a)^m = ⁿ√(a^m)
~~~

分数指数分母表示根指数，分子表示乘方次数。本节限定正数底数；计算时可在根式与分数指数之间选择方便的表示，并用乘方检查结果。
