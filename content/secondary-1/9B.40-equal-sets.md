# 9B.40 相等集合

两个集合相等，当且仅当它们包含完全相同的元素。判断相等时，要逐一核对元素，而不能只看书写顺序、集合名称或元素的个数。

## 一、相等集合的定义

若集合 A 与集合 B 的元素完全相同，就称 A 与 B 相等，记作：

~~~text
A = B
~~~

这表示 A 中每个元素都在 B 中，B 中每个元素也都在 A 中。若至少有一个元素不同，则这两个集合不相等。

## 二、元素排列顺序不影响相等

集合中的元素没有固定顺序。因此：

~~~text
A = {1, 2, 3}
B = {3, 1, 2}
~~~

A 与 B 的元素完全相同，所以 A = B。列举集合时可以调整书写顺序，不会改变集合。

## 三、重复书写不产生新元素

集合不记录同一元素出现了几次。若 A = {a, b, c}，而 B = {a, b, b, c}，重复的 b 不会成为另一个不同元素，因此 A = B。

~~~text
{2, 2, 4, 6} = {6, 4, 2}
~~~

但如果题目讨论的是数据记录及频数，重复次数可能有意义；集合相等的规则不能用来替代频数表。

## 四、元素个数相同不一定相等

两个有限集合若相等，它们的元素个数必然相同；但元素个数相同并不能保证集合相等。

~~~text
A = {1, 2, 3}
B = {1, 2, 4}
~~~

A 和 B 都有 3 个元素，但 3 属于 A 而不属于 B，4 属于 B 而不属于 A，所以 A ≠ B。

## 五、逐项检查是否相等

比较两个有限集合时，可以检查：

1. A 中的每个元素是否都在 B 中；
2. B 中的每个元素是否都在 A 中。

两项都成立，集合才相等。任一方向找到了不相同的元素，就足以判定不相等。

例如 A = {2, 4, 6}，B = {4, 6, 8}。2 在 A 中却不在 B 中，已经可以确定 A ≠ B。

## 六、用性质描述判断相等

集合可以用列举法，也可以用文字性质描述。判断相等时，要根据性质找出所有元素，再比较。

~~~text
C = {小于 6 的正偶数}
D = {2, 4}
~~~

小于 6 的正偶数只有 2 和 4，因此 C = D。

## 七、注意范围条件

性质描述中的范围会影响集合。只看相同的“倍数”或“因数”词语，而忽略限定范围，可能误判。

~~~text
E = {10 以内的正整数中，3 的倍数} = {3, 6, 9}
F = {20 以内的正整数中，3 的倍数} = {3, 6, 9, 12, 15, 18}
~~~

虽然两个集合都由 3 的倍数组成，但范围不同，元素不同，因此 E ≠ F。

## 八、利用相等关系确定未知元素

若集合相等，未知元素必须使两边的元素完全一致。

~~~text
{1, 3, x} = {1, 3, 5}
~~~

要使集合相等，左边不能多出其他元素或缺少 5，因此 x = 5。

如果 x 可能等于左边已出现的元素，要特别注意集合不会重复计数。例如 `{1, 1, x}` 实际包含哪些不同元素，应先按集合规则整理再判断。

## 九、含重复项的未知元素

考虑：

~~~text
{2, 2, x} = {2, 5}
~~~

左边已确定包含 2。要与右边元素完全相同，x 必须提供 5，因此 x = 5。若 x = 2，左边只有一个不同元素 2，缺少 5，集合不相等。

## 十、集合名称不同也可以相等

集合名称只是标记。名称不同不代表集合不同；名称相同也不代表在题目中被定义为相同，必须看元素定义。

~~~text
P = {a, e, i, o, u}
V = {u, o, i, e, a}
~~~

虽然分别叫 P、V，且排列次序不同，但元素一致，所以 P = V。

## 十一、用符号表达不相等

若两个集合至少有一个元素不同，可写作 `A ≠ B`。例如：

~~~text
A = {1, 2, 3}
B = {1, 2, 3, 4}
A ≠ B
~~~

因为 4 属于 B 却不属于 A，元素集合不完全相同。

## 十二、常见错误

- 因为元素排列顺序不同，就认为两个集合不相等。
- 把重复元素当成多个不同元素，误以为集合元素个数不同。
- 只比较元素个数，不核对具体元素。
- 忽略性质描述中的范围或限制条件。
- 只检查 A 是否包含 B 的元素，却不检查反方向。
- 在含未知元素的题目中忽略集合元素不重复的规则。

## 十三、回顾

两个集合相等，要求它们包含完全相同的元素。元素的书写顺序无关，重复列出某元素也不会改变集合；只比较元素个数并不足以判断相等。

判断时可以逐一核对两边元素，或先根据性质描述列出元素。集合相等关系也可用来确定未知元素，但要始终遵守集合不重复计数的约定。
