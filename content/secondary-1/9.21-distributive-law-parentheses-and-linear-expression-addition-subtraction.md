# 9.21 分配律、括号与一次代数式的加减

每个礼袋中有 x 支铅笔，另加 2 支彩笔。准备 3 个相同礼袋，总支数可以表示为 3(x + 2)。

也可以分别计算两类笔：铅笔共有 3x 支，彩笔共有 6 支，总数为 3x + 6。

~~~text
3(x + 2) = 3x + 6
~~~

两种写法表示同一个数量。分配律帮助我们从一个整体的倍数，转为各部分的倍数之和；括号则告诉我们这个整体包含哪些项。

## 一、本节讨论什么样的一次代数式

观察：

~~~text
3x + 2
−5x + 7
2a − 3b + 4
~~~

这些式子的含字母项都是一个字母的一次方乘数字系数，不含 x²、ab 等项。本节把这种形式称为一次代数式，或一次式。

它可以含一个字母，也可以含多个字母，还可以有常数项。

例如 2x² + 3 不是一次式，xy + 1 也不是一次式。只看到字母上没有写出指数，并不能断定是一次式：xy 是两个字母相乘的项。

一次式运算后，含字母项也可能全部抵消，最后只剩常数或 0。

## 二、分配律让每一项都参与乘法

分配律可以写成：

~~~text
k(a + b) = ka + kb
~~~

左边把 a 与 b 的整个和乘以 k；右边分别把两部分乘以 k，再相加。

例如：

~~~text
4(x + 3) = 4x + 12
~~~

括号中的 x 和 3 都要乘以 4，不能只乘第一项而写成 4x + 3。

本节主要用常数 k 乘一次式，不在这里展开两个含字母的括号相乘。

## 三、含减法的括号也使用分配律

因为 a − b = a + (−b)：

~~~text
k(a − b)
= k[a + (−b)]
= ka + k(−b)
= ka − kb
~~~

例如：

~~~text
5(2x − 3) = 10x − 15
~~~

第二项原来是 −3，所以乘以 5 后为 −15。减号并没有消失，而是包含在这一项的符号中。

## 四、负系数也要乘括号内的每一项

展开 −3(2x − 5)：

~~~text
−3(2x − 5)
= (−3) × 2x + (−3) × (−5)
= −6x + 15
~~~

第一项的系数是负数乘正数，得到 −6；第二项是两个负数相乘，得到 +15。

不能仅凭“括号前有负号”就跳过系数计算。这里既要把 3 分配给每一项，也要处理负号。

## 五、括号前是正号时，各项符号不变

加上一个和，就是把这个和的各项加进来：

~~~text
a + (b + c) = a + b + c
a + (b − c) = a + b − c
~~~

例如：

~~~text
2x + (3x − 4)
= 2x + 3x − 4
= 5x − 4
~~~

去掉括号后，里面的 −4 仍为 −4。括号前的加号不要求把里面所有项都改成正数。

## 六、括号前是负号时，取整个式子的相反数

减去一个式子，等于加上这个式子的相反数。括号前的负号相当于乘以 −1：

~~~text
−(b + c) = (−1)(b + c) = −b − c
−(b − c) = (−1)[b + (−c)] = −b + c
~~~

所以，负号作用于整个括号时，括号里面每一项的符号都反过来。

例如：

~~~text
7 − (2x − 3)
= 7 − 2x + 3
= 10 − 2x
~~~

不能写成 7 − 2x − 3，那只是改变了第一项的符号，没有取整个式子的相反数。

## 七、两个一次式相加

计算 (3x + 5) + (2x − 7)。

先去掉加号后面的括号，保留各项符号：

~~~text
(3x + 5) + (2x − 7)
= 3x + 5 + 2x − 7
~~~

再把同类项放在一起：

~~~text
= (3x + 2x) + (5 − 7)
= 5x − 2
~~~

字母项合并系数，常数项按普通数相加减。字母的指数仍为 1，不因为相加而变成平方。

## 八、两个一次式相减

计算 (3x + 5) − (2x − 7)。

减号作用于整个第二个式子：

~~~text
(3x + 5) − (2x − 7)
= 3x + 5 − 2x + 7
= (3x − 2x) + (5 + 7)
= x + 12
~~~

第一个括号中的项保持原样，第二个括号中的每一项都变为相反数。

两个式子的差，不能只把开头的 3x 与 2x 相减，却漏掉常数项。

## 九、多个字母分别合并同类项

计算：

~~~text
(2a − 3b + 4) − (5a + b − 6)
~~~

先去括号：

~~~text
= 2a − 3b + 4 − 5a − b + 6
~~~

再比较字母部分：

~~~text
= (2a − 5a) + [(−3b) + (−b)] + (4 + 6)
= −3a − 4b + 10
~~~

a 项只与 a 项合并，b 项只与 b 项合并，常数项另算。不能把 −3a 和 −4b 合成 −7ab。

## 十、分数或小数系数不改变展开方法

展开 (1/2)(6x − 4)：

~~~text
(1/2)(6x − 4)
= (1/2) × 6x − (1/2) × 4
= 3x − 2
~~~

再看：

~~~text
−0.5(2y + 6)
= (−0.5) × 2y + (−0.5) × 6
= −y − 3
~~~

展开规律相同，系数的数值计算使用有理数乘法。系数为分数或小数，并不意味着式子不是一次式。

## 十一、嵌套括号可以从内向外整理

整理 4x − [2x − (x + 3)]：

~~~text
4x − [2x − (x + 3)]
= 4x − [2x − x − 3]
= 4x − (x − 3)
= 4x − x + 3
= 3x + 3
~~~

先处理最内层括号，外层减号暂时保持不变。直到去掉外层括号时，再改变整个外层括号内各项的符号。

逐层整理能避免把同一项的符号多变一次或少变一次。

## 十二、演示：展开与合并一起完成

整理：

~~~text
3(2x − 1) − 2(x + 4)
~~~

分别展开两个乘积：

~~~text
3(2x − 1) − 2(x + 4)
= 6x − 3 − 2x − 8
~~~

这里第二个乘积前的减号，可以和 2 合成系数 −2，再分配到括号里的每一项。

合并同类项：

~~~text
= (6x − 2x) + (−3 − 8)
= 4x − 11
~~~

检查 x = 2 时，原式为 3 × 3 − 2 × 6 = −3，结果式为 8 − 11 = −3，两者一致。

这个代入能帮助发现错误；变形对所有 x 都成立，依据的仍是分配律和同类项合并。

## 十三、演示：相减时字母项可能完全抵消

计算 (5x + 2) − (5x − 6)：

~~~text
(5x + 2) − (5x − 6)
= 5x + 2 − 5x + 6
= (5x − 5x) + 8
= 8
~~~

无论 x 取什么值，两个式子的差都是 8。

结果只剩常数，并不说明前面的运算错了。两个相同字母项互为相反数时，会完全抵消。

注意，抵消的是 5x 与 −5x，不是因为两个原式“都有 x”，就能把含 x 的所有项随意删掉。

## 十四、演示：两组费用的和与差

每盒彩笔售价 x 元。甲买 3 盒，另付 5 元包装费；乙买 2 盒，另付 8 元包装费。

~~~text
甲的费用：(3x + 5) 元
乙的费用：(2x + 8) 元
~~~

两人合计费用为：

~~~text
(3x + 5) + (2x + 8) = 5x + 13（元）
~~~

甲的费用减去乙的费用为：

~~~text
(3x + 5) − (2x + 8) = x − 3（元）
~~~

虽然甲多买一盒，但包装费少 3 元，所以费用差为“多一盒的价格减去 3 元”。

若 x = 10，甲比乙多付 7 元；若 x = 2，差为 −1 元，表示甲反而少付 1 元。表达式的符号要结合数量意义解释，不能预先认定差一定为正。

## 十五、分清展开与合并的作用

展开括号，是用分配律把整体乘法改写为各项的和。

合并同类项，是把相同字母部分的系数相加减。

例如：

~~~text
2(x + 3) + 4x
= 2x + 6 + 4x       展开
= 6x + 6             合并同类项
~~~

不能把常数 6 和字母项 6x 合成 12x。它们不是同类项。

也不能随意去掉乘法中的括号。2(x + 3) 不等于 2x + 3；只有把乘法分配到每一项，才能保持等价。

## 十六、小结

分配律把括号中的每一项都乘以外面的因数，系数为负数、分数或小数时也一样。

括号前是加号，各项符号保持不变；括号前是减号，要取整个括号的相反数，各项符号都反过来。

两个一次式相加减，先看清括号范围与符号，再展开或去括号，最后按字母部分合并同类项。多个字母要分别处理，常数项单独合并。

每次变形都应保持原来的数量关系。可以用代入帮助检查，但正确性的依据是分配律、相反数关系和同类项的结构。
