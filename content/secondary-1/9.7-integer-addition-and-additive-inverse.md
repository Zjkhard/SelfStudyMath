# 9.7 整数加法与相反数

早晨的气温是 −3°C，后来升高了 5°C。气温先从 −3°C 升到 0°C，再升到 2°C。

~~~text
原来气温：−3°C
温度变化：+5°C
后来气温：2°C

−3 + 5 = 2
~~~

加法把原来的数与变化联系起来。遇到负数后，加法仍然有清晰的数量意义，但结果不一定比原来的数大。

## 一、读清加号与负号的作用

看下面的算式：

~~~text
4 + (−2)
~~~

中间的“+”表示加法运算；括号里的“−”是负号，说明第二个加数是负数 −2。

这表示把 4 和 −2 相加，不是把 4 和 2 相加。

本节常把负数加数放在括号里，让运算符号和数的符号容易区分。例如：

~~~text
(−4) + (−2)
~~~

这里的两个加数都是负数。

## 二、数轴上加正数，就是向右移动

规定数轴向右为正。计算 −3 + 5，可以先在 −3 处确定起点，再向右移动 5 个单位。

~~~text
−3 → −2 → −1 → 0 → 1 → 2
             向右共 5 步
~~~

所以：

~~~text
−3 + 5 = 2
~~~

起点是负数，不代表移动方向也向左。方向由加上的数决定：加正数向右，加负数向左。

如果加 0，就不移动，仍停在原来的位置。

## 三、数轴上加负数，就是向左移动

计算 4 + (−6)，从 4 出发，向左移动 6 个单位：

~~~text
4 → 3 → 2 → 1 → 0 → −1 → −2
              向左共 6 步
~~~

因此：

~~~text
4 + (−6) = −2
~~~

再看：

~~~text
4 + (−2) = 2
~~~

加上的数是负数，结果却仍是正数。移动方向和最终位置是两种不同的信息。

加一个正数，结果比原数大；加一个负数，结果比原数小。不能因为运算叫“加法”，就认为数值一定增大。

## 四、正负单位配对后互相抵消

把 +1 看作一个正单位，把 −1 看作一个负单位。一正一负配对，合计为 0：

~~~text
(+1) + (−1) = 0
~~~

计算 5 + (−3)，可以把五个正单位和三个负单位放在一起：

~~~text
正单位：+1  +1  +1  +1  +1
负单位：−1  −1  −1
配对后：三对抵消，剩下两个 +1。
~~~

所以 5 + (−3) = 2。

反过来，三个正单位和五个负单位配对，会剩下两个负单位：

~~~text
3 + (−5) = −2
~~~

这种抵消模型与数轴移动得到的是同一个结果。

## 五、同号相加：合并同一个方向的数量

两个正整数相加，沿用已经熟悉的方法：

~~~text
4 + 7 = 11
~~~

两个负整数相加，是把同一负方向的数量合并：

~~~text
(−4) + (−7) = −11
~~~

在数轴上，从 −4 再向左移动 7 个单位，得到 −11；用单位模型看，四个负单位和七个负单位合成十一个负单位。

所以，同号整数相加，把绝对值相加，并保留共同的符号。

~~~text
|−4| + |−7| = 4 + 7 = 11
两个加数都为负，结果为 −11。
~~~

“两个负数相乘得正”是乘法规律，不能搬到加法中。两个负数相加仍是负数。

## 六、异号相加：先抵消，再看剩下的方向

计算 (−9) + 4：

~~~text
九个负单位与四个正单位配对。
四对抵消后，剩下五个负单位。
所以 (−9) + 4 = −5。
~~~

用绝对值表达这个过程：

~~~text
|−9| = 9，|4| = 4
9 − 4 = 5
绝对值较大的加数是 −9，结果取负号。
~~~

因此，异号整数相加，用较大的绝对值减去较小的绝对值，结果取绝对值较大的加数的符号。

如果正方向的数量更多，结果为正：

~~~text
(−4) + 9 = 5
~~~

决定符号的是绝对值较大的加数，不是写在前面的加数，也不是数值较大的加数。

## 七、绝对值相等时，恰好抵消为零

计算 6 + (−6)，六个正单位和六个负单位正好全部配对：

~~~text
6 + (−6) = 0
~~~

6 与 −6 互为相反数。它们相加后没有剩余方向，所以结果是 0。

0 既不是正数，也不是负数，不需要给它加一个负号来表示“来自负方向”。

## 八、相反数也是加法逆元

两个数相加得到 0，就能在加法中互相抵消。因此，一个数的相反数也叫作它的**加法逆元**。

~~~text
8 的加法逆元是 −8。
−8 的加法逆元是 8。
0 的加法逆元是 0。
~~~

“相反数”强调数轴上的对称位置；“加法逆元”强调相加得到 0 的作用。这里两个名称指的是同一个数。

对于任意整数 a：

~~~text
a + (−a) = 0
~~~

如果 a = −8，那么 −a = 8。字母前面的负号表示取相反数，不保证结果一定为负。

相反数也不同于倒数：8 的相反数是 −8，倒数是 1/8。前者与原数相加得 0，后者与原数相乘得 1。

## 九、加零不改变原数

在数轴上，加 0 表示移动 0 个单位。因此：

~~~text
7 + 0 = 7
(−7) + 0 = −7
0 + 0 = 0
~~~

一般地：

~~~text
a + 0 = 0 + a = a
~~~

0 在加法中保持原数不变，而相反数把原数抵消为 0。这是两种不同的作用。

## 十、交换加数，和不变

比较：

~~~text
(−5) + 8 = 3
8 + (−5) = 3
~~~

不论先写哪一方向的单位，最终配对后都剩下三个正单位。

整数加法也满足**交换律**：

~~~text
a + b = b + a
~~~

交换时，加数要连同它自己的符号一起移动。把 −5 移到后面后，仍应写成 −5，不能变成 +5。

## 十一、改变加法的分组，和不变

计算 [(−7) + 4] + 6：

~~~text
[(−7) + 4] + 6 = (−3) + 6 = 3
~~~

也可以先把后两个数相加：

~~~text
(−7) + (4 + 6) = (−7) + 10 = 3
~~~

不论先合并哪一组，最后都是七个负单位与十个正单位配对，结果相同。

整数加法满足**结合律**：

~~~text
(a + b) + c = a + (b + c)
~~~

它允许改变相加的分组，不会改变任何一个加数的符号。

## 十二、利用相反数配对简化计算

计算：

~~~text
(−18) + 7 + 18 + (−12) + 5
~~~

先观察有没有能相互抵消的加数。−18 和 18 互为相反数，可以利用交换律与结合律把它们放在一起：

~~~text
(−18) + 7 + 18 + (−12) + 5
= [(−18) + 18] + (7 + 5) + (−12)
= 0 + 12 + (−12)
= 0
~~~

每次调整都保留了原来的加数及其符号，只改变顺序和分组。

另一种方法是分别合并正、负加数：

~~~text
正加数合计：7 + 18 + 5 = 30
负加数合计：(−18) + (−12) = −30
总和：30 + (−30) = 0
~~~

两种方法得到同样的结果。

## 十三、演示：连续温度变化

气温原来是 −4°C，先升高 7°C，再降低 5°C。

升高记为正变化，降低记为负变化：

~~~text
后来气温 = (−4) + 7 + (−5)
~~~

按发生顺序计算：

~~~text
(−4) + 7 = 3
3 + (−5) = −2
~~~

所以后来气温是 −2°C。

也可以先求总变化：

~~~text
7 + (−5) = 2
(−4) + 2 = −2
~~~

总变化为 +2°C，表示最终比原来升高 2°C；最终温度 −2°C 则表示仍低于 0°C。变化量与最终温度不能混为一谈。

## 十四、演示：找出能抵消一个和的数

先计算 (−6) + 10：

~~~text
(−6) + 10 = 4
~~~

要让这个结果再加一个整数后变成 0，需要加上 4 的相反数 −4：

~~~text
[(−6) + 10] + (−4) = 4 + (−4) = 0
~~~

再取相反数时，要针对整个和 4，而不是只看其中的 −6 或 10。

这个例子说明：先弄清被抵消的是哪个数，再寻找它的加法逆元。

## 十五、小结

在向右为正的数轴上，加正整数向右移动，加负整数向左移动，加 0 不移动。

同号相加，绝对值相加，保留共同符号；异号相加，绝对值相减，取绝对值较大的加数的符号。异号且绝对值相等时，结果为 0。

一个数与它的相反数相加得 0，所以相反数也叫加法逆元。0 的相反数仍是 0。

整数加法满足交换律与结合律，可以通过相反数配对或分别合并正负加数来简化计算。调整顺序和分组时，每个加数都要保留自己的符号。
