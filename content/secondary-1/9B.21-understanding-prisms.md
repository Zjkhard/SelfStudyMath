# 9B.21 棱柱的认识

长方体、三棱柱和五棱柱的底面形状不同，但它们有共同结构：两端是相同且平行的多边形，中间的侧面把两端连接起来。

这样的立体叫作棱柱。认识它的关键是观察底面与侧面的对应关系，而不是只看摆放方向或外形像什么。

## 一、什么是棱柱

棱柱有两个形状和大小都相同、互相平行的多边形面。这两个面叫作底面。连接两底面对应边的面叫作侧面。

~~~text
两个全等、平行的多边形：底面
连接两底面的面：侧面
连接底面对应顶点的棱：侧棱
~~~

本节讨论的棱柱由平面围成。两个底面处于相对位置，沿棱柱的方向观察时，一个底面可以移动到另一个底面的位置，形状大小保持不变。

## 二、底面不一定在图形的下方

“底面”是棱柱结构中的名称，不表示它必须接触桌面或画在纸张下方。把棱柱转动或横放后，两个底面仍是原来那一对全等且平行的多边形。

例如，把三棱柱横放，两个三角形端面仍是底面，连接它们的三个长方形仍是侧面。

识别时先找两个相对的全等多边形，再看其余的面如何连接。

## 三、按底面的边数给棱柱命名

棱柱名称由底面多边形的边数决定：

~~~text
三角形底面 → 三棱柱
四边形底面 → 四棱柱
五边形底面 → 五棱柱
n 边形底面 → n 棱柱
~~~

名称中的“三”“四”“五”指底面边数，不是棱柱有多少个面。三棱柱有两个三角形底面和三个侧面，共五个面。

## 四、棱柱的侧面与侧棱

每一条侧棱连接两个底面上相对应的顶点。侧面围绕底面一周排列，通常每条底边对应一个侧面。

若底面是 n 边形，棱柱有 n 个侧面和 n 条侧棱。每个侧面连接两个相邻的侧棱。

直棱柱的侧棱垂直于底面，侧面都是长方形。斜棱柱的侧棱倾斜，侧面通常是平行四边形。

## 五、直棱柱与斜棱柱

~~~text
直棱柱：侧棱垂直于底面
斜棱柱：侧棱不垂直于底面
~~~

一个直三棱柱横放或斜着画在纸上，仍可能是直棱柱；判断直与斜，要看侧棱和底面的关系，不看图形相对纸张的方向。

本单元后续计算主要使用直棱柱。判断高度时，仍以两底之间的垂直距离为准。

## 六、三棱柱的结构

三棱柱的底面是三角形，因此有两个三角形底面和三个侧面：

~~~text
底面：2 个三角形
侧面：3 个平行四边形（直棱柱中为长方形）
面数：5 个
~~~

两个三角形大小相同、方向相对；三个侧面围绕着它们，把对应边连接起来。

## 七、四棱柱与长方体、正方体

四棱柱的底面是四边形，有两个四边形底面和四个侧面。底面若为长方形、侧面也为长方形，就形成长方体。

正方体是长方体的特殊情形，所有面都是相同的正方形。因此，长方体和正方体也可以看作特殊的四棱柱。

并非所有四棱柱都是长方体：若侧面倾斜，或底面不是长方形，整体仍可能是四棱柱，但不是长方体。

## 八、五棱柱的结构

五棱柱的两个底面是全等的五边形，另有五个侧面：

~~~text
底面：2 个五边形
侧面：5 个
总面数：7 个
~~~

直五棱柱的五个侧面是长方形；每个侧面沿着一条五边形底边连接到底面。

## 九、面数与底边数的关系

若底面有 n 条边，侧面有 n 个，此外还有两个底面，所以总面数为：

~~~text
面数 = n + 2
~~~

例如六棱柱有 6 个侧面、2 个底面，共 8 个面。这里的计数要包含背面和底部看不见的面。

## 十、棱数与顶点数

两个 n 边形底面各有 n 个顶点与 n 条边；两个底面之间还有 n 条侧棱。因此：

~~~text
顶点数 = 2n
棱数 = n + n + n = 3n
~~~

三棱柱有 6 个顶点、9 条棱；五棱柱有 10 个顶点、15 条棱。计数时不能只数图上看得见的部分。

## 十一、用三棱柱核对计数

~~~text
底面边数 n = 3
面数：3 + 2 = 5
棱数：3 × 3 = 9
顶点数：2 × 3 = 6
~~~

三个侧面、两块底面、九条棱和六个顶点都与三棱柱的结构相符。这个例子也说明名称里的“三”不等于面数。

## 十二、平行截面形状相同

把棱柱沿着平行于底面的方向切开，得到的截面与底面形状、大小都相同。沿棱柱方向的每一层都保持同样的横截面。

~~~text
一个底面 → 相同的平行截面 → 另一个底面
~~~

这与棱锥不同：棱锥只有一个底面，侧面汇聚到一个顶点，平行于底面的截面通常越靠近顶点越小。

## 十三、棱柱与棱锥的区别

| 特征 | 棱柱 | 棱锥 |
| --- | --- | --- |
| 底面 | 两个全等且平行的多边形 | 一个多边形 |
| 侧面 | 连接两个底面 | 三角形并汇聚于一个顶点 |
| 平行于底面的截面 | 与底面全等 | 通常随位置改变大小 |

观察一个立体时，找有没有两个全等平行底面，通常能快速区分棱柱与棱锥。

## 十四、棱柱与圆柱的区别

圆柱也有两个全等且平行的圆形底面，但圆不是多边形，圆柱侧面是曲面。因此本单元所说的棱柱底面为多边形，侧面由平面组成。

圆柱可以沿侧面展开成一个长方形和两个圆面；棱柱展开后则由多边形底面和侧面组成。它们结构相似之处是有两个平行且相同的底面，侧面形状不同。

## 十五、棱柱展开图中的面

棱柱沿侧棱剪开后，侧面可以依次摊开成一条相连的带状图形，两个底面仍是全等的多边形。

~~~text
展开图 = 两个全等底面 + 一圈依次连接的侧面
~~~

直棱柱的侧面是长方形。折回时，侧面带首尾相接，两个底面封住两端；每条底边要与相应侧面的边匹配。

## 十六、棱柱高与底面内部的高不同

棱柱的高是两底面之间的垂直距离。底面本身也可能有“高”，例如三角形底面求面积时使用的三角形高。

~~~text
底面中的高：在底面平面内，求多边形面积
棱柱的高：两底面之间的垂直距离
~~~

这两个长度服务于不同计算，不能混为一谈。下一节计算棱柱体积时，会先求底面面积，再乘棱柱高。

## 十七、识别棱柱的步骤

~~~text
先找两个全等且平行的多边形面。
确认其余的面连接两个底面。
按底面边数给棱柱命名。
看侧棱是否垂直于底面，判断直棱柱或斜棱柱。
需要计数时，包含看不见的背面、棱和顶点。
~~~

如果只看到一个多边形面，不能马上判定为棱柱；还要确认另一个对应底面和连接两底面的侧面。

## 十八、小结

棱柱有两个全等、平行的多边形底面，以及连接底面的侧面。底面有 n 条边时，棱柱有 n 个侧面、n + 2 个面、3n 条棱和 2n 个顶点。

长方体和正方体是特殊的四棱柱；直棱柱的侧棱垂直于底面，侧面为长方形。棱柱与棱锥的底面数量、侧面汇聚方式不同，与圆柱则在底面和侧面的形状上不同。
