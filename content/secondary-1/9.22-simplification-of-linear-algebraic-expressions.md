# 9.22 一次代数式的化简

每个礼袋放 x 支铅笔和 2 支彩笔。准备 3 袋后，又另外放入 2x 支铅笔和 1 支彩笔。

总支数可以表示为：

~~~text
3(x + 2) + 2x + 1
~~~

展开后，共有 3x + 2x = 5x 支铅笔，6 + 1 = 7 支彩笔，所以总支数也可以写成 5x + 7。

~~~text
3(x + 2) + 2x + 1 = 5x + 7
~~~

把式子改写得更简洁，同时保持原来的值不变，就是化简。

## 一、化简不需要先知道字母的值

例如：

~~~text
3x + 2x + 4 = 5x + 4
~~~

这个关系不依赖某个指定的 x。只要在允许的取值范围内，两种表示的值始终相同。

化简不是猜测一个字母值，也不是随意删掉看起来复杂的部分，而是使用运算律进行等价变形。

较简洁的式子通常更容易求值，也更容易看清数量之间的关系。

## 二、先观察结构，再选择步骤

化简一次式时，常用的思路是：

1. 看清括号层次、运算符号和各项的系数。
2. 利用分配律展开，或从内向外去括号。
3. 连同符号辨认各项，把同类项放在一起。
4. 相加减系数，保留字母部分；合并常数项。
5. 整理写法，检查是否遗漏或重复计算。

这不是要求每个式子都机械写满所有步骤。没有括号时，可以直接合并同类项；有方便的结构时，也可以先作等价整理。

## 三、没有括号时直接合并同类项

化简 7x − 3 + 2x + 8：

~~~text
7x − 3 + 2x + 8
= (7x + 2x) + (−3 + 8)
= 9x + 5
~~~

7x 和 2x 的字母部分相同，系数相加；−3 和 8 是常数项，单独合并。

调整顺序时，每项连同自己的符号一起移动。−3 不能移到后面后变成 +3。

## 四、先展开，再合并

化简 4(2x + 3) − 5x：

~~~text
4(2x + 3) − 5x
= 8x + 12 − 5x
= (8 − 5)x + 12
= 3x + 12
~~~

括号中的 2x 与 3 都乘以 4，所以常数项变为 12。

不能写成 8x + 3 − 5x，也不能把 3x 与 12 合并成 15x，因为它们不是同类项。

## 五、负系数展开时逐项判断符号

化简 −2(3x − 4) + 5(x − 1)：

~~~text
−2(3x − 4) + 5(x − 1)
= −6x + 8 + 5x − 5
= (−6 + 5)x + (8 − 5)
= −x + 3
~~~

−2 乘 −4 得到 +8，5 乘 −1 得到 −5。每项的符号来自相应的乘法，而不是统一改成某一个符号。

最后 x 的系数为 −1，通常写成 −x，不写成 −1x。

## 六、减去括号要取整个式子的相反数

化简 6x − (2x + 5) − (x − 3)：

~~~text
6x − (2x + 5) − (x − 3)
= 6x − 2x − 5 − x + 3
= (6 − 2 − 1)x + (−5 + 3)
= 3x − 2
~~~

第一个括号里的两项都变号，第二个括号里的两项也都变号。

把 x 的系数看成 1，有助于清楚记录 −x 对系数总和的贡献。

## 七、嵌套括号逐层整理

化简 5x − 2[3x − (x − 4)]：

~~~text
5x − 2[3x − (x − 4)]
= 5x − 2(3x − x + 4)
= 5x − 2(2x + 4)
= 5x − 4x − 8
= x − 8
~~~

先处理最内层的减法，外面的“−2 倍”暂时保持原样。内部简化后，再把 −2 分配给整个括号。

逐层替换时，未计算部分的符号和范围都要保留。这样可以避免漏掉外层减号。

## 八、多字母一次式分别合并

化简 3(2a − b) − 2(a + 4b) + 5：

~~~text
3(2a − b) − 2(a + 4b) + 5
= 6a − 3b − 2a − 8b + 5
= (6 − 2)a + (−3 − 8)b + 5
= 4a − 11b + 5
~~~

a 项、b 项和常数项各自合并。

两个字母都为一次方，并不意味着它们是同类项。4a 与 −11b 必须分别保留。

## 九、分数系数先按有理数运算处理

化简 (1/2)(3x − 4) − (1/3)(x + 6)：

~~~text
(1/2)(3x − 4) − (1/3)(x + 6)
= (3/2)x − 2 − (1/3)x − 2
= (3/2 − 1/3)x − 4
= (9/6 − 2/6)x − 4
= (7/6)x − 4
~~~

通分的是数字系数 3/2 和 1/3，字母部分 x 保持不变。

不必把系数过早换成小数近似值，否则可能失去准确的化简结果。

## 十、整体除以常数可以逐项分配

化简 (6x − 9)/3 + x，其中除数 3 是非零常数。

~~~text
(6x − 9)/3 + x
= 2x − 3 + x
= 3x − 3
~~~

除以 3 等于乘以 1/3，所以分子中的每一项都要除以 3。

不能只把 6x 除以 3，却让 −9 保持不变。分数线表示整个分子作为一个整体参与除法。

## 十一、小数系数也可以准确合并

化简 0.4(5x − 2) + 0.5x + 1.3：

~~~text
0.4(5x − 2) + 0.5x + 1.3
= 2x − 0.8 + 0.5x + 1.3
= 2.5x + 0.5
~~~

这里各步使用有限小数的准确运算，不需要把结果写成近似关系。

也可以把小数系数化成分数再计算，两种方法应得到等值结果。

## 十二、字母项抵消后可能只剩常数

化简 2(3x + 4) − 6x − 5：

~~~text
2(3x + 4) − 6x − 5
= 6x + 8 − 6x − 5
= 3
~~~

原式虽然含 x，最终的值却不随 x 改变，因为含 x 的两项完全抵消了。

如果所有项都抵消，例如 4(x + 2) − 4x − 8，结果就是 0。

结果为常数或 0，并不表示“一次式不能这样计算”，而是说明它的字母部分在运算中消去了。

## 十三、规范整理结果，但不追求唯一外观

系数为 1 时通常省略 1，系数为 −1 时写成负号，系数为 0 的项可以省略。

例如：

~~~text
1x + 0y − 3 = x − 3
~~~

通常把字母项写在前、常数项写在后，多字母项按一致顺序排列，方便阅读。

但 3x − 2 与 −2 + 3x 是等价的；x + 5 与 5 + x 也一样。化简的目标是准确和清楚，不是只有某一种排列才正确。

## 十四、演示：用不同方法检查综合化简

化简 3(2x − 1) − 2(x + 4) + x：

~~~text
3(2x − 1) − 2(x + 4) + x
= 6x − 3 − 2x − 8 + x
= (6 − 2 + 1)x − 11
= 5x − 11
~~~

选择 x = 2 代入原式：

~~~text
3 × (4 − 1) − 2 × (2 + 4) + 2
= 9 − 12 + 2
= −1
~~~

代入结果式也得到 5 × 2 − 11 = −1。

还可以观察展开后的系数总和为 5，常数总和为 −11，与结果对应。

代入一致能帮助检查，但一个数值例子不是对所有取值成立的证明。原式与结果式始终等价，依据的是每一步正确使用了运算律。

## 十五、演示：化简后看清数量关系

一个长方形长为 (2x + 3) 厘米，宽为 (x + 1) 厘米，其中 x 为正数。

周长为：

~~~text
P = 2[(2x + 3) + (x + 1)]
  = 2(3x + 4)
  = 6x + 8
~~~

所以周长可以简洁地表示为 (6x + 8) 厘米。

当 x = 2 时，长为 7 厘米、宽为 3 厘米，周长为 20 厘米；简式也给出 6 × 2 + 8 = 20。

化简后的系数 6 还告诉我们：x 每增加 1，周长数值增加 6。简洁表示不仅方便计算，也让变化关系更容易看见。

## 十六、化简、求值与解方程分别做什么

~~~text
化简：3x + 2x − 4 → 5x − 4。
求值：给定 x = 2，得到 5x − 4 = 6。
解方程：给定 5x − 4 = 6，寻找 x。
~~~

化简改变表示方式，求值计算指定取值下的数值，解方程寻找满足等量条件的未知数。

不能在化简 5x − 4 时，擅自令它等于 0，再去寻找 x。原来的任务没有给出这样的等式条件。

也不能把某次代入得到的 6 当作原式对所有 x 的化简结果。

## 十七、小结

一次代数式化简，是在允许的取值范围内保持值不变，把表示整理得更简洁。

常用流程是看清结构、展开或去括号、连同符号辨认项、合并同类项，再规范书写结果。

负系数要分配到每一项，减去括号要取整个括号的相反数。分数和小数系数按有理数规则计算，字母部分保持不变。

字母项可能抵消，结果可以是常数或 0。通过代入、检查系数与实际数量关系来复核，并分清化简、求值与解方程的不同目的。
