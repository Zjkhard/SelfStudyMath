# 9.40 角的测量与分类

一扇门从关闭的位置转开，开得越大，门与原来位置之间的转动越大。我们可以用角描述这种转动。

在纸上，把两条射线从同一个点画出，也能表示一个角。

这一节学习怎样命名角、用量角器测量，并按度数分类。图形只作示意，不一定按标注角度准确绘制。

## 一、角有顶点和两条边

从同一个点出发的两条射线形成角。共同端点叫作角的**顶点**，两条射线叫作角的**边**。

~~~text
        A
       ↗
      /
O ●────────────→ B
~~~

顶点为 O，两边为射线 OA 和射线 OB。A、B 用来说明射线方向，不是射线的终点。

通常用一条弧线或角度标记说明正在讨论哪个开口区域。

## 二、三个字母命名时，顶点写在中间

符号 ∠ 表示角。例如 ∠AOB 读作“角 AOB”。

~~~text
∠AOB：顶点是 O。
∠BOA：也表示由 OB、OA 构成的同一个已标明的角。
~~~

顶点字母必须在中间，不能把这个角写成 ∠OAB，因为那会把顶点改成 A。

当顶点处只有一个明确的角时，可以简写为 ∠O；如果有多条射线形成多个角，就应使用三个字母或编号，避免混淆。

## 三、角的大小表示转过多少

把一个方向绕顶点转动到另一个方向，转动量可以用角度描述。

完整一圈分成 360 个相等的角度单位，每个单位叫作一**度**，记为 1°。

~~~text
一整圈：360°
半圈：180°
四分之一圈：90°
~~~

45° 读作“四十五度”。度是角度单位，不是长度单位，不能把角度写成厘米。

90° 的角为直角，常用小方角标记。

## 四、边画得更长，角并不会更大

角的大小由两边的方向和所标明的转动范围决定，不由边上的线条长度决定。

沿原方向把两条射线画得更长，角度仍然相同。把图放大或缩小，只要方向关系不变，角度也不变。

同样，把整个图旋转，角的大小不会改变。

因此，判断角大小要看开口与转动量，不能比较哪幅图的边更长或占纸面积更多。

## 五、同两条边可能对应不同转动范围

两条不重合、也不相反的射线，可以标出小于 180° 的较小角，也可以标出大于 180° 的另一侧角。

例如较小角为 60°，另一侧绕行的角为 300°，两者合计一整圈。

~~~text
60° + 300° = 360°
~~~

只看到两条边，未必足以确定讨论的是哪个角。看弧线、度数或“较小角”“优角”等说明，才能明确范围。

三个字母通常命名已经在图中明确标记的角，不应忽略范围而把两种转动混为一谈。

## 六、量角器用刻度表示角度

常见半圆量角器有中心标记、一条基线和 0° 至 180° 的刻度。

通常有内外两套数字，分别从两端的 0° 开始，方便从不同方向测量。

测量前先找中心与两端的零刻度，不要把半圆边缘或旁边某个数字误当作中心。

两套刻度不是两个不同的角度单位，只是起始方向不同。

## 七、测量时中心与顶点对齐

测量一个不超过 180° 的角，可以这样放置量角器：

1. 把中心标记准确放在角的顶点上。
2. 让基线的一侧与角的一条边重合。
3. 找到这条边对应的 0°，选择从该 0° 开始的刻度。
4. 读另一条边所指向的度数。

如果角的边画得太短，可以沿原方向用直尺延长，使它达到刻度边缘；延长不改变角度。

不能让量角器中心离开顶点，再用“看起来接近”的刻度代替准确对齐。

## 八、读数前先估计锐角还是钝角

假设一条边与量角器右端 0° 对齐，另一条边落在一组标为 35°、另一组标为 145° 的位置。

应该读从右端 0° 开始的刻度，即 35°。

~~~text
从对齐边的 0° 出发读数。
不能随意选另一套刻度的 145°。
~~~

先观察开口小于还是大于直角，也能帮助检查：明显小于直角的角，不应读成 145°。

估计用于发现读数错误，但不能代替对齐和测量。

## 九、按度数分类

| 类型 | 角度范围 | 例子 |
| --- | --- | --- |
| 锐角 | 大于 0°，小于 90° | 35° |
| 直角 | 等于 90° | 90° |
| 钝角 | 大于 90°，小于 180° | 120° |
| 平角 | 等于 180° | 180° |
| 优角 | 大于 180°，小于 360° | 240° |
| 周角 | 等于 360° | 360° |

优角也称反角，英文常称 reflex angle。

0° 表示没有转动，也称零角，不属于锐角。90°、180° 与 360° 是各自的边界类型，不能放入旁边的开区间类别。

## 十、平角的两边是相反方向的射线

平角为 180°，两边从同一顶点向相反方向延伸，合在一起形成一条直线。

~~~text
←────A────● O────B────→
~~~

射线 OA 与 OB 是相反射线，所形成的已指定半圈角为 180°。

两条边共线并不总代表平角。如果两条射线方向相同且重合，未转动时为 0°，转满一圈时为 360°；需要看明确的转动说明。

## 十一、测量优角可以先量较小角

半圆量角器不能直接显示大于 180° 的整个优角，可以先测量同两条边之间的较小角。

若较小角测得约为 70°，另一侧优角约为：

~~~text
360° − 70° = 290°
~~~

如果题目已准确给出较小角为 70°，则优角准确为 290°；若 70° 是实测近似值，计算的优角也应视为近似值。

测量前确认标出的确是优角，而不是把较小角的读数直接当作答案。

## 十二、演示：命名、测量与分类连起来

一个角的顶点为 O，两边分别经过 A、B。把量角器中心放在 O，基线对齐 OB，从 OB 的零刻度读到 OA，约为 125°。

可以记录：

~~~text
∠AOB ≈ 125°
~~~

因为 90° < 125° < 180°，所以它是钝角。

如果题目标注 ∠AOB = 125°，标注提供的是准确条件，应按 125° 使用，不必因为示意图画得不精确而改动它。

## 十三、演示：比较边长不同的两个角

两个角分别为 40° 和 55°。第一个角的边画得更长，第二个角的边画得更短。

~~~text
40° < 55°
~~~

第二个角更大，因为它的转动量更多，而不是因为边更长。

两者都小于 90°，所以都为锐角。属于同一类，不代表度数相等。

## 十四、相邻区域的角度可以组成整体

射线 OC 位于较小角 AOB 的内部，把它分成两个不重叠的角区域。

若 ∠AOC = 25°，∠COB = 40°，则：

~~~text
∠AOB = 25° + 40° = 65°
~~~

相加成立的前提是这两个区域恰好组成所讨论的整个角，既不重叠，也不遗漏。

不能随意把任何两个角度相加，就认为得到某个图中的大角。下一节会进一步学习邻角、互余角与互补角的关系。

## 十五、用量角器画一个给定角

画一个顶点为 O、大小为 60° 的角，可以先画射线 OB，再把量角器中心对准 O、零刻度对准 OB。

在正确刻度的 60° 处标一个点 A，移开量角器，用直尺画射线 OA。

标出角弧，并注明 ∠AOB = 60°。这个角是锐角。

标点的位置决定射线方向，不代表射线只延伸到 A。使用工具的实际作图有精度限制，理论上给定的目标角度仍是 60°。

## 十六、小结

角有一个顶点和两条射线边，三个字母命名时顶点在中间。角度描述转动量，用度表示，一整圈为 360°。

角的大小与边画多长、图是否旋转无关。相同两边可能对应不同转动范围，要看角弧或明确说明。

使用量角器时，中心对顶点，基线对一边，从这条边对应的 0° 读另一边。先估计角的类型可以帮助检查读错刻度。

按度数分类为锐角、直角、钝角、平角、优角和周角。实测读数可能是近似值，题目给定的准确度数与图形示意应当分清。
