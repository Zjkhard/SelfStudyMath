# 9B.10 简单一元一次不等式

有些条件给出的不是一个确定的数，而是一段范围。例如，活动年龄须满 12 岁，设年龄为 x 岁，就可以写成 x ≥ 12。

如果条件中还有其他运算，我们可以像解方程那样逐步整理，但每一步都要保持原来的解集。遇到乘以或除以负数时，必须反转不等号。

## 一、什么是一元一次不等式

只含一个未知数，并且未知数的最高次数为 1 的不等式，叫作一元一次不等式。

例如：

~~~text
2x + 3 < 11
−4x ≥ 8
~~~

x 是唯一的未知数，它只以一次形式出现。整理后可写成 ax + b < 0、ax + b ≥ 0 等形式，其中 a、b 是常数，a 不为 0。

求解的目标不是只找一个数，而是找出所有使不等式成立的 x 值，也就是解集。

## 二、解不等式的基本想法

解不等式时，对两边做等价变形，使含未知数的部分逐步单独留下。

~~~text
同加或同减一个数：方向不变。
同乘或同除一个正数：方向不变。
同乘或同除一个负数：方向反转。
~~~

每一步都要保留与原不等式相同的解集。变形完成后，还可以代入边界附近的数检查方向是否合理。

## 三、一步加法不等式

解 x + 4 < 9。两边同时减去 4：

~~~text
x + 4 − 4 < 9 − 4
x < 5
~~~

所以所有小于 5 的数都是解，5 本身不包括在内。

## 四、一步减法不等式

解 x − 6 ≥ 2。两边同时加上 6：

~~~text
x − 6 + 6 ≥ 2 + 6
x ≥ 8
~~~

解集包含 8 以及所有大于 8 的数。加回 6 后，不等号方向保持不变。

## 五、未知数前系数为正数

解 3x < 12。两边同时除以正数 3：

~~~text
3x ÷ 3 < 12 ÷ 3
x < 4
~~~

因为除数为正，不等号方向不变。数轴上在 4 处画空心圈，并向左延伸。

## 六、未知数前系数为负数

解 −2x ≤ 6。两边同时除以 −2：

~~~text
(−2x) ÷ (−2) ≥ 6 ÷ (−2)
x ≥ −3
~~~

除以负数时不等号反转，所以“小于或等于”变成“大于或等于”。解集从 −3 向右延伸，并包含 −3。

## 七、演示：先消去加数，再除以负数

解 −3x + 5 > 14。

先两边同时减去 5：

~~~text
−3x > 9
~~~

再两边同时除以 −3。除数为负，不等号反转：

~~~text
x < −3
~~~

代入 x = −4，原式左边为 12 + 5 = 17，17 > 14，成立。代入边界 x = −3，左边为 14，14 > 14 不成立，因此边界不包括在解集中。

## 八、演示：系数为负时方向如何改变

解 7 − 2x ≥ 1。

两边同时减去 7：

~~~text
−2x ≥ −6
~~~

两边同时除以 −2，方向反转：

~~~text
x ≤ 3
~~~

检查 x = 3，原式两边相等，符合“≥”；检查 x = 4，左边为 −1，−1 ≥ 1 不成立。因此解集包括 3 及其左侧的数。

## 九、未知数项在不等式两边

解 3x + 1 < x + 7。先两边同时减去 x，再同时减去 1：

~~~text
3x + 1 − x < x + 7 − x
2x + 1 < 7
2x < 6
~~~

两边除以正数 2，方向不变，得到 x < 3。

把含 x 的项集中到一边只是同减相同的代数式。每次移项都可以展开写成两边同加或同减，检查符号更清楚。

## 十、数轴表示求得的解集

若解得 x < 3，3 不属于解集，在 3 处画空心圈，向左表示所有小于 3 的数：

~~~text
          3
←════════○────────→
~~~

若解得 x ≥ −2，−2 属于解集，在 −2 处画实心圈，向右延伸：

~~~text
         −2
←────────●════════→
~~~

求解式子给出代数范围，数轴把这个范围直观显示出来。严格不等号对应空心圈，带等号的不等号对应实心圈。

## 十一、用代入检查解集方向

求得 x ≤ 3 后，可以检查边界值和边界两侧的值。

对 7 − 2x ≥ 1：

~~~text
x = 3：7 − 2 × 3 = 1，满足等号边界。
x = 2：7 − 2 × 2 = 3，3 ≥ 1，成立。
x = 4：7 − 2 × 4 = −1，−1 ≥ 1，不成立。
~~~

这与数轴上 3 及其左侧为解相符。代入检查适合确认步骤和方向，但几个例子本身不能代替完整求解。

## 十二、整理后出现恒真不等式

考虑 x + 2 < x + 5。两边同时减去 x：

~~~text
2 < 5
~~~

这个关系对所有 x 都成立。因此原不等式的解集是所有实数。

若变量来自实际情境，还要再考虑情境对变量的限制；“所有实数”是单看这个不等式的结果。

## 十三、整理后出现矛盾

考虑 x + 5 < x + 2。两边同时减去 x：

~~~text
5 < 2
~~~

这是错误的数值关系，对任何 x 都不成立。因此原不等式无解，解集为空。

不能把相同的 x 项消去后就停下；还要判断剩下的数值关系是真还是假。

## 十四、求解步骤中的关键判断

~~~text
先整理含未知数的项与常数项。
未知数项两边都有时，做相同的加减运算来合并。
最后除以未知数的系数时，先判断系数正负。
系数为正：方向不变；系数为负：方向反转。
用数轴表示边界、方向和端点是否包含。
~~~

通常把未知数项集中到一边，再把常数项集中到另一边。选哪一边都可以，只要运算正确、解集保持不变。

## 十五、不要把不等式当成等式

在方程两边同时乘以非零数，等号方向不变；不等式两边乘以负数则要改变方向。

例如，−2x < 8 两边除以 −2 后，必须得到 x > −4。若照搬方程步骤而保留小于号，就会把解集画到错误的一侧。

每当未知数系数为负，除法这一步就是最需要停下来检查的地方。

## 十六、只做可逆的变形

两边同乘 0 会把原来的大小关系变成 0 = 0，无法保留哪些 x 满足原式的信息。因此求解时不能用乘以 0 的方式消去未知数项。

除以 0 没有定义。两边同除未知数系数时，要先确认这个系数不是 0；一元一次不等式整理后的未知数系数正是非零数。

同乘或同除变量表达式时，还必须知道它的正负。简单一元一次不等式通常只需除以固定的非零系数。

## 十七、演示：从解式到解集图

解 4x − 3 ≤ 9：

~~~text
4x − 3 ≤ 9
4x ≤ 12       两边同加 3，方向不变
x ≤ 3         两边同除以正数 4，方向不变
~~~

解集是所有小于或等于 3 的数。数轴上在 3 处画实心圈并向左延伸。边界代回原式得到 9 ≤ 9，成立。

## 十八、小结

解一元一次不等式时，用同加、同减、同乘或同除逐步隔离未知数，并确保每步保留原来的解集。最后处理未知数系数时，先看它的正负：除以正数方向不变，除以负数方向反转。

求得结果后，用数轴表示解集，再检查端点是否应包含、方向是否正确。若整理后得到恒真关系，解集为所有允许的数；若得到矛盾关系，则无解。
