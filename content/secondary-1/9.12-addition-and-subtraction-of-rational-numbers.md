# 9.12 有理数加法与减法

一处水位原来比基准低 0.75 米，后来上升了 0.5 米。约定高于基准为正、低于基准为负：

~~~text
原来位置：−0.75 米
变化：+0.5 米
后来位置：(−0.75) + 0.5 = −0.25（米）
~~~

水位上升了，但仍比基准低 0.25 米。

整数加减法中的方向与抵消关系，同样适用于分数和小数。变化的是数量大小的计算方式，不是正负号的意义。

## 一、数轴移动不只限于整数步长

计算 (−3/4) + 1/2，可以从 −3/4 出发，向右移动 1/2 个单位。

把单位长度分成四等份，1/2 就是两个 1/4：

~~~text
起点 −3/4 → −2/4 → −1/4
           向右移动两个 1/4
~~~

所以：

~~~text
(−3/4) + 1/2 = −1/4
~~~

加正数向右，加负数向左，加 0 不移动。这些关系不因加数是分数或小数而改变。

## 二、同号与异号加法的规则仍然适用

两个同号的非零有理数相加，绝对值相加，保留共同符号。

~~~text
(−0.6) + (−0.8) = −1.4
~~~

两个异号有理数相加，用较大的绝对值减去较小的绝对值，结果取绝对值较大的加数的符号。

~~~text
(−0.8) + 0.6 = −0.2
~~~

异号且绝对值相等时，恰好抵消：

~~~text
(−0.8) + 0.8 = 0
~~~

判断符号与计算绝对值是相互配合的步骤。分数需要统一分数单位，小数需要按照位值计算。

## 三、同分母分数用同一种份来计数

计算 (−5/8) + 3/8，两个加数都以 1/8 为单位。

五个负的 1/8 与三个正的 1/8 抵消后，剩下两个负的 1/8：

~~~text
(−5/8) + 3/8
= (−5 + 3)/8
= −2/8
= −1/4
~~~

分母保持不变，因为每份仍是 1/8。变化的是正负份数。

不能把分母也相加。分母相加会改变每份的大小，破坏原来的数量关系。

## 四、异分母分数先通分

计算 (−2/3) + 1/4，三分之一与四分之一不是同样大小的份。

3 和 4 的最小公倍数是 12，用 1/12 作共同单位：

~~~text
−2/3 = −8/12
1/4 = 3/12
~~~

于是：

~~~text
(−2/3) + 1/4
= (−8/12) + 3/12
= −5/12
~~~

通分时，分子与分母同时乘相同的非零数，原来的分数值保持不变。

这里负方向的八份与正方向的三份抵消，剩下五份负的 1/12，所以结果为负。

## 五、异号时先比较准确的绝对值

计算 (−5/6) + 7/9，不能只凭分子 7 比 5 大，就判断结果为正。

先通分：

~~~text
5/6 = 15/18
7/9 = 14/18
~~~

5/6 的绝对值较大，结果应为负：

~~~text
(−5/6) + 7/9
= (−15/18) + 14/18
= −1/18
~~~

分母不同，份的大小也不同。比较绝对值要依据等值表示，不能只比较分子。

## 六、减法仍然转化为加相反数

对于任意有理数 a、b：

~~~text
a − b = a + (−b)
~~~

被减数不变，减数变为相反数。

例如：

~~~text
(−3/5) − 1/4
= (−3/5) + (−1/4)
= (−12/20) + (−5/20)
= −17/20
~~~

减去负分数时：

~~~text
(−3/5) − (−1/4)
= (−3/5) + 1/4
= (−12/20) + 5/20
= −7/20
~~~

两个算式只差减数的符号，数量关系和结果却不同。转化后要保留第一个数原来的负号。

## 七、负带分数先明确负号范围

负带分数 −(1 又 2/3) 表示整个 1 又 2/3 的相反数：

~~~text
−(1 又 2/3) = −5/3
~~~

它不是 −1 + 2/3。

例如：

~~~text
−(1 又 2/3) + 3/4
= (−5/3) + 3/4
= (−20/12) + 9/12
= −11/12
~~~

先把带分数化成假分数，往往能让符号与通分过程更清楚。

## 八、小数计算要对齐相同数位

计算 (−2.35) + 0.8。两个数异号，且 2.35 > 0.8，所以结果为负。

先计算绝对值之差：

~~~text
  2.35
− 0.80
------
  1.55
~~~

因此：

~~~text
(−2.35) + 0.8 = −1.55
~~~

0.8 = 0.80，补零没有改变数值。对齐小数点，是为了让个位、十分位、百分位分别与同样的单位相加减。

不能把数字简单地右端对齐，否则可能把十分之一与百分之一放在同一列。

## 九、小数减法也先处理相反数

计算 (−1.2) − (−0.75)：

~~~text
(−1.2) − (−0.75)
= (−1.2) + 0.75
~~~

1.20 的绝对值较大，结果为负；绝对值之差为 1.20 − 0.75 = 0.45。

~~~text
(−1.2) + 0.75 = −0.45
~~~

减去 −0.75，相当于向右移动 0.75 个单位，从 −1.2 到 −0.45。结果比 −1.2 大，但仍是负数。

## 十、分数与小数混合时选择准确表示

计算 (−3/4) + 0.6，可以都写成有限小数：

~~~text
(−0.75) + 0.6 = −0.15
~~~

也可以都写成分数：

~~~text
(−3/4) + 3/5
= (−15/20) + 12/20
= −3/20
~~~

−3/20 = −0.15，两种方法得到同一个准确结果。

如果分数化成小数会循环，保留分数通常更方便。例如：

~~~text
1/3 − 0.2
= 1/3 − 1/5
= 5/15 − 3/15
= 2/15
~~~

不能先把 1/3 改成近似值 0.33，再把 0.13 当作准确答案。

## 十一、零与相反数的作用不变

任意有理数 a 都满足：

~~~text
a + 0 = a
a + (−a) = 0
a − a = 0
0 − a = −a
~~~

例如：

~~~text
(−7/8) + 7/8 = 0
0 − (−0.4) = 0.4
~~~

相反数保留绝对值、改变方向，所以分数与小数也能在加法中完全抵消。

## 十二、利用加法运算律简化连续加减

有理数加法仍满足交换律与结合律。可以先把减法转化为加法，再把方便的加数放在一起。

例如：

~~~text
(−3/4) + 2/5 + 3/4 − 7/5
= (−3/4) + 2/5 + 3/4 + (−7/5)
= [(−3/4) + 3/4] + [2/5 + (−7/5)]
= 0 + (−5/5)
= −1
~~~

相反数先抵消，同分母的分数再合并，就不必让所有分数统一成分母 20。

调整顺序时，加数要连同符号一起移动。不能在减法尚未转化时，随意使用交换律或结合律。

## 十三、括号里面先算成一个整体

计算：

~~~text
1/2 − [(−1/3) + 5/6]
~~~

先算方括号里面的和：

~~~text
(−1/3) + 5/6 = (−2/6) + 5/6 = 1/2
~~~

再计算外面的减法：

~~~text
1/2 − 1/2 = 0
~~~

外面的减号作用于整个括号，不是只减去里面的第一个数。

用加法形式看，也可以写成：

~~~text
1/2 + 1/3 + (−5/6)
= 3/6 + 2/6 − 5/6
= 0
~~~

减去一个和，相当于加上这个和的相反数，因此里面两项的符号都要反过来。

## 十四、演示：连续位置变化

水位原来比基准低 3/4 米，先上升 1/2 米，再下降 0.2 米。约定上升为正。

~~~text
后来位置 = (−3/4) + 1/2 + (−0.2)
~~~

把 0.2 写成 1/5，统一成二十分之一：

~~~text
(−3/4) + 1/2 + (−1/5)
= (−15/20) + 10/20 + (−4/20)
= −9/20
= −0.45
~~~

所以后来水位比基准低 0.45 米。

总变化为 1/2 − 1/5 = 3/10 米，表示水位总体上升了 0.3 米。原来位置 −0.75 米加上总变化 0.3 米，确实得到 −0.45 米。

最终位置为负，不表示总变化也为负；应分别说明位置和变化的意义。

## 十五、有理数相加减，结果仍是有理数

为什么这些计算不会超出有理数范围？先把两个数写成整数之比 a/b 和 c/d，其中 b、d 不为 0。

通分后：

~~~text
a/b + c/d = (a × d + b × c)/(b × d)
a/b − c/d = (a × d − b × c)/(b × d)
~~~

分子由整数乘法和加减法得到，仍是整数；分母是两个非零整数的乘积，也不为 0。

所以结果仍能写成整数之比，也就是有理数。这里的表达式说明通分的结构，不需要把它当作新的孤立规则来记忆。

## 十六、用逆运算与大小关系检查

例如已经算出：

~~~text
(−3/5) − (−1/4) = −7/20
~~~

把减数加回去，应还原被减数：

~~~text
(−7/20) + (−1/4)
= (−7/20) + (−5/20)
= −12/20
= −3/5
~~~

数轴上，减去负数应使数值增大。−7/20 = −0.35 大于 −3/5 = −0.6，也与方向判断一致。

逆运算检查数值，数轴关系检查方向。两者结合，比只重复同一套计算更容易发现符号错误。

## 十七、小结

有理数加法沿用整数加法的符号规律：同号相加合并绝对值，异号相加先抵消，绝对值相等的相反数相加为 0。

分数加减先统一分数单位，小数加减要对齐数位。减法统一转化为加相反数，被减数保持不变。

分数与小数混合时，选择方便的准确表示，避免过早使用近似值。连续加减可以借助加法交换律、结合律简算，但每个加数都要保留自己的符号。

有理数加减的结果仍是有理数。计算后，可以用逆运算、数轴方向或另一种等值表示检查，并分清结果表示位置、变化还是相差的数量。
