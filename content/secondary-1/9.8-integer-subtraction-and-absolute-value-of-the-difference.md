# 9.8 整数减法与差的绝对值

早晨气温是 −3°C，中午气温是 5°C。中午比早晨升高了多少度？

从 −3°C 升到 0°C，需要升高 3°C；再从 0°C 升到 5°C，需要升高 5°C。总共升高 8°C。

~~~text
后来气温 − 原来气温 = 温度变化
5 − (−3) = 8
~~~

为什么减去一个负数，结果反而变大？这一节从加法的逆运算出发解释减法，再把数的差与数轴上的距离联系起来。

## 一、减法寻找的是哪个数

在算式 a − b 中，a 叫作被减数，b 叫作减数，计算结果叫作差。

计算 9 − 4，就是寻找一个数，使它加上 4 后得到 9：

~~~text
5 + 4 = 9
所以 9 − 4 = 5。
~~~

这个意义也适用于整数。

例如计算 3 − 7，要找的是“加上 7 后得到 3”的数：

~~~text
(−4) + 7 = 3
所以 3 − 7 = −4。
~~~

减数比被减数大时，整数减法仍有结果，只是差为负数。

## 二、减去负数也可以用加法验证

计算 5 − (−3)，就是找一个数，加上 −3 后得到 5。

~~~text
8 + (−3) = 5
~~~

因此：

~~~text
5 − (−3) = 8
~~~

它与 5 + 3 得到相同的结果。

减去 −3，等于加上 −3 的相反数 3。这里不是把负号随意删掉，而是利用相反数抵消与加法逆运算。

## 三、减法可以统一转化为加相反数

对于整数 a 和 b：

~~~text
a − b = a + (−b)
~~~

为什么这个表达式符合减法的意义？把 b 加回去：

~~~text
[a + (−b)] + b
= a + [(−b) + b]
= a + 0
= a
~~~

所以 a + (−b) 正是“加上 b 后得到 a”的数，也就是 a − b。

转化时，被减数不变，减号改成加号，减数改成它的相反数。

## 四、用同一方法处理四种符号组合

比较下面四个算式：

| 原来的减法 | 转化为加法 | 结果 |
| --- | --- | --- |
| 4 − 7 | 4 + (−7) | −3 |
| 4 − (−7) | 4 + 7 | 11 |
| (−4) − 7 | (−4) + (−7) | −11 |
| (−4) − (−7) | (−4) + 7 | 3 |

第一个数始终保持原样。转化完成后，再使用上一节的同号、异号加法规律。

尤其要注意，(−4) − (−7) 的结果是 3，不是 11。减数变为相反数，不代表被减数 −4 也要变成 4。

## 五、数轴上的减法移动方向

在向右为正的数轴上：

~~~text
减去正数，等于加负数，向左移动。
减去负数，等于加正数，向右移动。
减去 0，不移动。
~~~

例如：

~~~text
2 − 5 = −3：从 2 向左移动 5 个单位。
2 − (−5) = 7：从 2 向右移动 5 个单位。
~~~

所以“做减法，结果一定变小”并不正确。减去负数时，结果比被减数大。

## 六、辨认减号与负号的不同作用

在 (−6) − (−2) 中，三个形状相同的符号承担不同作用：

~~~text
(−6)：第一个数是负数 −6。
中间的 −：进行减法。
(−2)：第二个数是负数 −2。
~~~

转化后：

~~~text
(−6) − (−2) = (−6) + 2 = −4
~~~

不能只数一数“有几个负号”，就决定结果的符号。

例如 (−6) + (−2) 是两个负数相加，结果为 −8；−(−2) 才表示取 −2 的相反数，结果为 2。

## 七、零与相同整数的减法

利用加相反数，可以得到：

~~~text
a − 0 = a
0 − a = −a
a − a = 0
~~~

例如：

~~~text
(−5) − 0 = −5
0 − (−5) = 5
(−5) − (−5) = 0
~~~

一个数减去自己，等于它与相反数相加，所以结果为 0。

0 减去一个数，得到的是那个数的相反数，而不是永远得到负数。

## 八、减法不能直接交换或重新分组

交换两个数的顺序，会改变差：

~~~text
7 − 3 = 4
3 − 7 = −4
~~~

改变减法分组，也可能改变结果：

~~~text
(8 − 3) − 2 = 5 − 2 = 3
8 − (3 − 2) = 8 − 1 = 7
~~~

所以减法不满足交换律或结合律。

想调整连续加减的顺序，必须先把减法转化为加法，并让每个加数保留自己的符号。

例如：

~~~text
8 − 3 − 2
= 8 + (−3) + (−2)
= 8 + [(−3) + (−2)]
= 8 + (−5)
= 3
~~~

## 九、差表示从一个位置到另一个位置的变化

若从数轴上的 b 移动到 a，位置变化就是：

~~~text
终点 − 起点 = a − b
~~~

从 −2 移动到 3：

~~~text
3 − (−2) = 5
~~~

变化为 +5，表示向右移动 5 个单位。

反过来，从 3 移动到 −2：

~~~text
(−2) − 3 = −5
~~~

变化为 −5，表示向左移动 5 个单位。

起点与终点交换，变化的方向相反，但移动的长度相同。

## 十、两点之间的距离是差的绝对值

距离只表示长度，不表示向左还是向右，因此必须是非负数。

数轴上 a 与 b 两点之间的距离是：

~~~text
|a − b|
~~~

它读作“a 减 b 的差的绝对值”。先计算整个差，再求绝对值。

例如 3 与 −2 两点之间的距离：

~~~text
|3 − (−2)| = |5| = 5
~~~

反过来计算也一样：

~~~text
|(−2) − 3| = |−5| = 5
~~~

因此 |a − b| = |b − a|。差可以有方向，距离则与两个点的书写顺序无关。

两个点重合时 a = b，差和距离都为 0。

## 十一、同侧与异侧都可以使用同一个距离公式

两个点都在原点左侧，例如 −8 和 −3：

~~~text
|(−3) − (−8)| = |(−3) + 8| = |5| = 5
~~~

两个点在原点不同侧，例如 −8 和 3：

~~~text
|3 − (−8)| = |11| = 11
~~~

同侧时，距离是它们到原点的距离之差；异侧时，距离是它们到原点的距离之和。

用 |a − b| 可以统一处理两种情况，不必只凭图形猜测。图示帮助理解，计算则依据点所表示的准确数值。

## 十二、差的绝对值不等于绝对值之差

比较两个表达式：

~~~text
|3 − (−2)| = |5| = 5
|3| − |−2| = 3 − 2 = 1
~~~

第一式表示 3 与 −2 两点之间的距离；第二式表示它们各自到原点的距离相差多少。

它们回答的问题不同，所以一般不能把：

~~~text
|a − b|
~~~

改写成 |a| − |b|。后者甚至可能为负，例如 |−2| − |3| = −1，而距离不可能为负。

即使用 ||a| − |b|| 把后一种差再取绝对值，也不总等于两点距离。对于 3 和 −2，它仍是 1，而两点距离是 5。

## 十三、演示：温度变化与温差

气温从早晨的 −3°C 变为中午的 5°C：

~~~text
温度变化 = 5 − (−3) = +8（°C）
~~~

正号说明升高了 8°C。

如果气温从 5°C 变为 −3°C：

~~~text
温度变化 = (−3) − 5 = −8（°C）
~~~

负号说明降低了 8°C。

不问变化方向，只问这两个温度相差多少，则取差的绝对值：

~~~text
温差 = |5 − (−3)| = 8（°C）
~~~

“后来减原来”保留升降方向；“差的绝对值”只保留相差的程度。

## 十四、演示：同一条直路上的两人相距多远

在一条东西方向的直路上，以车站为原点，向东为正。小林位于 −7 米处，小安位于 −2 米处。

两个人都在车站西侧，但小安更靠近车站。他们之间沿直路的距离是：

~~~text
|(−2) − (−7)|
= |(−2) + 7|
= |5|
= 5（米）
~~~

不能用 7 + 2 = 9 米，因为两人位于原点同一侧，走到对方的位置不需要先到原点再折返。

如果小安改为位于 +2 米处，两人就在原点不同侧，此时距离是：

~~~text
|2 − (−7)| = |9| = 9（米）
~~~

这个公式适用于同一条数轴表示的直线距离，不是任意二维位置之间的距离公式。

## 十五、演示：先计算差，再取绝对值

计算 |(−12) − (−5)|：

~~~text
|(−12) − (−5)|
= |(−12) + 5|
= |−7|
= 7
~~~

绝对值符号覆盖的是整个差，不能在减法完成前把 −12 和 −5 分别改成 12 和 5。

可以用位置验证：−12 与 −5 都在原点左侧，它们相隔 7 个单位。

## 十六、小结

减法是加法的逆运算。减去一个数，等于加上它的相反数：a − b = a + (−b)。被减数保持不变。

在数轴上，减正数向左移动，减负数向右移动，减 0 不移动。减法不满足交换律与结合律；要调整顺序，应先转化为加法。

终点减起点表示带方向的变化，差可能为正、为负或为 0。差的绝对值表示数轴上两点之间的距离，总是非负数。

|a − b| 要先算整个差，再取绝对值。它与 |a| − |b| 的意义不同，不能随意拆开绝对值符号。
