# 9.27 含分数形式的一元一次方程

一条彩带长 x 米，取出它的三分之一，再加上另一段 2 米长的彩带，合计长 5 米。

~~~text
x/3 + 2 = 5
~~~

先减去 2，得到 x/3 = 3；再把两边乘以 3，得到 x = 9。

含有分数不意味着需要一套全新的方程规律。我们仍然依据等式性质，只是可以选择合适的乘数，让分母消去。

## 一、本节的分母是非零常数

本节讨论的方程主要是：

~~~text
x/3 + 2 = 5
(x + 1)/2 = 4
(2/3)x − 1/2 = 5/6
~~~

分母为已经确定的非零数，未知数不在分母中。

例如 1/x = 2 的未知数在分母中，需要另行讨论 x ≠ 0 的限制，不属于本节主要内容。

这里说“含分数形式”，不把它与后面涉及字母分母的分式方程混为一谈。

## 二、分数线把分子看成整体

~~~text
(x + 2)/3
~~~

表示 x 与 2 的整个和除以 3，不是 x + 2/3。

如果 (x + 2)/3 = 5，两边乘以 3：

~~~text
(x + 2)/3 = 5
x + 2 = 15
x = 13
~~~

分母消去后，留下的是整个分子 x + 2，不能只留下 x 而漏掉 2。

## 三、消去分母的依据是同乘非零数

对于 x/3 + 2 = 5，两边同时乘以 3：

~~~text
3(x/3 + 2) = 3 × 5
~~~

再按分配律计算：

~~~text
x + 6 = 15
x = 9
~~~

这个过程叫作**消去分母**，也常简称去分母。

它不是把分数线直接擦掉，而是让等式两边的整个式子都乘同一个非零数。因为可以再除以这个数还原，所以解保持不变。

## 四、没有分母的项也必须相乘

仍看 x/3 + 2 = 5。如果误写成 x + 2 = 15，就遗漏了常数项 2 也要乘以 3。

正确的是：

~~~text
3 × x/3 + 3 × 2 = 3 × 5
x + 6 = 15
~~~

“去分母”不能只处理看起来像分数的项。整数项也属于等式的一部分。

不确定时，先在左右两边外面写出完整括号和乘数，再逐项分配。

## 五、多个分母通常选择最小公倍数

解 x/2 + x/3 = 5。分母 2 和 3 的最小公倍数为 6，两边同时乘以 6：

~~~text
6(x/2 + x/3) = 6 × 5
3x + 2x = 30
5x = 30
x = 6
~~~

6/2 = 3，6/3 = 2，因此两个分母都能消去。

也可以选 12 等其他公倍数，但通常会产生更大的系数。选最小公倍数能让计算更简洁。

验根：6/2 + 6/3 = 3 + 2 = 5。

## 六、分子有多个项时先保留括号

解 (2x + 1)/3 = (x − 2)/2。两边同时乘以 6：

~~~text
(2x + 1)/3 = (x − 2)/2
2(2x + 1) = 3(x − 2)
4x + 2 = 3x − 6
x + 2 = −6
x = −8
~~~

左边剩余因子 2 乘整个分子 2x + 1，右边因子 3 乘整个分子 x − 2。

验根：左边 (−16 + 1)/3 = −5，右边 (−8 − 2)/2 = −5。

先保留分子括号，再展开，能够避免只把乘数分配给分子的第一项。

## 七、减去分数时负号作用于整个分子

解 (x + 1)/2 − (x − 3)/4 = 3。两边同时乘以 4：

~~~text
(x + 1)/2 − (x − 3)/4 = 3
2(x + 1) − (x − 3) = 12
2x + 2 − x + 3 = 12
x + 5 = 12
x = 7
~~~

第二个分母消去后，原来的减号仍然在整个 x − 3 前面，所以去括号得到 −x + 3。

验根：8/2 − 4/4 = 4 − 1 = 3。

不能因为分母消去了，就顺便把前面的减号或分子中的负号也删掉。

## 八、分数系数可以直接乘倒数，也可以去分母

解 (3/4)x = 6，可以两边乘以 3/4 的倒数 4/3：

~~~text
x = 6 × 4/3 = 8
~~~

也可以先两边乘以 4：

~~~text
3x = 24
x = 8
~~~

两种方法都来自等式两边同乘非零数，结果相同。

简单结构可以直接用逆运算；分数项较多时，统一消去分母往往更方便。

## 九、负分数系数保持完整符号

解 (−2/3)x + 1/2 = 5/6，分母的最小公倍数为 6：

~~~text
(−2/3)x + 1/2 = 5/6
−4x + 3 = 5
−4x = 2
x = −1/2
~~~

6 × (−2/3) = −4，所以未知数系数仍为负。

验根：

~~~text
(−2/3) × (−1/2) + 1/2
= 1/3 + 1/2
= 5/6
~~~

分数解 −1/2 是准确结果，不需要为了“看起来整齐”把它取整。

## 十、带分数先化成假分数

解 (1 又 1/2)x − 1/4 = 2。先把系数写成 3/2：

~~~text
(3/2)x − 1/4 = 2
~~~

两边同时乘以 4：

~~~text
6x − 1 = 8
6x = 9
x = 3/2
~~~

验根：(3/2) × (3/2) − 1/4 = 9/4 − 1/4 = 2。

负带分数也要先明确负号作用于整个数，再转换，不能把整数部分与分数部分分开改变符号。

## 十一、两边各有多个项时逐项记录

解 x/3 + 1 = x/4 + 2，选择公分母 12：

~~~text
x/3 + 1 = x/4 + 2
4x + 12 = 3x + 24
x + 12 = 24
x = 12
~~~

左边两项、右边两项都乘以 12。分别展开后，再按简单一元一次方程的方法求解。

验根：左边 12/3 + 1 = 5，右边 12/4 + 2 = 5。

“两边都有分数”不要求把左右两边分别选不同乘数；要保持等价，应使用同一个非零乘数。

## 十二、演示：综合去分母与去括号

解 (2x − 1)/3 − (x + 2)/6 = 1/2。

分母 3、6、2 的最小公倍数为 6，两边同时乘以 6：

~~~text
2(2x − 1) − (x + 2) = 3
~~~

去括号并合并：

~~~text
4x − 2 − x − 2 = 3
3x − 4 = 3
3x = 7
x = 7/3
~~~

代回原方程验根：

~~~text
第一项 = [2 × (7/3) − 1]/3 = 11/9
第二项 = [(7/3) + 2]/6 = 13/18
左边 = 11/9 − 13/18 = 22/18 − 13/18 = 1/2
右边 = 1/2
~~~

原方程成立。保持分数形式验证，避免循环小数近似值掩盖准确相等关系。

## 十三、比例形式也依据同乘公分母

对于分母为非零常数的等式：

~~~text
A/b = B/d
~~~

两边同时乘以 b × d，可得：

~~~text
dA = bB
~~~

这解释了常见的交叉相乘关系。A、B 如果是多个项的和，必须保留整体括号。

例如 (x + 1)/3 = 4/5 可得 5(x + 1) = 12。

但对于 x/3 + 1 = 4/5，左边还有额外的加数 1，不能把它当作只有两个单独分数的等式随意交叉相乘。先写出两边同乘公分母，最不容易漏项。

## 十四、常数分母与字母分母不要混淆

本节所有分母都是非零常数，因此同乘公分母不会额外限制未知数，也不会产生因分母为 0 而不能代入的候选解。

如果未来遇到 1/(x − 2) 这样的式子，则 x = 2 不允许代入。涉及字母分母的方程还要检查定义条件，不能完全照搬本节而忽略限制。

本节验根仍然必要，主要帮助发现计算、符号或漏项错误，并检查原方程是否真正成立。

## 十五、演示：解释彩带长度

回到开头的 x/3 + 2 = 5。

~~~text
x/3 + 2 = 5
x/3 = 3
x = 9
~~~

原彩带长 9 米。取它的三分之一得到 3 米，再加上 2 米，合计为 5 米。

9 为正，符合长度条件。这里 x 表示原彩带长度，不是取出的长度；取出的长度是 x/3 = 3 米。

计算得到未知数后，还要回到字母的含义说明答案，不能只写一个没有单位的数字。

## 十六、小结

本节讨论分母为非零常数的分数形式一次方程。求解仍依据等式性质，可以先用逆运算，也可以两边同乘公分母。

去分母时，等式两边每一项都必须乘同一个数，包括没有分母的整数项。分子含多项时保留括号，再正确展开和合并。

减去一个分数时，负号作用于整个分子。分数系数、负系数与带分数都要保持准确数值和完整符号。

求出解后代回原方程验根，尽量使用准确分数。涉及字母分母的方程还有额外取值限制，不属于本节主要范围。
