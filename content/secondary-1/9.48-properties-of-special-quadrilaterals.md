# 9.48 特殊四边形的性质

把一个长方形的两条对角线画出来，可以观察到它们长度相等，而且交点把每条对角线都分成等长两段。

但普通长方形的两条对角线并不一定垂直。相等、平分和垂直，是不同的关系。

这一节整理特殊四边形的性质，并学习怎样依据条件推理。沿用上一节约定：梯形恰有一组平行对边；风筝形采用包含菱形的凸四边形定义。

## 一、先固定顶点和对角线名称

本节四边形都按边界顺序命名为 ABCD，必要时把对角线 AC 与 BD 的交点记为 O。

~~~text
对边：AB 与 CD；BC 与 AD。
对角：角 A 与角 C；角 B 与角 D。
对角线：AC 与 BD。
~~~

只有在交点确实存在于讨论的线段上时，才使用 O 的相关长度关系。本节主要讨论普通凸四边形。

图形可以旋转，字母对应关系不变。性质不依赖哪条边画成水平或竖直。

## 二、平行四边形的对边相等

平行四边形定义为两组对边分别平行。

它还具有：

~~~text
AB = CD
BC = AD
~~~

画对角线 AC，平行线的内错角关系使分出的两个三角形具有对应的相等角，且共用 AC，因此它们大小形状相同，对应边相等。

这里先用直观的对应三角形解释，严格的判定可以在后续三角形全等学习中进一步论证。

对边相等，不表示四边全相等。普通平行四边形的两种邻边长度可以不同。

## 三、平行四边形的对角相等、邻角互补

平行四边形中，一条边可以作为另一组平行边的截线。由同旁内角关系：

~~~text
角 A + 角 B = 180°
角 B + 角 C = 180°
~~~

所以角 A = 角 C。同理角 B = 角 D。

因此：

~~~text
对角相等。
相邻内角之和为 180°。
~~~

若一个内角为直角，其邻角与对角也都是直角，得到长方形。

## 四、平行四边形的对角线互相平分

若 AC、BD 交于 O，则：

~~~text
AO = OC
BO = OD
~~~

可以理解为图形绕 O 转半圈，A 与 C 对应，B 与 D 对应；两条对角线的两半因此分别等长。

“互相平分”只说明 O 是每条对角线的中点，不表示两条对角线长度相等，也不表示 AO = BO。

普通平行四边形的对角线通常既不等长，也不垂直。

## 五、长方形继承平行四边形性质

长方形是四角都为直角的特殊平行四边形，因此具有对边相等、对角线互相平分等性质。

它还有：

~~~text
AC = BD
~~~

也就是两条对角线等长。可以比较由两种邻边与夹角直角组成的两个三角形来理解这个关系。

由对角线等长且互相平分，还得到：

~~~text
AO = BO = CO = DO
~~~

但长方形的对角线不一定垂直，也不一定平分内角，除非另有正方形等条件。

## 六、菱形的对角线垂直

菱形四边等长，也是平行四边形，因此对角线互相平分。

因为 AB = BC，点 B 到 A、C 等距；AD = DC，点 D 也到 A、C 等距。

由垂直平分线性质，B、D 都在 AC 的垂直平分线上，所以：

~~~text
BD ⊥ AC
~~~

菱形的两条对角线垂直，但不一定等长。不能从“垂直”推断四个半段都相等。

## 七、菱形的对角线平分对应内角

菱形关于每条对角线都具有对称关系。

所以 AC 平分角 A 与角 C，BD 平分角 B 与角 D。例如：

~~~text
∠BAC = ∠CAD
∠ABD = ∠DBC
~~~

平分角度与平分线段是两种不同性质，菱形恰好同时具有它们。

每条对角线平分的是它所经过的两个顶点内角，不是把四个内角都平分。

## 八、正方形同时具有长方形与菱形性质

正方形四边相等、四角为直角，因此同时具有：

~~~text
对角线相等。
对角线互相平分。
对角线互相垂直。
对角线平分所经过的内角。
~~~

每个直角被对应对角线分成两个 45° 角。

若两条对角线交于 O，四个半段都相等，O 处形成四个直角。

正方形是这些性质的共同特殊情形，不能把它的全部性质搬到普通长方形或普通菱形上。

## 九、普通梯形的角关系

梯形 ABCD 中若 AB ∥ CD，AD 与 BC 为两腰，则由同旁内角：

~~~text
角 A + 角 D = 180°
角 B + 角 C = 180°
~~~

同一条腰两端的内角互补。

普通梯形不保证两腰相等、底角相等或对角线等长，也不保证对角线互相平分。

如果 AD 垂直于两底，角 A、角 D 都为 90°，得到直角梯形。

## 十、等腰梯形的底角与对角线

若梯形两腰 AD = BC，它是等腰梯形。

同一底上的两个内角相等：

~~~text
角 A = 角 B
角 D = 角 C
~~~

它的对角线也等长，即 AC = BD。这些关系可通过两腰对称的图形结构理解。

等腰梯形的对角线不保证互相平分。对角线等长不只出现在长方形中，因此不能单凭这条性质就判断长方形。

## 十一、风筝形的一条对角线是对称轴

若凸四边形满足 AB = AD、CB = CD，那么 AC 连接的是两对等边相遇的顶点。

A、C 都到 B、D 等距，所以 AC 所在直线是 BD 的垂直平分线。

因此若两对角线交于 O：

~~~text
AC ⊥ BD
BO = OD
~~~

AC 还平分角 A 与角 C；角 B 与角 D 相等。

但普通风筝形不保证 AO = OC，也不保证角 A = 角 C。它通常只有一条对角线平分另一条，不能说“对角线互相平分”。

## 十二、用对角线关系作比较

| 类型 | 两对角线等长 | 互相平分 | 互相垂直 |
| --- | --- | --- | --- |
| 一般平行四边形 | 不保证 | 是 | 不保证 |
| 长方形 | 是 | 是 | 不保证 |
| 菱形 | 不保证 | 是 | 是 |
| 正方形 | 是 | 是 | 是 |
| 等腰梯形 | 是 | 不保证 | 不保证 |
| 一般风筝形 | 不保证 | 不保证，AC 平分 BD | 是 |

“不保证”不等于“绝不可能”。例如风筝形在菱形这一特殊情形下，确实互相平分；菱形在正方形情形下，对角线等长。

使用表格时，要先确认图形类别与字母对应。

## 十三、演示：平行四边形中求角

平行四边形 ABCD 的角 A 为 (2x + 10)°，角 B 为 (3x + 20)°。

相邻内角互补：

~~~text
2x + 10 + 3x + 20 = 180
5x = 150
x = 30
~~~

角 A、C 均为 70°，角 B、D 均为 110°。

检查：70 + 110 + 70 + 110 = 360，满足内角和。

不能把邻角设为相等；相等的是对角。

## 十四、演示：长方形中求对角线半段

长方形 ABCD 的对角线 AC 长 10 厘米，两对角线交于 O。

~~~text
BD = 10 厘米，对角线相等。
AO = OC = 5 厘米，AC 被平分。
BO = OD = 5 厘米，BD 被平分。
~~~

四个半段都为 5 厘米，但不能进一步认定 O 处角都是 90°，因为普通长方形不保证对角线垂直。

长度条件与角度条件不能互相替代。

## 十五、演示：菱形中求被平分的角

菱形 ABCD 的角 A 为 80°，对角线 AC、BD 交于 O。

~~~text
角 C = 80°，对角相等。
角 B = 角 D = 100°，邻角互补。
∠BAC = ∠CAD = 40°，AC 平分角 A。
∠ABD = ∠DBC = 50°，BD 平分角 B。
~~~

O 处角为 90°，由菱形对角线垂直。

这几个结论分别来自不同性质，逐步注明依据能避免把底角、半角与交点角混淆。

## 十六、演示：风筝形中不要多用性质

风筝形满足 AB = AD、CB = CD，且 BD 长 12 厘米，AC 与 BD 交于 O。

由 AC 平分 BD，BO = OD = 6 厘米，并且两对角线垂直。

但没有其他条件时，不能求 AO、OC 的准确长度，也不能认定 AO = OC。

如果再给 AO = 4 厘米、OC = 7 厘米，则 AC = 11 厘米；这些数据不违反普通风筝形性质。

先判断能推出什么，也要判断哪些信息还不够。

## 十七、性质与判定方向要分清

已知平行四边形，可以推出对角线互相平分。反过来，在普通简单四边形中，对角线互相平分也能作为平行四边形的判定条件。

但“对角线相等”本身不能判断长方形，因为等腰梯形也可以满足。

“对角线垂直”本身不能判断菱形，因为普通风筝形也满足。

若已经知道是平行四边形，再增加对角线等长条件，可判断为长方形；增加对角线垂直条件，可判断为菱形。

逆向判断需要完整的适用条件，不能把任意单条性质随意反过来使用。

## 十八、小结

特殊四边形的性质要按边、角、对角线分别整理。平行四边形对边相等、对角相等、邻角互补，对角线互相平分。

长方形增加对角线等长性质；菱形增加对角线垂直并平分对应内角性质；正方形同时具有两者性质。

梯形同一腰两端角互补，等腰梯形还具有同底角相等与对角线等长。风筝形的对称轴对角线垂直平分另一条，但通常不互相平分。

使用性质前先确认类别与条件，求解后检查角度和长度关系。相等、平分、垂直不是同一种关系，逆向判定也不能遗漏前提。
