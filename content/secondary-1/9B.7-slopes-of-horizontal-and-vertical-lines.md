# 9B.7 水平线与竖直线的斜率

一条直线向右走时既不上升也不下降，是水平线。另一条直线沿上下方向延伸，横坐标始终不变，是竖直线。

两者都不是上一节向右上升或下降的普通斜线，但并不能都说成“斜率为 0”。

回到纵向变化除以横向变化的定义，就能看清区别。

## 一、计算斜率要选两个不同的点

对 A(x₁, y₁)、B(x₂, y₂)，斜率公式为：

~~~text
m = (y₂ − y₁)/(x₂ − x₁)
~~~

计算有限斜率时，要求 x₂ − x₁ 不为 0。

如果选同一个点两次，得到 0/0，不能用来计算任何直线的斜率。因此不仅要看坐标差，也要确认选了两个不同点。

## 二、水平线上的纵坐标都相同

直线经过 A(−2, 3)、B(4, 3)，两点纵坐标都是 3。

~~~text
纵向变化：3 − 3 = 0
横向变化：4 − (−2) = 6
m = 0/6 = 0
~~~

向右移动了 6 个单位，但没有纵向变化，所以斜率为 0。

水平线上任何两个不同点的横坐标不同，纵坐标相同，都得到零斜率。

## 三、水平线的方程是 y = 常数

关系 y = 3 的图像是一条水平线：x 可以取任意实数，y 始终为 3。

~~~text
线上一些点：(−2, 3)，(0, 3)，(4, 3)
方程：y = 3
~~~

一般写成 y = c，其中 c 为固定实数。

这也可以写成 y = 0x + c，属于 y = mx + c 的形式，斜率 m = 0。

不必给表中的每个 x 都算出不同 y，所有对应纵坐标都是同一个常数。

## 四、纵坐标为负不表示负斜率

直线 y = −2 位于 x 轴下方，经过 (−3, −2)、(2, −2)。

~~~text
m = [(−2) − (−2)]/[2 − (−3)] = 0/5 = 0
~~~

虽然纵坐标为负，但它没有下降变化，斜率仍为 0。

位置高低与变化方向不同。y = 3、y = −2 都是水平线，它们不同的位置由常数决定。

## 五、水平线与坐标轴的关系

y = c 总在 (0, c) 与 y 轴相交。

若 c 不为 0，它不与 x 轴相交，而是平行于 x 轴。

若 c = 0，方程 y = 0 表示的正是 x 轴，两条对象重合，不能说只有一个交点。

~~~text
y = 3：与 y 轴交于 (0, 3)，与 x 轴平行。
y = 0：就是 x 轴。
~~~

“平行”通常用于同一平面内不同且不相交的直线，重合要另行说明。

## 六、竖直线上的横坐标都相同

取竖直线上的两个点 A(2, −1)、B(2, 4)：

~~~text
横向变化：2 − 2 = 0
纵向变化：4 − (−1) = 5
~~~

尝试按斜率公式求值，会得到 5/0。

除以 0 没有定义，所以竖直线的斜率没有定义，或称斜率未定义。

这不是斜率为 0。水平线的公式是“0 除以非零数”，竖直线则是“非零数除以 0”，两者完全不同。

## 七、不要把未定义写成无穷大

在本节的实数运算与斜率定义中，5/0 不是一个实数，不能写成斜率等于无穷大。

“没有定义”也不表示直线不存在，或它不能画出来。竖直线是明确的几何对象，只是不具备这个实数斜率比值。

有时可以直观说一条斜线越来越接近竖直，但这不能把最终的竖直线赋予一个有限或无限的实数斜率。

准确结论是：竖直线的斜率未定义。

## 八、竖直线的方程是 x = 常数

关系 x = 2 要求横坐标固定为 2，纵坐标可以改变。

~~~text
线上一些点：(2, −1)，(2, 0)，(2, 4)
方程：x = 2
~~~

一般写成 x = a，其中 a 为固定实数。

不能把它误写成 y = 2。前者为竖直线，后者为水平线。

方程固定的是哪个坐标，决定另一坐标可以沿哪个方向变化。

## 九、竖直线与坐标轴的关系

x = a 总在 (a, 0) 与 x 轴相交。

若 a 不为 0，它不与 y 轴相交，而是平行于 y 轴。

若 a = 0，方程 x = 0 表示的就是 y 轴。

~~~text
x = −3：与 x 轴交于 (−3, 0)，与 y 轴平行。
x = 0：就是 y 轴。
~~~

x = −3 的负号只说明直线在 y 轴左侧，不表示它有负斜率。

## 十、为什么竖直线不能写成 y = mx + c

在 y = mx + c 中，固定一个 x，等式只能得到一个 y 值。

但竖直线 x = 2 上，横坐标为 2 时，可以有 y = −1、0、4 等许多值。

不存在固定实数 m、c，能让 y = mx + c 在同一个 x = 2 时同时给出这些不同 y。

所以不是所有直线都能写成这种形式。水平线可以，竖直线不可以。

这也为后续理解函数中“每个输入对应一个输出”的条件提供了例子。

## 十一、把几种斜率情况放在一起比较

| 从左向右观察 | 斜率情况 | 方程示例 |
| --- | --- | --- |
| 上升 | 正斜率 | y = 2x + 1 |
| 下降 | 负斜率 | y = −x + 3 |
| 高度不变 | 零斜率 | y = 3 |
| 只有上下延伸，没有横向变化 | 斜率未定义 | x = 2 |

判断时区分图形方向与坐标位置。经过负坐标、位于轴下方或轴左侧，都不会单独决定斜率。

## 十二、演示：画两条特殊直线并求交点

画 y = −2 与 x = 3。

前者通过 (0, −2)、(2, −2)，是水平线；后者通过 (3, 0)、(3, 2)，是竖直线。

交点必须同时满足两个条件：

~~~text
x = 3，y = −2
交点：(3, −2)
~~~

水平线与竖直线互相垂直，因为它们分别平行于互相垂直的坐标轴。

这个例子不需要把竖直线写成斜率形式，也不能给它随意规定一个斜率后使用。

## 十三、演示：从两点判断方向与方程

点 P(−4, 1)、Q(2, 1) 纵坐标相同，所在直线为 y = 1，斜率为 0。

点 R(−4, 1)、S(−4, 5) 横坐标相同，所在直线为 x = −4，斜率未定义。

两条线在 R 与 P 所表示的同一个位置 (−4, 1) 相交。

不同字母可以标记同一坐标位置；点的坐标相同，就不是两个不同的几何点，不能用它们单独确定一条直线。

## 十四、演示：长方形的边与坐标条件

点 A(−2, −1)、B(3, −1)、C(3, 2)、D(−2, 2) 按顺序连接形成长方形。

~~~text
AB 所在直线：y = −1，斜率 0。
CD 所在直线：y = 2，斜率 0。
BC 所在直线：x = 3，斜率未定义。
DA 所在直线：x = −2，斜率未定义。
~~~

两条水平边平行，两条竖直边平行，相邻边垂直。

这里方程表示边所在的完整直线，线段本身还要限制端点之间的范围。例如 AB 只对应 −2 ≤ x ≤ 3 的那一段。

## 十五、实际图像中水平线表示什么

若横轴表示时间，纵轴表示水量，某段图像水平表示该段水量不变，变化率为 0 升/分。

水量可以为 10 升、20 升等，并不因为斜率为 0 就要求水量本身为 0。

若纵轴表示总路程，水平段表示所记录的总路程没有增加，常对应停留；若纵轴表示速度，则水平段可能表示保持某个非零速度。

同一种图形方向，因轴标签不同，实际含义也不同。不能见水平线就一律说物体停止。

## 十六、实际图像中的竖直线要谨慎解释

若横轴是时间，纵轴是位置或水量，竖直线会在同一时刻对应许多不同值，不能直接当作普通过程中的有限变化率。

它可能只是图中的辅助线，也可能来自图示约定或简化模型，需要说明，而不能用“无限速度”草率解释。

如果横纵轴都表示平面位置，则竖直线完全可以表示一条南北方向的直路，只是它相对于该坐标系的斜率未定义。

数学图像与实际含义要结合标签、定义和条件判断。

## 十七、小结

水平线上纵坐标不变，两个不同点之间纵向变化为 0、横向变化非零，因此斜率为 0，方程为 y = c。

竖直线上横坐标不变，斜率公式的分母为 0，因此斜率没有定义，方程为 x = a。未定义不等于零，也不写成实数意义的无穷大斜率。

水平线能写成 y = mx + c，取 m = 0；竖直线不能，因为同一个横坐标对应多个纵坐标。

坐标轴本身是两种特殊情况：x 轴为 y = 0，y 轴为 x = 0。实际图像还要按轴标签解释，区分整条直线与有限线段范围。
