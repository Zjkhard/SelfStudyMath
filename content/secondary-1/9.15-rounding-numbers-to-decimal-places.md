# 9.15 按小数位取近似值

一个正方形的面积是 2 平方米，它的边长准确表示为 √2 米。计算器可以给出小数近似显示：

~~~text
√2 ≈ 1.41421356
~~~

如果只需要把边长记录到百分之一米，就不必写出这么多位小数，可以写为约 1.41 米。

怎样从较多的小数位中选出合适的近似值？关键是先明确保留哪一位，再判断原数更接近哪个候选值。

## 一、保留几位小数是什么意思

小数点右边依次是十分位、百分位、千分位等。

| 要求 | 最后保留的数位 | 相邻候选值之间的间隔 |
| --- | --- | --- |
| 保留一位小数 | 十分位 | 0.1 |
| 保留两位小数 | 百分位 | 0.01 |
| 保留三位小数 | 千分位 | 0.001 |

例如，把 3.746 保留两位小数，就是在相邻的百分之一刻度中寻找最近的值。

“两位小数”数的是小数点右边的位数，不是整个数中数字的总个数。12.35 有两位小数，0.003 也有三位小数。

## 二、四舍五入选择最近的候选值

把 3.746 保留两位小数，附近的两个候选值是 3.74 和 3.75。

~~~text
到 3.74 的距离：3.746 − 3.74 = 0.006
到 3.75 的距离：3.75 − 3.746 = 0.004
~~~

它更接近 3.75，所以：

~~~text
3.746 ≈ 3.75（保留两位小数）
~~~

两个候选值的中点是 3.745。千分位为 0 至 4 时，原数在中点左边；千分位为 5 至 9 时，原数在中点或右边。

这就解释了“看下一位，四舍五入”的依据。

## 三、正数四舍五入的步骤

对非负数保留指定小数位，可以这样处理：

1. 找到最后要保留的数位。
2. 看它右边紧邻的一位。
3. 这一位为 0、1、2、3、4，保留位不变。
4. 这一位为 5、6、7、8、9，保留位增加 1，必要时向前进位。
5. 删去保留位右边的数字，并保持要求的小数位数。

例如：

~~~text
6.283 保留两位小数：看千分位 3，得到 6.28。
6.287 保留两位小数：看千分位 7，得到 6.29。
~~~

判断的是保留位右边紧邻的一位，不是随意选择更后面的某一位。

## 四、同一个数可以取不同精度的近似值

把 12.4876 分别保留一位、两位和三位小数：

~~~text
保留一位：看百分位 8，12.4876 ≈ 12.5。
保留两位：看千分位 7，12.4876 ≈ 12.49。
保留三位：看万分位 6，12.4876 ≈ 12.488。
~~~

每次都从原来的 12.4876 出发，按照指定数位判断。

保留更多小数位，通常能让舍入误差更小，但并不表示实际测量一定有这么高的精度。

## 五、进位可能越过小数点

把 4.996 保留两位小数。千分位是 6，百分位的 9 要进 1：

~~~text
4.996 ≈ 5.00
~~~

百分位进位到十分位，十分位也从 9 进位到个位，最后得到 5.00。

再看：

~~~text
9.999 保留两位小数，得到 10.00。
0.0996 保留三位小数，得到 0.100。
~~~

进位后仍要保留题目要求的小数位数，不能因为出现了整数就把所有小数位删掉。

## 六、末尾零表达所保留的数位

把 2.304 保留两位小数：

~~~text
2.304 ≈ 2.30
~~~

2.30 与 2.3 的数值相等，但在报告舍入结果时，2.30 清楚表明保留到了百分位。

同样，5.00 表明结果按两位小数记录；5.0 表明按一位小数记录。

如果准确数 2.3 要用两位小数表示，可以写成：

~~~text
2.3 = 2.30
~~~

这只是补零，没有改变数值，也没有产生误差，不必把准确相等强行改成近似关系。

## 七、负数先按绝对值舍入，再保留负号

本节采用通常的四舍五入约定：恰在两个候选值中间时，取离 0 更远的那个值。

因此，负数可以先对绝对值四舍五入，再恢复负号：

~~~text
−2.346 保留两位小数。
2.346 ≈ 2.35。
所以 −2.346 ≈ −2.35。
~~~

再看：

~~~text
−2.344 ≈ −2.34（保留两位小数）
−2.345 ≈ −2.35（保留两位小数）
~~~

在中点 −2.345 处，−2.34 与 −2.35 距离相等，按本节约定选择离 0 更远的 −2.35。

有些软件使用其他中点处理规则，例如取末位为偶数的结果。若工具与手算不同，要先检查舍入约定，而不是把不同规则混用。

## 八、负数进位不表示数值增加

把 −1.78 保留一位小数：

~~~text
−1.78 ≈ −1.8
~~~

这里绝对值从 1.78 舍入到 1.8，但 −1.8 的数值小于 −1.78。

所以“五入”不能统一解释成“原数变大”。它首先表示绝对值的数位进位，再根据原来的符号确定结果。

如果一个很接近 0 的负数舍入后为 0，例如：

~~~text
−0.004 ≈ 0.00（保留两位小数）
~~~

0 没有正负之分。即使计算器出现 −0.00，也不应把它理解成一个小于 0 的新数。

## 九、舍入与直接截取不同

把 3.789 保留两位小数，四舍五入得到 3.79。

如果直接删去千分位及后面的数字，则得到 3.78，这种处理叫作截取，或截断。

~~~text
四舍五入：3.789 ≈ 3.79
直接截取：保留前两位小数，写成 3.78
~~~

四舍五入选择最近的候选值；截取只是删掉后面的数字。它们有时结果相同，有时不同。

题目要求四舍五入时，不能用直接截取代替。

## 十、不要逐次舍入代替直接舍入

把 2.449 保留一位小数，应直接看原数的百分位 4：

~~~text
2.449 ≈ 2.4（保留一位小数）
~~~

如果先保留两位小数，再保留一位：

~~~text
2.449 ≈ 2.45
2.45 ≈ 2.5
~~~

就会得到不同结果。第一次舍入改变了下一次判断所用的数字，这叫作重复舍入带来的影响。

需要不同精度的近似值时，每次都应从原始准确值或足够精确的原始数据出发，不要逐层舍入。

## 十一、计算中间保留更多信息

计算 3 × (1/3)，准确结果是 1。

如果先把 1/3 保留两位小数为 0.33，再相乘：

~~~text
3 × 0.33 = 0.99
~~~

0.99 已经不是原式的准确值。若要求最终结果保留两位小数，应先完成准确计算，再写成 1.00。

能保留分数或根号时，优先保留准确形式。使用计算器时，尽量沿用内部结果，不要每一步都重新输入截短的屏幕数字。

若原始数据本来就是测量近似值，计算结果还受测量误差影响；多写小数位不能消除这类误差。

## 十二、用半个刻度理解舍入误差

保留两位小数时，相邻候选值相差 0.01；选择最近的值，到原数的距离最多为半个间隔，也就是 0.005。

若准确值为 x，舍入结果为 r，则：

~~~text
|x − r| ≤ 0.005（保留两位小数）
~~~

类似地：

~~~text
保留一位小数：舍入误差最多为 0.05。
保留三位小数：舍入误差最多为 0.0005。
~~~

这里的误差指单次四舍五入引入的差异，不包括原始测量误差或此前计算误差。

按本节的中点约定，正数舍入为 3.75 的原数范围是：

~~~text
3.745 ≤ x < 3.755
~~~

3.745 舍入为 3.75，而 3.755 会舍入为 3.76。端点是否包括，要根据中点处理约定判断。

## 十三、演示：对分数与根号取近似值

把 5/6 保留两位小数：

~~~text
5/6 = 0.8333…（3 无限重复）
~~~

千分位为 3，所以：

~~~text
5/6 ≈ 0.83
~~~

把 √2 保留三位小数，使用足够多的小数位判断：

~~~text
√2 ≈ 1.41421356
~~~

保留千分位，看万分位 2，得到：

~~~text
√2 ≈ 1.414
~~~

5/6 和 √2 仍是准确表示，0.83 和 1.414 是对应的近似值。不能因为结果写成有限小数，就改变原数的分类。

## 十四、演示：先计算周长，再舍入

圆的半径为 2.5 厘米，把圆周长保留两位小数。

先保留 π 的准确符号：

~~~text
C = 2 × π × 2.5 = 5π（厘米）
~~~

用计算器计算可得：

~~~text
5π ≈ 15.70796327
~~~

千分位为 7，百分位进 1，所以圆周长约为 15.71 厘米。

如果在中途把 π 取为 3.14，会得到 15.70 厘米。这不是按原来的 5π 直接舍入所得的结果。

除非题目明确指定使用 π = 3.14，否则应避免过早降低计算精度。

## 十五、小数位数不等于有效数字位数

本节讨论的是保留小数点右边多少位，不是保留多少位有效数字。

例如：

~~~text
0.00476 保留两位小数，得到 0.00。
12.345 保留两位小数，得到 12.35。
~~~

两者都保留到百分位，并不要求总共只留下两个数字。有效数字是另一种描述精度的方法，不能与小数位数混为一谈。

选择精度还要看单位与用途。例如 1.23 米对应按百分之一米记录，也就是按 1 厘米的刻度记录；1.23 厘米对应的刻度则是 0.01 厘米。

小数位数相同，单位不同，表示的长度刻度也不同。

## 十六、小结

保留指定小数位，是把数舍入到十分之一、百分之一或千分之一等刻度。四舍五入看最后保留位右边紧邻的一位，并处理必要的进位。

负数先对绝对值舍入，再恢复负号；恰在中点时，本节约定取离 0 更远的值。结果为 0 时，不再区分正负。

末尾零可以表达保留的小数位数。准确相等用 =，近似关系用 ≈，直接截取不能代替四舍五入。

每次舍入应从原始数值出发，避免重复舍入；多步计算尽量保留准确形式或更多位数，最后再按要求取近似值。
