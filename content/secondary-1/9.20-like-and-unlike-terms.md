# 9.20 同类项与非同类项

每盒彩笔的价格是 x 元，买 3 盒需要 3x 元，再买 2 盒需要 2x 元。

两次合计买了 5 盒，总费用可以表示为：

~~~text
3x + 2x = 5x
~~~

两部分都以同一个 x 为基础，只是倍数不同。如果另买一本价格为 y 元的书，就不能把 3x 和 2y 直接写成 5x。

代数式中，哪些部分能够这样合并？我们需要先认识项，再比较它们的字母部分。

## 一、把代数式看成若干项的和

观察：

~~~text
4x + 3y − 7
~~~

把减法看成加相反数，可以写成 4x + 3y + (−7)。这些相加的部分叫作代数式的**项**。

~~~text
三个项：4x、3y、−7。
~~~

负号属于它后面的项，所以第三项是 −7，不是 7。

这里讨论的是已经写成若干简单项相加减的形式。不能不看括号层次，就把式子内部的每个加减号都当作最外层分项的标志。

## 二、乘法因数不是不同的项

~~~text
3xy = 3 × x × y
~~~

3xy 是一个项，3、x、y 是这个项的因数，不是三个项。

同样，2x²y 也是一个项；而 2x² + y 是两个项。

辨认项时，先看最外层是相加减还是相乘。指数中的重复乘法不会增加项数。

例如 x² + 3x − 4 有三个项：x²、3x、−4。

## 三、系数与字母部分

在本节这些简单单项式中，数字因数叫作系数，剩下的字母乘积叫作字母部分。

| 项 | 系数 | 字母部分 |
| --- | --- | --- |
| 5x | 5 | x |
| −3x² | −3 | x² |
| 0.4ab | 0.4 | ab |
| (2/3)y | 2/3 | y |
| −x | −1 | x |

负号是系数的一部分。x 的系数是 1，−x 的系数是 −1，虽然这个 1 通常不写出来。

比较字母部分时，既要看字母是什么，也要看每个字母的指数。

## 四、不含字母的项叫常数项

在 2x + 5 中，5 不含字母，叫作**常数项**。

在 3a − 8 中，常数项是 −8。

常数项的值不随字母取值改变。其他项中的系数虽然也是固定数字，但整个项可能随字母改变。

例如 3x 的系数 3 固定，3x 的值却随 x 改变，所以不能把整个 3x 叫作常数项。

## 五、同类项的两个判断条件

所含字母相同，而且每个字母的指数也分别相同的项，叫作**同类项**。

~~~text
3x 与 −5x：字母都是 x，指数都是 1。
2x² 与 7x²：字母都是 x，指数都是 2。
4ab 与 −ab：字母都是 a、b，各自指数都是 1。
~~~

它们的字母部分完全相同，只有数字系数可能不同。

判断同类项不要求系数相同，也不要求符号相同。3x 与 −5x 虽然一正一负，仍然是同类项。

## 六、字母相同但指数不同，不是同类项

~~~text
3x 与 3x²：不是同类项。
2a²b 与 5ab²：不是同类项。
~~~

第一对的 x 指数分别为 1 和 2。

第二对都含 a 和 b，但 a 的指数不同，b 的指数也不同，字母部分并不一致。

不能只数“有几个字母因数”。a²b 和 ab² 都有三个字母因数相乘，但每一种字母出现的次数不同。

同类项比较的是每个字母及它对应的指数，而不是总指数是否相等。

## 七、指数相同但字母不同，也不是同类项

~~~text
4x 与 4y：不是同类项。
3a² 与 −2b²：不是同类项。
~~~

它们虽然有相同的指数，甚至可能有相同系数，但字母不同。

字母通常代表独立指定的数。没有额外关系时，不能把 x 与 y 当成同一个字母。

不满足同类项条件的项，叫作**非同类项**。

## 八、因数顺序不同，字母部分仍可能相同

乘法交换律说明 ab = ba，因此：

~~~text
3ab 与 −5ba 是同类项。
~~~

把后一项整理成 −5ab，字母部分就更容易比较。

另一个例子：

~~~text
2x²y 与 7yx² 是同类项。
~~~

它们都含两个 x 因数和一个 y 因数。通常按一致的字母顺序书写，能减少视觉上的干扰。

但是 x²y 与 xy² 不会因为调整顺序就变成同类项，交换律不改变每种字母的数量。

## 九、所有常数项都可以归为同一类

常数项都不含字母，因此把常数项看作同类项。

~~~text
5、−8、1/2、0.3 都是常数项。
~~~

它们可以按普通数的加减法合并。例如 5 + (−8) = −3。

常数项与含字母的项不是同类项。5 与 5x 虽然都有数字 5，字母部分却不同。

## 十、演示：把一个代数式中的项分组

观察：

~~~text
4x² − 3x + 2y + 5x² + x − y − 6 + 9
~~~

先连同符号读出各项，再根据字母部分分组：

| 类别 | 属于这一类的项 |
| --- | --- |
| x² 类 | 4x²、5x² |
| x 类 | −3x、x |
| y 类 | 2y、−y |
| 常数类 | −6、9 |

4x² 与 −3x 都含 x，但不能放在同一类，因为指数不同。

这里只是辨认和分组，还没有要求改变整个式子的值。分组是后续合并同类项的准备。

## 十一、为什么同类项可以合并

同类项具有相同的字母部分，可以利用分配律合并数字系数。

~~~text
3x + 2x = (3 + 2)x = 5x
~~~

再看带负号的例子：

~~~text
7a² + (−4a²)
= [7 + (−4)]a²
= 3a²
~~~

合并后，字母部分保持不变。改变的是系数，不是指数。

因此，3x + 2x 不能写成 5x²。加法合并份数，与乘法增加因数数量是不同关系。

下一节会把分配律与括号运算联系起来，后面再系统学习化简。

## 十二、非同类项不能按同一种字母部分合并

例如 3x + 2y，一般不能合并成 5x、5y 或 5xy。

当 x = 2、y = 4 时：

~~~text
3x + 2y = 6 + 8 = 14
5x = 10，5y = 20，5xy = 40
~~~

这些值不同，说明随意改写会破坏数量关系。

非同类项并不是“不能相加”。3x + 2y 本身就是它们的和；只是不能像同类项那样，仅相加系数并保留一个共同字母部分。

## 十三、代入后恰好相等，不代表是同类项

当 x = 2 时，2x 与 x² 的值都是 4：

~~~text
2x = 4
x² = 4
~~~

但它们的字母部分分别是 x 与 x²，仍是非同类项。

换成 x = 3，两个值分别为 6 和 9，就不相等了。

同样，即使某次取值 a = b，3a 与 2b 也不会因此成为同类项。判断同类项依据代数结构，不依据某次代入的巧合。

## 十四、同类项也不保证数值相等

3x 与 5x 是同类项，但当 x = 2 时，它们的值分别是 6 和 10。

同类项的意思是字母部分一致，方便合并系数，不是“两个项一定相等”。

对同类项进行抵消时，需要系数互为相反数，例如：

~~~text
3x + (−3x) = 0
~~~

3x 与 −5x 虽然同类，却不能完全抵消。它们相加得到 −2x。

## 十五、演示：同一种长度单位下的数量组合

两条彩带分别长 3x 米与 2x 米，其中 x 表示同一个正的长度数值。

总长度为：

~~~text
3x + 2x = 5x（米）
~~~

两条都以 x 米为共同长度单位，所以可以合并为五份这样的长度。

若第二条改为长 2y 米，总长度只能先写成 3x + 2y 米，除非再给出 x 与 y 的关系。

在实际情境中，还要统一计量单位。例如 3x 米与 2x 厘米不能直接相加为 5x 米，必须先换算单位，再把数量关系写成一致的代数形式。

字母结构相同是代数判断的依据，而单位一致是实际数量相加的前提，两者都要注意。

## 十六、小结

辨认代数式的项时，先看最外层的加减结构，负号要随项保留。乘法中的因数不是不同的项。

同类项的字母相同，每个字母的指数也分别相同。系数和符号可以不同，字母因数的排列顺序也可以不同；常数项属于同一类。

字母不同或对应指数不同的项是非同类项。某次代入后数值相等，不能改变这个结构判断；同类项本身也不保证数值相等。

同类项可以利用分配律相加系数，字母部分保持不变。非同类项可以写在同一个和中，但不能随意合成一个共同字母项。
