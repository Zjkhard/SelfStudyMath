# 9.41 互余角、互补角与邻角

一个直角被内部的一条射线分成 35° 和 55° 两部分。两部分合起来是 90°，所以这两个角互余。

如果把这两个角分别画在纸的不同位置，它们仍然互余，因为度数之和没有改变。

但“相邻”描述的是图上的位置关系，不能只从两个度数判断。这一节把角度和关系与位置关系分开整理。

## 一、两个角之和为 90°，就互余

如果两个角的度数之和为 90°，就说它们是**互余角**，或说两角互余。

~~~text
35° + 55° = 90°
所以 35° 与 55° 互余。
~~~

其中每一个角都是另一个角的**余角**。35° 的余角是 55°，55° 的余角是 35°。

互余是两个角之间的关系，不能只说“35° 是互余角”而不说明它与哪个角互余。

## 二、求余角就是从 90° 中减去已知角

若一个角为 a°，其余角的度数为 90 − a，只要所得度数符合讨论范围。

例如：

~~~text
28° 的余角：90° − 28° = 62°
45° 的余角：90° − 45° = 45°
~~~

在本节通常讨论的正角范围内，互余的两个角都为锐角。

钝角大于 90°，不可能再与一个正角相加得到 90°。若允许零角，则 0° 与 90° 也满足和为 90° 的关系。

## 三、两个角之和为 180°，就互补

如果两个角的度数之和为 180°，就说它们是**互补角**，或说两角互补。

~~~text
65° + 115° = 180°
所以 65° 与 115° 互补。
~~~

其中每一个角都是另一个角的**补角**。

互补与互余的目标和不同：互余是 90°，互补是 180°。名称相近，判断依据不能混用。

## 四、补角不一定是一锐一钝

~~~text
40° 的补角：140°
120° 的补角：60°
90° 的补角：90°
~~~

两角互补时，可能一锐一钝，也可能都是直角。

在正角范围内，两个锐角的和小于 180°，两个钝角的和大于 180°，所以这些组合不能互补。

若允许零角，则 0° 与 180° 也满足和为 180° 的关系。本节常见图形主要使用大于 0°、小于 180° 的角。

## 五、互余与互补不要求位置相邻

一个 30° 的角画在纸左边，一个 60° 的角画在纸右边，它们仍然互余。

一个 70° 的角与另一个独立画出的 110° 的角，也仍然互补。

这两种关系只要求度数之和正确，不要求公共顶点、公共边或接触。

不能因为两个角在图上分开，就否定它们互余或互补；也不能因为靠在一起，就自动判断它们的和是 90° 或 180°。

## 六、邻角描述共同边与位置关系

两个角有公共顶点和一条公共边，且内部区域不重叠，就称为**邻角**。

例如射线 OB 位于较小角 AOC 内部，∠AOB 与 ∠BOC 有：

~~~text
公共顶点：O
公共边：射线 OB
内部区域：分处公共边两侧，没有重叠
~~~

所以它们是邻角。

邻角的英文常称 adjacent angles。判断邻角，需要知道图形位置，不能只看度数。

## 七、只共用顶点还不够

两个角都以 O 为顶点，但没有公共边，不一定是邻角。

两个角虽然共用顶点与一条边，如果一个角的内部包含另一个角的内部，也不是本节定义下的邻角，因为区域重叠了。

例如 OB 在较小角 AOC 内部，∠AOB 与 ∠AOC 共用 OA，但前者包含在后者内部，所以不是邻角。

比较的是角的区域关系，不是两条角弧是否在纸上碰到。

## 八、邻角不一定互余或互补

两个邻角分别为 30° 和 40°，它们的和是 70°，既不互余，也不互补。

若两个邻角为 35° 和 55°，则它们同时是邻角与互余角。

若两个邻角为 65° 和 115°，则它们同时是邻角与互补角。

“邻角”说明怎样相邻，“互余或互补”说明度数和是多少。同一对角可以同时具有这两类关系，但一种关系不能代替另一种。

## 九、邻补角还要求非公共边为相反射线

两个邻角的非公共边是相反射线时，它们共同组成平角，叫作**邻补角**。

例如 A、O、C 共线，O 位于 A、C 之间，射线 OB 不在这条直线上。取公共边两侧、共同组成平角的 ∠AOB 与 ∠BOC：

~~~text
∠AOB + ∠BOC = 180°
~~~

它们既相邻又互补。

所有邻补角都是邻角，也都是互补角；但互补角可以分开画，邻角也可以不组成平角，所以不能反过来把任何一种都直接叫作邻补角。

## 十、演示：直角被分成两个邻角

已知 OA 与 OC 垂直，射线 OB 位于它们所形成的直角内部，∠AOB = 32°。

~~~text
∠AOB + ∠BOC = 90°
∠BOC = 90° − 32° = 58°
~~~

这两个角因为位置条件是邻角，因为度数和为 90° 又互余。

依据是 OA 与 OC 垂直且 OB 位于该直角内部，不是因为图形看起来接近直角。

## 十一、演示：平角被分成两个邻补角

A、O、C 共线，O 位于 A、C 之间。射线 OB 把所讨论的平角分成两个邻角，∠AOB = 124°。

~~~text
∠BOC = 180° − 124° = 56°
~~~

检查：124° + 56° = 180°。一个为钝角，一个为锐角。

如果没有共线和点序条件，就不能仅凭三个字母出现在图中，认定 OA 与 OC 是相反射线。

## 十二、演示：用方程求互余角

两个角互余，第一个比第二个大 18°。设第二个角为 x°，第一个为 (x + 18)°。

~~~text
x + (x + 18) = 90
2x = 72
x = 36
~~~

两个角分别为 36° 和 54°。

检查：36 + 54 = 90，54 − 36 = 18，两条条件都满足。

没有位置条件时，只能说它们互余，不能进一步声称它们相邻。

## 十三、演示：用方程求互补角

两个角互补，其中一个是另一个的 2 倍。设较小角为 x°，较大角为 2x°。

~~~text
x + 2x = 180
3x = 180
x = 60
~~~

两个角为 60° 和 120°。

如果还知道它们是邻角，那么它们共同组成平角，是邻补角；若只给出倍数与互补条件，则不增加位置结论。

## 十四、演示：从整体角减去一部分

射线 OB 位于较小角 AOC 内部，∠AOC = 140°，∠AOB = 45°。

~~~text
∠BOC = 140° − 45° = 95°
~~~

∠AOB 与 ∠BOC 是邻角，但它们的和为 140°，既不互余，也不互补。

不能看到“一大角被分成两部分”，就自动用 90° 或 180° 减。应先确定整体角的准确度数。

## 十五、演示：一个角的余角与补角

一个角为 38°，它的余角为 52°，补角为 142°。

~~~text
余角：90° − 38° = 52°
补角：180° − 38° = 142°
~~~

补角比余角大 90°。

这说明同一个角可以与不同的角形成不同关系。余角与补角本身并不是一对互余角或互补角，它们的和为 194°。

不要把“都是某个角的对应角”误当成“它们互相满足同一种关系”。

## 十六、检查角度与位置两类条件

判断互余或互补时，计算度数和；判断邻角时，检查公共顶点、公共边和内部不重叠。

判断邻补角还要确认非公共边为相反射线，或等价地确认两个邻角共同组成平角。

求未知角后，检查度数范围与图中条件。例如由直角内部分得的正角应小于 90°；由平角分得的正角应小于 180°。

图形只作示意，准确关系来自已知度数、共线或垂直条件，不应靠纸上量出的近似读数替换。

## 十七、小结

互余角的度数和为 90°，互补角的度数和为 180°。它们描述角度关系，不要求位置相邻。

邻角有公共顶点与公共边，内部不重叠，描述位置关系；邻角不一定互余或互补。

邻补角的非公共边为相反射线，两角共同组成平角。因此邻补角既相邻又互补，但普通邻角不能直接叫作邻补角。

求未知角时先确认整体角或角度和条件，再用减法或方程求解，并分别检查度数与位置条件。
