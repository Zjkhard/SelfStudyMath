# 9B.13 圆周长

给圆形花坛围一圈矮栏，需要知道沿边缘一周有多长。圆的边界是曲线，不能像长方形那样把几条直边直接相加，但它与圆的直径之间有固定关系。

本节从“绕一圈”的长度开始，理解圆周率，并学习用半径或直径计算圆周长。

## 一、圆周长表示沿圆周一周的长度

圆的边界叫作圆周。沿着圆周绕一整圈的长度叫作圆周长，通常用 C 表示。

~~~text
圆周：围成圆的曲线边界
圆周长：沿这条边界一周的长度
~~~

圆周长用厘米、米等长度单位表示。圆内部区域有多大是面积问题，之后会单独学习，不能把周长与面积混为一谈。

## 二、测量圆周长的想法

可以用细绳测量圆周长：把绳子沿圆形物体边缘贴紧绕一周，标记起点和终点，再把绳子拉直测量两标记间的长度。

~~~text
圆形边缘绕一周 → 细绳标记 → 拉直 → 用尺测长度
~~~

测量时绳子不能松开、重叠或被拉伸。由于圆周是曲线，实际测得的数值会受工具和操作影响，通常是近似值。

## 三、直径是横跨圆心的线段

半径从圆心连到圆周，常用 r 表示；直径连接圆周上的两点并经过圆心，常用 d 表示。

~~~text
圆周上的 A ─── 圆心 O ─── 圆周上的 B
AO = r，OB = r，AB = d
d = 2r
~~~

直径由两条半径组成，所以直径是半径的 2 倍。连接圆周上任意两点的线段不一定经过圆心，只有经过圆心的那条才是直径。

## 四、比较圆周长与直径

把不同大小的圆量一量，再比较圆周长 C 与直径 d 的比值，会看到一个共同规律：

| 圆 | 直径 d（cm） | 圆周长 C（cm，约） | C ÷ d（约） |
| --- | ---: | ---: | ---: |
| 甲 | 5 | 15.7 | 3.14 |
| 乙 | 10 | 31.4 | 3.14 |
| 丙 | 20 | 62.8 | 3.14 |

不同圆的大小不一样，但圆周长除以直径总是同一个固定比值。测量结果会有误差，因此表中比值写作“约 3.14”。

## 五、圆周率 π

圆周长与直径的固定比值叫作圆周率，用希腊字母 π 表示，读作“派”：

~~~text
π = 圆周长 ÷ 直径 = C ÷ d
π ≈ 3.14159…
~~~

π 是一个数，没有长度单位。它的小数位无限延伸且不循环。常用 3.14 或 22/7 作为计算近似值：

~~~text
π ≈ 3.14
π ≈ 22/7
~~~

这两个都只是近似值。π 不等于 3.14，也不精确等于 22/7。题目若指定取值，应按要求使用。

## 六、由圆周率得到直径公式

由 π = C ÷ d，两边乘以 d，可以得到：

~~~text
C = πd
~~~

也就是说，圆周长是直径的 π 倍。因为 π 约为 3.14，圆周长约为直径的 3.14 倍。

若直径是 10 cm，准确表示为 C = 10π cm；按 π ≈ 3.14 计算，C ≈ 31.4 cm。

## 七、用半径表示圆周长

因为 d = 2r，把它代入 C = πd：

~~~text
C = π × 2r
C = 2πr
~~~

因此有两种等价写法：

~~~text
C = πd = 2πr
~~~

已知直径时用 πd 直接计算；已知半径时用 2πr，或先把半径乘 2 求出直径。不要把给出的直径又乘 2。

## 八、演示：已知直径求圆周长

自行车轮的直径为 70 cm，求轮子转一周沿外缘经过的长度，结果用 π 表示并取 π ≈ 3.14 估算。

~~~text
C = πd
C = 70π cm
C ≈ 3.14 × 70
C ≈ 219.8 cm
~~~

准确表达是 70π cm；219.8 cm 是近似值。圆周长与直径一样，都是长度，所以单位为 cm。

## 九、演示：已知半径求圆周长

一个圆形桌面的半径为 0.6 m：

~~~text
C = 2πr
C = 2 × π × 0.6
C = 1.2π m
~~~

按 π ≈ 3.14 估算：

~~~text
C ≈ 1.2 × 3.14
C ≈ 3.768 m
~~~

若要求保留两位小数，可写成约 3.77 m。写“约”能表明这是把 π 换成近似值后的结果。

## 十、两种公式得到同一个结果

圆形桌面的半径是 0.6 m，直径就是 1.2 m。分别用两种公式计算：

~~~text
用直径：C = π × 1.2 = 1.2π m
用半径：C = 2π × 0.6 = 1.2π m
~~~

结果相同，因为 d = 2r。若两种方法结果不一致，先检查是否把半径和直径弄混。

## 十一、由圆周长反求直径或半径

从 C = πd 可以得到 d = C ÷ π；从 C = 2πr 可以得到 r = C ÷ (2π)。

若一个圆的准确周长为 18π cm：

~~~text
d = 18π ÷ π = 18 cm
r = 18 ÷ 2 = 9 cm
~~~

若周长为近似测量值，例如约 62.8 cm，按 π ≈ 3.14 反求直径：d ≈ 62.8 ÷ 3.14 = 20 cm。由于输入是近似值，求得的直径也应理解为近似值。

## 十二、圆按比例放大时，周长也按比例放大

一个圆的直径从 4 cm 变为 12 cm，变为原来的 3 倍。对应圆周长分别为 4π cm 与 12π cm，后者也是前者的 3 倍。

这是因为 C = πd 中 π 不变，圆周长与直径成正比例。半径扩大若干倍，直径和圆周长也扩大相同倍数。

这里讨论的是长度变化；圆面积的变化关系不同，不能把这个结论直接用于面积。

## 十三、估算结果并检查合理性

直径为 8 cm 的圆，圆周长应约为直径的 3 倍多：

~~~text
C ≈ 3.14 × 8 ≈ 25.12 cm
~~~

若计算结果只有 8 cm 左右，可能漏乘了 π；若用 8 cm 当半径而题目给的是直径，则结果会约大一倍。估算与检查输入量能帮助发现错误。

## 十四、单位必须前后一致

半径为 4 cm 的圆与直径为 8 cm 的圆是同一个尺寸。用任一公式：

~~~text
C = 8π cm
C ≈ 25.12 cm
~~~

如果题目把半径写成 4 cm、却要求答案用米，应先换算或在结果后正确换单位。圆周长的单位始终是长度单位，不是平方单位。

## 十五、准确值与近似值

保留 π 的表达，如 14π cm，是准确表达；代入 3.14 或 22/7 计算，得到的是近似值。

~~~text
C = 14π cm       准确表达
C ≈ 43.96 cm     使用 π ≈ 3.14 的近似结果
~~~

使用计算器时，可保留较多位数到最后再按要求取舍。中途过早四舍五入可能让最终结果略有差异。

## 十六、常见混淆

~~~text
直径 d = 2r；半径 r = d ÷ 2。
已知直径：C = πd；已知半径：C = 2πr。
圆周长是长度，使用 cm、m 等单位。
π 是无单位的固定比值，3.14 是它的常用近似值。
使用近似值计算后，用“约”或 ≈ 表示结果。
~~~

公式本身简短，错误多发生在读错半径与直径、遗漏单位或把近似值写成精确等号。

## 十七、小结

圆周长是沿圆周一周的长度。圆周长与直径的比值是固定的圆周率 π，因此 C = πd；又因为 d = 2r，所以 C = 2πr。

计算前辨明给出的是半径还是直径，并统一长度单位。保留 π 时可写准确表达，代入 3.14 或 22/7 后应说明结果为近似值。
