# 9.23 提取公因式

三个相同礼袋，每袋放 x 支铅笔和 2 支彩笔。可以分别数两类笔，也可以先数每袋的总支数：

~~~text
分别计算：3x + 6
按袋计算：3(x + 2)
~~~

上一节利用分配律把 3(x + 2) 展开为 3x + 6。现在反过来，把共同的因子 3 提出来，就能把和改写成乘积。

## 一、从展开反过来看分解

分配律说明：

~~~text
a(b + c) = ab + ac
~~~

反过来读同一个等式：

~~~text
ab + ac = a(b + c)
~~~

左边两项都含有因子 a，把它提到括号外，括号内留下 b 和 c。

这里没有改变数值，只是从“两个乘积的和”改成“一个整体乘积”。

## 二、什么是因式与因式分解

把一个代数式写成几个因式相乘的形式，叫作**因式分解**，也常称为分解因式。

在 3(x + 2) 中，3 与 x + 2 都是乘积的因式。“因式”可以是数字、字母乘积，也可以是含加减法的整个括号。

~~~text
3x + 6 = 3(x + 2)
~~~

这是把 3x + 6 分解成 3 与 x + 2 的乘积。

与正整数的质因数分解不同，这里不要求每个因式都是质数；我们处理的是代数式的结构。

## 三、公因式是每一项共同含有的因子

观察 6x + 9：

~~~text
6x = 3 × 2x
9 = 3 × 3
~~~

两项都含因子 3，称 3 为它们的**公因式**。

因此：

~~~text
6x + 9 = 3(2x + 3)
~~~

x 不是这两项的公因式，因为常数项 9 不含 x。不能只看第一项就决定提什么。

公因式必须从每一项的乘法结构中都能取出。

## 四、数字部分通常取最大公因数

分解 12x + 18，可以提取 2，也可以提取 3：

~~~text
12x + 18 = 2(6x + 9)
12x + 18 = 3(4x + 6)
~~~

这两种等式都正确，但括号内仍有共同数字因子。

12 和 18 的最大公因数是 6，一次提取它：

~~~text
12x + 18 = 6(2x + 3)
~~~

括号内的数字系数 2 和 3 已经互质，没有更大的共同正整数因子。

在整数系数的式子中，通常比较各项系数的绝对值，取它们的最大公因数作为数字公因子。

## 五、共同字母取各项中的最小指数

观察 8x³ + 12x²：

~~~text
8x³ = 4x² × 2x
12x² = 4x² × 3
~~~

数字系数的最大公因数是 4，两项都至少含有两个 x 因子，因此共同字母部分为 x²。

~~~text
8x³ + 12x² = 4x²(2x + 3)
~~~

不能提取 x³，因为第二项只有两个 x 因子。共同部分受数量较少的那一项限制。

提取后，第一项留下一个 x，第二项不再留下 x；可以通过展开因数来理解，不需要把字母取成一个具体非零数。

## 六、多种字母分别比较

分解 12a²b + 18ab²：

~~~text
数字部分：12 与 18 的最大公因数是 6。
a：两项指数分别为 2、1，共同取 a。
b：两项指数分别为 1、2，共同取 b。
~~~

所以最大公因式为 6ab：

~~~text
12a²b + 18ab² = 6ab(2a + 3b)
~~~

展开检查：6ab × 2a = 12a²b，6ab × 3b = 18ab²，恰好还原每一项。

对于这些整数系数的单项式，最大公因式由“系数绝对值的最大公因数”和“共同字母的最小指数”组成。

## 七、提取后的括号记录每项剩下什么

分解 15x²y − 10xy + 5x：

~~~text
15x²y = 5x × 3xy
−10xy = 5x × (−2y)
5x = 5x × 1
~~~

于是：

~~~text
15x²y − 10xy + 5x = 5x(3xy − 2y + 1)
~~~

y 不是所有项共有的字母，所以不提取 y。

每一项都必须在括号中有对应的剩余部分，原来的项数与符号关系不能遗漏。

## 八、剩余部分为 1 时不能漏写

分解 7x + 7：

~~~text
7x + 7 = 7(x + 1)
~~~

第二项 7 提出 7 后，剩下的是 1，不是 0，也不是“什么都不写”。

同样：

~~~text
4x² − 4x = 4x(x − 1)
~~~

若漏掉 −1 而只写成 4x × x，展开后就没有原来的 −4x 项。

## 九、负号可以作为公因式的一部分

分解 −6x − 9，可以提取正的 3：

~~~text
−6x − 9 = 3(−2x − 3)
~~~

也可以提取 −3，让括号内的第一项为正：

~~~text
−6x − 9 = −3(2x + 3)
~~~

两种形式都正确。

再看：

~~~text
−8x + 12 = −4(2x − 3)
~~~

提取负数时，每项剩余部分的符号要相应变化。−4 × (−3) = 12，所以括号中第二项为 −3。

## 十、括号整体也可以是公因式

观察 2(x + 1) + 5(x + 1)。两项都含同一个整体 x + 1。

~~~text
2(x + 1) + 5(x + 1)
= (2 + 5)(x + 1)
= 7(x + 1)
~~~

再看：

~~~text
a(x − 2) + b(x − 2) = (a + b)(x − 2)
~~~

不必先把每个括号展开。直接看出共同整体，有时更简洁。

但 x + 1 与 x − 1 不是相同因式，不能把它们当作共同部分直接提取。下一节会进一步学习通过分组形成共同因式。

## 十一、分数与小数系数也能提取因子

例如：

~~~text
(1/2)x + 3/2 = (1/2)(x + 3)
0.4x + 0.8 = 0.4(x + 2)
~~~

分配律对有理数系数同样成立。展开后应准确还原每个系数。

“系数的最大公因数”通常用于整数系数的情形。对分数和小数，不要未经说明就套用整数最大公因数的名称；可以选择便于整理的共同数字因子。

## 十二、因式分解不同于把每项单独改写

对于 6x + 9，写成：

~~~text
3 × 2x + 3 × 3
~~~

虽然找出了共同因子，但整体仍是一个和。继续写成 3(2x + 3)，才完成了这次提取公因式。

因式分解的结果应体现整个原式的乘积结构，而不是只有某一个加数被写成乘积。

也不能写成 3 × 2x × 3，那会把原来的加法改变成乘法，数值不再相同。

## 十三、演示：完整分解并检查 18x² − 24x

先比较数字系数：18 和 24 的最大公因数是 6。

再比较字母：x 的指数分别是 2 和 1，共同部分为 x。

~~~text
18x² = 6x × 3x
−24x = 6x × (−4)
~~~

因此：

~~~text
18x² − 24x = 6x(3x − 4)
~~~

括号内的两项不再有大于 1 的共同正整数系数因子，也没有共同字母因子。

展开验证：

~~~text
6x(3x − 4) = 18x² − 24x
~~~

当 x = 2 时，原式为 72 − 48 = 24，分解式为 12 × 2 = 24，也能帮助检查。

证明两个表示对所有 x 都等价，依据的是分配律；一次代入只是辅助检验。

## 十四、字母为 0 时，分解等式仍可成立

例如：

~~~text
3x² + 6x = 3x(x + 2)
~~~

x = 0 时，两边都等于 0，等式仍然正确。

找出剩余因式时，可以观察每项的乘法组成。不能误以为提取 3x 就一定实际做了“除以 3x”，从而擅自加上 x ≠ 0 的限制。

因式分解没有把原式整体除以公因式，而是改写成乘积。若在其他任务中真的除以含字母的式子，则必须另行检查除数不为 0。

## 十五、演示：面积模型中的共同长度

两个长方形并排放置，没有重叠，高都为 3 厘米，宽分别为 x 厘米和 2 厘米，其中 x 为正数。

分别计算面积，总面积为 3x + 6 平方厘米。

合成的大长方形高为 3 厘米，总宽为 x + 2 厘米，所以面积也可以写成 3(x + 2) 平方厘米。

~~~text
3x + 6 = 3(x + 2)
~~~

共同高度对应提取出的因子 3，两块的宽度对应括号里的 x 和 2。图形帮助我们看见分配律的两个方向。

这个长度情境要求 x 为正，而代数等式本身对所有实数 x 都成立。情境限制与等式的适用范围要分清。

## 十六、因式分解不等于解方程

分解 6x + 9，得到 3(2x + 3)，只是改变表示方式，没有要求找 x。

不能因此擅自写成 3(2x + 3) = 0，再开始求解。原来的任务没有给出等于 0 的条件。

展开把乘积写成和，提取公因式把和写成乘积，两者都是等价变形；解方程则需要明确的等式条件，并寻找满足条件的未知数。

## 十七、小结

提取公因式是分配律的逆向使用：把每一项共同含有的因子提到括号外，括号内记录每项剩下的部分。

整数系数的单项式中，数字部分通常取系数绝对值的最大公因数，共同字母取最小指数。没有在每项中出现的字母不能提取。

剩余部分为 1 时必须写出；提取负因子时注意各项符号。相同的括号整体也可以作为公因式。

分解后的整体应是乘积，展开应还原原式。提取含字母的因式并不自动增加非零限制，也不等于给原式添加一个方程条件。
