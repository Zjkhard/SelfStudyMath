# 9B.46 样本空间与事件

分析随机试验时，先要知道试验可能产生哪些结果。一次试验所有可能结果组成的集合称为样本空间，常用字母 (S) 表示。我们关心的事件则由样本空间中的一个或多个结果组成。

## 一、样本空间

样本空间是某个随机试验全部可能结果的集合。列出样本空间时，应包含每一种可能结果，不应加入试验中不可能出现的结果。

~~~text
试验：掷一次标准六面骰子
样本空间：S = {1, 2, 3, 4, 5, 6}
~~~

样本空间只描述试验可能出现的结果，不表示哪一个结果更容易发生。结果是否等可能，需要结合试验条件另外判断。

## 二、样本空间要与试验描述一致

描述试验时要说明进行什么操作、观察并记录什么。例如“掷骰子一次，记录朝上的点数”与“掷骰子一次，只记录结果是否大于 3”采用了不同的记录方式，样本空间也不同。

~~~text
记录点数：{1, 2, 3, 4, 5, 6}
只记是否大于 3：{是，不是}
~~~

两种表示都可以正确描述相应的观察结果，但不能在同一道题中混用不同记录方式。

## 三、列出样本空间的检查方法

列样本空间时可以依次检查：

1. 试验条件是否明确；
2. 所有可能结果是否都已列出；
3. 是否误把不可能的结果列入；
4. 每个结果的描述是否清楚、彼此可区分。

若结果很多，可以使用表格或树状图帮助检查；本节先从结果数较少的试验开始。

## 四、掷硬币的样本空间

掷一枚硬币一次，并记录朝上的一面。若硬币只有正面和反面两种可能：

~~~text
S = {正面，反面}
~~~

结果名称可使用文字，也可使用符号，例如 H 表示正面，T 表示反面：

~~~text
S = {H, T}
~~~

只要符号定义清楚，文字与符号表示的是同一个结果范围。

## 五、事件是样本空间的子集

事件是由样本空间中的若干结果组成的集合。因此每个事件都是 S 的子集。

~~~text
掷一次骰子，S = {1, 2, 3, 4, 5, 6}
A = 掷出偶数 = {2, 4, 6}
~~~

A 中每个结果都属于 S，所以 A ⊆ S。试验结果如果是 4，就说事件 A 发生；如果结果是 5，A 不发生。

## 六、事件可以包含一个或多个结果

在一次掷骰子试验中：

~~~text
B = 掷出 5 = {5}
C = 掷出大于 4 的点数 = {5, 6}
~~~

B 只包含一个结果，C 包含两个结果。它们都是事件。事件不一定只对应一个结果。

## 七、必然事件与不可能事件的集合表示

必然事件包含样本空间中的所有结果，因此它对应整个样本空间 S；不可能事件没有任何结果，因此对应空集：

~~~text
必然事件：S
不可能事件：∅
~~~

掷骰子时，“点数在 1 到 6 之间”对应 S；“点数为 8”对应 ∅。这与前一节学习的事件分类一致。

## 八、事件是否发生

设事件 A 是样本空间 S 中的一个子集。实际试验得到结果 x 时：

~~~text
x ∈ A：事件 A 发生
x ∉ A：事件 A 不发生
~~~

例如 A = {2, 4, 6}。若掷出 2，A 发生；若掷出 3，A 不发生。判断时将实际结果与事件集合逐项对照。

## 九、事件的补集

事件 A 的补集 A' 包含 S 中所有不属于 A 的结果，也就是 A 不发生的所有可能结果。

~~~text
S = {1, 2, 3, 4, 5, 6}
A = {2, 4, 6}
A' = {1, 3, 5}
~~~

A 与 A' 没有共同结果，合起来恰好是 S。补集中不能出现样本空间以外的结果。

## 十、样本空间中的结果要区分清楚

掷两枚硬币并记录每枚的结果时，结果可以写成有顺序的组合：

~~~text
S = {HH, HT, TH, TT}
~~~

HT 表示第一枚为正面、第二枚为反面；TH 则相反。若试验中两枚硬币有不同身份或先后顺序，HT 与 TH 是不同结果。

如果题目只记录“正面总数”，则样本空间可以写为 `{0, 1, 2}`。先确定记录什么，再决定结果怎样表示。

## 十一、样本空间与等可能性不同

列出样本空间并不自动说明各结果机会相同。只有在试验条件支持等可能时，才可以把每个列出的结果当作同样可能。

例如，一个不均匀转盘可能有样本空间 `{红，蓝}`，但停在红色和蓝色的机会未必相同。结果种类只有两个，并不能证明概率各为一半。

等可能结果的条件和概率计算将在后续内容中进一步学习。

## 十二、样本空间不必永远用列举法

结果较少时，列举法简单清楚；若结果很多，可以用表格、可能性图或树状图组织。无论用哪种方式，目标都是完整且不重复地表示可能结果。

~~~text
结果较少：直接列出集合
有两步试验：可用表格或树状图
~~~

不同表示方式应反映相同的试验和相同的结果范围。

## 十三、常见错误

- 样本空间漏掉某种可能结果，或加入不可能结果。
- 没有说明试验记录什么，导致结果含义不清楚。
- 把事件当成单个结果，忘记事件可以包含多个结果。
- 认为样本空间列出的结果必然等可能。
- 把 HT 与 TH 混为一谈，却忽略试验是否记录顺序或对象身份。
- 将样本空间外的对象放进事件或事件补集。

## 十四、回顾

样本空间 S 是一次随机试验的全部可能结果；事件是 S 的子集。若实际结果属于事件集合，事件发生；若不属于，事件不发生。必然事件对应 S，不可能事件对应空集，事件的补集由 S 中其余结果组成。

列样本空间前先明确试验和观察方式，并检查结果范围是否完整。样本空间的列举本身不代表各结果等可能，判断等可能性还需要依据试验条件。
