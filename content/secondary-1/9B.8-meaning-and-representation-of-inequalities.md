# 9B.8 不等式的意义与解的表示

等式告诉我们两个数量相等。不等式则表示两个数量有大小关系。

例如，“盒子里至少有 5 支笔”并没有说笔恰好有 5 支。笔可以有 5 支、6 支或更多。用一个字母表示笔的数量，就可以写出一个条件，并找出所有符合条件的数。

本节先理解不等式说的是什么，再学习用数轴把它的解表示出来。怎样对不等式两边进行运算，留到下一节讨论。

## 一、从数量条件到不等式

设盒子里的笔有 x 支。“至少有 5 支”表示 x 可以等于 5，也可以大于 5：

~~~text
x ≥ 5
~~~

这里的符号“≥”读作“大于或等于”。它把两种可能合在一起：x 大于 5，或者 x 等于 5。

相反，“少于 5 支”不包括 5 支，写作 x < 5。符号“<”读作“小于”。

## 二、认识常用的不等号

| 符号 | 读法 | 含义 |
| --- | --- | --- |
| > | 大于 | 左边的数比右边大 |
| < | 小于 | 左边的数比右边小 |
| ≥ | 大于或等于 | 左边大于右边，或两边相等 |
| ≤ | 小于或等于 | 左边小于右边，或两边相等 |

尖口的一端朝向较小的一边，开口的一边朝向较大的一边。例如 3 < 8，也可以反过来写成 8 > 3。

符号下面多出的横线表示“也可以相等”。因此 5 ≤ 5 为真，而 5 < 5 为假。

## 三、等式与不等式表达不同关系

~~~text
x = 5     x 的值恰好是 5
x < 5     x 的值小于 5
x ≤ 5     x 的值小于或等于 5
~~~

等式通常只限定某些特定数值，不等式常表示一段范围。比较时要读清符号，不能把“低于 5”误读成“不超过 5”：前者不含 5，后者含 5。

## 四、什么是含有变量的不等式

像 x > 2 这样的式子包含一个还未确定的数 x，并用不等号表示关系，叫作含有变量的不等式。

x 取不同的数时，这句话可能为真，也可能为假：

~~~text
x = 4 时，4 > 2 为真。
x = 2 时，2 > 2 为假。
x = 1 时，1 > 2 为假。
~~~

变量并不是“什么数都可以代进去而条件仍成立”。只有使不等式成立的取值才符合条件。

## 五、一个解与解集

如果把一个数代入不等式后，得到的大小关系为真，这个数就是不等式的一个解。

对 x > 2，数 3 是一个解，因为 3 > 2；数 2 不是它的解，因为 2 并不大于 2。

使不等式成立的所有取值合在一起，叫作它的解集。x > 2 的解不只有 3，而是所有大于 2 的数。

解集说的是完整的范围。只列出几个符合条件的数，只能举例，不能代替整个解集。

## 六、代入检查一个数是不是解

要检查某个数是不是解，可以把它代入原不等式，计算两边，再比较大小。

检查 x = −1 是否满足 2x + 1 < 0：

~~~text
左边：2 × (−1) + 1 = −1
右边：0
−1 < 0，关系成立
~~~

所以 −1 是这个不等式的一个解。

再检查 x = 1：左边为 2 × 1 + 1 = 3，3 < 0 不成立。因此 1 不是解。

## 七、不等式的解可能有很多个

对 x ≤ 4，数轴上 4 左边的数以及 4 本身都属于解。

~~~text
符合条件的数：…，1，2，3，4
不符合条件的数：5，6，…
~~~

如果 x 可以取任意实数，那么 4 与 5 之间也有许多解，例如 4.5。整数只是解中的一部分。

## 八、数轴如何表示解

在数轴上，越往右数越大，越往左数越小。于是，不等式的大小范围可以画成从某个边界点向左或向右延伸的一段线。

边界点是否属于解集，决定端点怎么画：

- 边界不属于解集，画空心圈 ○。
- 边界属于解集，画实心圈 ●。
- 解在边界右边，向右延伸；解在边界左边，向左延伸。

数轴上的圈表示边界值；延伸的线和箭头表示范围还在继续。

## 九、表示大于某个数

x > 2 表示所有大于 2 的数。2 本身不包括在内，所以在 2 处画空心圈，并向右延伸。

~~~text
          2
←────────○════════→
~~~

图中横线的长短不代表精确距离，只表示 2 右侧的数都符合条件。

## 十、表示大于或等于某个数

x ≥ 2 也从 2 向右延伸，但 2 本身符合条件，因此端点画实心圈。

~~~text
          2
←────────●════════→
~~~

x > 2 与 x ≥ 2 只差边界 2 是否属于解集。这个小小的差别会改变端点的画法。

## 十一、表示小于某个数

x < 2 表示所有小于 2 的数。边界 2 不包含在内，画空心圈，并向左延伸。

~~~text
          2
←════════○────────→
~~~

例如 −1、0、1.9 都小于 2；2 与 3 不满足这个条件。

## 十二、表示小于或等于某个数

x ≤ 2 包含边界 2，因此在 2 处画实心圈，并向左延伸。

~~~text
          2
←════════●────────→
~~~

注意数轴方向：小于在左，大于在右。端点的圈则只回答“这个边界值算不算解”。

## 十三、演示：把文字条件画在数轴上

某场活动规定，儿童身高不超过 140 厘米才能使用某设施。设身高为 h 厘米。

“不超过 140”包括恰好 140，因此条件写成 h ≤ 140。若只讨论非负身高，符合条件的范围从 0 到 140，两个端点都包括。

~~~text
          0                         140
──────────●════════════════════════●──────────
~~~

这里数轴图还用了实际身高不能为负这一条件。若只看不等式 h ≤ 140，它本身还包括所有负实数；情境条件会进一步限制可取范围。

## 十四、端点取舍来自符号

| 不等式 | 边界值是否属于解 | 数轴端点 |
| --- | --- | --- |
| x < 3 | 不属于 | 3 处空心圈 |
| x > 3 | 不属于 | 3 处空心圈 |
| x ≤ 3 | 属于 | 3 处实心圈 |
| x ≥ 3 | 属于 | 3 处实心圈 |

左右方向由小于号或大于号决定，空心圈或实心圈由是否包含等号决定。这两项信息要分别判断。

## 十五、解集也可以只有几个离散数

解集画成一整段数轴，默认变量可以取这段中的任意实数。但实际问题有时规定变量只能取整数或整件物品的数量。

例如整数 n 满足 2 < n ≤ 6，则符合条件的整数为 3、4、5、6。此时不应把 2 与 6 之间所有实数都说成实际可行的数量。

题目给出的变量范围和单位会决定解集中的候选数。如果没有额外限制，通常按所讨论的数的范围理解；读题时要留意“整数”“正整数”“人数”等条件。

## 十六、两个边界一起限定范围

有时一个条件同时规定下界和上界。例如 1 ≤ x < 4，表示 x 至少为 1，但必须小于 4。

~~~text
          1                         4
←─────────●════════════════════════○────────→
~~~

1 包含在范围内，所以画实心圈；4 不包含，所以画空心圈。图上的线段表示两个条件都满足的部分。

## 十七、常见误读

~~~text
x > 5 不包括 5；x ≥ 5 包括 5。
x < 5 的解在 5 左边；x > 5 的解在 5 右边。
空心圈表示边界值不属于解；实心圈表示边界值属于解。
~~~

不能只看箭头方向，也不能只看端点的圈。数轴图必须同时正确表达方向与边界。

## 十八、小结

不等式用大于、小于、大于或等于、小于或等于表示数量间的大小关系。代入后使不等式成立的数是它的解，所有解组成解集。

一元不等式的解集常用数轴表示：小于向左，大于向右；不包括边界画空心圈，包括边界画实心圈。表示情境范围时，还要结合变量能取哪些数。
