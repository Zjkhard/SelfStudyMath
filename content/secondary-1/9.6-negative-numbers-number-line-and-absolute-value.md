# 9.6 负数与数轴、绝对值

两个地方的气温分别是零上 4°C 和零下 4°C。

~~~text
零上 4°C：+4°C
零下 4°C：−4°C
~~~

它们都与 0°C 相差 4°C，但一个在零上，一个在零下，表示的温度不同。

正负号帮助我们表示方向；数轴帮助我们看见位置；绝对值帮助我们描述离零有多远。这三种表示既有联系，也各有不同的作用。

## 一、负数表示零以下或约定的相反方向

小于 0 的数叫作**负数**。负数前面的“−”叫作负号。

~~~text
−3，−12，−0.5，−3/4
~~~

负数不只包括整数，也可以是分数和小数。

大于 0 的数叫作正数。正数前面的“+”可以省略，例如 +5 和 5 表示同一个数。

0 既不是正数，也不是负数。−0 与 0 相等，不是一个新的负数。

## 二、先说明零点和正负号的约定

正负数的实际意义取决于比较的基准和方向约定。

| 情境 | 零的基准 | 正数表示 | 负数表示 |
| --- | --- | --- | --- |
| 温度 | 0°C | 零上温度 | 零下温度 |
| 高度 | 海平面 | 海平面以上 | 海平面以下 |
| 位置 | 指定的起点 | 起点以东 | 起点以西 |
| 收支记录 | 不收入也不支出 | 收入 | 支出 |

例如，约定向东为正，某人位于起点以西 5 米，就可以把位置记为 −5 米。

负数不表示“没有意义的数量”，也不总表示“坏”或“少”。它首先表示相对于基准的位置或与约定正方向相反的意义。

## 三、整数包括正整数、零和负整数

把没有分数或小数部分的这些数放在一起：

~~~text
……，−3，−2，−1，0，1，2，3，……
~~~

它们叫作**整数**。

正整数、0 和负整数共同组成整数。−2 是整数，−2.5 不是整数；0 虽然不是正整数或负整数，但仍是整数。

整数向正、负两个方向都可以继续延伸，没有最大的整数，也没有最小的整数。

## 四、建立数轴需要三个约定

在一条直线上表示数，需要明确：

1. 原点：用来表示 0 的点。
2. 正方向：通常规定向右为正。
3. 单位长度：表示数值相差 1 时对应的长度。

这样规定了原点、正方向和单位长度的直线叫作**数轴**。

~~~text
←───●────●────●────●────●────●────●───→
   −3   −2   −1    0    1    2    3
                   ↑
                  原点
~~~

图中相邻整数点之间的间隔相等，每个间隔表示 1 个单位。左右箭头表示数轴向两边继续延伸。

纸上画一个单位长度可以选 1 厘米，也可以选 2 厘米；选定以后，同一幅图中的单位长度必须保持一致。

## 五、用方向和距离确定数的位置

表示 3 时，从原点向右走 3 个单位；表示 −3 时，从原点向左走 3 个单位。

~~~text
−3：从 0 向左 3 个单位。
 3：从 0 向右 3 个单位。
~~~

负数的负号告诉我们点位于原点左侧，而负号后面的数帮助我们确定距离。

如果约定向右为正，就不能把 −3 画在原点右边，也不能让 −3 与 0 的距离比 3 与 0 的距离短。

数轴表示的是数的位置，不是“负数要画得更小”。

## 六、分数和小数也能表示在数轴上

把 −1 到 0、0 到 1 的单位间隔各分成四等份：

~~~text
←──●────●────●────●────●────●────●────●────●──→
  −1  −3/4 −1/2 −1/4  0   1/4  1/2  3/4   1
~~~

−3/4 位于 0 左边，离 0 有 3/4 个单位；1/2 位于 0 右边，离 0 有 1/2 个单位。

由于 −0.75 = −3/4，−0.75 和 −3/4 表示数轴上的同一个点。

数轴上的整数点之间还有许多其他数，不能把数轴理解为只由整数点组成。

## 七、沿数轴向右，数越来越大

在规定向右为正的数轴上，右边的数总比左边的数大。

~~~text
−3 < −2 < −1 < 0 < 1 < 2 < 3
~~~

所以任何负数都小于 0，任何正数都大于 0；正数也一定大于负数。

例如：

~~~text
−100 < 0 < 0.01
−0.001 < 0.001
~~~

一正一负时，不必先比较负号后面的数字大小，就能判断正数较大。

## 八、比较两个负数时要看位置

比较 −2 和 −5：−5 在原点左边 5 个单位，−2 在原点左边 2 个单位。

−2 更靠右，因此：

~~~text
−5 < −2
~~~

两个负数中，离原点更远的数更小。

同样：

~~~text
−1.5 < −0.5
−3/4 < −1/4
~~~

不能把 5 > 2 直接照搬成 −5 > −2。负号改变了数轴上的方向。

## 九、相反数位于原点两侧的对称位置

3 和 −3 到原点的距离相等，但位于原点的不同侧。我们称它们互为**相反数**。

~~~text
3 的相反数是 −3。
−3 的相反数是 3。
0.5 的相反数是 −0.5。
~~~

0 的相反数是 0，因为 −0 = 0。

一个数 a 的相反数可以写成 −a。这里的“−”表示取相反数，不保证结果一定是负数。例如 a = −3 时：

~~~text
−a = −(−3) = 3
~~~

后面的加法章节会进一步解释相反数怎样在运算中互相抵消。

## 十、绝对值表示到原点的距离

数轴上，一个数所表示的点到原点的距离，叫作这个数的**绝对值**。

用两条竖线表示绝对值：

~~~text
|3| = 3
|−3| = 3
~~~

|−3| 读作“负 3 的绝对值”。竖线不是括号，也不是除号，它表示要寻找这个数到原点的距离。

3 和 −3 到原点都相距 3 个单位，所以绝对值相等。

距离不会是负数，因此绝对值总是非负的，也就是大于或等于 0。

## 十一、按数的正负求绝对值

从数轴上的距离可以总结：

~~~text
正数的绝对值是它本身。
0 的绝对值是 0。
负数的绝对值是它的相反数。
~~~

例如：

~~~text
|7| = 7
|0| = 0
|−7| = 7
|−0.25| = 0.25
|−2/3| = 2/3
~~~

只有 0 的绝对值是 0。其他数与原点都有正的距离，所以它们的绝对值都大于 0。

“绝对值总是正数”漏掉了 0；准确的说法是“绝对值总是非负数”。

## 十二、数值大小和绝对值大小不是一回事

比较 −8 和 3：

~~~text
数值大小：−8 < 3
绝对值大小：|−8| = 8 > 3 = |3|
~~~

−8 的位置更靠左，所以数值较小；它离原点更远，所以绝对值较大。

两种比较回答的问题不同：

| 比较对象 | 回答的问题 | 数轴上的依据 |
| --- | --- | --- |
| 数值 | 哪个数更大？ | 哪个点更靠右？ |
| 绝对值 | 哪个数离零更远？ | 哪个点到原点的距离更大？ |

因此，绝对值较大不能直接推出原数较大。

## 十三、演示：比较气温与离零的程度

甲地气温为 −6°C，乙地气温为 −2°C。

比较温度高低，要比较数值：

~~~text
−6 < −2
~~~

因此乙地温度更高。

比较离 0°C 的程度，要比较绝对值：

~~~text
|−6| = 6
|−2| = 2
~~~

甲地气温离 0°C 更远，零下程度更大。不能因为 6 比 2 大，就说 −6°C 比 −2°C 温度高。

## 十四、演示：位置带方向，距离不带方向

在一条东西方向的直路上，选车站作为起点，向东为正。小林位于车站以西 4 米，小安位于车站以东 4 米。

~~~text
小林的位置：−4 米
小安的位置：+4 米
~~~

两人的位置互为相反数，但到车站的距离相同：

~~~text
小林到车站：|−4| = 4（米）
小安到车站：|4| = 4（米）
~~~

这不表示两个人在同一位置。绝对值保留距离，却不保留在起点哪一侧的信息。

两人之间沿直路的距离是 4 + 4 = 8 米。|−4| 表示小林到原点的距离，不是小林到小安的距离。

## 十五、演示：从绝对值反过来寻找数

如果一个数的绝对值是 5，就表示它到原点的距离为 5 个单位。

原点左右两侧各有一个符合条件的点：

~~~text
|5| = 5
|−5| = 5
~~~

所以这个数可能是 5，也可能是 −5。

如果又知道它是负数，就只能是 −5；如果知道它是正数，就只能是 5。

绝对值是 0 时只有一个可能，就是 0。绝对值不可能是 −5，因为距离不能为负数。

## 十六、小结

正负数可以表示相对于基准的不同位置或相反意义的数量。使用它们时，要先说明零点和正方向的约定。

数轴有原点、正方向和单位长度。在向右为正的数轴上，越靠右的数越大；负数小于 0，正数大于 0。

互为相反数的两个数到原点距离相等、方向相反；0 的相反数仍是 0。

绝对值表示到原点的距离，总是非负数。正数的绝对值是本身，负数的绝对值是相反数，0 的绝对值是 0。

比较数值时看左右位置，比较绝对值时看离零的距离。分清位置与距离，才能准确理解负数和绝对值。
