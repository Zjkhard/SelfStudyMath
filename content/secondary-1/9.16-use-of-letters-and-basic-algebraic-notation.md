# 9.16 用字母表示数与基本代数记号

每本练习本售价 3 元。买 2 本、5 本或 8 本，总价分别是：

~~~text
3 × 2 = 6（元）
3 × 5 = 15（元）
3 × 8 = 24（元）
~~~

本数虽然改变，“每本单价乘本数”的关系没有改变。

如果用 n 表示购买的本数，总价就可以统一写成 3 × n，通常简写为 3n 元。字母让我们不用为每个本数另写一条关系。

## 一、字母可以表示数

在数学中，a、b、x、y、n 等字母常用来表示数。

例如用 n 表示本数，n 可以取 2、5、8 等不同的值；用 x 表示一条线段的长度数值，x 也可以是 1.5 等非整数。

字母本身不是某个物体的名称，而是在已经说明的情境中表示一个数或数量的数值。

写“3n”前，要先说明 n 表示什么。没有这个说明，别人无法判断它表示总价、总长度还是其他数量。

## 二、变量与常数要结合问题理解

在练习本情境中，本数 n 可以改变，叫作**变量**；单价 3 固定不变，是这个关系中的**常数**。

~~~text
总价：3n 元
变量：n
固定单价：3 元/本
~~~

字母不一定总是变量。也可以用字母 a 表示某个已经固定的单价，在只改变本数时，a 就作为固定参数使用。

判断变量与常数，要看当前问题中什么会变化，不能只凭“字母”或“数字”的外观判断。

## 三、字母也可以表示未知数

如果总价已知为 15 元，而本数未知，可以用 n 表示要找的本数：

~~~text
3n = 15
~~~

此时 n 是**未知数**，我们要找出满足等式的值。因为 3 × 5 = 15，所以 n = 5。

同一个字母，在一个关系中可以表示变化的数，在一个具体方程中又可以表示待求的数。

字母没有固定的“身份”，它的作用由问题和表达式决定。

## 四、代数式表示数或运算关系

用数字、字母和运算符号组成、表示数值的式子，叫作**代数式**。

~~~text
3n
x + 5
2a − b
(p + q)/2
~~~

例如 x + 5 表示“比 x 多 5 的数”。x 的值确定后，这个式子的值也随之确定。

代数式不要求带等号。3n 是一个式子，3n = 15 则是说明两个式子相等的等式；其中含有待求数时，可以作为方程。

读写时要分清“表示一个数量”和“说明两个数量相等”。

## 五、数字与字母相乘通常省略乘号

数字与字母相乘，通常把数字写在字母前面，并省略乘号：

~~~text
3 × x = 3x
x × 5 = 5x
0.4 × a = 0.4a
~~~

3x 读作“3 乘 x”或“x 的 3 倍”，不是三位数，也不是 3 + x。

两个普通数字相乘，不能这样省略：

~~~text
3 × 5 = 15
~~~

不能把 3 × 5 写成 35，因为 35 已经表示三十五。

## 六、字母与字母相乘也可以简写

在本课程的普通代数记号中：

~~~text
a × b = ab
2 × a × b = 2ab
~~~

ab 表示 a 与 b 的乘积，不表示 a + b，也不是一个按十位、个位拼出的两位数。

数字因数通常放在前面，字母常按字母顺序排列。例如 b × 3 × a 通常整理为 3ab。

整理时依据乘法交换律，数值不变。若两个字母分别表示不同数量，它们各自的含义也不改变。

## 七、乘以整个括号时可以省略乘号

~~~text
4 × (x + 2) = 4(x + 2)
a × (b − c) = a(b − c)
~~~

4(x + 2) 表示“x 与 2 的和的 4 倍”，整个括号都是乘法的一个因数。

比较：

~~~text
4(x + 2)
4x + 2
~~~

如果 x = 3，前一式为 4 × 5 = 20，后一式为 12 + 2 = 14，所以它们不同。

省略乘号没有省略乘法，也没有改变括号范围。

## 八、乘以 1 与 −1 的写法

一个数乘以 1 仍是本身，因此：

~~~text
1 × x = 1x = x
~~~

乘以 −1 得到相反数：

~~~text
(−1) × x = −x
~~~

所以 x 中省略的数字因数是 1，−x 中省略的数字因数是 −1。

−x 表示 x 的相反数，不保证结果为负。例如 x = −4 时，−x = 4。

## 九、简单字母项中的数字因数叫系数

在 5x、−3a、0.2b 这样的简单项中，数字因数叫作字母部分的**系数**。

~~~text
5x：系数是 5。
−3a：系数是 −3。
x：系数是 1。
−x：系数是 −1。
~~~

系数说明字母所表示的数被乘了多少倍，负号是系数的一部分。

系数也可以是分数。例如 (2/3)x 表示 x 的三分之二，系数是 2/3。后面学习同类项时，会进一步使用这个概念。

## 十、除法通常用分数线表示

~~~text
x ÷ 3 = x/3
a ÷ b = a/b（b ≠ 0）
~~~

x/3 表示 x 的三分之一，也可以写成 (1/3)x。

分子或分母含有多个部分时，要明确它们是整体。用斜线书写时，可以加括号：

~~~text
(x + 2)/3：x 与 2 的和除以 3。
x/(y + 1)：x 除以 y 与 1 的和。
~~~

第二式要求 y + 1 不为 0，也就是 y 不能取 −1。字母作分母时，同样遵守不能除以 0 的限制。

## 十一、平方与立方也可以用于字母

相同字母重复相乘，可以用指数记法：

~~~text
x × x = x²
a × a × a = a³
~~~

x² 表示 x 的平方，不表示 2x。2x 表示两个 x 相加，即 x 的 2 倍。

如果 x = 3：

~~~text
x² = 3² = 9
2x = 2 × 3 = 6
~~~

这一节先辨认基本含义。下一节会进一步整理代数中的指数与作用范围。

## 十二、同一字母在同一表达中表示同一个数

观察 x + x。两个 x 都表示同一个数，因此它表示这个数的两倍：

~~~text
x + x = 2x
~~~

不能把第一个 x 取成 3，第二个 x 又取成 5，除非已经改变了问题的表示方式。

不同字母可以表示不同数，也可能恰好取相同值。例如 a = 4、b = 4 并不矛盾；写成不同字母，不代表它们必然不相等。

保持字母含义一致，是读懂数量关系的基础。

## 十三、字母的取值范围由条件决定

没有额外限制的基本实数代数式，可以让字母取实数值；但实际问题或运算条件常会缩小这个范围。

~~~text
购买本数 n：通常取非负整数。
正方形边长 x：必须为正数。
分母 b：不能为 0。
~~~

如果讨论至少买一本，则 n 还要大于或等于 1；如果允许不购买，则 n 可以为 0。

不能因为字母“可以表示数”，就把任何数都代入任何情境。例如购买 −2 本或 1.5 本完整练习本，不符合这里的条件。

## 十四、演示：表示总价并检查单位

每本练习本 3 元，另付固定包装费 2 元。用 n 表示购买的本数，总费用为：

~~~text
练习本费用：3n 元
包装费用：2 元
总费用：(3n + 2) 元
~~~

买 4 本时：

~~~text
3 × 4 + 2 = 14（元）
~~~

这与“12 元练习本费用加 2 元包装费”一致。

不能写成 3(n + 2)，因为那相当于把固定的 2 元也乘以 3。列式要依据关系，而不是把出现的数字随意放进括号。

## 十五、演示：用字母统一表示长方形周长

用 l 和 w 分别表示长方形长、宽的数值，长度单位统一为厘米。

两条长边与两条宽边相加：

~~~text
周长 = l + w + l + w
     = 2l + 2w
     = 2(l + w)
~~~

周长单位为厘米。l 与 w 都应为正数，而且必须使用同一种长度单位。

例如 l = 5、w = 3：

~~~text
2(l + w) = 2 × (5 + 3) = 16
~~~

周长是 16 厘米。字母表达式能保留适用于不同长方形的共同关系，而代入数值能检查我们是否正确理解了记号。

## 十六、小结

字母可以表示变化的数、固定但未指定的数，或待求的数。使用前要说明含义、取值条件和必要的单位。

数字与字母、字母与字母、因数与括号相乘时，通常可以省略乘号。数字因数一般写在前面，但两个普通数字相乘不能直接拼写在一起。

−x 表示相反数，x/3 表示除以 3，x² 表示平方。括号与分数线限定整体范围，省略乘号不会改变运算关系。

同一表达中，同一字母表示同一个数。代数式表示数值或关系，等式则说明两边相等；通过简单代入，可以检查表达式是否符合原来的数量意义。
