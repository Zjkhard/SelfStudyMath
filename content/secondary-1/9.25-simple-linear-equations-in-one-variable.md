# 9.25 简单一元一次方程

每本练习本售价 3 元，另付一次包装费 2 元。总费用是 17 元，购买本数未知。

用 x 表示本数，就有：

~~~text
3x + 2 = 17
~~~

左边表示按单价和本数计算的费用，右边表示已知总费用。两者相等，让我们能够反过来寻找 x。

这一节重点学习怎样保持等式成立，逐步把未知数单独留在一边。

## 一、方程与方程的解

含有未知数的等式叫作**方程**。

例如 x + 4 = 9 是方程，x + 4 只是代数式，而 5 + 4 = 9 是不含未知数的等式。

使方程两边的值相等的未知数取值，叫作方程的**解**。

~~~text
x = 5 时，x + 4 = 5 + 4 = 9。
所以 5 是方程 x + 4 = 9 的解。
~~~

寻找解的过程叫作解方程。写出 x = 5，是明确说明未知数的值，而不只是报告一个没有含义的数字。

## 二、一元一次是什么意思

“一元”表示只有一个未知数；“一次”表示整理后未知数的最高次数为 1。

本节的一元一次方程可以通过等价整理写成：

~~~text
ax + b = 0，其中 a ≠ 0。
~~~

a、b 是已知常数，x 是未知数。非零系数 a 保证未知数的一次项确实存在。

~~~text
3x + 2 = 17：一元一次方程。
2x − 5 = x + 4：一元一次方程。
x² = 9：不是一次方程。
x + y = 9：含两个未知数，不是一元方程。
~~~

字母在等式中出现几次，不决定“几元”。2x − 5 = x + 4 虽然两边都有 x，仍只有一个未知数。

## 三、等式两边同时加减同一个数

如果两个数量相等，两边同时增加相同数量或减少相同数量，仍然相等。

~~~text
若 A = B，则 A + c = B + c。
若 A = B，则 A − c = B − c。
~~~

这里 A、B 可以表示整个式子的值，c 表示两边同时加上或减去的同一个数。

例如解 x + 4 = 9，两边同时减去 4：

~~~text
x + 4 = 9
x + 4 − 4 = 9 − 4
x = 5
~~~

未知数不是因为“走过等号”而自动变号。实际依据是两边进行了相同的减法。

## 四、等式两边同时乘除同一个非零数

等式两边同时乘以或除以同一个非零数，可以保持等式，并且操作可以反向恢复。

解 3x = 15，两边同时除以 3：

~~~text
3x = 15
3x ÷ 3 = 15 ÷ 3
x = 5
~~~

不能除以 0。两边同时乘以 0 虽然会得到 0 = 0，但会丢失原方程的信息，所以不能用它作保留原解的等价求解步骤。

解方程不仅要求新等式正确，还要求变形前后的解保持一致。

## 五、一步加减方程

解 x − 7 = −2，两边同时加上 7：

~~~text
x − 7 = −2
x − 7 + 7 = −2 + 7
x = 5
~~~

解 x + 6 = −4，两边同时减去 6：

~~~text
x + 6 = −4
x = −4 − 6
x = −10
~~~

方程的解可以是负数。是否符合实际情境，还需要另看字母表示的数量和取值条件。

## 六、未知数被减去时注意它的系数

解 8 − x = 3。未知数项 −x 的系数是 −1。

~~~text
8 − x = 3
−x = 3 − 8
−x = −5
x = 5
~~~

第一步两边减去 8，最后一步两边除以 −1。

不能看到 −x = −5 就写成 x = −5，左边的负号也是需要处理的系数。

## 七、负数系数的方程

解 −4x = 12：

~~~text
−4x = 12
x = 12 ÷ (−4)
x = −3
~~~

异号相除，解为负数。

检验：(−4) × (−3) = 12，确实满足原方程。

不能只把系数的负号删掉，再除以 4。两边都必须除以完整的系数 −4。

## 八、两步方程先消去常数项

解 3x + 2 = 17：

~~~text
3x + 2 = 17
3x = 17 − 2
3x = 15
x = 15 ÷ 3
x = 5
~~~

先两边减去 2，再两边除以 3，把未知数逐步单独留下。

原来的数量过程是“乘以 3，再加 2”；反向寻找时，可以“先减去 2，再除以 3”。

如果先除以 3 也可以，但必须把等式两边的整个式子都除以 3，不能只处理某一个项。

## 九、两边都有未知数时合并到一边

解 5x + 2 = 2x + 14，先两边同时减去 2x：

~~~text
5x + 2 = 2x + 14
3x + 2 = 14
3x = 12
x = 4
~~~

把未知数项集中到左边，常数集中到右边，得到容易求解的乘法关系。

检验：左边 5 × 4 + 2 = 22，右边 2 × 4 + 14 = 22，两边相等。

也可以把未知数项集中到右边，得到相同的解。选择较方便的一边，不改变等式性质。

## 十、同一边有同类项时先化简

解 3x + 2x − 4 = 11：

~~~text
3x + 2x − 4 = 11
5x − 4 = 11
5x = 15
x = 3
~~~

第一步是在等式左边把表达式改写成等值形式，后面的步骤再利用等式两边同时运算。

化简与解方程可以配合：化简整理式子，解方程寻找满足等式的未知数值。

## 十一、小数系数与非整数解

解 0.5x + 1 = 3.5：

~~~text
0.5x + 1 = 3.5
0.5x = 2.5
x = 2.5 ÷ 0.5
x = 5
~~~

再看 2x = 5：

~~~text
x = 5/2 = 2.5
~~~

一元一次方程的解不一定是整数。求解时保留准确的分数或有限小数，不应随意取整。

更复杂的分数形式方程，后面的章节会专门讲解。

## 十二、不要把所有“跨等号”都理解为变号

由 x + 4 = 9 得到 x = 9 − 4，可以把这种整理简称为移项，但依据仍是两边同时减去 4。

由 3x = 15 得到 x = 15/3，则是两边除以 3，不是把 3 改成 −3。

加减关系与乘除关系的逆运算不同。只记“到另一边变号”，容易把乘法系数错误处理成加减项。

不确定某一步时，把两边同时进行的运算写出来，就能看清依据。

## 十三、验根要代回原方程

解 7 − 2x = 13：

~~~text
7 − 2x = 13
−2x = 6
x = −3
~~~

代回原方程：

~~~text
左边 = 7 − 2 × (−3) = 7 + 6 = 13
右边 = 13
~~~

两边相等，所以 −3 是原方程的解。

只代回中间某一步，可能漏掉更早发生的错误。验根应针对原方程，而不是只检查最后的乘除法。

## 十四、未知数抵消后的两种特殊情况

观察 2x + 3 = 2x + 7，两边减去 2x 后得到：

~~~text
3 = 7
~~~

这是不成立的等式，所以没有任何实数 x 能满足原方程。

再看 2x + 3 = 2x + 3，整理后得到 3 = 3。它恒成立，所有实数 x 都满足。

这两种式子看起来都有一次项，但整理后未知数系数为 0，不属于能写成 ax + b = 0 且 a ≠ 0 的一元一次方程。

真正的一元一次方程在实数范围内有唯一解。遇到未知数完全抵消时，要检查剩余等式，而不是尝试除以 0。

## 十五、演示：解释方程解的实际意义

回到开头的购物情境：每本 3 元，包装费 2 元，总费用 17 元。

~~~text
3x + 2 = 17
3x = 15
x = 5
~~~

这里 x 表示本数，所以答案是买了 5 本。

检验费用：3 × 5 + 2 = 17 元；检验取值条件：5 是正整数，适合作为完整练习本的数量。

如果数学运算得到负数或非整数的本数，就要检查情境是否可行、数据或列式是否有误，不能直接把不合条件的解当作实际答案。

本节用这个情境解释求解的意义；后面会进一步学习怎样从实际问题建立方程。

## 十六、小结

方程的解，是使原方程两边相等的未知数取值。一元一次方程只有一个未知数，整理后能写成 ax + b = 0，且 a 不为 0。

求解依据等式性质：两边同时加减同一个数，或同时乘除同一个非零数。目标是把未知数单独留在一边，并保持解不变。

可以先化简同类项，再集中未知数项与常数项，最后除以未知数系数。负系数要连同负号一起处理。

求出值后代回原方程验根；在实际情境中，还要说明单位与含义，并检查取值条件。未知数抵消时，另行判断剩余等式是否成立。
