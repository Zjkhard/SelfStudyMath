# 9.29 含有理数的比与化简

调配一杯饮料，使用 0.75 升果汁和 0.5 升水。果汁与水的体积比是：

~~~text
0.75 : 0.5
~~~

把每 0.25 升看作一份，果汁有 3 份，水有 2 份，所以同一个关系可以写成 3 : 2。

比的两项不一定是整数。分数、小数都可以参与比较；化简帮助我们用更清楚的份数表达同一个倍数关系。

## 一、比比较两个数量的相对大小

a : b 读作“a 比 b”。a 是比的前项，b 是比的后项。

当 b 不为 0 时，比值为：

~~~text
a ÷ b = a/b
~~~

例如 6 : 4 的比值是 6/4 = 3/2，表示前项是后项的 1.5 倍。

比强调两个数量按顺序对应的关系，比值用一个数表达这个倍数关系。3 : 2 与 3/2 有联系，但写法和表达重点不同。

## 二、比的顺序不能交换

果汁与水的比是 3 : 2，水与果汁的比就是 2 : 3。

~~~text
果汁 : 水 = 3 : 2
水 : 果汁 = 2 : 3
~~~

前一种比值为 3/2，后一种为 2/3。交换顺序通常会改变比值。

写比之前，先说明“谁与谁比”。不能在化简过程中把前项和后项交换。

## 三、同类数量的比先统一单位

比较 1.5 米彩带与 60 厘米彩带的长度，不能直接把 1.5 : 60 当作统一单位后的长度比。

先换算：

~~~text
1.5 米 = 150 厘米
长度比 = 150 : 60 = 5 : 2
~~~

也可以把 60 厘米换成 0.6 米，得到 1.5 : 0.6，化简结果仍为 5 : 2。

同类数量用相同单位比较后，比值不带该计量单位。不同种类数量的比较常表示带单位的率，后面的章节会进一步学习。

## 四、等值比来自同时乘除相同的数

看 6 : 4，同时除以 2：

~~~text
6 : 4 = 3 : 2
~~~

两个比的比值都为 3/2，所以表达同一个相对关系，叫作等值比。

一般地，当后项 b 不为 0，且 k 不为 0 时：

~~~text
a : b = ka : kb
~~~

因为 (ka)/(kb) = a/b。两项同时乘或除以同一个非零数，比值不变。

不能只改变一项，也不能一般地把两项同时加上相同数。例如 3 : 2 的比值为 1.5，而 4 : 3 的比值为 4/3，已经不同。

## 五、最简整数比的含义

对于两项为正有理数的比，可以化成两项都是正整数、且互质的形式，叫作最简整数比。

例如：

~~~text
18 : 24
= (18 ÷ 6) : (24 ÷ 6)
= 3 : 4
~~~

18 与 24 的最大公因数是 6，3 与 4 已经互质，所以不能再共同除以大于 1 的整数。

6 : 8 与 3 : 4 等值，但还不是最简整数比。这里“最简”不要求两项都是质数，例如 8 : 9 已经最简。

## 六、分数比先消去分母

化简 2/3 : 5/6。分母 3 和 6 的最小公倍数是 6，两项同时乘以 6：

~~~text
2/3 : 5/6
= (2/3 × 6) : (5/6 × 6)
= 4 : 5
~~~

4 和 5 互质，结果为最简整数比。

乘数作用于比的两项，不是把分子直接比较成 2 : 5。分母不同，每份大小不同，必须先保持原来的数值关系。

## 七、消去分母后还要检查能否约简

化简 3/4 : 5/8，两项同时乘以 8：

~~~text
3/4 : 5/8 = 6 : 5
~~~

这已经最简。

再看 3/4 : 9/10，选择公倍数 20：

~~~text
3/4 : 9/10
= 15 : 18
= 5 : 6
~~~

去掉分母只是得到整数比，还需要把整数两项的共同因数约去。

## 八、小数比同时放大为整数比

化简 0.75 : 0.5，先把两项同时乘以 100：

~~~text
0.75 : 0.5
= 75 : 50
= 3 : 2
~~~

0.5 = 0.50，所以两项都乘以 100 后，第二项为 50，不是 5。

再看：

~~~text
1.2 : 0.045
= 1200 : 45
= 80 : 3
~~~

两项同时乘以 1000，足以让它们都变成整数，再除以最大公因数 15。

不能让第一项乘以 10、第二项乘以 1000，那会改变原比值。

## 九、混合写法先选择准确的统一表示

化简 0.6 : 3/4，把 0.6 写成 3/5：

~~~text
0.6 : 3/4
= 3/5 : 3/4
= 12 : 15
= 4 : 5
~~~

也可以把 3/4 写成 0.75，再化简 0.6 : 0.75，结果相同。

带分数先化成假分数：

~~~text
1 又 1/2 : 3/4
= 3/2 : 3/4
= 6 : 3
= 2 : 1
~~~

尽量使用准确表示，不要先把循环小数分数截短，再化简一个已经改变数值的比。

## 十、演示：循环小数比保留分数更方便

化简 1/3 : 0.2，0.2 = 1/5：

~~~text
1/3 : 0.2
= 1/3 : 1/5
= 5 : 3
~~~

两项同时乘以 15，得到最简整数比。

如果把 1/3 近似成 0.33，则 0.33 : 0.2 化为 33 : 20，不等于准确的 5 : 3。

原比的准确关系不能用近似值随意替换。若只能得到近似数据，应明确结果也只是近似比较。

## 十一、可以用比值检查化简

例如 0.6 : 3/4 化简为 4 : 5，检查：

~~~text
原比值 = (3/5) ÷ (3/4) = 4/5
结果比值 = 4 ÷ 5 = 4/5
~~~

比值相同，说明两比等值；再检查 4 和 5 互质，说明结果最简。

也可以检查两项是否确实乘除相同的数。等值与最简是两个条件，不能只检查其中一个。

## 十二、最简比表示份数，不是原来的实际数量

果汁 0.75 升、水 0.5 升，化简为 3 : 2，表示相同大小的份数关系。

~~~text
每份：0.25 升
果汁：3 份，共 0.75 升
水：2 份，共 0.5 升
~~~

它不表示原来有 3 升果汁与 2 升水。若另一次调配用 3 升果汁和 2 升水，也满足同一个比，但总量不同。

所以单独知道比，通常不能确定两项的实际数量，还需要总量、一项数量或其他条件。

## 十三、部分比与整体比要分清

果汁与水为 3 : 2，共有 5 份。于是：

~~~text
果汁 : 水 = 3 : 2
果汁 : 总量 = 3 : 5
水 : 总量 = 2 : 5
~~~

果汁占总量的 3/5，而不是 3/2。3/2 是果汁与水的比值，不是果汁占全部饮料的比例。

这里假设混合后的体积等于两部分体积之和，作为本节的简单数量模型。

## 十四、零与负数需要明确约定

本节的实际分配和份数比较主要使用正数量。若前项为 0、后项非零，例如 0 : 5，比值为 0，可以化为 0 : 1。

若后项为 0，a/0 没有定义，所以本节不把 a : 0 作为具有比值的比来运算。

纯数学中，也可以讨论后项非零的带符号比。例如：

~~~text
(−3/4) : (1/2) = −3 : 2
~~~

比值为 −3/2，表明两项符号不同，不适合直接解释为正的物品份数。

对于 (−3) : (−2)，同时乘以 −1 可写成 3 : 2，两者比值相同。但在带方向的实际记录中，还需要保留原数量的方向信息，不能把化简后的正份数误当作原数量变为正。

## 十五、演示：不同单位与分数数量一起处理

两段彩带分别长 3/4 米和 45 厘米，求第一段与第二段的最简长度比。

先统一成厘米：

~~~text
3/4 米 = 75 厘米
长度比 = 75 : 45
       = 5 : 3
~~~

第一段长度是第二段的 5/3 倍。最简比 5 : 3 只说明相对长度，并不把两段长度改成 5 厘米和 3 厘米。

检查：75 ÷ 45 = 5/3，与结果比值一致；5 与 3 互质，化简完成。

## 十六、小结

比按顺序比较两个数量，后项非零时，比值为前项除以后项。同类数量先统一计量单位。

比的两项同时乘除同一个非零数，比值不变。正有理数的比可以化为两项互质的正整数比。

分数比先同乘公分母，小数比先同倍放大，混合写法选择方便的准确表示。得到整数比后，还要检查能否约简。

最简比表示相同大小的份数，不是实际数量本身。部分与部分的比、部分与整体的比，以及带符号数的比较，都应说明各项对应什么。
