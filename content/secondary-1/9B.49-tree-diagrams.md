# 9B.49 树状图

当一个随机试验分成几个步骤时，可以用树状图逐步展开每种可能选择。每一个分支表示某一步的一种结果；从起点沿树枝走到末端的一条完整路径，表示一次完整试验结果。

树状图尤其适合展示多个步骤，或后续选项会因前面结果而改变的情形。

## 一、树状图的基本结构

树状图从一个起点出发，第一步的每种可能结果画成一条分支。每个分支末端再画出下一步所有可能结果，依此展开。

~~~text
起点
 ├─ 第一步结果 1
 │   ├─ 第二步结果 a
 │   └─ 第二步结果 b
 └─ 第一步结果 2
     ├─ 第二步结果 a
     └─ 第二步结果 b
~~~

树枝表示步骤中的选项，完整路径才表示整个试验结果。不要把某一层的单个分支误认为完整结果。

## 二、两次掷硬币

掷一枚硬币两次，每次可能为正面 H 或反面 T：

~~~text
第一次
├─ H
│  ├─ 第二次 H  → HH
│  └─ 第二次 T  → HT
└─ T
   ├─ 第二次 H  → TH
   └─ 第二次 T  → TT
~~~

样本空间是 `{HH, HT, TH, TT}`，共有 4 条完整路径。`HT` 与 `TH` 不同，因为它们对应的先后次序不同。

## 三、沿路径读取结果

读树状图时从起点开始，每经过一层就记录该步骤的结果，直到末端。这样得到完整有序结果。

例如沿着“第一次 T，第二次 H”的路径，到达末端结果 `TH`。如果只写 T，就只记录了第一步，尚未形成完整试验结果。

## 四、用树状图定义事件

在两次掷硬币的树状图中，事件 A 为“恰有一次正面”。符合条件的末端路径为：

~~~text
HT，TH
~~~

因此事件 A = `{HT, TH}`，包含 2 个结果。事件 B 为“至少出现一次正面”，末端路径为 `HH、HT、TH`，包含 3 个结果。

筛选事件时要检查完整路径是否满足条件，而不是只看某一步。

## 五、列举所有结果并检查

绘制树状图后，可以从左到右或按深度顺序列出所有末端路径，再检查是否漏项或重复。

~~~text
两次硬币：HH，HT，TH，TT
每个结果包含两个步骤
共有四条完整路径
~~~

如果树有两层却只列出两位结果中的一个，就可能漏掉另一种顺序；如果同一条路径被写两次，则发生重复计数。

## 六、选择上衣和裤子

一人有两件上衣（蓝、白）和三条裤子（黑、灰、棕），穿搭由先选上衣再选裤子组成：

~~~text
上衣
├─ 蓝
│  ├─ 黑裤 → 蓝黑
│  ├─ 灰裤 → 蓝灰
│  └─ 棕裤 → 蓝棕
└─ 白
   ├─ 黑裤 → 白黑
   ├─ 灰裤 → 白灰
   └─ 棕裤 → 白棕
~~~

共有六种搭配。树状图表示每种组合，不表示这些搭配在实际生活中的发生概率相同。

## 七、分支数不同时

并不是每个节点都必须有相同数量的分支。例如从盒子里先抽一张卡片，若不放回，再抽第二张，第二步可抽到的卡片会受第一步影响。

~~~text
卡片为红、蓝两张；不放回抽两次
第一次红 → 第二次只能蓝
第一次蓝 → 第二次只能红
~~~

此时树的不同节点可以有不同分支数。按条件准确画出可发生的分支，不能机械复制同一组选择。

## 八、放回与不放回的区别

抽取后放回，下一步的可选对象通常与前一步前相同；不放回，下一步可选对象会减少。树状图能把这种变化表现出来。

画图前要读清题目中的“放回”“不放回”或其他限制条件。若条件改变，完整路径集合也会改变。

## 九、树状图与可能性图表

可能性图表用行列交叉表示两个步骤的组合；树状图则按步骤先后逐层展开。两者可以表示相同的样本空间。

~~~text
结果组合规整、两个步骤选项固定：表格通常简洁
步骤连续、分支会变化：树状图通常更直观
~~~

选择更容易核查完整结果的表示方法即可。

## 十、路径数与结果总数

树状图中每条末端路径对应一个完整结果。数末端路径即可得到样本空间中的结果总数。

若每个节点的分支数相同，可以用分支数辅助检查。例如两次掷硬币，每层有 2 个分支，总末端路径为 2 × 2 = 4。若分支数不同，则逐层数路径，不能直接套用同一个乘数。

## 十一、等可能性不是由树形决定

树枝画得等长或排列整齐，并不表示相应结果等可能。若每次掷的是公平硬币，分支结果有相同机会；若装置有偏，或不同分支概率不相同，完整路径的机会也可能不相同。

树状图首先是列举结果的工具。要用结果条数计算概率，还需要确认所有完整结果等可能。

## 十二、路径标记与事件计数

可以在符合事件条件的路径末端做记号，再数出有利路径数。例如两次掷硬币，“第二次为正面”的有利路径是 `HH` 和 `TH`，共两条。

若已知样本空间结果等可能，可以进一步用有利路径数除以总路径数求概率。若不等可能，仅靠路径条数不足以计算概率；具体的多步概率方法将在后续内容中学习。

## 十三、绘制树状图的步骤

1. 明确试验分几步，并按发生顺序排列；
2. 从起点画出第一步所有可能结果；
3. 从每个分支末端继续展开下一步的可能结果；
4. 按题目限制排除不能发生的分支；
5. 逐条读取末端路径，写出完整结果；
6. 检查结果是否完整、清楚且没有重复。

## 十四、常见错误

- 漏画某个步骤的可能分支，导致样本空间不完整。
- 把中途的分支当成完整结果，少记录后续步骤。
- 忽略结果次序，错误合并不同路径。
- 在不放回抽取中仍画出不可能的后续分支。
- 看到路径数量相同或图形对称，就认为完整结果等可能。
- 只数符合条件的单步选项，没有筛选完整路径。

## 十五、回顾

树状图按试验步骤逐层展开。每条分支表示一步的结果，从起点到末端的一条完整路径表示一种完整结果。事件可由满足条件的末端路径组成。

树状图帮助系统列举、读取和计数复合结果；结果条数只有在完整结果等可能时才能直接用于概率计算。画图时要忠实反映试验顺序和限制条件，并检查路径是否完整。
