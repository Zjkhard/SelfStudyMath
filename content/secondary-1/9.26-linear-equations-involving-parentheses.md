# 9.26 含括号的一元一次方程

有 3 个相同礼袋，每袋装 x 支铅笔和 2 支彩笔，合计装了 21 支笔。

先数每袋总支数，再乘礼袋个数：

~~~text
3(x + 2) = 21
~~~

括号说明 x 与 2 的和是一个整体。求解时，既可以先算每袋有多少支，也可以先展开括号，把铅笔和彩笔分别计算。

## 一、括号改变求解的结构，不改变等式性质

上一节使用的等式性质仍然适用：两边同时加减同一个数，或同时乘除同一个非零数，保持解不变。

含括号时，还可以先用分配律把一边的式子改写成等值形式。

~~~text
3(x + 2) = 3x + 6
~~~

所以 3(x + 2) = 21 与 3x + 6 = 21 有相同的解。

展开是改写表达式；两边同时运算是使用等式性质。两种操作可以配合，但依据不同。

## 二、基本流程：展开、合并、求解、检验

含括号的一元一次方程，常用流程是：

1. 看清括号层次和外面的系数。
2. 用分配律展开或逐层去括号。
3. 分别合并两边的同类项。
4. 利用等式性质集中未知数项与常数项。
5. 除以非零系数，求出未知数。
6. 把解代回原方程检验。

每一步都保留原来的等式关系，不能在计算一边时漏掉另一边。

## 三、演示：正系数乘括号

解 3(x + 2) = 21：

~~~text
3(x + 2) = 21
3x + 6 = 21
3x = 15
x = 5
~~~

3 要乘括号里的每一项。不能写成 3x + 2 = 21，那遗漏了彩笔数量的三倍。

验根：3(5 + 2) = 3 × 7 = 21，原方程成立。

在礼袋情境中，每袋有 5 支铅笔，另有 2 支彩笔，3 袋合计 21 支。

## 四、有时先除以外面的系数更方便

同一个方程也可以两边先除以 3：

~~~text
3(x + 2) = 21
x + 2 = 7
x = 5
~~~

这相当于先求每袋总支数，再减去每袋的 2 支彩笔。

两种方法都正确，不必规定含括号就一定先展开。选择方法时，观察整个一边是否是一个方便处理的乘积。

如果左边是 3(x + 2) + 6，则不能只把第一部分除以 3，而把额外的 6 留着不动。

## 五、负系数展开时每项都乘负数

解 −2(x − 3) = 10：

~~~text
−2(x − 3) = 10
−2x + 6 = 10
−2x = 4
x = −2
~~~

−2 乘 −3 得到 +6。负号与数字 2 共同组成外面的系数。

验根：−2[−2 − 3] = −2 × (−5) = 10。

也可以先两边除以 −2，得到 x − 3 = −5，再求出 x = −2。

## 六、减去括号，里面每项都取相反数

解 7 − (2x − 3) = 4：

~~~text
7 − (2x − 3) = 4
7 − 2x + 3 = 4
10 − 2x = 4
−2x = −6
x = 3
~~~

括号前的减号作用于整个 2x − 3，去括号后成为 −2x + 3。

验根：7 − (6 − 3) = 7 − 3 = 4。

不能只改变 2x 的符号，而把 −3 仍写成 −3。

## 七、一边有多个括号时分别处理

解 2(x + 4) − 3(x − 1) = 7：

~~~text
2(x + 4) − 3(x − 1) = 7
2x + 8 − 3x + 3 = 7
−x + 11 = 7
−x = −4
x = 4
~~~

第二个乘积前的减号可与 3 合成系数 −3，再分配给 x 和 −1。

验根：2 × 8 − 3 × 3 = 16 − 9 = 7。

每个括号单独展开后，再合并同类项，能减少符号混乱。

## 八、两边都有括号时分别化简两边

解 3(x − 2) + 4 = 2(x + 1)：

~~~text
3(x − 2) + 4 = 2(x + 1)
3x − 6 + 4 = 2x + 2
3x − 2 = 2x + 2
x − 2 = 2
x = 4
~~~

第四行两边同时减去 2x，最后两边同时加上 2。

验根：左边 3(4 − 2) + 4 = 10，右边 2(4 + 1) = 10。

先分别整理左右两边，再集中未知数项，通常比展开过程中同时移动许多项更清楚。

## 九、嵌套括号从最内层开始

解 2[3x − (x − 4)] = 20：

~~~text
2[3x − (x − 4)] = 20
2(3x − x + 4) = 20
2(2x + 4) = 20
4x + 8 = 20
4x = 12
x = 3
~~~

内层括号去掉后，−(x − 4) 变为 −x + 4；外面的系数 2 暂时保持不变。

验根：2[9 − (3 − 4)] = 2[9 − (−1)] = 20。

括号的形状帮助辨认层次，先处理哪一层由内外位置决定。

## 十、括号中的和可以先作为整体保留

解 5 − 2(x + 1) = −9，也可以不立即展开。

~~~text
5 − 2(x + 1) = −9
−2(x + 1) = −14
x + 1 = 7
x = 6
~~~

先两边减去 5，再两边除以 −2，最后减去 1。

验根：5 − 2(6 + 1) = 5 − 14 = −9。

保留整体的方法适合能够直接逐步还原的结构。两边有多个含未知数的部分时，展开通常更便于合并。

## 十一、小数系数也使用相同方法

解 0.5(2x − 4) + 1 = 3：

~~~text
0.5(2x − 4) + 1 = 3
x − 2 + 1 = 3
x − 1 = 3
x = 4
~~~

0.5 同时乘以 2x 和 −4。系数计算使用有理数乘法，解方程的等式性质没有改变。

验根：0.5(8 − 4) + 1 = 2 + 1 = 3。

本节主要关注括号；下一节会专门处理分数形式中的分母和等式变形。

## 十二、方程的解不一定是整数

解 2(x + 3) = x + 9.5：

~~~text
2(x + 3) = x + 9.5
2x + 6 = x + 9.5
x + 6 = 9.5
x = 3.5
~~~

验根：左边 2 × 6.5 = 13，右边 3.5 + 9.5 = 13。

没有整数限制的纯数学方程可以有小数解，不应擅自把 3.5 取整。如果 x 表示实际物品个数，则还要检查这种解是否符合情境。

## 十三、未知数抵消时检查剩下的等式

观察 2(x + 3) = 2x + 6，展开后得到：

~~~text
2x + 6 = 2x + 6
6 = 6
~~~

所有实数 x 都满足。

如果方程改成 2(x + 3) = 2x + 7，整理后得到 6 = 7，没有任何实数解。

这两种式子整理后未知数系数为 0，不属于系数非零的一元一次方程。不能尝试除以 0，也不能在恒等式情况下写成“x = 0”。

## 十四、演示：综合求解并逐边验根

解 4(x − 1) − 2(x + 3) = 3(x − 2) + 1：

~~~text
4(x − 1) − 2(x + 3) = 3(x − 2) + 1
4x − 4 − 2x − 6 = 3x − 6 + 1
2x − 10 = 3x − 5
−10 = x − 5
−5 = x
~~~

所以 x = −5。

代回原方程分别计算：

~~~text
左边 = 4(−5 − 1) − 2(−5 + 3)
     = −24 − (−4)
     = −20

右边 = 3(−5 − 2) + 1
     = −21 + 1
     = −20
~~~

左右两边相等，−5 是原方程的解。

把未知数集中在右边同样正确。最后得到 −5 = x，可以利用等号的对称性写成 x = −5，不需要再改变符号。

## 十五、常见错误可以通过还原关系检查

把 3(x + 2) 错写成 3x + 2，是遗漏了常数项的乘法。

把 −(x − 4) 错写成 −x − 4，是没有取整个括号的相反数。

把 2(x + 1) + 4 = 10 两边除以 2，却写成 x + 1 + 4 = 5，是没有把左边的整个式子都除以 2。正确结果应为 x + 1 + 2 = 5。

出现不确定的步骤时，重新写出分配律或两边同时进行的运算，再用原方程验根，比只记简略口号更可靠。

## 十六、小结

含括号的一元一次方程，可以先展开、合并同类项，再利用等式性质求解；有时先把括号作为整体处理更方便。

展开时，括号内每一项都要乘以外面的系数。括号前是减号，要取整个括号的相反数；嵌套括号通常从内向外整理。

等式两边同时运算时，要对各自的整个式子进行相同操作。求出的值应代回原方程，分别计算两边验证。

未知数抵消后，要判断剩余等式是否成立；在实际情境中，还要检查解的单位、含义与取值条件。
