# 9B.2 数列的通项

一组图形的方块数从 5 开始，之后每幅增加 3 块：

~~~text
5，8，11，14，17，……
~~~

要知道第 20 幅有多少块，可以逐次加 3，也可以直接计算：从第 1 幅到第 20 幅，经历 19 次增加。

~~~text
第 20 项 = 5 + 19 × 3 = 62
~~~

如果把位置 20 换成字母 n，就得到表示第 n 项的式子。这种把位置与项值直接联系起来的表示，叫作通项。

## 一、第 n 项的记号

用 aₙ 表示数列的第 n 项，其中 n 是位置，aₙ 是这个位置上的数值。

~~~text
a₁：第 1 项
a₂：第 2 项
aₙ：第 n 项
~~~

这里的小数字或字母叫作下标，用来标明项的位置，不是指数。

a₃ 不表示 a 的三次方，也不表示 3a。对开头的数列，a₃ = 11。

本节的位置从 1 开始，因此 n 取正整数。

## 二、通项给出位置与项值的关系

开头的数列可以用：

~~~text
aₙ = 3n + 2，n = 1，2，3，……
~~~

表示。给定位置 n，就能直接计算对应项值。

~~~text
n = 1：a₁ = 3 × 1 + 2 = 5
n = 2：a₂ = 3 × 2 + 2 = 8
n = 3：a₃ = 3 × 3 + 2 = 11
~~~

3n + 2 叫作这个数列的通项式；aₙ = 3n + 2 记录通项关系。通项不一定都是一次式，关键是能表示每个允许位置上的项。

## 三、固定差：数清经历多少次变化

若第一项为 5，每次增加 3：

~~~text
第 1 项：5
第 2 项：5 + 1 × 3
第 3 项：5 + 2 × 3
第 4 项：5 + 3 × 3
~~~

第 n 项经历 n − 1 次增加，因此：

~~~text
aₙ = 5 + 3(n − 1)
   = 5 + 3n − 3
   = 3n + 2
~~~

5 + 3(n − 1) 强调起点和变化次数，3n + 2 是化简后的表示，两者等价。

不能写成 5 + 3n，那样在 n = 1 时已经多增加了一次。

## 四、用倍数列作比较也能找到通项

比较目标数列与 3 的正倍数：

| 位置 n | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| 3n | 3 | 6 | 9 | 12 | 15 |
| 目标项 | 5 | 8 | 11 | 14 | 17 |

每项都比对应的 3n 多 2，所以通项为 3n + 2。

这里比较的是相同位置上的两项，不是把第一列的数与下一列错位比较。

这个方法适合明确按固定差继续的数列。仅观察几个差相同的数字，还不能证明所有后续项都保持这个规则。

## 五、固定差可以为负数

数列从 20 开始，每次减少 4：

~~~text
20，16，12，8，4，0，−4，……
~~~

后一项减前一项的固定差为 −4，所以：

~~~text
aₙ = 20 + (n − 1)(−4)
   = 24 − 4n
~~~

第 7 项为 24 − 28 = −4，与逐项计算一致。

如果数列表示可无限继续的一般数值，负项可以存在；若表示物品剩余数量，可能需要在变成负数前停止，并明确 n 的允许范围。

## 六、固定差也可以是分数或小数

第一项为 1/2，每次增加 1/4：

~~~text
1/2，3/4，1，5/4，……
~~~

通项为：

~~~text
aₙ = 1/2 + (n − 1)/4
   = (n + 1)/4
~~~

第 10 项为 11/4，也就是 2.75。

位置 n 仍是正整数，但项值可以是分数或小数。“第 2.5 项”不属于本节的位置约定。

## 七、一般的固定差通项

如果第一项为 a₁，后一项减前一项总等于固定数 d，则：

~~~text
aₙ = a₁ + (n − 1)d
~~~

a₁ 是起点，n − 1 是变化次数，d 是每次带方向的变化。

这种固定差数列称为等差数列。d 为正时递增，为负时递减，为 0 时各项相同。

例如第一项为 7、d = 0，通项就是 aₙ = 7。相同项值可以出现在许多不同位置。

公式适用于固定差条件，不适用于所有看起来有规律的数列。

## 八、平方规律的通项不是一次式

数列按位置数的平方生成：

~~~text
1，4，9，16，25，……
~~~

通项为 aₙ = n²。例如第 12 项为 12² = 144。

如果每个平方数再增加 1，则：

~~~text
2，5，10，17，26，……
aₙ = n² + 1
~~~

这些数列的相邻差不固定，但位置与项值之间仍有直接关系。

找到通项不等于一定找到“固定增加多少”，应依据实际生成方式选择表达式。

## 九、演示：从连续方格结构推导通项

用小棒排一行相邻正方形，邻接的两个正方形共用一条边。第 n 幅由 n 个正方形组成。

~~~text
第 1 幅：┌──┐
         │  │
         └──┘

第 3 幅：┌──┬──┬──┐
         │  │  │  │
         └──┴──┴──┘
~~~

第一个正方形用 4 根小棒，每增加一个正方形，因共用一边，只新增 3 根。

~~~text
aₙ = 4 + 3(n − 1) = 3n + 1
~~~

也可以直接数：上边 n 根，下边 n 根，竖边 n + 1 根，共 3n + 1 根。

两个推导都依据明确图形结构，所以不仅解释前几幅，也解释任意正整数 n 对应的图形。

## 十、代入求指定项时保留运算范围

若 aₙ = 2(n + 3)，求第 8 项：

~~~text
a₈ = 2(8 + 3) = 22
~~~

不能把它算成 2 × 8 + 3 = 19，因为原来的 2 乘整个括号。

若 aₙ = (n + 1)/4，第 7 项就是 (7 + 1)/4 = 2，而不是 7 + 1/4。

通项求值仍遵守代数式代入和运算顺序，位置记号不会改变这些规则。

## 十一、演示：反过来寻找项的位置

数列的通项为 aₙ = 3n + 2，求数值 62 位于第几项。

把项值设为 62：

~~~text
3n + 2 = 62
3n = 60
n = 20
~~~

20 是正整数，所以 62 是第 20 项。

检验：a₂₀ = 3 × 20 + 2 = 62。

这里求的是位置 n，不是再把 62 当作位置代入计算 a₆₂。

## 十二、方程得到非整数位置，说明不是该数列的项

仍对 aₙ = 3n + 2，判断 60 是否为其中一项：

~~~text
3n + 2 = 60
n = 58/3
~~~

58/3 不是正整数，因此 60 不是这个数列的项。

不能把位置四舍五入为 19 或 20，因为这两个位置上的值分别为 59 和 62，都不是 60。

若数列只取前十项，即使解出正整数 n = 20，也不属于该有限数列。反求位置要检查整数条件和范围。

## 十三、项值未必唯一对应一个位置

在严格递增或递减数列中，同一项值不会重复出现。

但常数列 aₙ = 7 中，每个位置的值都是 7；交替数列中也可能重复。

所以“给一个项值就能唯一确定位置”不是所有数列都具备的性质。

反求位置时，可能有一个、多个、无限多个或没有符合条件的位置，应结合通项与范围判断。

## 十四、通项与相邻项规则不同

“第一项为 5，之后每次加 3”告诉我们怎样从前一项生成后一项。

“aₙ = 3n + 2”则直接从位置 n 得到项值。

两种描述对应同一数列，但计算第 100 项时，通项更直接：a₁₀₀ = 302，不需要逐项增加 99 次。

若用固定倍数生成数列，也可以寻找相应通项，但不能套用固定差公式。本节重点是位置关系的含义与固定差、平方等典型结构。

## 十五、检查候选通项需要规则依据

对于已明确“从 5 开始、每次加 3”的数列，可以检查 aₙ = 3n + 2：第一项为 5，位置每增加 1，项值就增加 3。

这两点与生成规则完全对应，说明它表示整个数列。

只把前两三项代入都算对，是有用的错误检查，却不一定能证明公式对所有后续位置成立。有限项可能符合多个不同规律。

推导应依据文字规则、图形结构或已经确定的关系，而不是把一次成功猜测当成唯一可能。

## 十六、演示：比较两个等价通项

第一项为 7，每次加 4，可以写成：

~~~text
aₙ = 7 + 4(n − 1)
~~~

利用分配律化简：

~~~text
7 + 4(n − 1) = 7 + 4n − 4 = 4n + 3
~~~

因此 aₙ = 4n + 3 是同一个通项关系的另一种写法，不是另一条数列。

第 6 项用两种写法都得到 27。代入可以检查具体值，代数化简说明它们对所有允许的 n 都相等。

## 十七、小结

通项把位置 n 与第 n 项的值直接联系起来。aₙ 的下标表示位置，不是指数；本节 n 从 1 开始，取正整数。

固定差数列的第 n 项等于第一项加上 n − 1 次变化，即 aₙ = a₁ + (n − 1)d。图形结构与对应倍数列也可以帮助推导通项。

求指定项，就是代入位置；寻找某个项值的位置，可以列方程，再检查正整数与范围条件。项值重复时，位置不一定唯一。

检验候选通项要结合完整生成规则，不能只凭有限项相符就断言后续唯一。准确的推导让通项真正解释整条数列。
