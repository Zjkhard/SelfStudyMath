# 9.11 有理数的意义

把 3 米彩带平均分给 4 个人，每个人得到 3/4 米，也就是 0.75 米。

~~~text
3 ÷ 4 = 3/4 = 0.75
~~~

如果把 3 米彩带平均分给 1 个人，每个人得到 3 米：

~~~text
3 ÷ 1 = 3/1 = 3
~~~

分数、小数和整数看起来写法不同，却都可以表示为两个整数相除的结果。满足这种条件的数有一个共同的名称：有理数。

## 一、有理数的定义

能够写成 p/q 形式的数，叫作**有理数**。这里 p、q 都是整数，而且 q 不等于 0。

~~~text
p/q = p ÷ q
p、q 是整数，q ≠ 0。
~~~

例如：

~~~text
3/4，−5/2，7/1，0/3
~~~

这些都表示有理数。

定义强调的是“能够写成”，不是“现在必须写成”。0.75 没有分数线，但它能写成 3/4，所以也是有理数。

“有理数”在这里是数学名称，不是日常语言中“有没有道理”的判断。

## 二、分子可以为零，分母不能为零

因为 0 除以非零整数等于 0：

~~~text
0/3 = 0
0/(−5) = 0
~~~

所以 0 是有理数。

但 3/0 与 0/0 都不能表示一个有定义的数，因为除以 0 没有定义。

因此，定义中的“分母不为 0”不能省略。它并不要求分子也不为 0。

## 三、所有整数都是有理数

任何整数都能写成分母为 1 的形式：

~~~text
6 = 6/1
−6 = −6/1
0 = 0/1
~~~

所以，正整数、负整数和 0 都是有理数。

整数与有理数不是互不相干的两类。整数包含在有理数中，只是有理数还包括许多非整数。

例如 3/2 是有理数，却不是整数，因为 3 ÷ 2 = 1.5。

## 四、分数形式不保证结果不是整数

比较：

~~~text
8/4 = 2
7/4 = 1.75
~~~

它们都是有理数，但第一个也是整数，第二个不是整数。

因此，判断一个数是否为整数，要看它的值，不能只看写法中有没有分数线。

小学常用的真分数、假分数和带分数，经过必要的转换，都能表示成整数之比。例如：

~~~text
2 又 1/3 = 7/3
−(2 又 1/3) = −7/3
~~~

负号作用于整个带分数，不能把后一式写成 −2 + 1/3。

## 五、负号可以统一放在分数前面

整数除法的符号规律帮助我们整理负分数：

~~~text
(−3)/4 = −3/4
3/(−4) = −3/4
(−3)/(−4) = 3/4
~~~

通常把分母写成正整数，把负号放在分数前面或分子上，便于比较和计算。

分母为负并不违反有理数定义，因为负整数也是整数。但分母仍不能为 0。

整理符号改变的是表示方式，不改变数值。

## 六、有限小数都能写成整数之比

**有限小数**的小数位数有限，例如 0.6、1.25 和 −0.375。

根据小数位值：

~~~text
0.6 = 6/10 = 3/5
1.25 = 125/100 = 5/4
−0.375 = −375/1000 = −3/8
~~~

一位小数可以写成分母为 10 的分数，两位小数可以写成分母为 100 的分数，依此类推。

这些分子和分母都是整数，分母也不为 0，所以所有有限小数都是有理数。

即使写成 2.0，它仍等于整数 2。小数点的出现不代表这个数一定不是整数。

## 七、循环小数也是有理数

**循环小数**是从某一位开始，一个数字或一组数字不断重复出现的小数。

~~~text
0.333…：数字 3 一直重复。
0.272727…：数字组 27 一直重复。
0.1666…：从第二位小数起，数字 6 一直重复。
~~~

这里省略号表示所说明的规律无限继续，而不是随意省略未知的数字。

例如：

~~~text
1/3 = 0.333…
3/11 = 0.272727…
1/6 = 0.1666…
~~~

这些循环小数都能写成整数之比，所以也是有理数。负的循环小数同样如此，例如 −0.333… = −1/3。

## 八、演示：把简单循环小数写成分数

用字母 x 表示 0.272727…：

~~~text
x = 0.272727…
~~~

循环的一组数字有两位，把它乘以 100，让小数点右移两位：

~~~text
100x = 27.272727…
~~~

这时，两数的小数部分完全相同。相减后重复的小数部分抵消：

~~~text
100x − x = 27
99x = 27
x = 27/99 = 3/11
~~~

所以 0.272727… = 3/11。

这个演示借助字母和等式展示转换的原因。一般循环小数也能通过适当移动小数点、相减来写成整数之比；后面学习方程后，会更系统地处理这些步骤。

## 九、为什么分数化小数会有限或循环

把一个有理数的分母整理为正整数后，用分子除以分母。

长除法中，每一步的余数只能是 0 到“分母减 1”之间的整数，可能的余数只有有限种。

~~~text
余数变成 0：除法结束，得到有限小数。
余数一直不为 0：某个余数必然再次出现。
~~~

同一个余数再次出现后，后续除法的步骤与商的数字也会重复，于是得到循环小数。

因此，有理数的小数表示要么有限，要么从某一位开始循环。不会出现无限继续、却始终没有循环规律的小数表示。

“小数无限长”不等于“不是有理数”，因为循环小数也无限长。

## 十、按是否为整数分类

可以把有理数分成两类：整数与非整数有理数。

~~~text
有理数
├─ 整数：……，−2，−1，0，1，2，……
└─ 非整数有理数：−3/2，1/4，0.6，0.333…，……
~~~

这里的分类依据是数值是否为整数，不是外观写成整数、分数还是小数。

例如 6/3 和 2.0 都属于整数；−1.5 与 −3/2 是同一个非整数有理数。

按这个依据分类时，一个数不会同时属于两类。

## 十一、也可以按正负分类

换一个分类依据，可以把有理数分成正有理数、0 和负有理数：

~~~text
正有理数：2，3/4，0.5，……
零：0
负有理数：−2，−3/4，−0.5，……
~~~

正有理数包括正整数和正的非整数有理数；负有理数同样包括负整数和负的非整数有理数。

0 必须单独列出，因为它既不是正数，也不是负数。

两个分类方法都正确，但每次要说明依据。不能把“正整数”和“正有理数”当作互不重叠的并列类别。

## 十二、不同表示对应同一个数轴点

观察：

~~~text
−1/2 = −2/4 = −0.5
~~~

这三种写法在数轴上都表示同一个点：位于 0 左侧，离原点半个单位。

约分、通分或分数小数互化，不会让这个点改变位置。

比较有理数时，可以选用方便的等值表示：

~~~text
−3/4 = −0.75
−1/2 = −0.5
−0.75 < −0.5
所以 −3/4 < −1/2。
~~~

数轴上的位置与大小规则没有改变：在向右为正的数轴上，越靠右的数越大。

## 十三、任意两个不同的有理数之间还有有理数

例如 1/2 和 3/4 之间，可以找到 5/8：

~~~text
1/2 = 4/8
3/4 = 6/8
4/8 < 5/8 < 6/8
~~~

一般地，两个不同有理数的平均数，也就是“它们的和除以 2”，仍是有理数，而且位于两数之间。

把有理数表示为整数之比后，通分相加并除以 2，所得仍有整数分子和非零整数分母。

还可以在新得到的数与原来的数之间继续寻找。因此，有理数不像整数那样有相邻两数之间固定的空隙。

但这并不表示数轴上的所有点都是有理数。后面学习实数时，还会认识不能写成整数之比的数。

## 十四、准确值与有限小数近似值不同

比较：

~~~text
1/3 = 0.333…
1/3 ≈ 0.33
~~~

第一行是准确相等，第二行是保留两位小数的近似表示。

0.33 本身等于 33/100，是有理数，但它不等于 1/3。用近似值代替原数，会改变准确数值。

同样，一个数在计算器上显示为有限位小数，并不能单凭屏幕上的数字判断原数是否有理。显示可能只是近似值。

判断有理数应依据原数能否准确写成整数之比，而不是某个近似结果的外观。

## 十五、演示：依据定义判断和分类

依次观察 −12、0、−1.25、8/4 和 0.666…，最后一个小数表示数字 6 无限重复。

| 原来的表示 | 写成整数之比 | 是否为整数 | 正负分类 |
| --- | --- | --- | --- |
| −12 | −12/1 | 是 | 负有理数 |
| 0 | 0/1 | 是 | 零 |
| −1.25 | −5/4 | 否 | 负有理数 |
| 8/4 | 2/1 | 是 | 正有理数 |
| 0.666… | 2/3 | 否 | 正有理数 |

每个数都能写成整数之比，且分母不为 0，所以它们都是有理数。

8/4 应按它的值 2 归为整数。−1.25 虽然写成小数，却与 −5/4 是同一个有理数。表示方法与分类依据应当分清。

## 十六、小结

能准确写成两个整数之比、且分母不为 0 的数叫作有理数。分子可以为 0，所以 0 也是有理数。

所有整数、有限小数和循环小数都是有理数。有理数化成小数时，要么有限，要么循环；无限小数不一定不是有理数。

可以按是否为整数分类，也可以按正、负与零分类。判断依据是数值，不是写法中有没有分数线或小数点。

等值表示对应同一个数轴点。准确值与近似值要区分，不能只根据有限位的小数显示判断原数的性质。
