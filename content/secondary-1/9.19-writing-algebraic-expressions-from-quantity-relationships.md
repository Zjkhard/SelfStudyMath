# 9.19 根据数量关系列代数式

每盒彩笔有 12 支，小林买了 n 盒，另外又买了 3 支单支彩笔。

先算盒装彩笔的数量，再加上单支彩笔：

~~~text
盒装数量：12 × n = 12n（支）
总数量：12n + 3（支）
~~~

列代数式不是把文字中的数字和字母随意拼在一起，而是把数量之间的关系用运算表示出来。

## 一、先说明字母表示什么

同一个字母可以用于不同问题，但在一个问题中必须有明确、固定的含义。

例如“用 n 表示彩笔盒数”，说明 n 是盒数，不是每盒支数，也不是总支数。

如果允许买 0 盒，n 可以取非负整数；如果至少买 1 盒，n 就取正整数。

先说明含义和条件，再列式，别人才能知道这个表达式代表哪个数量。

## 二、从熟悉的数字例子看出关系

如果买 2 盒，总支数为 12 × 2 + 3；如果买 5 盒，总支数为 12 × 5 + 3。

~~~text
2 盒：12 × 2 + 3
5 盒：12 × 5 + 3
n 盒：12 × n + 3 = 12n + 3
~~~

变化的是盒数，不变的是“每盒支数乘盒数，再加单支数量”的关系。

遇到较复杂的描述，先用一个具体数理解过程，再把那个数换成字母，往往更容易看清结构。

## 三、合并与增加通常用加法表示

~~~text
x 与 7 的和：x + 7
比 x 多 7 的数：x + 7
x 增加 7 后的数：x + 7
~~~

这些描述措辞不同，但都表示在 x 的基础上增加 7。

如果甲有 a 本书，乙有 b 本书，两人合计有 a + b 本。

相加的数量要有可比较的同类单位。不能直接把 3 米与 2 千克相加当作总长度或总质量。

## 四、减法顺序由关系决定

比较：

~~~text
比 x 少 7 的数：x − 7
从 7 中减去 x：7 − x
~~~

它们一般不同。若 x = 10，前一式为 3，后一式为 −3。

“甲比乙多 5 本”也要先看谁作为比较基准。如果乙有 x 本，则甲有 x + 5 本；如果甲有 y 本，则乙有 y − 5 本。

不能只看到“多”就一律加，也不能只看到“少”就一律减。先确定已知用字母表示的是哪个数量，再根据关系表达另一个数量。

## 五、几倍与几分之一用乘法表示

~~~text
x 的 4 倍：4x
x 的一半：x/2，或 (1/2)x
x 的三分之二：(2/3)x
~~~

例如一条彩带长 x 米，另一条是它的 3 倍，另一条长 3x 米。

倍数或比例本身没有长度单位。乘上原来的长度后，结果仍用米表示。

4x 表示 x 的 4 倍，不表示 x + 4。倍数关系与增加固定数量的关系不同。

## 六、整体的几倍要用括号

比较两个描述：

~~~text
x 与 3 的和的 2 倍：2(x + 3)
x 的 2 倍再加 3：2x + 3
~~~

第一种先相加，再把整个和乘以 2；第二种先把 x 乘以 2，再加 3。

若 x = 4：

~~~text
2(x + 3) = 2 × 7 = 14
2x + 3 = 8 + 3 = 11
~~~

括号标明文字中“和的”“差的”等整体关系。先用语言说清先做什么、再做什么，能帮助判断括号的位置。

## 七、除法也要看清先后顺序

~~~text
x 除以 5：x/5
5 除以 x：5/x（x ≠ 0）
~~~

被除数和除数不能交换。

“a 与 b 的和除以 3”写成 (a + b)/3；“a 加上 b 的三分之一”写成 a + b/3。

前者把整个和平均分成三份，后者只把 b 分成三份。分数线或括号的范围必须与数量关系一致。

## 八、平方与倍数不要混淆

~~~text
x 的平方：x²
x 的 2 倍：2x
x 与 3 的和的平方：(x + 3)²
x 的平方与 3 的和：x² + 3
~~~

“平方”表示两个相同因数相乘，不表示加倍。

同样，“和的平方”要把整个和作为底数，不能漏掉括号，也不能直接写成各项平方相加。

## 九、演示：购物总价与找零

每本练习本售价 4 元，每支笔售价 2.5 元。买 n 本练习本和 2 支笔，付出 50 元。

先把费用分成两部分：

~~~text
练习本费用：4n 元
笔的费用：2.5 × 2 = 5（元）
总费用：(4n + 5) 元
~~~

找回的钱是付款减去总费用：

~~~text
找零：[50 − (4n + 5)] 元
~~~

减号作用于整个总费用，不能写成 50 − 4n + 5，否则把笔的费用加回了付款中。

如果只使用这 50 元且不欠款，n 必须是非负整数，且满足 4n + 5 ≤ 50，所以最多可买 11 本。

代入 n = 6 检查：总费用为 29 元，找零为 21 元，两者相加为 50 元，符合付款关系。

## 十、演示：平均分配与剩余数量

有 x 块饼干，先拿出 6 块，剩下的平均分给 3 个人。

~~~text
剩下的数量：x − 6
每人得到的数量：(x − 6)/3
~~~

不是 x − 6/3，因为题意要求平均分的是拿出 6 块之后的整个剩余量。

如果饼干必须保持完整，每人也要分得整数块，则 x 是不小于 6 的整数，而且 x − 6 应能被 3 整除。

例如 x = 18，先剩下 12 块，再分给 3 人，每人 4 块，与表达式的值一致。

情境条件不一定全部写进代数式中，但解释表达式时不能忽略它们。

## 十一、演示：年龄关系与时间变化

小林今年 x 岁，小安比小林大 3 岁。以相同时间点比较年龄：

~~~text
小安今年：x + 3 岁
小林 5 年后：x + 5 岁
小安 5 年后：x + 3 + 5 岁
~~~

两个人同时经过 5 年，年龄差仍为 3 岁。

若只问小安今年的年龄，就不能把未来的 5 年也加进去。列式要确定所描述的时间点。

这里 x 表示今年的年龄数值，不是 5 年后的年龄。字母的基准一旦确定，就要保持一致。

## 十二、演示：图形尺寸与面积

一个长方形宽为 x 厘米，长比宽多 4 厘米，其中 x 为正数。

~~~text
宽：x 厘米
长：(x + 4) 厘米
~~~

周长与面积分别为：

~~~text
周长：2[x + (x + 4)] 厘米
面积：x(x + 4) 平方厘米
~~~

面积用长乘宽，不能把“长比宽多 4”误当成面积也只多 4。

代入 x = 3，长为 7 厘米，周长为 20 厘米，面积为 21 平方厘米。结果与直接使用长、宽计算一致。

## 十三、演示：百分数表示数量的一部分

一件商品原价为 p 元，打八折出售，也就是售价为原价的 80%。

~~~text
售价：0.8p 元
节省的钱：(p − 0.8p) 元
~~~

原价的 80% 是用 0.8 乘以原价，不是从原价中减去 80 元。

若在折后售价基础上另加 5 元固定运费，总付款为 (0.8p + 5) 元。运费并未参与折扣，不能把整个付款写成 0.8(p + 5)。

代入 p = 100 检查：售价 80 元，加运费后付款 85 元，符合先打折、再加固定费用的关系。

## 十四、演示：总量与平均量

三次测量的长度数值分别为 a、b、c，单位都为厘米。平均长度为：

~~~text
(a + b + c)/3 厘米
~~~

先求总长度，再除以测量次数。不能写成 a + b + c/3，因为那只把第三个数除以 3。

如果三个长度都相同，都是 6 厘米，表达式得到 (6 + 6 + 6)/3 = 6 厘米，符合平均数的意义。

选择这样的简单值检查，能帮助发现括号范围错误。

## 十五、列代数式与列方程的区别

“每盒有 12 支彩笔，买 n 盒，另有 3 支，表示总支数”，可以列出：

~~~text
12n + 3
~~~

这是代数式，表示一个数量。

如果再知道总共有 39 支，就得到等量关系：

~~~text
12n + 3 = 39
~~~

这才是含未知数的方程。不要在题意没有给出相等条件时，随意补一个等号和结果。

也可以给总量另取字母 T，写成 T = 12n + 3，用等式记录关系。每个字母仍要说明含义。

## 十六、检查表达式是否保留原来的关系

列式后，可以反过来把它读成语言，确认运算顺序与题意一致。

再选一个符合条件的简单值代入，用原来的情境直接计算，比较两个结果。

还可以观察变化规律：每盒彩笔有 12 支，盒数增加 1 时，12n + 3 的值应增加 12，而不是增加 3。

最后检查单位和范围。表示长度的结果不能写成面积单位；除数不能为 0；表示完整物品数量的字母通常不能任意取负数或分数。

一次代入检查有助于发现错误，但不能代替数量关系的解释。表达式为什么正确，仍要依据它完整保留了原来的运算关系。

## 十七、小结

根据数量关系列代数式，先说明字母含义，再确定数量之间的关系，最后按关系选择运算与括号。

合并用加法，求差要辨认顺序，倍数与比例用乘法，平均分配用除法。平方与加倍、整体的几倍与某一部分的几倍，都要分清。

复杂情境可以先分成几步表达，再组合成完整代数式。单位、时间基准和取值范围也属于数量关系的一部分。

列式后，通过读回文字、代入检查和观察变化规律来验证。代数式表示数量，方程还需要一个明确的等量条件。
