# 9.24 分组分解因式

观察一个长方形：宽分成 a、b 两段，高分成 x、y 两段，所有长度数值使用同一种单位，而且都为正。

四块小长方形的面积数值分别为 ax、bx、ay、by，总面积为：

~~~text
ax + bx + ay + by
~~~

把上下两条横带分别合起来，再合成整个长方形：

~~~text
ax + bx + ay + by
= x(a + b) + y(a + b)
= (x + y)(a + b)
~~~

原来的四项没有共同的字母因子，但分成两组后，各组都出现了 a + b。再次提取这个共同整体，就完成了分解。

## 一、分组的目的是什么

上一节可以直接把 ab + ac 中的 a 提出来：

~~~text
ab + ac = a(b + c)
~~~

但 ax + bx + ay + by 的四项中，没有一个字母在每项里都出现。

这时可以先把项分成适当的组，每组分别提取公因式，再寻找各组之间的共同因式。

这种方法叫作**分组分解因式**。

目的不是任意加几个括号，而是通过分组让原来隐藏的共同乘法结构显现出来。

## 二、从两次提取看清过程

分解 ax + ay + bx + by：

~~~text
ax + ay + bx + by
= (ax + ay) + (bx + by)
= a(x + y) + b(x + y)
= (a + b)(x + y)
~~~

第一次分别从两组中提取 a 和 b，得到相同的括号 x + y。

第二次把 x + y 作为整体公因式提取，括号外原来的 a 和 b 合成 a + b。

分解的关键是两组留下的括号相同，不是两组提取出的字母必须相同。

## 三、共同括号可以暂时看作一个整体

为了看清最后一步，可以暂时用 M 表示 x + y：

~~~text
a(x + y) + b(x + y) = aM + bM
~~~

提取 M：

~~~text
aM + bM = (a + b)M
~~~

再把 M 换回 x + y，就得到 (a + b)(x + y)。

这个临时记号只是帮助阅读，不改变原来的字母含义，也没有增加一个独立未知数。

## 四、数字与字母混合也可以分组

分解 3x + 6 + xy + 2y：

~~~text
3x + 6 + xy + 2y
= (3x + 6) + (xy + 2y)
= 3(x + 2) + y(x + 2)
= (3 + y)(x + 2)
~~~

第一组提取 3，第二组提取 y，两组留下相同的 x + 2。

也可以把结果写成 (x + 2)(y + 3)，因式顺序和加数顺序调整后，乘积的值不变。

## 五、项的顺序不合适时可以重新排列

分解 ax + by + ay + bx。相邻两项未必最适合放在一起。

利用加法交换律，把含 a 的项与含 b 的项分别放在一起：

~~~text
ax + by + ay + bx
= ax + ay + bx + by
= a(x + y) + b(x + y)
= (a + b)(x + y)
~~~

重新排列时，每项必须连同自己的符号移动。

例如原来是 −bx，换位置后仍是 −bx，不能为了凑出相同括号而擅自改成 +bx。

## 六、不同分组可能得到相同乘积

对 ax + ay + bx + by，也可以把含 x 与含 y 的项分别分组：

~~~text
ax + ay + bx + by
= (ax + bx) + (ay + by)
= x(a + b) + y(a + b)
= (x + y)(a + b)
~~~

这与 (a + b)(x + y) 是同一个乘积。

分组方式可以不同，只要每一步保持等价，并且最终形成共同因式即可。

因此，不必只记住某一个固定位置的分组方式，应观察各项的因子结构。

## 七、减法分组时先保留各项符号

分解 ax − ay + bx − by：

~~~text
ax − ay + bx − by
= (ax − ay) + (bx − by)
= a(x − y) + b(x − y)
= (a + b)(x − y)
~~~

两组中的第二项都是负项，所以共同括号是 x − y。

不能把第二组写成 b(x + y)，因为展开后会得到 +by，与原式的 −by 不同。

## 八、提取负因子可以让括号一致

分解 ax − ay − bx + by：

~~~text
ax − ay − bx + by
= (ax − ay) + (−bx + by)
= a(x − y) − b(x − y)
= (a − b)(x − y)
~~~

第二组提取的是 −b：

~~~text
−bx + by = −b(x − y)
~~~

展开时 −b × x = −bx，−b × (−y) = +by，所以符号正确。

提取负因子不是为了随意“凑答案”，而是利用相反数关系，让两个等价的括号形式统一。

## 九、相反的括号要先转换

观察 a(x − y) + b(y − x)。两个括号不是相同的，但互为相反数：

~~~text
y − x = −(x − y)
~~~

因此：

~~~text
a(x − y) + b(y − x)
= a(x − y) − b(x − y)
= (a − b)(x − y)
~~~

不能直接写成 (a + b)(x − y)，那会漏掉第二个括号的负号。

看到括号内容不同，先判断它们能否通过正确的等价变形统一，而不是只凭外观相近就提取。

## 十、有整体公因式时可以先提取

分解 2ax + 2ay + 6x + 6y：

~~~text
2ax + 2ay + 6x + 6y
= 2(ax + ay + 3x + 3y)
= 2[a(x + y) + 3(x + y)]
= 2(a + 3)(x + y)
~~~

先提取整体的数字公因式 2，让后面的系数更简单，再分组。

也可以直接分组得到 2a(x + y) + 6(x + y)，继续提取并整理成相同结果。

整体提取与分组方法可以结合，不必把它们看成互不相干的技巧。

## 十一、含平方项也可以按因子结构分组

分解 x² + 3x + 2x + 6：

~~~text
x² + 3x + 2x + 6
= (x² + 3x) + (2x + 6)
= x(x + 3) + 2(x + 3)
= (x + 2)(x + 3)
~~~

第一组的共同因式为 x，第二组为 2，两组都留下 x + 3。

如果先把 3x 与 2x 合并，得到 x² + 5x + 6，反而暂时隐藏了这里的四项结构。

本节借这个已经拆成四项的例子说明分组过程，不在这里系统学习怎样把任意二次式的中间项拆开。

## 十二、演示：完整分组并展开验证

分解 2ax − 6a + bx − 3b：

~~~text
2ax − 6a + bx − 3b
= (2ax − 6a) + (bx − 3b)
= 2a(x − 3) + b(x − 3)
= (2a + b)(x − 3)
~~~

展开检查每一部分：

~~~text
(2a + b)(x − 3)
= 2a(x − 3) + b(x − 3)
= 2ax − 6a + bx − 3b
~~~

四项及其符号全部还原，说明分解等价。

若取 a = 1、b = 2、x = 5，原式与乘积都为 8，也可以辅助检查。对所有取值成立的依据仍是每一步正确使用分配律。

## 十三、只有括号一致才完成下一次提取

例如把 ax + ay + bx + 2by 分成两组：

~~~text
(ax + ay) + (bx + 2by)
= a(x + y) + b(x + 2y)
~~~

留下的 x + y 与 x + 2y 不同，不能继续写成 (a + b)(x + y)。

可以检查其他分组是否有用，但不能为了让括号一致而改动原来的系数 2。

分组法不是对任意四项式都必然成功。某种分组没出现共同因式，既不允许错误提取，也不能仅凭一次尝试就断言所有其他方法都不可行。

## 十四、分解结果应是整个原式的乘积

写到 a(x + y) + b(x + y) 时，已经分别分解两组，但整体仍是和。

继续提取共同括号，写成 (a + b)(x + y)，才完成了这次分组分解。

同样，不能把原式中的某一部分分解成乘积，就认为整个式子已经完成因式分解。

检查时可以问：最外层是否已经是因式相乘？是否还有本节能够直接提取的共同部分？展开后是否完整还原原式？

## 十五、演示：面积模型验证四项乘积

回到开头的长方形，把宽分成 a、b，高分成 x、y：

~~~text
             a          b
        ┌──────────┬──────────┐
     x  │    ax    │    bx    │
        ├──────────┼──────────┤
     y  │    ay    │    by    │
        └──────────┴──────────┘
~~~

图形只示意分割关系，不按长度比例绘制。四个区域没有重叠，也没有空缺。

分别相加，面积数值为 ax + bx + ay + by；按整个长方形计算，面积数值为 (a + b)(x + y)。

这里的正长度情境直观解释了分组。代数等式本身还可用于字母取负数或 0 的情况，因为它依据分配律，而不是依赖这些数必须能作长度。

## 十六、小结

分组分解因式，是先把项分成适当的组，各组提取公因式，再提取各组共同的括号因式。

分组可以重新排列项，但每项必须带着自己的符号。必要时提取负因子，把互为相反数的括号统一。

可以先提整体公因式，也可以尝试不同分组。关键是各组留下相同的共同因式，不能为了配合分组而改变原式。

最终应把整个原式写成乘积，并用展开还原各项来验证。分组不一定适用于任意式子，也不意味着给原式添加等于 0 的方程条件。
