# 9.45 三角形分类

三个三角形，一个三边等长，一个只有两边等长，另一个三边长度都不同。它们都是三角形，却有不同的边长特点。

如果换成观察角度，又可以区分三个角都小于 90°、有一个角等于 90°、有一个角大于 90°。

分类的依据不同，同一个三角形就可以同时有边长名称和角度名称。本节把这两条线索分开，再联系起来。

## 一、三角形由三个不共线的点连接而成

连接三个不共线的点 A、B、C，得到线段 AB、BC、CA，围成三角形。

用 △ABC 表示，读作“三角形 ABC”。

~~~text
三个顶点：A、B、C
三条边：AB、BC、CA
三个内角：∠BAC、∠ABC、∠ACB
~~~

内角指三角形内部、各顶点处由相邻两边形成的角。

若三点共线，就不能围成非退化的三角形。图中的边有可见粗细，但讨论的是理想线段与角。

## 二、边与对角对应

边 BC 不经过顶点 A，称为角 A 的对边；角 A 是边 BC 的对角。

~~~text
边 BC ↔ 角 A
边 CA ↔ 角 B
边 AB ↔ 角 C
~~~

只有在顶点处内角明确时，才把 ∠BAC 简称为角 A，其余类似。

说“相等边对应相等角”时，比较的是这些对角，不是随意选择与某条边挨着的角。

## 三、按边长：不等边三角形

三边长度两两不同的三角形，叫作**不等边三角形**。

例如三边为 4 厘米、5 厘米、6 厘米，三个长度各不相同，可以形成不等边三角形。

图上看起来长度略有差别，不足以作为准确判断。应依据给定数值、等长标记或已经证明的关系。

不等边不表示角度一定为钝角，也不表示哪条边必须朝下；它只说明边长关系。

## 四、按边长：等腰三角形

至少有两条边相等的三角形，叫作**等腰三角形**。

例如 AB = AC，通常把这两条边叫作腰，BC 叫作底边，角 A 叫作顶角，角 B、角 C 叫作底角。

底边是相对于选定相等两腰命名的，不要求图上一定水平朝下。

若整个三角形旋转，腰、底边和顶角的对应关系不变。

## 五、按边长：等边三角形

三边都相等的三角形，叫作**等边三角形**。

~~~text
AB = BC = CA
~~~

按照本节“至少两边相等”的定义，等边三角形是特殊的等腰三角形。

若需要把边长类型分成互不重叠的三组，可以写成：三边各不相同、恰有两边相等、三边都相等。

不同资料可能把“等腰”只用于恰有两边相等的情形。阅读时要看定义，本节采用包含等边三角形的约定。

## 六、三角形内角和为 180°

任何平面中的普通三角形，都有：

~~~text
角 A + 角 B + 角 C = 180°
~~~

可以过顶点 A 作一条与 BC 平行的直线。由内错角相等，B、C 处的两个内角可以对应到 A 两侧的角区域。

它们与角 A 在这条直线的一侧组成平角，所以三个内角合计 180°。

这把上一节的平行线性质与三角形联系起来，不依赖某幅图用量角器测得的近似结果。

## 七、按角度：锐角三角形

三个内角都是锐角的三角形，叫作**锐角三角形**。

~~~text
50°、60°、70°
~~~

三角都小于 90°，且合计 180°，是锐角三角形的角度组合。

只知道其中一个角是锐角，还不能判断整个三角形为锐角三角形。必须确认三个内角都为锐角。

## 八、按角度：直角三角形

有一个内角为 90° 的三角形，叫作**直角三角形**。

直角的两条邻边叫作直角边，直角的对边叫作斜边。

其余两角合计 90°，因此都是锐角。例如 30°、60°、90°。

三角形不可能有两个直角，因为两个直角已合计 180°，没有留下正的第三个内角。

斜边由直角的对边确定，不由图中是否倾斜决定。

## 九、按角度：钝角三角形

有一个内角为钝角的三角形，叫作**钝角三角形**。

~~~text
110°、40°、30°
~~~

钝角超过 90°，其余两角之和小于 90°，所以都为锐角。

三角形不能有两个钝角，否则它们的和已经大于 180°。

按最大内角判断很方便：最大角小于 90°为锐角三角形，等于 90°为直角三角形，大于 90°为钝角三角形。

## 十、等腰三角形的底角相等

若 AB = AC，则对边对应的角相等：

~~~text
∠ABC = ∠BCA
~~~

可以从顶点 A 作角平分线到 BC。以它为轴，两个等长的腰与相等的顶角部分对应，使三角形的两侧具有对称关系，底角因此相等。

更严格的证明可用后续学习的三角形全等。

反过来，一个三角形中两个角相等，它们的对边也相等。因此可以由边长条件或角度条件判断等腰。

## 十一、等边三角形每个内角为 60°

等边三角形的三边相等，所以三个对角也相等。

~~~text
每个内角 = 180° ÷ 3 = 60°
~~~

因此每个等边三角形都是锐角三角形，不可能是直角或钝角三角形。

反过来，若三角形三个内角都为 60°，由等角对等边，也可以判断三边相等。

## 十二、两种分类可以同时使用

| 边长条件与角度示例 | 边长名称 | 角度名称 |
| --- | --- | --- |
| 三边等长，60°、60°、60° | 等边 | 锐角 |
| 两腰相等，45°、45°、90° | 等腰 | 直角 |
| 两腰相等，30°、30°、120° | 等腰 | 钝角 |
| 两腰相等，70°、70°、40° | 等腰 | 锐角 |
| 30°、60°、90°，三角各不同 | 不等边 | 直角 |

角度各不同的三角形，三边也各不同；这是等角对等边、等边对等角关系的对应结果。

不能把“等腰”和“直角”当作互相排斥的名称。它们来自不同分类依据。

## 十三、演示：由等腰条件求角并分类

△ABC 中 AB = AC，顶角 A 为 40°。

~~~text
角 B = 角 C
角 B + 角 C = 180° − 40° = 140°
每个底角 = 140° ÷ 2 = 70°
~~~

三个内角为 40°、70°、70°，所以它既是等腰三角形，又是锐角三角形。

检验：40 + 70 + 70 = 180，两个底角相等。

若把“每个底角”误写成 140°，就没有把剩余角度分给两个相等底角。

## 十四、演示：用方程求三角形的角

一个等腰三角形的顶角是每个底角的 2 倍。设每个底角为 x°，顶角为 2x°。

~~~text
x + x + 2x = 180
4x = 180
x = 45
~~~

顶角为 90°，因此是等腰直角三角形。

这里内角和方程包含三个角，不是只把“顶角与一个底角”相加等于 180°。

## 十五、给定数值要先检查能否形成三角形

三个正角度必须合计 180°，才可能成为三角形的三个内角。例如 90°、60°、40°合计 190°，不能组成所描述的三角形。

三个正边长还需满足任意两边之和大于第三边。

~~~text
4、5、6：4 + 5 > 6，且其余两对也满足，可以组成三角形。
2、3、6：2 + 3 < 6，不能组成三角形。
2、3、5：2 + 3 = 5，只能拉成一直线，不形成三角形。
~~~

连接两端点时，绕过第三点的两段路径比直接线段长，帮助理解为什么三角形要求严格的大于关系。

下一节作图时会利用这一条件检查给定边长。

## 十六、图形标记与准确条件

同样的短划线标记表示边长相等，同样的角弧标记表示角度相等，小方角表示直角。

不同数量的划线或不同角标记，用来区分不同的等长、等角组，不表示它们彼此也相等。

示意图画得近似对称，不等于已经给出等腰条件；一条边看起来最长，也不能仅凭视觉完成准确分类。

用给定数值、明确标记和已经建立的性质判断，再用图形辅助理解。

## 十七、小结

三角形由三个不共线的点和连接它们的三条线段围成，三个内角合计 180°。

按边长可区分不等边、等腰与等边；本节把等边看作特殊等腰。按角度可区分锐角、直角与钝角三角形。

等腰三角形的底角相等，等边三角形每个内角为 60°。两种分类可以同时使用，例如等腰直角三角形。

判断时先检查给定角度或边长能否构成三角形，再依据准确条件分类。图形方向、边画多长和视觉印象都不能代替条件。
