# 分数与小数的四则运算

气温原来是 −0.5°C，升高了 1.2°C。最终温度可以用 `−0.5 + 1.2` 计算。

分数和小数带上正负号后，仍然可以进行加、减、乘、除。这一节先理解符号怎样影响运算，再把符号规则与已经学过的计算方法结合起来。

## 一、用数轴理解加法

在数轴上，加上正数表示向右移动，加上负数表示向左移动。移动的距离是所加的数的绝对值。

```text
起点：−0.5
加上 1.2：向右移动 1.2 个单位
先向右 0.5 到达 0，再向右 0.7 到达 0.7

−0.5 + 1.2 = 0.7
```

因此，气温从 −0.5°C 升高 1.2°C 后，变成 0.7°C。

运算结果的正负号表示最终在 0 的哪一侧，不一定与起点的符号相同。

## 二、同号相加

两个负数相加，可以理解为连续向左移动。先向左 0.6，再向左 0.4，一共向左 1 个单位：

```text
(−0.6) + (−0.4) = −1
```

所以，同号相加时，把绝对值相加，结果保留共同的符号。

```text
(+0.6) + (+0.4) = +1
(−1/4) + (−2/4) = −3/4
```

分数部分仍按原来的方法相加。上面的两个负分数分母相同，合并的是几个四分之一。

## 三、异号相加

两个数符号不同，表示相反方向的移动。我们观察 `−0.8 + 0.3`：

```text
向左 0.8，与向右 0.3 抵消一部分
还剩向左 0.5
−0.8 + 0.3 = −0.5
```

异号相加时，先比较绝对值，用较大的绝对值减去较小的绝对值，结果取绝对值较大的那个数的符号。

```text
−0.3 + 0.8 = 0.5
(−3/4) + 1/4 = −1/2
```

如果绝对值相等，相反方向恰好抵消，结果为 0：

```text
(−0.7) + 0.7 = 0
```

## 四、异分母的加法先统一份的大小

计算 `(−1/2) + 3/4`，先把二分之一改写成两个四分之一：

```text
(−1/2) + 3/4
= (−2/4) + 3/4
= 1/4
```

负方向的 2 份与正方向的 3 份抵消后，剩下正方向的 1 份。

加法中不能把分子、分母分别相加。通分是为了让两边表示相同大小的份，再合并这些份。

下一节会进一步展开分数加减法的计算方法。

## 五、减法转化为加相反数

减去一个数，等于加上它的相反数：

```text
a − b = a + (−b)
```

这让我们可以用加法的方向规则理解减法。

```text
0.6 − 0.9 = 0.6 + (−0.9) = −0.3
0.6 − (−0.9) = 0.6 + 0.9 = 1.5
```

减去正数，对应向左移动；减去负数，对应向右移动。

只改变被减去的那个数的符号，第一个数保持不变。

## 六、两个负数相减

计算 `(−0.7) − (−0.2)`，先把减法转化成加法：

```text
(−0.7) − (−0.2)
= (−0.7) + 0.2
= −0.5
```

第一个数 −0.7 没有改变，第二个数 −0.2 换成了它的相反数 0.2。

再看一个分数例子：

```text
(−1/3) − (−1/2)
= (−1/3) + 1/2
= (−2/6) + 3/6
= 1/6
```

两个负数相减，结果不一定是负数，要看相反数相加后的结果。

## 七、小数加减仍按位值计算

计算 `(−1.25) + 0.8`，先判断结果符号。1.25 比 0.8 大，所以结果为负。

再计算绝对值的差，按小数点对齐：

```text
  1.25
− 0.80
------
  0.45
```

所以 `(−1.25) + 0.8 = −0.45`。

符号规则决定怎样合并两个带方向的量，小数位值决定具体数值怎样计算。不能把 0.8 当作 0.08 来对齐。

## 八、异号相乘为什么得到负数

每小时水位下降 0.4 m，持续 3 小时。把每小时的变化记作 −0.4 m，总变化是三个相同的负变化相加：

```text
(−0.4) × 3
= (−0.4) + (−0.4) + (−0.4)
= −1.2
```

总变化是 −1.2 m，表示下降 1.2 m。

乘数也可以是正分数。例如，半小时的变化是每小时变化的一半：

```text
(−0.4) × 1/2 = −0.2
```

负数乘正数得到负数，绝对值按原来的乘法计算。交换两个乘数的顺序，积不变，所以正数乘负数也得到负数。

## 九、两个负数相乘为什么得到正数

乘法仍要满足分配律。我们用 `0.5 + (−0.5) = 0` 观察：

```text
(−0.4) × [0.5 + (−0.5)] = (−0.4) × 0 = 0
```

按分配律展开：

```text
(−0.4) × 0.5 + (−0.4) × (−0.5) = 0
```

第一项是 −0.2。为了使两项相加得到 0，第二项必须是 0.2。因此：

```text
(−0.4) × (−0.5) = 0.2
```

两个负数相乘得到正数，是保持分配律和相反数关系一致的结果。

## 十、乘法的符号规则

两个非零数相乘，同号得正，异号得负；积的绝对值等于两个因数的绝对值的积。

| 因数符号 | 积的符号 | 例子 |
| --- | --- | --- |
| 正、正 | 正 | `0.4 × 0.5 = 0.2` |
| 负、负 | 正 | `(−0.4) × (−0.5) = 0.2` |
| 正、负 | 负 | `0.4 × (−0.5) = −0.2` |
| 负、正 | 负 | `(−0.4) × 0.5 = −0.2` |

例如：

```text
(−2/3) × 3/4
= −(2 × 3)/(3 × 4)
= −1/2
```

分数乘法仍然把分子相乘、分母相乘，可以先约分。符号规则另外决定积的正负。

## 十一、用乘法理解除法的符号

除法与乘法互为逆运算。计算 `(−1.2) ÷ 0.4`，就是找一个数，使它乘 0.4 得到 −1.2。

```text
(−3) × 0.4 = −1.2
所以 (−1.2) ÷ 0.4 = −3
```

计算 `(−1.2) ÷ (−0.4)`，则要找一个数，使它乘 −0.4 得到 −1.2：

```text
3 × (−0.4) = −1.2
所以 (−1.2) ÷ (−0.4) = 3
```

因此，两个非零数相除，也遵循同号得正、异号得负。商的绝对值用两个数的绝对值相除。

## 十二、除以分数仍然乘倒数

计算 `(−3/4) ÷ 1/2`，结果为负，绝对值是 `3/4 ÷ 1/2`：

```text
(−3/4) ÷ 1/2
= (−3/4) × 2
= −3/2
```

如果除数也是负数，倒数也带负号：

```text
(−3/4) ÷ (−1/2)
= (−3/4) × (−2)
= 3/2
```

`−1/2` 与 `−2` 的乘积是 1，所以它们互为倒数。除以一个非零数，等于乘这个数的倒数。

下一节之后的「分数乘法与除法」会进一步讲解约分、带分数和多步计算。

## 十三、小数乘除法的数值计算

计算 `(−0.6) × (−0.25)`，先判断同号相乘，结果为正，再计算绝对值：

```text
6 × 25 = 150
0.6 与 0.25 一共有三位小数
0.6 × 0.25 = 0.150 = 0.15
```

因此，原式等于 0.15。

计算 `0.84 ÷ (−0.2)`，异号相除，结果为负。计算绝对值时，被除数和除数同时乘 10：

```text
0.84 ÷ 0.2 = 8.4 ÷ 2 = 4.2
所以 0.84 ÷ (−0.2) = −4.2
```

不能只移动除数的小数点。被除数与除数必须作相同倍数的变化，商才保持不变。

## 十四、零在四则运算中

加上或减去 0，数不变；任何数乘 0，结果为 0；0 除以非零数，结果为 0。

```text
−0.6 + 0 = −0.6
−0.6 − 0 = −0.6
(−0.6) × 0 = 0
0 ÷ (−0.6) = 0
```

0 既不是正数，也不是负数，不能把结果 0 判为“同号得正”或“异号得负”。

除数不能为 0。例如，`0.6 ÷ 0` 没有定义，因为不存在一个数乘 0 得到 0.6；`0 ÷ 0` 也没有定义，因为它不能确定唯一的商。

## 十五、混合分数与小数时选择统一形式

计算 `(−3/4) + 0.6`，可以都化成有限小数：

```text
(−3/4) + 0.6
= −0.75 + 0.6
= −0.15
```

也可以都化成分数：

```text
(−3/4) + 3/5
= (−15/20) + 12/20
= −3/20
```

`−3/20 = −0.15`，两种方法结果相同。

如果出现 `1/3` 等不能化成有限小数的分数，通常保留分数更便于准确计算：

```text
(−1/3) + 0.5
= (−1/3) + 1/2
= 1/6
```

不要先把 `1/3` 近似写成 0.33，再把结果当作准确值。

## 十六、混合运算的顺序

带正负号的分数和小数，仍遵循原来的运算顺序：先算括号内，再算乘除，最后算加减。同一级运算从左到右进行。

例如：

```text
−0.5 + 0.6 ÷ (−0.3)
= −0.5 + (−2)
= −2.5
```

先做除法，不能先把 −0.5 与 0.6 相加。

再看连续除法：

```text
(−1.2) ÷ 0.3 ÷ (−2)
= (−4) ÷ (−2)
= 2
```

不能把后两个数先相除，否则就改变了原式的运算顺序。

## 十七、含括号的分数与小数混合运算

我们一起计算 `[(−1/2) + 0.75] ÷ (−0.5)`。先统一括号内的表示，再计算括号内的和：

```text
[(−1/2) + 0.75] ÷ (−0.5)
= (−0.5 + 0.75) ÷ (−0.5)
= 0.25 ÷ (−0.5)
= −0.5
```

也可以全部化成分数：

```text
[(−1/2) + 3/4] ÷ (−1/2)
= 1/4 ÷ (−1/2)
= 1/4 × (−2)
= −1/2
```

两种算法一致。最后用乘法检验：`(−0.5) × (−0.5) = 0.25`，正好得到除法中的被除数。

## 十八、用分配律简化计算

分配律对正负分数和小数仍然成立。例如：

```text
(−0.25) × 3.6 + (−0.25) × 0.4
= (−0.25) × (3.6 + 0.4)
= (−0.25) × 4
= −1
```

两个乘积有相同因数 −0.25，可以把它提出来。合并后，3.6 与 0.4 正好凑成 4，计算更方便。

简便计算必须依据运算规律。减法和除法不能随意交换顺序，也不能随意改变括号。

## 十九、检查符号、大小和逆运算

计算完成后，可以从三个方面检查。

- 符号是否合理。例如两个负数相乘，非零结果应为正数。
- 绝对值是否合理。例如乘以 0.5，结果的绝对值应是原来的一半；除以 0.5，结果的绝对值应是原来的两倍。
- 能否用逆运算回到原数。例如 `(−0.9) ÷ 0.3 = −3`，检查 `−3 × 0.3 = −0.9`。

结果不一定因为进行了乘法就变大，也不一定因为进行了除法就变小。对于带负号的数，先看绝对值怎样变化，再看符号。

## 二十、完整演示：连续两次水位变化

以水池的一条标记线为 0，高于标记线为正。水位起初在标记线下 0.5 m，先上升 `3/4 m`，再下降 0.2 m。

我们先把位置与变化分别表示出来：

```text
初始位置：−0.5 m
第一次变化：+3/4 m
第二次变化：−0.2 m
```

把分数化成小数，沿着变化顺序计算：

```text
最终位置的数值 = −0.5 + 0.75 − 0.2
               = 0.25 − 0.2
               = 0.05
```

最终水位在标记线上方 0.05 m。

也可以先求两次变化的合计：上升 0.75 m，又下降 0.2 m，合计上升 0.55 m。从原来下方 0.5 m 上升 0.55 m，恰好到达上方 0.05 m，与计算结果一致。

这里的 0.55 m 是总变化量，0.05 m 是最终位置，不能把它们混为同一个数量。

## 二十一、小结

正负分数和小数的加法可以用相反方向的移动理解：同号相加，绝对值相加并保留共同符号；异号相加，比较绝对值后求差，绝对值相等时结果为 0。减法可以转化为加上相反数。

两个非零数相乘或相除，同号得正，异号得负。数值部分继续使用分数和小数的计算方法，除以非零数可以转化为乘它的倒数。除数不能为 0。

混合运算时，选择便于准确计算的表示，遵守括号、乘除和加减的顺序。最后用符号、大小、逆运算和实际数量关系检查结果。
