# 圆周长

给一个圆形盒盖的边缘绕上一圈细线，再把细线拉直，就能观察盒盖边缘一周有多长。

长方形的周长可以把四条边相加。圆的边界是曲线，这一节学习怎样用直径或半径求这条曲线一周的长度。

## 一、圆周与圆周长

圆的边界叫作圆周。沿圆周绕一周的长度，叫作圆周长，通常用字母 `C` 表示。

```text
圆周：围成圆的封闭曲线
圆周长：这条曲线一周的长度
```

圆周长使用 cm、m 等长度单位，不用 cm²、m² 等面积单位。

绕盒盖一圈所需的细线长度，就是盒盖的圆周长；圆内能覆盖多大的区域，则属于下一节的圆面积。

## 二、用细线把曲线长度转成直线长度

我们一起观察测量过程：

1. 让细线贴着圆形盒盖边缘绕一周，不重叠、不留空隙。
2. 标记起点和一周结束的位置。
3. 把这段细线拉直，但不拉伸。
4. 用尺测量两个标记之间的距离。

这个过程把曲线的一周长度转成可以用直尺测量的长度。

细线没有贴紧、绕了多于一圈，或拉直时被拉长，都会影响结果。实际测量得到的长度通常是近似值。

## 三、再测量圆的直径

直径是通过圆心、两端都在圆周上的线段。半径从圆心连接到圆周，通常用 `r` 表示；直径用 `d` 表示。

```text
圆周上的 A ─── 圆心 O ─── 圆周上的 B
AO = r，OB = r，AB = d
d = 2r
```

沿圆绕一周的长度是 `C`，穿过圆心横跨圆的长度是 `d`。它们是不同的长度。

测量直径时必须经过圆心，不能把任意一条连接圆周上两点的线段都当作直径。

## 四、比较圆周长与直径

下面是一组示意测量记录，不同大小的圆都测量圆周长与直径：

| 圆 | 直径 d（cm） | 测得圆周长 C（cm） | C ÷ d |
| --- | ---: | ---: | ---: |
| 甲 | 5 | 约 15.7 | 约 3.14 |
| 乙 | 10 | 约 31.4 | 约 3.14 |
| 丙 | 20 | 约 62.8 | 约 3.14 |

圆越大，直径越长，圆周长也越长。但圆周长除以直径，总是接近同一个数。

这些测量帮助我们发现规律，不能单靠有限次测量证明所有圆都如此。数学上，每个圆的圆周长与直径之比是同一个固定数。

## 五、圆周率 π

圆周长与直径的固定比值叫作圆周率，用符号 `π` 表示，读作“派”。

```text
π = 圆周长 ÷ 直径
π ≈ 3.14159…
```

π 的小数位无限延伸，而且不循环。常用 3.14 或 22/7 作为近似值：

```text
π ≈ 3.14
π ≈ 22/7
```

π 不是 3.14 的另一个准确写法，22/7 也不是 π 的准确值。计算时要根据给定要求选择近似值。

π 是两个长度相除得到的比值，不带 cm、m 等长度单位。

## 六、由直径得到圆周长公式

由 `C ÷ d = π`，两边同时乘直径 `d`，得到：

```text
C = πd
```

这表示圆周长是直径的 π 倍，稍多于直径的 3 倍。

如果圆的直径为 10 cm：

```text
C = π × 10 = 10π cm
```

`10π cm` 是准确表达。如果按 `π ≈ 3.14` 计算，则 `C ≈ 31.4 cm`。

## 七、由半径得到圆周长公式

因为直径是半径的 2 倍，把 `d = 2r` 代入公式：

```text
C = πd = π × 2r = 2πr
```

因此，两种写法表达同一个关系：

```text
C = πd = 2πr
```

`2πr` 表示 `2 × π × r`。半径乘 2 先得到直径，再乘 π 得到圆周长。

计算前确认给定的是半径还是直径，不能把直径再次乘 2。

## 八、已知直径求圆周长

圆形桌面的直径为 1.2 m，以 `π ≈ 3.14` 计算桌面边缘一周的长度。

```text
C = πd
C ≈ 3.14 × 1.2
C ≈ 3.768 m
```

若要求保留两位小数，可以写成约 3.77 m。

这里的 3.768 m 已经使用了 π 的近似值，仍是近似结果，并不是圆周长的准确值。

## 九、已知半径求圆周长

一个圆形图案半径为 7 cm，按给定的 `π ≈ 22/7` 计算：

```text
C = 2πr
C ≈ 2 × 22/7 × 7
C ≈ 44 cm
```

也可以先求直径 14 cm，再计算 `14 × 22/7 = 44`。

虽然数值计算恰好得到整数 44，它仍是使用 π 近似值所得的近似周长。准确表达是 `14π cm`。

## 十、已知圆周长反求直径与半径

由 `C = πd`，可以得到：

```text
d = C ÷ π
r = C ÷ (2π)
```

一个圆的准确周长为 `18π cm`：

```text
d = 18π ÷ π = 18 cm
r = 18 ÷ 2 = 9 cm
```

如果记录的周长约为 62.8 cm，按 `π ≈ 3.14` 反求，则直径约为 `62.8 ÷ 3.14 = 20 cm`，半径约为 10 cm。

周长本身是测量近似值时，反求结果也应保留“约”的含义。

## 十一、圆扩大时周长怎样变化

两个圆的直径分别为 4 cm 和 12 cm，直径比为 `1 : 3`。

```text
周长分别为 4π cm 与 12π cm
周长比 = 4π : 12π = 1 : 3
```

直径扩大到原来的 3 倍，半径和圆周长也都扩大到原来的 3 倍。

圆周长与直径有固定比值 π，属于正比例关系。这个长度规律不能直接作为圆面积的变化规律，面积将在下一节单独讨论。

## 十二、半圆弧长不等于半圆周长

圆的一半曲线叫作半圆弧，它的长度是圆周长的一半：

```text
半圆弧长 = C ÷ 2 = πr
```

但半圆形区域的完整边界，还包括连接弧两端的直径：

```text
半圆周长 = 半圆弧长 + 直径
         = πr + 2r
```

例如直径 10 cm 的半圆，弧长为 `5π cm`，完整周长为 `5π + 10 cm`；使用 3.14 计算，分别约为 15.7 cm 和 25.7 cm。

求边界长度时，先沿边界走一圈，确认曲线与直线段是否都已计入。

## 十三、四分之一圆的边界

把一个圆沿两条互相垂直的直径分成四个相同的部分。每部分的曲线占圆周的四分之一：

```text
四分之一圆弧长 = 2πr ÷ 4 = πr/2
```

一个四分之一圆形区域的完整边界，由这段弧和两条半径组成：

```text
周长 = πr/2 + 2r
```

半径为 4 cm 时，完整周长为 `2π + 8 cm`，按 `π ≈ 3.14` 计算约为 14.28 cm。

只求圆弧长度时不加半径；求整个区域的周长时，则要计入两条直边。

## 十四、滚动一周对应的路程

一个圆轮沿直线滚动，例子约定它不打滑。轮缘上的起始点接触地面后，滚动一整周再次接触地面，前进的路程等于圆周长。

圆轮直径为 50 cm，滚动 4 整周：

```text
一周路程 = 50π cm
四周路程 = 4 × 50π = 200π cm
```

使用 `π ≈ 3.14`，路程约为 628 cm，也就是 6.28 m。

“不打滑”保证滚动周数与路程对应。若轮子原地打滑，就不能直接用周数乘圆周长求实际前进路程。

## 十五、完整演示：给半圆边框贴带

一块半圆形板的直径为 28 cm，要给完整边界贴上一层装饰带。例子不计接头和损耗，按 `π ≈ 22/7` 计算。

先分清边界包含什么：一条半圆弧和一条直径。

```text
完整圆周长 ≈ 28 × 22/7 = 88 cm
半圆弧长 ≈ 88 ÷ 2 = 44 cm
完整边界长 ≈ 44 + 28 = 72 cm
```

所以所需装饰带约为 72 cm。

也可以先求半径 14 cm，用 `πr + 2r` 检查：`22/7 × 14 + 28 = 72`。

如果只贴弯曲的边缘，所需长度约为 44 cm。两种长度的差别来自是否包括直径，不是计算方法不同。

## 十六、检查公式、单位与近似值

计算前后可以沿着三个关系检查：

- 半径与直径是否满足 `d = 2r`。
- 完整圆周长是否略大于直径的 3 倍，且 `C ÷ d` 接近 π。
- 结果是否使用长度单位，是否按条件标明近似关系。

对于半圆或四分之一圆，额外检查问的是弧长还是完整周长。反求结果时，再代入圆周长公式核对。

π 的近似值应按条件选择，并在同一次计算中保持一致。若最后要求四舍五入，尽量保留中间计算精度，再在末尾取近似值。

## 十七、小结

圆周长是沿圆周一周的长度。每个圆的圆周长与直径之比都等于圆周率 π，因此 `C = πd = 2πr`。

已知直径或半径可以求圆周长，已知圆周长也可以反求直径与半径。使用 3.14 或 22/7 代替 π 时，得到的是近似结果。

求部分圆形区域的周长，要沿完整边界确认哪些圆弧和直线段需要计入，并始终使用长度单位。
