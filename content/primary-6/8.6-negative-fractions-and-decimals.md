# 负分数与负小数

气温可以是零下 2°C，也可以是零下半摄氏度。零下半摄氏度可以记作 `−0.5°C`，也可以记作 `−1/2°C`。

负数不只有负整数。分数和小数也可以带负号，表示基准以下或规定负方向上的数量。

## 一、从零下半摄氏度开始

把温度计上 0°C 到 −1°C 之间的距离平均分成两份，中间的刻度就是 −0.5°C。

```text
  1°C ──
       │
 0.5°C ──
       │
  0°C ──  基准
       │
−0.5°C ──  零下半摄氏度
       │
 −1°C ──
```

这里相邻刻度的距离都表示 0.5°C；1°C 到 0°C 的距离是其中两段的长度。

`−0.5` 表示比 0 低 0.5。因为 `0.5 = 1/2`，这个温度也可以写成 `−1/2°C`。

## 二、负分数和负小数

在正分数或正小数前面加上负号，就得到对应的负数。

```text
正分数：1/2、3/4、7/5
对应的负分数：−1/2、−3/4、−7/5

正小数：0.5、0.75、1.4
对应的负小数：−0.5、−0.75、−1.4
```

负分数和负小数都小于 0。它们可以表示零下温度、低于基准的高度，也可以表示某个规定方向上的位置或变化。

## 三、读法和负号的范围

```text
−3/4：读作“负四分之三”
−0.75：读作“负零点七五”
−1.25：读作“负一点二五”
```

`−3/4` 表示整个 `3/4` 的负数，可以写成 `−(3/4)`。本节统一把负号写在整个分数前面，分母写成正整数。

负号是数的一部分，不能随意省略。`−0.75` 与 `0.75` 表示零两侧的不同数。

## 四、数轴上的零两侧

在数轴上，0 是原点，通常规定向右为正方向。正数在 0 右边，负数在 0 左边。

把每一个单位平均分成两份，就可以标出半个单位的位置：

```text
←───●──────●──────●──────●──────●───→
   −1    −0.5     0     0.5     1
```

相邻两点的距离都是 0.5 个单位。`−0.5` 从 0 向左半个单位，`0.5` 从 0 向右半个单位。

数轴上的一个单位，可以代表 1°C、1 m 或纯粹的数值单位，具体含义要看情境。

## 五、在数轴上表示负分数

表示 `−3/4` 时，先找到 0 和 −1，再把它们之间的距离平均分成 4 份。

```text
←───●──────●──────●──────●──────●───→
   −1    −3/4   −1/2   −1/4     0
```

从 0 向左走 3 个四分之一单位，得到 `−3/4`。它在 −1 与 0 之间，到 0 的距离是 `3/4` 个单位。

这里的四分之一是把一个单位平均分成 4 份得到的长度。负号表示点在 0 的左侧，不表示长度本身是负的。

## 六、在数轴上表示负小数

表示 `−0.3` 时，把 −1 到 0 之间的距离平均分成 10 份。每份是 0.1 个单位。

从 0 向左走 3 份，就到达 `−0.3`。

```text
从 0 向左走 0.1：−0.1
从 0 向左走 0.2：−0.2
从 0 向左走 0.3：−0.3
```

如果要表示 `−0.35`，它在 −0.3 与 −0.4 之间。再把这一小段平均分成 10 份，每份是 0.01 个单位，从 −0.3 向左走 5 份即可。

定位时先确定单位长度，再根据十分位、百分位等逐步细分。

## 七、负数也可以离零超过一个单位

`−1.25` 表示从 0 向左 1.25 个单位。可以先向左走一个完整单位，到 −1，再向左走四分之一个单位。

```text
−1.25 = −(1 + 0.25)
```

它在 −2 与 −1 之间。负数前面的负号作用于整个 1.25，不能只理解成整数部分为负。

同样，`−7/4` 到 0 的距离是 `7/4`，也就是 `1 又 3/4` 个单位。

## 八、负带分数表示整个数的负数

`负 1 又 1/4` 表示 `1 又 1/4` 的相反数，记作 `−(1 又 1/4)`。

```text
−(1 又 1/4)
= −(1 + 1/4)
= −5/4
= −1.25
```

负号作用于整数部分与分数部分组成的整个数。

它与 `−1 + 1/4` 不同。后者表示从 −1 向右移动四分之一个单位，得到 −0.75。使用括号可以看清负号的范围。

## 九、负分数化小数

先把对应的正分数化成小数，再取它的相反数：

```text
3/4 = 3 ÷ 4 = 0.75
所以 −3/4 = −0.75
```

两种表示到 0 的距离相同，又都在 0 左边，因此表示数轴上的同一个点。

再看一个需要三位小数的例子：

```text
7/8 = 0.875
所以 −7/8 = −0.875
```

转换时，分数的数值大小和负方向都要保留。

## 十、负小数化分数

先按位值把对应的正小数化成分数并约分，再保留原来的负号。

```text
0.35 = 35/100 = 7/20
所以 −0.35 = −7/20
```

再看 `−0.045`：

```text
0.045 = 45/1000 = 9/200
所以 −0.045 = −9/200
```

十分位的占位零仍然决定后面数字的位值。添上负号不会改变小数位值的意义。

## 十一、大于一个单位的量也能互化

把 `−2.375` 化成分数，先处理 2.375：

```text
2.375 = 2375/1000 = 19/8 = 2 又 3/8
```

所以：

```text
−2.375 = −19/8 = −(2 又 3/8)
```

反过来，把 `−(2 又 3/8)` 化成小数，先算出 `2 + 3/8 = 2.375`，再写成 −2.375。

不论使用小数、假分数还是带分数，都表示从 0 向左 2.375 个单位的位置。

## 十二、末尾零与零的符号

小数末尾添上或去掉 0，不改变数值，这对负小数也成立：

```text
−0.5 = −0.50 = −0.500 = −1/2
```

但 `−0.05` 与 `−0.5` 不相等，因为到 0 的距离分别是 0.05 和 0.5。

0 既不是正数，也不是负数。0 的相反数仍是 0：

```text
−0 = 0
−0.0 = 0
```

一个非常接近 0 的负数仍然是负数，例如 `−0.001`。不能因为小数部分有很多零，就把它当作 0。

## 十三、相反数与绝对值

`3/4` 和 `−3/4` 到 0 的距离相等，方向相反，它们互为相反数。`0.6` 和 `−0.6` 也互为相反数。

一个数到 0 的距离叫作它的绝对值，用两条竖线表示：

```text
|−3/4| = 3/4
|−0.6| = 0.6
|0| = 0
```

负数的绝对值是正数，因为距离不能是负的。绝对值告诉我们离 0 多远，负号则说明点位于 0 的哪一侧。

例如，点的位置是 −0.6 m，它到原点的距离是 0.6 m。位置和距离表达的信息不同。

## 十四、先说明基准与正方向

同样是 `−0.75 m`，在不同情境中可能有不同含义：

| 规定 | `−0.75 m` 的含义 |
| --- | --- |
| 以水面为 0，高于水面为正 | 低于水面 0.75 m |
| 以标记点为 0，向右为正 | 在标记点左边 0.75 m |
| 用正数表示水位上升的变化量 | 水位下降了 0.75 m |

前两行描述位置，第三行描述变化量。读数时，要先看记录的是哪一种数量。

下降了 0.75 m，不一定意味着最终位置是 −0.75 m；还要知道开始时的位置。

## 十五、负号与减号

`−0.5` 前面的符号是负号，说明这个数是负数。`2 − 0.5` 中间的符号是减号，表示减法运算。

```text
−0.5：一个负数
2 − 0.5：从 2 减去 0.5
```

写出带负数的算式时，可以用括号标明整个数。例如：

```text
(−0.5) + 2
```

括号中的 `−0.5` 是一个整体。负分数同样可以写成 `(−3/4)`，以免与前后的运算符号混淆。

## 十六、循环小数仍要保留负号

由 `1/3 = 0.333…`，可以得到：

```text
−1/3 = −0.333…
```

省略号表示数字 3 一直重复，这是一种准确表示。

如果按四舍五入保留两位小数，先对对应的正数取近似值，再保留负号：

```text
1/3 ≈ 0.33
−1/3 ≈ −0.33
```

`−0.33 = −33/100`，不能用等号把它当成准确的 `−1/3`。反向转换近似值，也不会恢复已经舍去的信息。

## 十七、完整演示：水面下的位置

一个水池中，以水面为 0，高于水面为正。测量点在水面下 `1 又 3/4 m`，我们一起写出它的位置。

先判断方向：测量点低于水面，所以位置用负数表示。

```text
位置 = −(1 又 3/4) m
```

把带分数化成假分数：

```text
1 又 3/4 = 7/4
位置 = −7/4 m
```

再把对应的正分数化成小数，并保留负号：

```text
7/4 = 1.75
位置 = −1.75 m
```

三种写法都表示水面下同一个位置。测量点到水面的距离是 1.75 m，距离本身写成正数。

反向检查：`1.75 = 175/100 = 7/4 = 1 又 3/4`，并且测量点位于基准下方，所以位置仍应带负号。

## 十八、小结

分数和小数也可以是负数。负号表示数在 0 的负方向一侧，分数或小数部分确定它到 0 的距离。

在数轴上表示负分数和负小数，先确定单位长度，再把单位细分，从 0 向左找到对应位置。负带分数的负号作用于整个带分数。

互化时，先转换对应的正数，再保留负号；取近似值时使用 `≈`。解释实际数量时，要说明基准和方向，并区分位置、距离与变化量。
