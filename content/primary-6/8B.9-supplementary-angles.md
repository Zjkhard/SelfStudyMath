# 互补角

一条直线上的点 O 引出一条射线，把直线一侧的平角分成两个角。其中一个是 65°，另一个就是 `180° − 65° = 115°`。

65°与 115°的和是 180°，它们互为补角。这一节进一步理解这种度数关系，并把它与相邻位置、对顶角和互余关系区分开来。

## 一、从平角的分割开始

A、O、C 在同一直线上，O 位于 A 与 C 之间。射线 OB 从 O 向直线一侧伸出。示意图不代表准确角度。

```text
         B
        ↗
       /
A ←───O────────→ C
```

OA 与 OC 是相反射线，∠AOC 为平角。∠AOB 与 ∠BOC 恰好覆盖这一侧的平角，没有重叠或遗漏。

```text
∠AOB + ∠BOC = 180°
```

这里两角既相邻，又具有和为 180°的关系。

## 二、互补角的含义

如果两个角的度数和为 180°，就说它们互为补角，也可以说它们是互补角。

```text
65° + 115° = 180°
65° 的补角是 115°
115° 的补角是 65°
```

“互为”说明关系是双向的。说某个角是补角时，要说明它是谁的补角。

互补关系只规定两个角的度数和，不规定它们必须相等。

## 三、互补角不一定相邻

两个分别画在不同位置的角，一个为 72°，一个为 108°，仍然互补：

```text
72° + 108° = 180°
```

它们可以有不同的顶点，也不一定有公共边。

邻补角同时满足相邻的位置条件和互补的度数条件。因此，邻补角一定互补，互补角却不一定是邻补角。

单凭“两个角相邻”也不能断定互补。若外侧两边不组成相反射线，整体角不一定是平角。

## 四、求已知角的补角

已知角为 47°，它的补角与它合计为 180°：

```text
补角 = 180° − 47° = 133°
```

检查：`47° + 133° = 180°`。

如果已知角为 128.5°，补角为 `180° − 128.5° = 51.5°`。小数角度同样适用。

图形中的角度如果由条件准确给定，按关系计算得到的补角也可以准确表示；若原角是测量近似值，结果也应保留近似含义。

## 五、互补角可能是哪类角

本节主要讨论大于 0°、小于 180°的角。若一个角是锐角，它的补角是钝角；若一个角是钝角，它的补角是锐角。

```text
40° 的补角：140°
140° 的补角：40°
90° 的补角：90°
```

两个直角互补。两个相等的互补角，都是 `180° ÷ 2 = 90°`。

两个锐角的和小于 180°，不能互补；两个钝角的和大于 180°，也不能互补。

如果纳入零角，0°与 180°的和同样为 180°。本节的普通分角图主要使用两个正度数的角，不把这个边界情形当作一般图形。

## 六、同角或等角的补角相等

如果 α 与 β 都是 58°角的补角：

```text
α = 180° − 58° = 122°
β = 180° − 58° = 122°
```

所以 α = β。

如果两个原来的角度数相等，即使位置不同，从相同的 180°中减去相等度数，也得到相等的补角。

这个结论要求对应同角或等角，不能说“所有补角都相等”。

## 七、对比互余与互补

| 关系 | 两角的和 | 已知角为 35°时 |
| --- | --- | --- |
| 互余 | 90° | 余角为 55° |
| 互补 | 180° | 补角为 145° |

同一个锐角的补角，比它的余角大 90°，因为两次减去同一个角，整体却相差 90°。

一个钝角没有本节意义下的正度数余角，但有正度数的补角。例如 120°的补角是 60°。

读条件时，先确认是“互余”还是“互补”，不能只看到“还差一个角”就使用 90°。

## 八、已知互补与差求两个角

两个角互补，较大角比较小角大 36°。设较小角为 x°，较大角为 `(x + 36)°`：

```text
x + (x + 36) = 180
2x + 36 = 180
2x = 144
x = 72
```

两个角为 72°和 108°。

检查：`72° + 108° = 180°`，`108° − 72° = 36°`。两个条件都成立。

如果只知道互补，可能有许多组角度，不能确定它们各是多少。

## 九、已知互补与比求两个角

两个角互补，度数比为 `2 : 3`。总共 5 份，对应 180°：

```text
每份 = 180° ÷ 5 = 36°
第一个角 = 36° × 2 = 72°
第二个角 = 36° × 3 = 108°
```

也可以设两个角为 2x°与 3x°，列 `2x + 3x = 180`，得到 x = 36。

比描述两个角的相对大小，互补条件确定共同的一份是多少。角度计算使用 °，不是长度单位。

## 十、两个互补角中再平分一个角

OA 与 OC 为相反射线，∠BOC = 64°。OD 是 ∠AOB 的角平分线，位于 ∠AOB 内部。

先求完整的邻补角：

```text
∠AOB = 180° − 64° = 116°
```

再按角平分线关系求两个部分：

```text
∠AOD = ∠DOB = 116° ÷ 2 = 58°
```

沿平角检查：`58° + 58° + 64° = 180°`。

不能把 64°的一半当作所求角，因为被平分的是 116°的 ∠AOB，不是 ∠BOC。

## 十一、结合对顶角与补角

直线 AC 与 BD 相交于 O，OA 与 OC、OB 与 OD 分别为相反射线，已知 ∠AOB = 73°。

```text
对顶角 ∠COD = 73°
邻补角 ∠BOC = 180° − 73° = 107°
对顶角 ∠DOA = 107°
```

每个 73°角与相邻的 107°角互补；两个 73°角互为对顶角，却不互补，因为它们的和为 146°。

只有两条直线垂直时，对顶角都为 90°，这时相对的两个角也恰好互补。位置关系和度数关系可以同时成立，但不能默认如此。

## 十二、多个角合计为平角

一条直线的一侧被依次分成 35°、60°和一个未知角，三个区域无重叠无遗漏。

```text
未知角 = 180° − 35° − 60° = 85°
```

这三个角合计为 180°，不表示任意两个角互补。

前两个角合成 95°，这个合成角与剩下的 85°角才互补。写关系前，先判断两个角各自覆盖哪个区域。

## 十三、完整演示：角度表达式与邻补关系

A、O、C 在同一直线上，O 位于 A 与 C 之间，OB 从 O 向直线一侧伸出。∠AOB 标为 `(3x + 12)°`，∠BOC 标为 `(2x + 18)°`。

先根据相反射线确定这两个角是邻补角：

```text
(3x + 12) + (2x + 18) = 180
5x + 30 = 180
5x = 150
x = 30
```

代回得到：

```text
∠AOB = 3 × 30 + 12 = 102°
∠BOC = 2 × 30 + 18 = 78°
```

检查：`102° + 78° = 180°`，一个钝角与一个锐角恰好组成平角。

若把 OB 反向延长得到 OD，∠COD 就是 ∠AOB 的对顶角，等于 102°；∠AOD 等于 78°。四角合计为 360°，与交点一周关系一致。

## 十四、小结

两个角的度数和为 180°，就互为补角。互补不要求相邻；邻补角则同时满足相邻且外侧边为相反射线的位置条件。

求已知角的补角，用 180°减去它的度数。同角或等角的补角相等，两个相等的互补角都是直角。

求未知角时，区分互余、互补、对顶和周角关系。先明确整体与角的范围，再列式或列方程，最后代回度数并检查和是否符合条件。
