# 多边形中的角一

三角形的内角和是 180°，四边形的内角和是 360°。如果图形有五条边、六条边，内角和又是多少？

我们可以把多边形分成已经熟悉的三角形。本节主要讨论边界不交叉的凸多边形，再用内角和求未知角。

## 一、多边形的内角

多边形由直线段首尾相连围成。相邻两条边在顶点处形成位于图形内部的角，叫作内角。

```text
五边形 ABCDE：沿边界依次经过 A、B、C、D、E，再回到 A
5 条边、5 个顶点、5 个内角
```

名称中的顶点顺序要沿实际边界排列。随意连接不相邻的顶点，可能画出交叉线段，改变图形。

本节的凸多边形没有向内部凹入的顶点，每个内角都小于 180°。

## 二、对角线连接不相邻顶点

连接多边形中两个不相邻顶点的线段，叫作对角线。

例如五边形 ABCDE，从 A 出发，AB 与 AE 是边，AC 与 AD 是对角线。

```text
与 A 相邻：B、E → 连接后是边
与 A 不相邻：C、D → 连接后是对角线
```

凸多边形的对角线位于图形内部，可以用它们分割区域。分割时不增加外边界的顶点，也不改变原来的内角总和。

## 三、回顾四边形的分割

凸四边形 ABCD 中，连接 AC，得到三角形 ABC 与 ACD。

```text
两个三角形的内角和 = 2 × 180° = 360°
```

原来 A 与 C 处的内角分别被拆成两部分，B 与 D 处的内角保持完整。合计两个三角形的内角，恰好计入四边形的每个内角，没有增加其他角。

所以四边形内角和为 360°。分割的依据比单纯测量四个角更能说明为什么总和固定。

## 四、五边形分成三个三角形

在凸五边形 ABCDE 中，从 A 连接 AC、AD，得到：

```text
△ABC、△ACD、△ADE
```

符号 △ 表示三角形。三个三角形没有重叠，合起来恰好覆盖五边形。

所有三角形的内角在原顶点处分割、合并，正好组成五边形的内角：

```text
五边形内角和 = 3 × 180° = 540°
```

从一个顶点分割，三角形的个数是 3，不是顶点数 5。

## 五、推广到 n 边形

在凸 n 边形中，从一个顶点向其他不相邻顶点画对角线，可以分成 `n − 2` 个三角形。

```text
3 边 → 1 个三角形
4 边 → 2 个三角形
5 边 → 3 个三角形
6 边 → 4 个三角形
```

因此：

```text
n 边形内角和 = (n − 2) × 180°
```

n 表示边数，是不少于 3 的整数。公式中的“减 2”来自三角形分割个数，不能写成 `n × 180°`。

## 六、用表格观察内角和

| 边数 n | 三角形个数 n − 2 | 内角和 |
| ---: | ---: | ---: |
| 3 | 1 | 180° |
| 4 | 2 | 360° |
| 5 | 3 | 540° |
| 6 | 4 | 720° |
| 7 | 5 | 900° |
| 8 | 6 | 1080° |

每增加一条边，内角和增加 180°。同样边数的凸多边形，边长和形状可以不同，内角和仍相同。

内角和相同，不意味着每个内角都相同。

## 七、另一种分割：从内部一点连接顶点

在凸五边形内部取一点 O，连接 O 与五个顶点，得到五个三角形。

五个三角形的角度合计为 `5 × 180° = 900°`。其中既有五边形的内角部分，也包含 O 周围的一整圈 360°。

```text
五边形内角和 = 900° − 360° = 540°
```

不能把从内部一点得到的五个三角形，和从顶点得到的三个三角形混用。两种模型分别需要判断有没有额外的内部角。

一般 n 边形用这种方法得到 `n × 180° − 360°`，与 `(n − 2) × 180°` 一致。

## 八、求一个未知内角

一个凸五边形的四个内角为 95°、110°、120°、100°，剩余角为 x°。

```text
内角和 = (5 − 2) × 180° = 540°
x = 540 − 95 − 110 − 120 − 100
x = 115
```

未知角为 115°。检查五个内角合计为 540°，每个角也都小于 180°，符合凸五边形的条件。

不能沿用四边形的 360°，也不能因为五边形有五个角就平均分配，除非另有各角相等的条件。

## 九、多个未知角需要额外关系

一个凸四边形有两个已知内角，分别为 80°和 100°，另外两个内角相等。

```text
两个未知角合计 = 360° − 80° − 100° = 180°
每个未知角 = 180° ÷ 2 = 90°
```

如果没有相等条件，只能确定两角合计为 180°，不能确定各自是多少。

内角和提供一个总量关系；多个未知量要确定具体数值，还需要相等、差、比或其他图形性质。

## 十、用方程求未知角

一个凸五边形的三个内角为 100°、110°、120°，另外两个分别为 x°、`(x + 10)°`。

```text
100 + 110 + 120 + x + (x + 10) = 540
2x + 340 = 540
x = 100
```

两个未知角为 100°和 110°。

检查：`100° + 110° + 120° + 100° + 110° = 540°`。x 是其中一个角的度数，另一个还要代入 `x + 10` 得到。

## 十一、正多边形的内角

所有边相等、所有内角也相等的多边形，叫作正多边形。

正 n 边形的 n 个内角平均分担总和，所以每个内角为：

```text
每个内角 = [(n − 2) × 180°] ÷ n
```

```text
正三角形：180° ÷ 3 = 60°
正四边形：360° ÷ 4 = 90°
正五边形：540° ÷ 5 = 108°
正六边形：720° ÷ 6 = 120°
```

边相等并不足以自动说明所有角相等，例如一般菱形的内角不全相等。只有明确正多边形或各内角相等时，才能平均分配内角和。

## 十二、已知内角和反求边数

一个凸多边形内角和为 1080°，设边数为 n：

```text
(n − 2) × 180 = 1080
n − 2 = 6
n = 8
```

它是八边形，不一定是正八边形。内角和只确定边数，没有告诉我们每条边或每个角是否相等。

若反求边数得到非整数，就需要检查条件或计算，因为多边形的边数不能是小数。

## 十三、对角线拆分后保留完整内角

凸四边形 ABCD 中画对角线 AC。它把 A 处内角分成 35°与 45°，把 C 处内角分成 40°与 50°。

```text
∠A = 35° + 45° = 80°
∠C = 40° + 50° = 90°
∠B + ∠D = 360° − 80° − 90° = 190°
```

使用四边形内角和时，A、C 两处要把小角合成完整内角。若已经计入完整内角，就不再重复加入分割的小角。

根据两个三角形也能分别求 B、D，但必须知道每个小角具体属于哪一个三角形，不能随意配对。

## 十四、适用范围要看清

本节用凸多边形说明内角和公式。对于边界不自交的凹多边形，经过适当的内部分割，同样有 `(n − 2) × 180°` 的内角和，但凹入处的内角可能大于 180°。

不能直接从凹多边形任意一个顶点画出所有对角线，就假定每条都位于内部。

对于边界交叉的星形线条，本节不直接套用普通多边形的内角和公式。先确认图形的边界与内部区域，才知道哪些角是要计算的内角。

## 十五、完整演示：六边形中的两个等角

一个凸六边形的四个内角为 100°、110°、120°、130°，另外两个内角相等。我们一起求这两个角。

先根据边数求整体：

```text
内角和 = (6 − 2) × 180° = 720°
```

再合并已知角：

```text
已知角合计 = 100° + 110° + 120° + 130° = 460°
未知两角合计 = 720° − 460° = 260°
每个未知角 = 260° ÷ 2 = 130°
```

检查所有角合计为 720°，两个未知角相等，而且各角均小于 180°。

这个六边形不是正六边形，因为它的内角不全相等。虽然正六边形每个内角为 120°，但不能把这个值套用到任意六边形。

## 十六、小结

多边形的内角和可以由三角形分割解释。凸 n 边形从一个顶点分成 `n − 2` 个三角形，因此内角和为 `(n − 2) × 180°`。

求未知角先确定边数与整体内角和，再减去已知部分。多个未知角还需要相等、差或比等条件；正多边形各角相等，可以把内角和平均分配。

对角线分割后的角要按顶点重新合并，避免遗漏或重复计算。最后检查总和、角度范围和图形条件是否一致。
