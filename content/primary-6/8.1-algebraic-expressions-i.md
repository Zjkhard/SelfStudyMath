# 代数式一

代数式用数字、字母和运算符号表示数量关系。六年级将进一步学习如何识别代数式的组成、合并同类项、展开括号，并用代数式表示更复杂的实际问题。

## 一、变量和常数

会变化或尚未确定的数量可以用字母表示，称为变量。固定不变的数称为常数。

```text
3x + 5
x：变量
3、5：常数
```

在同一个问题中，字母的含义应保持一致。

## 二、代数式的项

代数式中由加号或减号分开的部分叫作项：

```text
4x + 3y − 7
项：4x、3y、−7
```

负号属于它后面的项，所以第三项是 `−7`，不是单独的减法符号。

## 三、系数

字母前面的数叫作系数：

```text
8a：系数是 8
−5b：系数是 −5
m：系数是 1
−n：系数是 −1
```

系数可以是整数、小数或分数，例如 `0.5x` 的系数是 0.5。

## 四、常数项

不含字母的项叫作常数项：

```text
6x + 4y − 9
常数项是 −9
```

如果代数式只有字母项，没有单独的数字，则没有常数项。

## 五、代数式的规范读法

```text
3x：x 的 3 倍
x + 7：x 加 7
2a − 5：a 的 2 倍减 5
(p + q) ÷ 4：p 与 q 的和除以 4
```

读清楚括号范围，可以避免把 `p + q ÷ 4` 错读成 `(p + q) ÷ 4`。

## 六、把文字写成代数式

先找出未知数量，再翻译运算关系：

```text
比 x 多 6：x + 6
比 y 少 4：y − 4
a 的 5 倍：5a
a 与 b 的和的 3 倍：3(a + b)
a 与 b 的 3 倍的和：a + 3b
```

“和的几倍”需要把和放在括号内。

## 七、乘法的简写

数字和字母相乘时省略乘号：

```text
4 × x = 4x
x × y = xy
(x + 2) × 3 = 3(x + 2)
```

数字写在字母前面，不能把 `2x` 当成两位数。

## 八、同类项的判断

字母部分完全相同的项是同类项：

```text
5x 与 −2x：同类项
3ab 与 7ab：同类项
4x 与 4x²：不是同类项
2a 与 2b：不是同类项
```

系数不同不影响同类项判断，但字母或字母的次数不同就不能直接合并。

## 九、合并同类项

合并同类项时，只对系数进行加减，字母部分保持不变：

```text
7x + 3x = 10x
9a − 4a = 5a
```

可以把同类项想象成相同单位的物品，先合并数量，再保留单位字母。

## 十、含多个项的化简

先找出同类项，再分别合并：

```text
4x + 3y + 2x − y
= 4x + 2x + 3y − y
= 6x + 2y
```

不同字母的项不能合并，化简后可以保留多个不同类型的项。

## 十一、合并常数项

常数项之间也可以合并：

```text
3x + 7 + 2x − 4
= 5x + 3
```

通常把含字母的项写在前面，把常数项写在后面，形式更清楚。

## 十二、去括号的分配律

乘法分配律是去括号的依据：

```text
a(b + c) = ab + ac
a(b − c) = ab − ac
```

例如：

```text
3(x + 4) = 3x + 12
5(2y − 1) = 10y − 5
```

括号外的数必须乘括号内的每一项。

## 十三、括号前是负号

括号前的负号相当于乘以 `−1`：

```text
−(x + 3) = −x − 3
−(a − 5) = −a + 5
```

括号内每一项的符号都要改变。

## 十四、合并与展开的综合

先展开括号，再合并同类项：

```text
2(x + 3) + 4x − 1
= 2x + 6 + 4x − 1
= 6x + 5
```

如果有多个括号，按顺序逐个处理，避免一次跳过中间步骤。

## 十五、提取公因数

提取公因数是展开括号的逆运算：

```text
6x + 12 = 6(x + 2)
8a − 4b = 4(2a − b)
```

括号外的数必须是每一项系数的公因数。

## 十六、代入求值

把变量换成给定数值，再按运算顺序计算：

```text
3x + 2，x = 6
= 3 × 6 + 2
= 20
```

代入后可以先写完整算式，再逐步计算。

## 十七、代入负数

代入负数时用括号包住该数：

```text
2x − 3，x = −4
= 2 × (−4) − 3
= −8 − 3
= −11
```

这样可以清楚区分负号和减号。

## 十八、先化简再代入

复杂代数式可以先化简，再代入数值：

```text
2(x + 3) + x − 1
= 3x + 5
```

当 `x = 4` 时：

```text
3 × 4 + 5 = 17
```

先化简通常能减少计算步骤和出错机会。

## 十九、用代数式表示连续数

若一个数为 `n`，相邻数可表示为：

```text
前一个数：n − 1
后一个数：n + 1
连续三个数：n − 1、n、n + 1
```

连续偶数可表示为 `2n`、`2n + 2`、`2n + 4`；连续奇数可表示为 `2n + 1`、`2n + 3`、`2n + 5`。

## 二十、用代数式表示周长

长方形的长为 `l`、宽为 `w`：

```text
周长 = l + w + l + w = 2l + 2w
```

若长为 `x + 2`、宽为 `x − 1`：

```text
周长 = 2(x + 2) + 2(x − 1)
= 2x + 4 + 2x − 2
= 4x + 2
```

## 二十一、用代数式表示面积

长方形长为 `a + 3`、宽为 `a`：

```text
面积 = a(a + 3) = a² + 3a
```

在本阶段，重点理解分配律展开；字母平方 `a²` 表示 `a × a`。

## 二十二、用代数式表示总价

单价为 `p` 元，购买 `n` 件，未打折时：

```text
总价 = pn 元
```

若每件先涨价 2 元，再买 `n` 件：

```text
新总价 = (p + 2)n 元
```

括号表示涨价后的单价整体乘以数量。

## 二十三、代数式的等价变形

如果两个代数式对所有允许的变量值都相等，它们是等价的：

```text
3(x + 2) 与 3x + 6 等价
```

可以用分配律说明，也可以代入几个数值进行检查。单次代入只能检查一个例子，不能单独证明对所有数都成立。

## 二十四、用表格观察代数式

对 `2x + 3` 取不同的 `x` 值：

| x | 0 | 1 | 2 | 3 |
| --- | ---: | ---: | ---: | ---: |
| 2x + 3 | 3 | 5 | 7 | 9 |

表格能帮助观察变量变化时代数式值的变化，为函数图像作准备。

## 二十五、综合例题

一个长方形宽为 `x cm`，长比宽多 5 cm。求周长的代数式，并在 `x = 7` 时求周长。

```text
长 = x + 5
周长 = 2x + 2(x + 5)
= 4x + 10
```

当 `x = 7` 时：

```text
周长 = 4 × 7 + 10 = 38 cm
```

## 二十六、常见错误

### 1. 把不同类项合并

`3x + 2y` 不能写成 `5x` 或 `5y`。

### 2. 去括号时漏乘一项

`4(a + b)` 必须展开为 `4a + 4b`，不能只乘第一项。

### 3. 负号没有分配到每一项

`−(x − 3) = −x + 3`，括号内两个符号都要处理。

### 4. 代入负数时不加括号

使用 `(−5)` 可以避免把负号看成减法符号。

### 5. 混淆“和的倍数”和“倍数的和”

`3(a + b)` 与 `3a + b` 不同，先明确语言关系再列式。

## 二十七、小结

```text
代数式由变量、常数、项和运算符号组成
同类项可以合并，系数相加减，字母部分保持不变
用分配律展开括号，括号前负号要改变每一项的符号
代入时遵循运算顺序，负数最好加括号
代数式可以表示连续数、周长、面积、总价等数量关系
```

学习代数式一时，先识别字母与数量关系，再进行展开、合并和代入；每一步都要检查符号、括号、单位和表达式的意义。
