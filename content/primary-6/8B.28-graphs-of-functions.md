# 函数图像

关系式 `y = 2x + 1` 中，x 可以取正数，也可以取负数。x = −2 时，y = −3，对应点就位于原点左下方。

上册已把数量关系画成坐标点。本节继续把负数运算与解方程连接到图像，并观察直线与简单曲线的不同变化。

## 一、每个允许的输入对应一个输出

在给定取值范围内，每个 x 按规则对应唯一一个 y，就形成函数关系。

```text
y = 2x + 1
输入 x → 乘 2，再加 1 → 输出 y
```

一个函数可以有两个不同输入对应相同输出，例如平方关系中 2 与 −2 都对应 4。但同一个允许输入不能按同一函数规则同时对应两个不同输出。

画图前说明 x 允许取哪些值，不能把没有给出的实际意义擅自扩展到所有负数。

## 二、负坐标的方向

坐标对写成 `(x, y)`，先横坐标，再纵坐标。原点为 `(0, 0)`。

```text
x 为正：向右；x 为负：向左
y 为正：向上；y 为负：向下
```

点 `(−2, −3)` 从原点向左 2 个单位、向下 3 个单位定位。点 `(−2, 3)` 则在左上方，两者不是同一个点。

如果 x = 0，点在纵轴上；如果 y = 0，点在横轴上。

## 三、数值表要保留负数括号

我们在 `−2 ≤ x ≤ 2` 的范围内研究 `y = 2x + 1`。先取整数输入：

| x | y 的计算 | y | 坐标点 |
| ---: | --- | ---: | --- |
| −2 | `2 × (−2) + 1` | −3 | `(−2, −3)` |
| −1 | `2 × (−1) + 1` | −1 | `(−1, −1)` |
| 0 | `2 × 0 + 1` | 1 | `(0, 1)` |
| 1 | `2 × 1 + 1` | 3 | `(1, 3)` |
| 2 | `2 × 2 + 1` | 5 | `(2, 5)` |

`−2 ≤ x ≤ 2` 表示 x 不小于 −2，也不大于 2。本例允许这个范围内的小数、分数等中间输入，不只允许表格中的整数。

## 四、描点并画出直线的一段

选择横轴覆盖 −2～2、纵轴覆盖 −3～5 的网格，每格分别表示 1 个单位，描出表中的五个点。

这些点在同一条直线上。因为整个允许范围内都使用 `y = 2x + 1`，用直尺画出从 `(−2, −3)` 到 `(2, 5)` 的线段，中间点也符合规则。

```text
输入每增加 1 → 输出增加 2
输入每增加 1/2 → 输出增加 1
```

直线关系来自每个输入变化都对应固定的输出变化，不是仅凭几个点看起来排得很齐。图像端点由本例取值范围决定，不任意延长。

## 五、取值范围决定是否连线

如果同一个关系式用于“一共有 x 袋卡片，每袋 2 张，另有 1 张”，x 就只能是非负整数。

此时画出 `(0,1)`、`(1,3)`、`(2,5)` 等分开的点，不能用实线表示所有中间袋数。

```text
纯数值模型：可明确允许负数与中间值
完整袋数模型：只允许 0、1、2 等整数
```

同样的关系式，允许输入不同，图像范围与形式也可能不同。

## 六、从图上找纵轴交点

在 `y = 2x + 1` 中，x = 0 时 y = 1，所以图像与纵轴相交于 `(0, 1)`。

这个点告诉我们输入为 0 时的输出，不表示图像经过原点。

关系 `y = 2x` 在 x = 0 时 y = 0，图像才经过原点。它具有固定比值 `y/x = 2`，但这个比值只能在 x ≠ 0 时计算。

`y = 2x + 1` 多了固定的 1，通常没有固定的 `y/x`，不能因为图像是直线就断定成正比例。

## 七、从图上找横轴交点

横轴上的点满足 y = 0。在 `y = 2x + 1` 中：

```text
2x + 1 = 0
2x = −1
x = −1/2
```

所以图像与横轴相交于 `(−0.5, 0)`。

表格没有列 x = −0.5，但它在允许范围内，可以补算并描出。图像不只由最初选出的五个点决定。

## 八、上升与下降的直线

比较 `y = 2x + 1` 与 `y = −x + 2`，两者都在 −2～2 范围内研究。

| x | 2x + 1 | −x + 2 |
| ---: | ---: | ---: |
| −2 | −3 | 4 |
| −1 | −1 | 3 |
| 0 | 1 | 2 |
| 1 | 3 | 1 |
| 2 | 5 | 0 |

从左向右观察，第一条直线上升：x 每增加 1，y 增加 2。第二条下降：x 每增加 1，y 减少 1。

输出为负与图像下降不是同一个意思。第一条直线在部分范围内 y 为负，却仍从左向右上升。

## 九、平方关系产生曲线

在 −2～2 范围内研究 `y = x²`，负数代入时保留括号：

```text
x = −2：y = (−2)² = 4
x = −1：y = (−1)² = 1
```

| x | −2 | −1 | 0 | 1 | 2 |
| --- | ---: | ---: | ---: | ---: | ---: |
| y = x² | 4 | 1 | 0 | 1 | 4 |

这些点不在同一直线上。为了看清中间变化，还可以补算 x = ±0.5 对应 y = 0.25，x = ±1.5 对应 y = 2.25。

依据平方关系连续变化的规则，画出经过这些点的平滑曲线，而不是用直尺把少量点连接成折线。有限个点本身不足以证明曲线的全部形状，关系式提供了中间值的依据。

本节只观察简单平方图像，不展开一般二次函数的完整性质。

## 十、相反输入与相同输出

在 `y = x²` 中，x 与 −x 的平方相同。图像上 `(−1,1)` 与 `(1,1)`、`(−2,4)` 与 `(2,4)` 分别关于纵轴对称。

输出都不为负，最小值为 0，在 x = 0 时取得。

但不能说 x 增大时 y 始终增大：从 −2 到 0，y 从 4 降到 0；从 0 到 2，y 又从 0 升到 4。

观察趋势要说明范围。一个函数有唯一输出，不意味着反过来由输出也只能找出一个输入。

## 十一、用图像读对应值

在 `y = 2x + 1` 图像上，已知 x = 1.5：先在横轴找 1.5，向上找到图像，再水平读出 y = 4。

用关系式检查：

```text
y = 2 × 1.5 + 1 = 4
```

若已知 y = −2，可以从纵轴 −2 水平找到图像，再读横坐标约为 −1.5。解 `2x + 1 = −2`，也得到准确的 x = −1.5。

图上读数受刻度和作图精度限制；关系式准确给定时，可以用计算核对。

## 十二、同一输出可能对应两个输入

在 `y = x²` 图像中，寻找 y = 1 对应的输入，可以画水平线 y = 1。

它在本例范围内与曲线交于 `(−1,1)` 和 `(1,1)`，所以 x = −1 或 x = 1。

这说明方程 `x² = 1` 有两个解。这里只用熟悉的平方关系验证：`(−1)² = 1`，`1² = 1`。

若要找 y = −1，对应水平线不与这条曲线相交，因为任何允许 x 的平方都不为负，方程 `x² = −1` 在实数范围内无解。

## 十三、两条图像交点联系方程

在同一坐标图中画 `y = 2x + 1` 与 `y = −x + 2`，研究范围都为 −2～2。

交点同时在两条图像上，同一个 x 对应的两个表达式相等：

```text
2x + 1 = −x + 2
3x = 1
x = 1/3
y = 2 × 1/3 + 1 = 5/3
```

准确交点为 `(1/3, 5/3)`。从图上可能读成约 `(0.33, 1.67)`，图像帮助观察位置，方程给出准确值。

不要把交点的纵坐标 5/3 当作这个方程中 x 的解。方程的未知数是 x，纵坐标需要另行代入求出。

## 十四、比较图像要看同一个输入

在 x = 0 时，第一条图像 y = 1，第二条 y = 2，所以第二条更高。

在 x = 1 时，第一条 y = 3，第二条 y = 1，所以第一条更高。

两条线在交点处输出相等，交点两侧的高低关系改变。不能只看某一端的位置就说一条图像在整个范围内都更高。

读图时，两条图像应使用同一组坐标轴刻度并有清楚的标签。高低比较的是相同横坐标处的纵坐标。

## 十五、完整演示：温度随时间变化

一个简化模型中，初始温度为 4°C，随后 3 小时内每小时均匀降低 2°C。设 x 为经过时间的小时数，y 为温度的摄氏度数。

```text
y = 4 − 2x
允许范围：0 ≤ x ≤ 3
```

| 时间 x（h） | 温度 y（°C） |
| ---: | ---: |
| 0 | 4 |
| 1 | 2 |
| 2 | 0 |
| 3 | −2 |

横轴表示时间，纵轴表示温度，分别标出单位。描点后，用直尺连接 `(0,4)` 至 `(3,−2)`，得到本例范围内的下降线段。

本例时间允许取中间值，均匀变化使中间时刻也遵循关系。x = 2.5 时，y = −1，对应 `(2.5,−1)`。

若求温度为 1°C 的时刻，解 `4 − 2x = 1`，得到 x = 1.5，即 1 小时 30 分钟。

虽然图上出现负的温度，本例不允许负的经过时间，也不能随意把线段延长到 3 小时之外。负坐标是否有意义，由它表示的数量与给定范围决定。

## 十六、小结

函数图像把允许输入与对应输出表示为坐标点。负数代入保留括号，描点时先横后纵，并确认各轴单位与刻度。

关系式与取值范围决定图像是否连线、画到哪里。固定变化率产生直线，简单平方关系产生曲线；图像上升或下降也要说明研究范围。

读对应值、找横轴交点或比较两条图像，都可以与解方程联系。图上读数可能只是近似值，准确关系式则能用于计算检验，结论还要符合实际数量含义。
