# 正负数的比较

两个地方的气温分别是 −0.5°C 和 −1.5°C。虽然 1.5 比 0.5 大，但 −1.5°C 表示零下得更多，温度反而更低。

比较带负号的数时，不能只比较负号后面的数。这一节从数轴的位置出发，解释正负数的大小关系。

## 一、数轴上越靠右，数越大

数轴通常规定向右为正方向。沿着数轴从左向右走，所表示的数逐渐增大。

```text
←───●──────●──────●──────●──────●───→
   −2     −1      0      1      2
```

−1 在 −2 的右边，所以 `−1 > −2`。0 在 −1 的右边，所以 `0 > −1`。

这个位置规则同样适用于分数和小数，而不只适用于整数。

## 二、读懂比较符号

```text
a > b：a 大于 b
a < b：a 小于 b
a = b：a 等于 b
```

比较符号的开口朝向较大的数。例如：

```text
−0.5 > −1.5
−1.5 < −0.5
```

两行表达同一个大小关系，只是左右顺序不同。交换两边的位置时，比较符号的方向也要随之改变。

## 三、先看与零的关系

在数轴上，所有负数都在 0 左边，所有正数都在 0 右边。因此：

```text
负数 < 0 < 正数
```

例如：

```text
−3/4 < 0 < 1/5
−0.001 < 0 < 0.002
```

无论一个正数多么接近 0，它仍大于任何负数。比较一正一负时，不必先通分或计算小数。

0 既不是正数，也不是负数。`−0` 与 `0` 相等，不能把 `−0` 当作比 0 小的数。

## 四、两个正数按原来的方法比较

两个数都是正数时，可以沿用分数和小数的比较方法。

```text
0.6 = 0.60 > 0.58
3/4 = 9/12 > 8/12 = 2/3
```

小数按照位值比较；分数可以先通分，再比较分子。正号可以省略，例如 `+0.6 = 0.6`。

## 五、为什么两个负数的比较会反过来

把 −2 到 0 之间的距离平均分成 4 份，每份是 0.5 个单位：

```text
←───●──────●──────●──────●──────●───→
   −2    −1.5    −1    −0.5     0
```

`−1.5` 从 0 向左 1.5 个单位，`−0.5` 从 0 向左 0.5 个单位。走得更远的点在更左边，所以：

```text
−1.5 < −0.5
```

两个数都为负数时，离 0 越远，数越小；离 0 越近，数越大。

## 六、用绝对值比较两个负数

绝对值表示一个数到 0 的距离。比较 −0.8 和 −0.3：

```text
|−0.8| = 0.8
|−0.3| = 0.3
0.8 > 0.3
```

−0.8 离 0 更远，而且两个点都在 0 左边，所以：

```text
−0.8 < −0.3
```

这个方法的前提是两个数都为负数。不能只凭绝对值大小比较任意两个数。例如，−5 的绝对值比 2 大，但 `−5 < 2`，因为负数小于正数。

## 七、比较位数不同的负小数

比较 −0.7 和 −0.65，先比较它们到 0 的距离：

```text
0.7 = 0.70
0.70 > 0.65
```

两个数都是负数，距离较大的那个更小：

```text
−0.7 < −0.65
```

小数位数多，不表示数一定更大或更小。要按位值比较对应的正数，再根据负号判断方向。

再看 −1.08 和 −1.8。由于 `1.08 < 1.80`，所以 `−1.08 > −1.8`。

## 八、比较同分母的负分数

比较 −3/7 和 −5/7。它们到 0 的距离分别是 3 个七分之一和 5 个七分之一。

```text
3/7 < 5/7
所以 −3/7 > −5/7
```

分母相同，且两个分数都带负号时，分子所表示的份数越多，点就越靠左，数就越小。

这里分母都写成正整数，负号写在整个分数前面。

## 九、比较异分母的负分数

比较 −2/3 和 −3/4，先把对应的正分数通分：

```text
2/3 = 8/12
3/4 = 9/12
8/12 < 9/12
```

`−2/3` 离 0 更近，所以：

```text
−2/3 > −3/4
```

也可以直接写出等值的负分数 `−8/12` 和 `−9/12`。从 0 向左 8 份的点，在向左 9 份的点右边。

通分改变的是表示方式，原数的位置和大小没有改变。

## 十、比较负分数与负小数

比较 −3/8 和 −0.4，可以把分数化成小数：

```text
−3/8 = −0.375
0.375 < 0.400
所以 −0.375 > −0.4
```

因此，`−3/8 > −0.4`。

也可以把小数化成分数，再通分：

```text
−0.4 = −2/5
−3/8 = −15/40
−2/5 = −16/40
−15/40 > −16/40
```

两种方法都保留准确值，结论一致。可以选择计算更简便的形式。

## 十一、比较负带分数

比较 `−(1 又 1/4)` 和 −1.2，先把带分数化成小数：

```text
−(1 又 1/4) = −1.25
1.25 > 1.20
所以 −1.25 < −1.2
```

负带分数中的负号作用于整个带分数，不能写成 `−1 + 1/4`。

如果比较 `−(2 又 1/5)` 和 `−(1 又 4/5)`，也可以先观察它们的位置：前者在 −3 与 −2 之间，后者在 −2 与 −1 之间，所以前者更小。

## 十二、不同写法可能表示相等的数

比较两个数，不一定得到大于或小于，也可能得到相等。

```text
−1/2 = −0.5
−0.50 = −0.500
−6/8 = −3/4 = −0.75
```

这些等值写法表示数轴上的同一个点。

负号并不会改变“约分保持数值不变”或“小数末尾零不改变数值”的性质。比较前可以先化成容易识别的形式。

## 十三、不要用近似相同判断准确相等

比较 −1/3 和 −0.33。如果只把 −1/3 保留两位小数，就会得到约 −0.33，但这不能说明两个数相等。

我们用准确分数比较：

```text
0.33 = 33/100 = 99/300
1/3 = 100/300
1/3 > 0.33
```

两个原数都是负数，所以：

```text
−1/3 < −0.33
```

准确比较时，尽量使用准确的互化或通分。两个数取近似值后看起来一样，原来的数仍可能不同。

## 十四、把多个数从小到大排列

我们一起排列 `−3/4`、`0.2`、`−0.6`、`0` 和 `1/2`。

先按符号分组：

```text
负数：−3/4、−0.6
零：0
正数：0.2、1/2
```

负数中，`−3/4 = −0.75`，离 0 比 −0.6 更远，所以 `−3/4 < −0.6`。

正数中，`1/2 = 0.5`，所以 `0.2 < 1/2`。

合起来得到：

```text
−3/4 < −0.6 < 0 < 0.2 < 1/2
```

这也对应着它们在数轴上从左到右的位置顺序。

## 十五、从大到小排列

从大到小，就是按照数轴上从右到左的顺序排列。

把上一节的顺序反过来：

```text
1/2 > 0.2 > 0 > −0.6 > −3/4
```

检查时，逐对确认左边的数大于右边的数。如果列表中有相等的数，要用等号表示它们的关系，而不是强行使用大于号或小于号。

## 十六、数值大小与距离大小

两个标记点的位置分别是 −1.2 m 和 −0.4 m，以同一个原点为 0，向右为正。

```text
位置数值：−1.2 < −0.4
到原点的距离：1.2 m > 0.4 m
```

−1.2 m 的点在更左边，它的位置数值更小，但它到原点的距离更大。

比较温度时也一样。−1.2°C 比 −0.4°C 低，但它低于 0°C 的幅度更大。要先弄清楚比较的是数值、距离，还是偏离基准的幅度。

## 十七、完整演示：比较三次气温记录

同一地点在三个时刻记录到的气温如下：

| 时刻 | 气温 |
| --- | --- |
| 清晨 | `−1.25°C` |
| 中午 | `0.5°C` |
| 傍晚 | `−3/4°C` |

先观察符号。中午的气温是正数，另外两个时刻是负数，所以中午气温最高。

再比较两个负数。把傍晚的气温化成小数：

```text
−3/4 = −0.75
```

1.25 比 0.75 大，清晨的气温离 0°C 更远，且在零下，所以清晨气温更低。

```text
−1.25 < −0.75 < 0.5
```

因此，气温从低到高依次是清晨、傍晚、中午。这里比较的是气温本身，而不是低于 0°C 的幅度。

## 十八、小结

数轴上越靠右，数越大。负数小于 0，正数大于 0，任何正数都大于任何负数。

两个正数沿用分数和小数的比较方法；两个负数则是离 0 越远的数越小。可以先比较绝对值，再根据两个数都为负数判断大小。

遇到分数与小数的混合表示，可以通分或准确互化，再比较和排序。始终保留负号，区分准确值与近似值，并确认比较的是数值还是到基准的距离。
