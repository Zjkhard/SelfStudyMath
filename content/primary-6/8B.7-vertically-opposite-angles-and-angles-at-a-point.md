# 对顶角与一个点周围的角

两根直杆交叉时，交点周围会形成四个角。相对的两个角看起来大小相同，但这个结论不能只靠观察图形。

这一节用已经学过的平角关系解释对顶角相等，再观察从一个点出发转一整圈时，各部分角怎样合起来。

## 一、两条直线相交形成四个角

直线 AC 与直线 BD 相交于 O，A 与 C 位于 O 的两侧，B 与 D 也位于 O 的两侧。示意图不代表准确角度。

```text
A             B
  \         /
    \     /
      \ /
       O
      / \
    /     \
  /         \
D             C
```

OA 与 OC 是相反射线，OB 与 OD 也是相反射线。围绕交点依次有四个角：∠AOB、∠BOC、∠COD、∠DOA。

相邻的两角组成平角，例如 ∠AOB 与 ∠BOC 的非公共边是 OA、OC，所以度数和为 180°。

## 二、辨认对顶角

两条直线相交时，相对的两个角叫作对顶角。更具体地说，一个角的两条边分别是另一个角两条边的相反射线。

在上面的图中：

```text
∠AOB 与 ∠COD：一对对顶角
∠BOC 与 ∠DOA：另一对对顶角
```

对顶角共用顶点，但不共用一条边，与邻角的关系不同。

仅仅位于同一个顶点附近、看起来相对，还不能断定它们是对顶角。必须确认两组边分别在同一直线上、方向相反。

## 三、为什么对顶角相等

∠AOB 与 ∠BOC 组成平角；∠BOC 与 ∠COD 也组成平角。

```text
∠AOB + ∠BOC = 180°
∠BOC + ∠COD = 180°
```

从同一个 180° 中减去同一个 ∠BOC，剩下的角相等：

```text
∠AOB = 180° − ∠BOC
∠COD = 180° − ∠BOC
所以 ∠AOB = ∠COD
```

同样可以说明 ∠BOC = ∠DOA。

因此，对顶角相等。这个理由依靠直线和平角关系，不需要假定图画得精确。

## 四、已知一个角求另外三个角

已知 ∠AOB = 68°：

```text
对顶角 ∠COD = 68°
邻补角 ∠BOC = 180° − 68° = 112°
对顶角 ∠DOA = 112°
```

检查相邻角之和：`68° + 112° = 180°`。

再检查交点周围合计：`68° + 112° + 68° + 112° = 360°`。

如果两条直线互相垂直，四个角都为 90°。对顶角相等并不说明它们一定是锐角或钝角。

## 五、对顶角与邻补角不要混淆

| 关系 | 位置特征 | 度数关系 |
| --- | --- | --- |
| 对顶角 | 两组边分别是相反射线 | 两角相等 |
| 邻补角 | 共用一条边，外侧边为相反射线 | 两角和为 180° |

在相交直线中，先看未知角与已知角是哪种位置关系，再决定使用相等还是相减。

例如，一个角为 68°，它的对顶角也是 68°；紧邻它的角才是 112°。

## 六、对顶角的边也可以被进一步分割

在原图的 ∠COD 内部加入射线 OE，已知 ∠AOB = 80°、∠COE = 35°。

先求完整的对顶角，再拆分：

```text
∠COD = 80°
∠EOD = ∠COD − ∠COE
      = 80° − 35°
      = 45°
```

∠EOD 本身不是 ∠AOB 的对顶角，因为它的一条边 OE 不是 OA 或 OB 的相反射线。

增加射线后，要认清完整角与小角的范围，不能把“相对一侧的任何小角”都当作对顶角。

## 七、一个点周围转一整圈

一条射线从 O 出发，绕 O 转动一整圈后回到原来的方向，转过的角为 360°，叫作周角。

```text
四个直角：90° × 4 = 360°
两个平角：180° × 2 = 360°
```

从一个点引出多条射线，把周围一整圈分成若干部分，这些部分若没有重叠、没有遗漏，度数和就是 360°。

这里的依据是围绕同一点完整一周，不是因为图形里恰好画了很多角。

## 八、列出一周中每个角

从 O 引出 OA、OB、OC、OD，按顺时针方向依次排列。沿同一方向，四个区域恰好围成一周。

如果对应角度依次为 70°、95°、110°、x°：

```text
70 + 95 + 110 + x = 360
x = 360 − 70 − 95 − 110
x = 85
```

未知角为 85°。检查四个数相加为 360°。

这里没有说明 OA 与 OC、OB 与 OD 分别在直线上，所以不能把相对的角自动判为对顶角。周角关系不要求这些射线形成两条直线。

## 九、两个方向之间也有优角

两条不同方向的射线围出两个区域：一侧可能是较小的角，另一侧是绕剩余部分转过的角。

若较小角为 120°，另一侧为：

```text
360° − 120° = 240°
```

大于 180°、小于 360° 的角叫作优角，240° 就是优角。

同样的两条边，选择的转动区域不同，角度可能不同。图中问号或角弧标在哪一侧，就要确认求的是哪一侧；只写三个字母而未说明区域时，不能随意把较小角换成优角。

## 十、不要重复计算重叠的角

如果 ∠AOC 包含 ∠AOB 与 ∠BOC，就有：

```text
∠AOC = ∠AOB + ∠BOC
```

计算 O 周围一整圈时，不能既计入 ∠AOC，又把其中两个小角再次加入。否则这些区域被算了两次。

稳妥的方法是选择一组依次相邻的最小区域，沿顺时针或逆时针绕一周，每个区域只记录一次。

还要确认所列角在同一个顶点。不能把不同点处的角相加后，仅凭“在附近”就使用 360°。

## 十一、先用直线关系，再用周角关系

A、O、C 在同一直线上，OA 与 OC 为相反射线。上侧有射线 OB，且 ∠AOB = 72°；下侧有射线 OD，且 ∠COD = 125°。

上侧两角组成平角：

```text
∠BOC = 180° − 72° = 108°
```

下侧两角也组成平角：

```text
∠DOA = 180° − 125° = 55°
```

合计检查：`72° + 108° + 125° + 55° = 360°`。

这里没有说明 OB 与 OD 是相反射线，所以它们不一定在同一直线上。不能用对顶角相等代替已知条件。

## 十二、用对顶角列方程

两条直线相交，一对对顶角分别标为 `(3x + 10)°` 和 `(5x − 30)°`。

对顶角相等，所以：

```text
3x + 10 = 5x − 30
40 = 2x
x = 20
```

代入得到两个角都为 70°。与它们相邻的角为 `180° − 70° = 110°`。

未知数 x 的值是 20，所求角却是 70°，两者不能混淆。得到 x 后要代回角的表达式。

## 十三、用周角列方程

围绕 O 的三个区域恰好组成一周，其中一个角为 90°，另外两角分别为 x° 和 2x°。

```text
90 + x + 2x = 360
3x = 270
x = 90
```

三个角分别为 90°、90° 和 180°。检查：`90° + 90° + 180° = 360°`。

只有明确三个区域完整围成一周，才能列这个方程；若它们只覆盖半圈，整体就应是 180°。

## 十四、完整演示：相交直线中的分角

直线 AC 与 BD 相交于 O，A 与 C 在 O 两侧，B 与 D 在 O 两侧。已知 ∠AOB = 126°。射线 OE 位于 ∠COD 内部，∠COE = 48°。

先利用对顶角关系求整个下方相对区域：

```text
∠COD = ∠AOB = 126°
```

再求其中剩余部分：

```text
∠EOD = 126° − 48° = 78°
```

相邻的另两角为：

```text
∠BOC = ∠DOA = 180° − 126° = 54°
```

最后沿交点一周按区域核对：

```text
126° + 54° + 48° + 78° + 54° = 360°
```

其中完整的 ∠COD 已被拆成 48° 与 78°，检验时不再重复加入 126°。对顶角、邻补角与周角关系相互配合，得到一致结果。

## 十五、小结

两条直线相交形成的对顶角相等，可以用同一个平角减去共同的邻角解释。判断对顶角时，必须确认两组边分别是相反射线。

一个点周围完整一周的角合计为 360°，所列区域必须同顶点、无遗漏、无重叠。求较大的转动区域时，还要分清较小角与优角。

求未知角先辨认位置与整体关系，再用相等、180° 或 360° 列式。最后代回表达式，并沿实际区域检查度数和。
