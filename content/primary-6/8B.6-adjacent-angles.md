# 邻角

从同一个点引出三条射线，中间的射线可以把一个大角分成两个小角。这两个小角挨在一起，共用顶点和一条边。

这一节观察这种相邻关系，学习怎样把角合起来或拆开，并确认什么时候可以使用 90° 或 180°。

## 一、观察两个挨在一起的角

下面的图中，射线 OB 位于 ∠AOC 的内部，把它分成 ∠AOB 与 ∠BOC。图形只示意位置，不表示准确度数。

```text
C
↑       B
│      ↗
│    /
│  /
O──────────→ A
```

两个小角都以 O 为顶点，都使用射线 OB 作一条边。它们分别位于 OB 的两侧，内部没有重叠。

从 OA 转到 OC 的过程，可以先从 OA 转到 OB，再从 OB 转到 OC。

## 二、邻角的三个条件

具有共同顶点、一条公共边，且内部不重叠的两个角，叫作邻角，也叫相邻角。

辨认时，依次检查：

- 顶点是不是同一个点。
- 是否有一条相同的射线作公共边。
- 两个角的内部是否没有重叠，并位于公共边的两侧。

仅仅画得很近，不足以说明两个角是邻角。邻角描述位置关系，不规定两个角各是多少度。

## 三、用三个字母看清公共边

在 ∠AOB 与 ∠BOC 中，中间字母 O 都是顶点，OB 是两角的公共边。

```text
∠AOB 的边：OA、OB
∠BOC 的边：OB、OC
公共边：OB
外侧的两条边：OA、OC
```

如果同一顶点周围有多个角，写完整名称能避免认错范围。只写“∠O”，可能不知道指的是小角还是整个大角。

字母 B 出现在两个角名中，还不足以判定邻角；必须结合图形确认两个角的内部不重叠。

## 四、有共同边但重叠，不是邻角

仍看第一幅图。∠AOB 与 ∠AOC 有相同顶点 O，也共用 OA，但 ∠AOB 在 ∠AOC 内部。

两个角的内部重叠，所以它们不是邻角。

如果把这两个角的度数直接相加，∠AOB 对应的转动会重复计算。判断能否合并成整体角，必须先看角的范围。

另外，两个只有顶点相同、没有公共边的角，也不符合本节的邻角条件。

## 五、邻角合成一个整体角

当 OB 位于 ∠AOC 内部，把整体角恰好分成两个邻角时：

```text
∠AOC = ∠AOB + ∠BOC
```

例如，∠AOB 为 35°，∠BOC 为 45°：

```text
∠AOC = 35° + 45° = 80°
```

两个邻角的和是这里的整体角 80°，不是自动等于 90° 或 180°。

整体的范围由外侧射线和选定的转动区域决定，不能把同一顶点处的任何两个角都相加当作某个已知大角。

## 六、已知整体角求其中一部分

已知 ∠AOC = 125°，OB 在它内部，∠AOB = 48°。

```text
∠BOC = ∠AOC − ∠AOB
      = 125° − 48°
      = 77°
```

检查：`48° + 77° = 125°`，两个部分合计回到整体角。

先确定整个角包含哪些部分，再做减法。不能仅凭图上哪一个角看起来较大决定计算。

## 七、直角内的邻角

如果 OA 与 OC 互相垂直，∠AOC 是直角；OB 在直角内部，就把它分成两个邻角。

```text
∠AOB + ∠BOC = 90°
```

若 ∠AOB = 28°，则 ∠BOC 为 `90° − 28° = 62°`。

使用 90° 的依据是整体角为直角，不是仅仅因为两个角相邻。图中的直角标记或明确的垂直条件，才提供这个信息。

## 八、平角内的邻角

A、O、C 在同一条直线上，O 位于 A 与 C 之间，OA 和 OC 是方向相反的射线。OB 从 O 向直线一侧伸出：

```text
         B
        ↗
       /
A ←───O────────→ C
```

∠AOB 与 ∠BOC 相邻，外侧两条边 OA、OC 组成平角，所以：

```text
∠AOB + ∠BOC = 180°
```

若 ∠BOC 为 65°，则 ∠AOB 为 `180° − 65° = 115°`。检查：`115° + 65° = 180°`。

## 九、邻补角是邻角的特殊情形

两个角是邻角，且它们的非公共边是两条相反射线，就称为邻补角。

邻补角组成平角，和为 180°；一般邻角则没有固定的度数和。

```text
35° 与 45° 挨在一起：可以是邻角，和为 80°
115° 与 65° 组成平角：是邻补角，和为 180°
```

“邻”说明位置关系，“补”说明度数和为 180°。下一些章节会进一步讨论互余、互补等度数关系，它们不一定要求角相邻。

## 十、多个角分割一个整体

从 O 引出 OA、OB、OC、OD，射线按这个顺序位于一个 140° 的 ∠AOD 内部，没有遗漏或重叠。

```text
∠AOB = 32°
∠BOC = 47°
∠COD 未知
```

三个部分合计等于整体：

```text
32° + 47° + ∠COD = 140°
∠COD = 140° − 32° − 47° = 61°
```

这里是依次相邻的多个角，不是说任意两部分都互为邻角。例如 ∠AOB 与 ∠COD 不共用一条边。

## 十一、角平分线提供相等关系

一条射线把一个角分成两个相等的角，这条射线叫作这个角的角平分线。

如果 OB 是 ∠AOC 的角平分线，且 ∠AOC = 86°：

```text
∠AOB = ∠BOC = 86° ÷ 2 = 43°
```

两个小角既相邻又相等。但仅仅相邻，不能断定它们相等；必须有角平分线或等角标记等明确条件。

画在大角中间附近的射线，也不一定就是角平分线。示意图的位置不能替代条件。

## 十二、用方程表示邻角关系

两个邻角组成平角，其中一个角是另一个角的 2 倍。设较小角为 x°，较大角为 2x°：

```text
x + 2x = 180
3x = 180
x = 60
```

所以两个角为 60° 与 120°。

检查：两者的和为 180°，而 `120 ÷ 60 = 2`。这里方程中的数字表示度数，最终结果要写上 °。

如果条件只说两角相邻、其中一个是另一个的 2 倍，却没有给出整体角或其他规模信息，就不能确定它们的具体度数。

## 十三、完整演示：先合并再拆分

OA 与 OD 互相垂直，∠AOD 为 90°。OB、OC 位于这个直角内部，从 OA 向 OD 的顺序为 OA、OB、OC、OD。已知 ∠AOB = 24°，∠BOC = 31°。

先合并前两个相邻部分：

```text
∠AOC = 24° + 31° = 55°
```

再从整个直角中去掉这部分：

```text
∠COD = 90° − 55° = 35°
```

也可以一次列出 `24° + 31° + ∠COD = 90°`，得到同样结果。

检查：`24° + 31° + 35° = 90°`。每个部分恰好计入一次，没有重叠，也没有遗漏。

## 十四、小结

邻角共用一个顶点和一条边，内部不重叠。判断时看清角的范围，不能只凭距离近或有公共边作结论。

邻角能按图形关系合并成整体角，已知整体和部分时可以用减法求剩余部分。整体为直角或平角时，才分别使用 90° 或 180°。

邻补角是外侧边组成相反射线的特殊邻角。求未知角时，先写出位置与整体关系，再列式或列方程，最后检验各部分的度数和。
