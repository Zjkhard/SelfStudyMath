# 代数式二

小安有 `x` 张卡片，小林比小安多 4 张。小安的数量可以写成 `x`，小林的数量可以写成 `x + 4`。

如果要表示两人的总数，就需要把这两个式子合起来。这一节继续学习怎样组合、化简和使用代数式，让式子清楚地表达数量关系。

## 一、把两个数量合起来

我们先用线段图表示两人的卡片数：

```text
小安：[       x       ]
小林：[       x       ][ 4 ]

总数：[       x       ][       x       ][ 4 ]
```

两人的总数是：

```text
x + (x + 4)
= x + x + 4
= 2x + 4
```

图中的两段 `x` 对应 `2x`，多出来的 4 张对应常数项 4。

`x + (x + 4)` 展示两个人各有多少，`2x + 4` 展示总数由两个相同部分和一个多出的部分组成。两种形式表示同一个数量。

## 二、代数式与方程的用途

如果只知道小林比小安多 4 张，总数可以用 `2x + 4` 表示，但还不能确定 `x` 的值。

如果又知道两人一共有 30 张，就可以写出方程：

```text
2x + 4 = 30
```

代数式用来表示数量，方程则用等号表示两个数量相等。化简 `2x + 4` 不需要找出 `x`；解这个方程才是在找符合相等关系的 `x`。

## 三、两个代数式的和

两盒彩笔，第一盒有 `2x + 3` 支，第二盒有 `x + 5` 支。总支数是两盒支数的和。

```text
(2x + 3) + (x + 5)
= 2x + 3 + x + 5
= 2x + x + 3 + 5
= 3x + 8
```

括号前是加号，去掉括号后，括号内各项的符号保持不变。随后分别合并含 `x` 的项和常数项。

当 `x = 4` 时，第一盒有 11 支，第二盒有 9 支，总数是 20 支；化简后的式子也得到 `3 × 4 + 8 = 20`。

## 四、两个代数式的差

一根绳子长 `(5x + 7) cm`，剪去 `(2x + 3) cm`。剩下的长度要用原长减去剪去的整段长度。

```text
(5x + 7) − (2x + 3)
= 5x + 7 − 2x − 3
= 3x + 4
```

剪去的部分既包含 `2x`，也包含 3，所以这两部分都要减去。

当 `x = 2` 时，原长是 17 cm，剪去 7 cm，剩下 10 cm。化简后的式子给出 `3 × 2 + 4 = 10`，与实际关系一致。

## 五、减去一个含减法的式子

看代数式 `(6x + 2) − (2x − 5)`。括号前的减号作用于整个 `2x − 5`。

减去这个整体，相当于先减去 `2x`，再加回 5：

```text
(6x + 2) − (2x − 5)
= 6x + 2 − 2x + 5
= 4x + 7
```

也可以把减号看成乘以 `−1`，用分配律解释：

```text
−(2x − 5)
= (−1) × 2x + (−1) × (−5)
= −2x + 5
```

当 `x = 3` 时，原式是 `20 − 1 = 19`，化简后的式子是 `12 + 7 = 19`。去括号时，原来括号中的每一项都要处理。

## 六、多个括号的化简

看代数式 `3(x + 2) + 2(x + 5)`。两个括号分别表示两种成组的数量。

先分别展开，再合并：

```text
3(x + 2) + 2(x + 5)
= 3x + 6 + 2x + 10
= 3x + 2x + 6 + 10
= 5x + 16
```

第一个括号中的两项都乘 3，第二个括号中的两项都乘 2。两个乘数各自对应自己的括号。

## 七、减去若干个整体

`4(x + 3) − 2(x + 1)` 表示从前一个数量中减去两个 `x + 1`。

可以先展开两个乘积，保留减法的整体范围：

```text
4(x + 3) − 2(x + 1)
= (4x + 12) − (2x + 2)
= 4x + 12 − 2x − 2
= 2x + 10
```

不能把第二个乘积写成 `−2x + 2`，因为被减去的是整个 `2x + 2`。

## 八、有两个字母时分别合并

一盒彩笔有 `a` 支，一盒铅笔有 `b` 支。两次购买的总支数分别是 `2a + b` 和 `a + 3b`。

```text
(2a + b) + (a + 3b)
= 2a + a + b + 3b
= 3a + 4b
```

`3a` 表示 3 盒彩笔的支数，`4b` 表示 4 盒铅笔的支数。每盒的支数可能不同，所以不能直接写成 `7a` 或 `7b`。

当 `a = 6`、`b = 10` 时：

```text
3a + 4b
= 3 × 6 + 4 × 10
= 18 + 40
= 58
```

总共买了 58 支笔。代入两个字母时，要分别使用各自给定的值。

## 九、把一个整体平均分

两盒相同的积木，每盒有 `x` 块，另有 6 块散装积木。把所有积木平均分给两组。

```text
总数：[ x 块 ][ x 块 ][ 6 块 ]

第一组：[ x 块 ][ 3 块 ]
第二组：[ x 块 ][ 3 块 ]
```

每组可以得到一盒的数量，再加上散装积木的一半：

```text
(2x + 6) ÷ 2
= 2x ÷ 2 + 6 ÷ 2
= x + 3
```

整个和除以 2，和中的每一项都要除以 2。

## 十、除以常数的化简

同样的道理适用于差。把 `(12x − 8)` 看成整体，除以 4：

```text
(12x − 8) ÷ 4
= 12x ÷ 4 − 8 ÷ 4
= 3x − 2
```

一般地，如果 `c` 是不为 0 的数：

```text
(a + b) ÷ c = a ÷ c + b ÷ c
(a − b) ÷ c = a ÷ c − b ÷ c
```

这是因为除以 `c` 可以看成乘以 `1/c`，再运用乘法分配律。这里的除数是整个式子共同的除数，且不能为 0。

## 十一、看清除法的范围

比较下面两个式子：

```text
(x + 6) ÷ 2：x 与 6 的和除以 2
x + 6 ÷ 2：x 加上 6 除以 2 的商
```

当 `x = 8` 时：

```text
(8 + 6) ÷ 2 = 7
8 + 6 ÷ 2 = 8 + 3 = 11
```

如果用分数形式写，`(x + 6)/2` 的分子是整个 `x + 6`，表示它们的和除以 2。

括号和分数线都可以表示整体的范围。去掉括号之前，要确认是否仍然表示同一个数量。

## 十二、分数系数表示什么

一段绳子长 `x m`，它的一半可以表示为：

```text
x ÷ 2 = x/2 = (1/2)x
```

这三种写法都表示 `x` 的一半。`(1/2)x` 中的系数是 `1/2`。

例如，把长 `x m` 的绳子的一半和四分之一合起来：

```text
(1/2)x + (1/4)x
= (1/2 + 1/4)x
= (3/4)x
```

字母部分相同，仍然只合并系数。当 `x = 8` 时，合起来长 `4 + 2 = 6 m`，也就是 8 m 的四分之三。

## 十三、先展开，再除以一个数

看代数式 `[2(x + 3) + 4x] ÷ 2`。这里的方括号 `[]` 与小括号一样，用来标明一个整体；使用不同形状可以看清内外范围。

```text
[2(x + 3) + 4x] ÷ 2
= (2x + 6 + 4x) ÷ 2
= (6x + 6) ÷ 2
= 3x + 3
```

先处理里面的小括号，再合并同类项，最后把整个和除以 2。也可以先把方括号中的两个部分分别除以 2，得到 `(x + 3) + 2x`，同样化简为 `3x + 3`。

## 十四、选择合适的形式

`6x + 12` 与 `6(x + 2)` 表示同一个数量。前一种形式展示两项的和，后一种形式展示 6 个相同的整体。

当 `x = 8` 时，用后一种形式计算很方便：

```text
6(x + 2)
= 6 × (8 + 2)
= 6 × 10
= 60
```

如果要与 `3x` 相加，展开的形式更方便合并：

```text
(6x + 12) + 3x = 9x + 12
```

化简不是必须去掉所有括号。我们可以根据要观察的关系或要完成的计算，选择合适的等价形式。

## 十五、判断两种形式是否等价

我们用分配律和合并同类项比较 `2(x + 3) + x` 与 `3x + 6`：

```text
2(x + 3) + x
= 2x + 6 + x
= 3x + 6
```

这些变形对所有允许的 `x` 值都成立，所以两个式子等价。

只代入一个数得到相同结果，还不能说明两个式子等价。例如，`2x` 和 `x + 1` 在 `x = 1` 时都等于 2，但在 `x = 2` 时分别等于 4 和 3。

代入可以帮助检查一个例子。要说明两种形式始终表示同一个数量，还需要解释数量关系或依据运算规律进行变形。

## 十六、同一情境的两种表示

一个长方形的宽为 `x cm`，长为 `(2x + 3) cm`。周长可以通过两条宽和两条长相加得到：

```text
周长的数值 = 2x + 2(2x + 3)
           = 2x + 4x + 6
           = 6x + 6
```

也可以先算一条长与一条宽的和，再乘 2：

```text
周长的数值 = 2[x + (2x + 3)]
           = 2(3x + 3)
           = 6x + 6
```

两种写法都对应长方形的同一条边界。当 `x = 4` 时，宽是 4 cm，长是 11 cm，周长是 `6 × 4 + 6 = 30 cm`。

## 十七、用代数式表示变化后的数量

一盒彩笔原来有 `x` 支。先放入 5 支，再从盒子中取出 2 支：

```text
原来的数量：x
放入后：x + 5
取出后：(x + 5) − 2 = x + 3
```

两次变化合起来，数量比原来多 3 支。

如果有 4 盒，每盒都经历同样的变化，总支数是：

```text
4(x + 3) = 4x + 12
```

这里的 3 是每盒增加的支数，12 是 4 盒合计增加的支数。先明确变化发生在每盒还是全部，才能确定是否需要乘 4。

## 十八、用表格观察数量变化

一叠卡片有 3 张散装卡片，再加上 `n` 袋卡片，每袋 2 张。总张数可以表示为 `2n + 3`。

| 袋数 n | 袋装卡片张数 2n | 总张数 2n + 3 |
| ---: | ---: | ---: |
| 0 | 0 | 3 |
| 1 | 2 | 5 |
| 2 | 4 | 7 |
| 3 | 6 | 9 |
| 4 | 8 | 11 |

每增加 1 袋，总张数就增加 2。散装的 3 张始终不变。

这里 `n` 表示袋数，只取 0、1、2 等非负整数。字母允许取哪些值，要结合它表示的数量判断。

下一节会把这样的对应关系画在坐标图上，观察一个数量变化时，另一个数量怎样变化。

## 十九、完整演示：平均分配后的数量

有 3 包相同的卡片，每包 `x` 张，另有 9 张散装卡片。把这些卡片平均分给 3 人，再给每人增加 2 张。

我们先沿着分配过程表示每个人的张数：

```text
原来的总张数：3x + 9
平均分后每人的张数：(3x + 9) ÷ 3
增加后每人的张数：(3x + 9) ÷ 3 + 2
```

把整个和除以 3，再合并常数：

```text
(3x + 9) ÷ 3 + 2
= 3x ÷ 3 + 9 ÷ 3 + 2
= x + 3 + 2
= x + 5
```

也可以直接从分配关系理解：每人先得到一包的数量和 3 张散装卡片，再增加 2 张，所以每人有 `x + 5` 张。

当每包有 8 张时：

```text
原来的总张数 = 3 × 8 + 9 = 33
每人分得 = 33 ÷ 3 = 11
增加后每人有 = 11 + 2 = 13
```

代入化简后的式子，也得到 `8 + 5 = 13`。后来每人增加的 2 张来自另外准备的卡片，3 人一共增加了 6 张。

## 二十、小结

组合代数式时，先看清每个式子表示哪个数量，再确定是相加、相减，还是把一个整体乘或除以一个数。

去括号时要保留原来的运算关系。减去一个整体，要处理其中每一项；一个和或差除以同一个不为 0 的数，也要把每一项分别除以这个数。合并同类项时，只合并系数，字母部分保持不变。

同一个数量可以有不同的等价表示。选择合适的形式，有助于解释关系和代入计算；数值表则能帮助我们观察字母的值改变时，所表示的数量怎样变化。
