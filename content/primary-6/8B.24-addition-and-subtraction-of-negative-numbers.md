# 负数加法与减法

一个点在数轴上的 −3 处，向右移动 5 个单位，会经过 0 到达 2。这个过程可以写成 `−3 + 5 = 2`。

上册已经接触过正负数运算。本节把数轴、相反数和逆运算联系起来，进一步解释规则，并处理连续加减和括号。

## 一、起点与移动是两种信息

数轴上通常规定向右为正，向左为负。

```text
起点：−3
变化：+5，表示向右 5 个单位
终点：2
```

起点为负，不意味着移动方向向左；变化为负，也不意味着终点一定为负。

例如从 4 加上 −2，表示向左移动 2 个单位，终点仍为正数 2。

## 二、用正负单位抵消

把 +1 与 −1 看作一对相反的单位，它们合计为 0。

```text
(+1) + (−1) = 0
```

计算 `−3 + 5`，五个正单位与三个负单位配对，三对抵消后，剩下两个正单位，结果为 2。

计算 `−5 + 3`，抵消后剩下两个负单位，结果为 −2。

这种模型帮助解释异号相加：结果取决于哪一方向的数量较多，而不是只看某个数写在前面。

## 三、同号相加保留共同方向

两个负数相加，表示负方向数量合并：

```text
(−4) + (−7) = −11
```

在数轴上，从 −4 再向左移动 7 个单位，得到 −11。

同号相加时，绝对值相加，保留共同符号：

```text
(+4) + (+7) = +11
(−0.8) + (−1.2) = −2
```

绝对值表示数量大小，符号表示方向。加上一个负数，数值会减少，而不是因为名称叫加法就一定变大。

## 四、异号相加比较绝对值

计算 `−8 + 5`，两个方向抵消 5 个单位，剩下负方向 3 个单位。

```text
8 − 5 = 3
结果为 −3
```

异号相加，用较大的绝对值减去较小的绝对值，结果取绝对值较大的数的符号。

```text
−5 + 8 = 3
−8 + 8 = 0
```

绝对值相等时恰好抵消，结果为 0，不能再给 0 判断正负。

## 五、零与相反数

```text
a + 0 = a
a + (−a) = 0
```

第二行说明任意数与它的相反数相加为 0。例如 `−1.5 + 1.5 = 0`。

如果 a 已经是负数，−a 就是它的相反数，可能为正。例如 a = −6，则 `−a = −(−6) = 6`。

因此，字母前面的负号表示取相反数，不能一律断定表达式的结果为负。

## 六、从逆运算理解减去负数

减法与加法互为逆运算。要计算 `3 − (−2)`，就是找一个数 x，使：

```text
x + (−2) = 3
```

因为 `5 + (−2) = 3`，所以 x = 5。

```text
3 − (−2) = 5 = 3 + 2
```

这说明减去 −2 等于加上它的相反数 +2。在数轴上，减去负数对应向右移动，不是向左移动两次。

## 七、减法统一转成加相反数

一般地：

```text
a − b = a + (−b)
```

只把被减去的数换成相反数，第一个数保持不变。

```text
4 − 7 = 4 + (−7) = −3
4 − (−7) = 4 + 7 = 11
(−4) − 7 = (−4) + (−7) = −11
(−4) − (−7) = (−4) + 7 = 3
```

四种算式的数值大小相同，但符号与运算关系不同。先转化减法，再使用加法规则，不必把它们记成互不相关的技巧。

## 八、负号与减号按作用辨认

在 `(−4) − (−7)` 中，两括号内的符号表示负数，中间的符号表示减法。

```text
第一个数：−4
运算：减去
第二个数：−7
```

括号标明整个数，避免把连续符号混在一起。

不能笼统地把“两个负号”都改成正号。`(−4) + (−7)` 是两个负数相加，结果为 −11；`−(−7)` 才表示 −7 的相反数 7。

## 九、分数与小数保留原计算方法

计算 `(−3/4) + 1/2`，先通分：

```text
(−3/4) + 1/2
= (−3/4) + 2/4
= −1/4
```

计算 `(−1.2) − (−0.75)`，先加相反数：

```text
(−1.2) + 0.75 = −0.45
```

符号规则决定两个数量怎样合并，通分或小数位值规则决定绝对值怎样计算。不能把负号作为省略通分或忽略小数点的理由。

## 十、连续加减先保留每项符号

计算 `−5 + 8 − (−3) − 6`，逐项转成加法：

```text
−5 + 8 + 3 + (−6)
= 3 + 3 − 6
= 0
```

也可以把正项与负项分别合并：正项为 `8 + 3 = 11`，负项为 `−5 − 6 = −11`，相加为 0。

加法可以交换和结合；移动的是整个带符号的加数。不能把 −6 换到前面时丢掉负号。

减法本身没有交换律。例如 `3 − 5 = −2`，而 `5 − 3 = 2`。

## 十一、括号前的加减影响整个括号

```text
−3 + (5 − 7)
= −3 + (−2)
= −5
```

括号前为加号，也可以去掉括号，保留里面各项方向：`−3 + 5 − 7 = −5`。

若括号前为减号，减去的是整个括号值：

```text
−3 − (5 − 7)
= −3 − (−2)
= −1
```

去括号后应为 `−3 − 5 + 7`。括号里的每一项都要取相反方向，不能只改变第一项。

## 十二、相反数作用于整个和或差

```text
−(a + b) = −a − b
−(a − b) = −a + b
```

可以用具体数检查第二个关系，例如 a = 4、b = 7：

```text
−(4 − 7) = −(−3) = 3
−4 + 7 = 3
```

理解负号的范围，也为后面的代数式化简与解方程准备依据。单次代入是检查例子，关系本身来自整个和或差的相反数。

## 十三、位置变化与距离

以地面为 0，一个平台的位置由 −2 m 上升到 3 m。

```text
变化量 = 最终位置 − 初始位置
       = 3 − (−2)
       = 5 m
```

正的变化量表示上升 5 m。反向从 3 m 下降到 −2 m，变化量为 `−2 − 3 = −5 m`。

两个位置之间的距离都是 5 m，距离不带负号。位置、带方向的变化量与距离不能混为一谈。

## 十四、用逆运算检验减法

计算 `(−8) − (−3) = −5` 后，可以检查：

```text
差 + 减数 = 被减数
−5 + (−3) = −8
```

回到被减数，说明减法关系正确。

还可以检查变化方向：从 −8 减去 −3，应向右移动 3 个单位，得到 −5，数值比 −8 大。

检查时同时看符号、数量大小和运算关系，不能只看答案有没有负号。

## 十五、完整演示：连续温度变化

某处起初温度为 −2.5°C，先升高 4°C，再降低 1.75°C。我们一起求最终温度及相对于起初的变化。

```text
升高后：−2.5 + 4 = 1.5°C
降低后：1.5 − 1.75 = −0.25°C
```

也可以一次列式：

```text
−2.5 + 4 − 1.75 = −0.25
```

两次变化合计为 `4 − 1.75 = +2.25°C`，说明最终比起初升高 2.25°C。

用两个温度相减检查：`−0.25 − (−2.5) = 2.25°C`，与总变化一致。

最终温度仍为负，并不表示整个过程比起初降温。判断变化要比较前后位置，而不是只看最终符号。

## 十六、小结

加法可以用数轴移动和正负单位抵消理解。同号相加合并绝对值并保留共同符号；异号相加比较绝对值，抵消后确定剩余方向。

减去一个数等于加上它的相反数。看清负号、减号与括号的范围，转化为加法后才可以灵活交换和组合带符号的项。

分数与小数继续使用通分和位值方法。最终用数轴方向、逆运算和实际情境检查，并区分位置、变化量和距离。
