# 互余角

一条射线把一个直角分成两个小角，其中一个是 32°，另一个就是 `90° − 32° = 58°`。

32° 与 58° 合起来正好是 90°。这种度数关系有一个名称：互余。这一节观察互余角的含义，以及它怎样帮助我们求未知角。

## 一、从分割直角开始

OA 与 OC 互相垂直，OB 位于直角 ∠AOC 内部。示意图只表示射线的位置关系。

```text
C
↑       B
│      ↗
│    /
│  /
O──────────→ A
```

两个小角分别是 ∠AOB 和 ∠BOC，恰好覆盖整个直角，没有重叠或遗漏。

```text
∠AOB + ∠BOC = 90°
```

这里邻角的合并关系与“整体是直角”的条件共同给出了 90°。

## 二、互余角的含义

如果两个角的度数和是 90°，就说这两个角互为余角，也可以说它们是互余角。

```text
32° + 58° = 90°
32° 的余角是 58°
58° 的余角是 32°
```

“互为”表示关系是双向的。不能单独说“32° 是余角”，而应说明它是谁的余角。

互余描述度数和，并不要求两角相等。

## 三、互余角不一定相邻

一个角为 20°，另一个角为 70°，即使它们画在不同的位置、有不同的顶点，仍然互余：

```text
20° + 70° = 90°
```

如果把它们按相邻且内部不重叠的方式放在一起，就能组成直角。但判断原来的两个角是否互余，只需确认度数和为 90°。

邻角是位置关系，互余角是度数关系。两个相邻角的和若为 80°，就不互余；两个不相邻角的和为 90°，则互余。

## 四、求一个已知角的余角

已知角为 37°，余角与它合计为 90°：

```text
余角 = 90° − 37° = 53°
```

检查：`37° + 53° = 90°`。

再看带小数的角：12.5° 的余角为 `90° − 12.5° = 77.5°`。角的度数不一定是整数，仍使用同一个关系。

计算结果要写上 °，不能把角度写成长度或百分数。

## 五、本节讨论的互余角都是锐角

本节主要讨论度数大于 0°的普通角。如果两个这样的角互余，它们都小于 90°，所以都是锐角。

但两个锐角不一定互余。例如 30°与 40°都是锐角，和为 70°，不能称为互余角。

一个 110°的角不能与一个正度数的普通角合成 90°。`90° − 110° = −20°` 不是本节意义下的余角。

若把 0°的零角也纳入讨论，90°与 0°的和也是 90°。本节的图形演示主要使用两个正度数锐角，不把这个边界情形混入普通分角图。

## 六、两个相等的角互余

如果两个互余角相等，它们平均分担 90°：

```text
每个角 = 90° ÷ 2 = 45°
```

在直角中，角平分线把直角分成两个 45°的邻角。这两个角既相邻、相等，又互余。

只有互余条件时，不能断定两个角都是 45°；只有相等条件时，也不能断定它们互余。这里同时使用了两种关系。

## 七、同一个角的余角相等

如果 α 和 β 都是一个 28°角的余角：

```text
α = 90° − 28° = 62°
β = 90° − 28° = 62°
```

所以 α 与 β 相等，哪怕它们位于不同图形中。

更一般地，两个相等的角，各自的余角也相等。原因是从相同的 90°中减去相等的度数，剩余度数相同。

这不是说“所有余角都相等”，而是要求它们对应同一个角或两个相等的角。

## 八、已知互余与差求两个角

两个角互余，较大角比较小角大 18°。设较小角为 x°，较大角为 `(x + 18)°`：

```text
x + (x + 18) = 90
2x + 18 = 90
2x = 72
x = 36
```

所以较小角为 36°，较大角为 54°。

检查：`36° + 54° = 90°`，`54° − 36° = 18°`。互余与差两个条件都满足。

## 九、已知互余与倍数求两个角

两个角互余，其中一个是另一个的 2 倍。设较小角为 x°，较大角为 2x°：

```text
x + 2x = 90
3x = 90
x = 30
```

两个角分别为 30°和 60°。

也可以用等份模型：两个角共占 3 份，3 份对应 90°，每份为 30°。

仅知道两个角互余，不能确定每个角是多少；还需要一个角的度数、差、倍数等条件。

## 十、从垂直条件找到互余关系

OA 与 OC 垂直，OB 在 ∠AOC 内部，已知 ∠AOB = 41°。

先说明依据，再计算：

```text
OA ⟂ OC → ∠AOC = 90°
∠AOB 与 ∠BOC 恰好组成 ∠AOC
所以 ∠BOC = 90° − 41° = 49°
```

符号 `⟂` 表示互相垂直。

如果图形没有垂直条件、直角标记或给定的 90°，不能因为两条射线看起来像竖直和水平，就断定两个小角互余。

## 十一、直角被分成三个部分

一个直角被依次分成 20°、25°和一个未知角，三个区域没有重叠或遗漏：

```text
未知角 = 90° − 20° − 25° = 45°
```

三个角合计为 90°，但这不表示任意两个角互余。20°与 25°的和只有 45°。

把前两个角合成一个 45°的角后，这个合成角与剩下的 45°角才互余。

“互余角”通常说的是两个角之间的关系。多个角合计为直角时，要先辨认哪两个区域合在一起覆盖整个直角。

## 十二、结合对顶角找余角

两条直线相交形成一对对顶角，其中一个为 34°，另一个为 α。另有一个角 β 与 α 互余。

```text
对顶角相等：α = 34°
互余关系：β = 90° − 34° = 56°
```

不能把 β 算成 146°。146°是与 34°组成平角所需的角，而这里的条件是互余，整体应为 90°。

先确认用的是相等、直角和还是平角和，再选择计算。

## 十三、直角三角形中的两个锐角

三角形内角和为 180°。一个直角三角形已有一个角为 90°，另外两个角的和为：

```text
180° − 90° = 90°
```

所以直角三角形的两个锐角互余。它们位于不同顶点，不是邻角，却有互余关系。

如果其中一个锐角为 38°，另一个为 `90° − 38° = 52°`。检查：`90° + 38° + 52° = 180°`。

这个结论来自三角形内角和与直角条件，而不是来自两个锐角在图上看起来大小接近。

## 十四、完整演示：表达式表示的互余角

两个角互余，分别标为 `(2x + 5)°` 和 `(3x − 10)°`。我们一起求 x 和两个角的度数。

先按互余列式：

```text
(2x + 5) + (3x − 10) = 90
5x − 5 = 90
5x = 95
x = 19
```

再代回各自的角度表达式：

```text
第一个角 = 2 × 19 + 5 = 43°
第二个角 = 3 × 19 − 10 = 47°
```

检查：两个角都是正度数锐角，`43° + 47° = 90°`，符合互余条件。

x 的值是 19，不等于任意一个角的度数。解方程之后，还要根据表达式找到真正要求的角。

## 十五、小结

两个角的度数和为 90°，就互为余角。互余是度数关系，不要求两个角相邻或共用顶点。

求已知角的余角，用 90°减去它的度数。同角或等角的余角相等；两个相等的互余角都是 45°。

遇到未知角，先从垂直、直角、三角形内角和或明确条件中确认互余关系，再列式或列方程。最后代回角度表达式，检查两个角的度数和是否为 90°。
