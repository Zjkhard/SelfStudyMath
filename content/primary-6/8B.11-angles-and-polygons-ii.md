# 多边形中的角二

沿正方形的边走一圈，每到一个顶点都转过 90°。四次转弯合起来，方向转了一整圈，也就是 360°。

这些转弯与多边形的外角有关。这一节继续比较内角与外角，解释外角和，并用它们求未知角。

## 一、延长一条边形成外角

在三角形 ABC 中，把 AB 经过 B 延长到 D。A、B、D 在同一直线上，B 位于 A 与 D 之间。

```text
       C
      / \
     /   \
A───/─────B────────→ D
```

B 处的内角是 ∠ABC；BC 与延长线 BD 形成的 ∠CBD 是一个外角。示意图不代表准确角度。

本节的外角，指多边形一条边与相邻边的延长线形成、和该顶点内角相邻的角，不是图形外部任意标出的角。

## 二、同一顶点内外角互补

BA 与 BD 是相反射线，内角 ∠ABC 与外角 ∠CBD 组成平角：

```text
内角 + 对应外角 = 180°
```

如果内角为 110°，对应外角为 `180° − 110° = 70°`。

如果外角为 35°，内角为 `180° − 35° = 145°`。

外角的计算依据是邻补关系，不是用 360°减去一个内角。后者得到的是同一对边围出的另一个转动区域，通常不是这里的外角。

## 三、每个顶点只取一个外角

在同一顶点，可以选择延长相邻两条边中的一条，形成两个位置不同的外角。对于凸多边形，这两个外角都等于 180°减去该内角。

计算外角和时，沿边界按同一个方向，每个顶点只取一个对应外角。

不能把一个顶点的两个外角都计入，又把别的顶点只计入一个。条件和计数方式必须保持一致。

本节主要讨论凸多边形，它的内角小于 180°，因此这些对应外角都是正角度。

## 四、外角表示沿边界的转弯

沿三角形边界从 A 走到 B，再走向 C。在 B 处，如果不转弯，会沿 AB 的延长方向 BD 继续走；实际却转向 BC。

从 BD 转到 BC 的角，就是 B 处的外角。

```text
内角：朝向上一条边的反方向 BA，与下一条边 BC 的夹角
转弯角：原行进方向 BD，与下一条边 BC 的夹角
```

这解释了为什么转弯角与内角合计为 180°。

## 五、凸多边形的外角和

沿凸多边形的边界按同一方向走一圈，每个顶点向同一侧转弯，最后回到出发位置与原来的行进方向。

所有转弯合计是一整圈，所以：

```text
凸多边形外角和 = 360°
```

正方形每次转 90°，四次合计 360°；其他凸多边形的每次转弯可能不同，但总转弯仍是 360°。

这些角分布在不同顶点，不是同一个点周围的角。它们通过沿边界一周的方向变化联系起来，不能只凭“都在外部”就相加为 360°。

## 六、从内角和再次解释

凸 n 边形每个内角与对应外角合计为 180°。n 组相加：

```text
内角和 + 外角和 = n × 180°
内角和 = (n − 2) × 180°
```

相减得到：

```text
外角和 = n × 180° − (n − 2) × 180°
       = 360°
```

内角和随边数变化，外角和却保持 360°。五边形内角和为 540°，六边形为 720°，两者按本节方式选取的外角和都是 360°。

## 七、求未知外角

一个凸五边形按同一方向、每个顶点取一个外角，已知其中四个为 50°、70°、80°、60°。

```text
未知外角 = 360° − 50° − 70° − 80° − 60°
         = 100°
```

该顶点的内角为 `180° − 100° = 80°`。

检查五个外角合计为 360°。如果给出的是部分内角、部分外角，不能混在一起直接求和，应先转换成同一类角。

## 八、正多边形的每个外角

正 n 边形各内角相等，对应外角也相等。n 个外角平均分担一周：

```text
每个外角 = 360° ÷ n
每个内角 = 180° − 360°/n
```

| 正多边形 | 每个外角 | 每个内角 |
| --- | ---: | ---: |
| 正三角形 | 120° | 60° |
| 正四边形 | 90° | 90° |
| 正五边形 | 72° | 108° |
| 正六边形 | 60° | 120° |
| 正八边形 | 45° | 135° |

不能用 360°除以边数，直接称为每个内角；这个平均分配的是外角和。

## 九、已知正多边形外角求边数

一个正多边形每个外角为 24°：

```text
边数 = 360° ÷ 24° = 15
```

它是正十五边形，每个内角为 `180° − 24° = 156°`。

检查：`15 × 24° = 360°`；内角和为 `15 × 156° = 2340°`，也等于 `(15 − 2) × 180°`。

这种直接除法需要每个外角相等，不能只知道一个不规则多边形的某个外角，就反求边数。

## 十、已知正多边形内角求边数

一个正多边形每个内角为 150°，先求对应外角：

```text
外角 = 180° − 150° = 30°
边数 = 360° ÷ 30° = 12
```

所以它是正十二边形。

反求的边数必须是至少为 3 的整数。如果得到非整数，应检查给定度数是否能作为正多边形的准确内角，而不是直接四舍五入边数。

## 十一、三角形外角与另外两个内角

三角形 ABC 中，AB 经过 B 延长到 D。三个内角和为 180°：

```text
∠A + ∠ABC + ∠C = 180°
∠CBD + ∠ABC = 180°
```

从同一个 180°中减去 ∠ABC，得到：

```text
∠CBD = ∠A + ∠C
```

三角形的一个外角，等于与它不相邻的另外两个内角之和。

例如 ∠A = 42°、∠C = 63°，则 B 处外角为 105°，B 处内角为 75°。

## 十二、已知三角形外角求内角

三角形 B 处外角为 128°，A 处内角为 53°：

```text
C 处内角 = 128° − 53° = 75°
B 处内角 = 180° − 128° = 52°
```

检查：`53° + 75° + 52° = 180°`。

不能把三角形外角等于另外两个内角之和的结论，直接套到任意多边形的一组角上。它的推导使用的是三角形内角和。

## 十三、用方程连接内角与外角

一个凸多边形某顶点的内角标为 `(3x + 20)°`，对应外角标为 `(x + 40)°`。

```text
(3x + 20) + (x + 40) = 180
4x + 60 = 180
x = 30
```

内角为 110°，外角为 70°。检查两者合计为 180°。

若条件是两个不同顶点的外角，就不能自动把它们的和设为 180°。需要先确认它们与哪些内角对应，以及是否有其他关系。

## 十四、直角标记与外角求和配合

一个凸五边形有两个内角为直角，其余三个顶点的外角分别为 50°、60°和 x°。

两个直角对应的外角也为 90°：

```text
90 + 90 + 50 + 60 + x = 360
x = 70
```

五个内角分别为 90°、90°、130°、120°、110°，合计 540°。

先把所有条件转换成外角求和，再用内角和检验，可避免把两个直角和三个外角不加解释地混合相加。

## 十五、适用范围与图形条件

本节的外角和计算使用凸多边形，每个顶点按同一行进方向取一个转弯外角。

凹多边形沿边界行走时，可能向不同侧转弯，要进一步约定带方向的转角，不能把所有看起来在外部的正角度简单相加为 360°。本节不展开这种计算。

同样，边界交叉的星形线条不直接使用这里的凸多边形模型。示意图也不能替代直线、正多边形、垂直或等角等已知条件。

## 十六、完整演示：两条途径求正多边形边数

一个正多边形的每个内角为 144°。我们一起求边数，并用内角和验证。

先转换到外角：

```text
每个外角 = 180° − 144° = 36°
边数 = 360° ÷ 36° = 10
```

它是正十边形。检验内角和：

```text
10 × 144° = 1440°
(10 − 2) × 180° = 1440°
```

也可以直接设边数为 n：

```text
144n = (n − 2) × 180
144n = 180n − 360
36n = 360
n = 10
```

两种方法得到相同的整数边数。一个使用外角一周 360°，另一个使用三角形分割得到的内角和，它们描述同一个图形。

## 十七、小结

凸多边形的对应内角与外角组成平角，度数和为 180°。沿边界按同一方向、每个顶点取一个外角，合计为 360°。

正多边形外角相等，每个外角为 360°除以边数；已知内角时，先减出对应外角，也能反求边数。三角形的一个外角，还等于另外两个不相邻内角之和。

综合求角时，先统一角的类型和范围，再选择平角、外角和或内角和关系。最后检查度数和、边数及图形条件是否一致。
