# 解方程

某处温度原来是 x°C，升高 5°C 后变成 2°C。数量关系为 `x + 5 = 2`，所以原来的温度是 −3°C。

方程的解可以是负数，也可以是分数或小数。本节承接上册的解方程方法，重点处理符号与括号，并说明每一步为什么保持相同的解。

## 一、从原关系找出未知数

```text
原温度：x°C
升高：5°C
最终温度：2°C
x + 5 = 2
```

方程的解是使左右两边相等的未知数值。把 x = −3 代入，`−3 + 5 = 2`，所以它符合原关系。

解方程不是把所有出现的数字依次计算，而是用相等关系找出 x。

## 二、等价变形保持相同的解

等式两边同时加或减同一个数，仍保持相等；同时乘或除以同一个非零数，也保持相等，且操作可以反向恢复。

```text
x + 5 = 2
x + 5 − 5 = 2 − 5
x = −3
```

原方程与新方程有相同的解，称为等价变形。

不能把两边都乘 0，得到 `0 = 0` 就说已经解出方程，因为这样丢失了原来的限制。除以 0 则没有定义。

本节乘除变形使用已知的非零数，不擅自除以可能为 0 的未知表达式。

## 三、负系数的方程

方程 `−3x = 12` 中，−3 是 x 的系数。两边同时除以 −3：

```text
−3x = 12
x = 12 ÷ (−3)
x = −4
```

检查：`−3 × (−4) = 12`。

负系数不意味着解一定是负数。例如 `−3x = −12` 的解为 x = 4。符号要按两边实际数值判断。

## 四、两步方程按逆顺序撤销

解 `−2x + 7 = 15`，先撤销加 7，再撤销乘 −2：

```text
−2x + 7 = 15
−2x = 15 − 7
−2x = 8
x = 8 ÷ (−2)
x = −4
```

检验原式：`−2 × (−4) + 7 = 15`。

未知数单独留下时，仍要注意系数的负号，不能只除以 2 而漏掉 −2。

## 五、未知数前只有负号

解 `5 − x = 9`，两边同时减 5：

```text
−x = 4
```

−x 表示 x 的相反数。再两边同时乘 −1：

```text
x = −4
```

检查：`5 − (−4) = 9`。

`−x = 4` 不能直接写成 `x = 4`。把负号去掉，需要对等式两边进行相同的运算。

## 六、括号可以先作为整体

解 `−3(x − 2) = 12`，先两边除以 −3：

```text
x − 2 = −4
x = −4 + 2
x = −2
```

检验：`−3 × [(−2) − 2] = −3 × (−4) = 12`。

也可以先展开成 `−3x + 6 = 12`，再减 6、除以 −3，同样得到 −2。选择哪种方法，取决于怎样更容易看清整体。

## 七、括号前的减号作用于每一项

解 `8 − (2x − 3) = 5`，先正确去括号：

```text
8 − 2x + 3 = 5
11 − 2x = 5
−2x = −6
x = 3
```

检查原式：`8 − (2 × 3 − 3) = 8 − 3 = 5`。

不能展开成 `8 − 2x − 3`。括号前的减号表示减去整个差，里面第二项原来的负方向也要改变。

## 八、两边都有未知数

解 `5x − 4 = 2x + 8`，两边同时减去 2x，再同时加 4：

```text
3x − 4 = 8
3x = 12
x = 4
```

对任何固定的 x，两边的 2x 是同一个数，所以同时减去它保持等价关系。

检验：左边 `5 × 4 − 4 = 16`，右边 `2 × 4 + 8 = 16`。

常说的“移项变号”，就是省略写出两边同时加减的中间步骤。它不适用于把乘数直接换边写成加减。

## 九、展开后再合并

解 `2(x + 3) − 3(x − 1) = 14`：

```text
2x + 6 − 3x + 3 = 14
−x + 9 = 14
−x = 5
x = −5
```

检查原式：`2 × (−2) − 3 × (−6) = −4 + 18 = 14`。

先展开、再合并同类项，能看清 x 的实际系数。每个括号中的每一项都要乘到，不一次跳过多个符号变化。

## 十、分数系数可以乘倒数

解 `(3/4)x − 1/2 = 1`，先两边加二分之一：

```text
(3/4)x = 3/2
x = 3/2 ÷ 3/4
x = 3/2 × 4/3
x = 2
```

检查：`3/4 × 2 − 1/2 = 1`。

除以非零分数等于乘它的倒数，x 仍是被乘的未知量。不能把 `3/4` 当作要移到右边减去的常数项。

## 十一、清除分母要乘整个等式

解 `x/3 − 1/2 = 5/6`，三个分母 3、2、6 的共同倍数可选 6。两边每一项都乘 6：

```text
6 × (x/3 − 1/2) = 6 × 5/6
2x − 3 = 5
2x = 8
x = 4
```

检验：`4/3 − 1/2 = 8/6 − 3/6 = 5/6`。

这里只是乘以一个已知非零数，使等式表示更简洁。不能只给含 x 的项乘 6，而漏掉 −1/2。

## 十二、分子整体的范围

解 `(x − 2)/4 = −3/2`，两边乘 4：

```text
x − 2 = −6
x = −4
```

分母 4 原来除的是整个 `x − 2`。不能把原式当作 `x − 2/4`，那会变成另一个方程。

检查：`[(−4) − 2] ÷ 4 = −6/4 = −3/2`。

单行书写分式时，用括号保留分子范围，帮助解释乘除变形。

## 十三、小数方程按相同关系计算

解 `0.2x + 0.7 = −0.5`：

```text
0.2x = −1.2
x = −1.2 ÷ 0.2
x = −6
```

也可以两边同时乘 10，得到 `2x + 7 = −5`，再求解。所有项都乘 10，才能保持等价。

检查原式：`0.2 × (−6) + 0.7 = −1.2 + 0.7 = −0.5`。

解可以不是整数。例如 `2x = 1` 得到 x = 1/2。未知数允许哪些值，还要看实际情境。

## 十四、未知数消去不一定表示解为零

解 `2(x + 3) = 2x + 6`，展开后两边相同。两边减去 2x，得到 `6 = 6`。

这是对所有允许的 x 都成立的恒等关系，不是只在 x = 0 时成立。本例若允许任意实数取值，每个数都是解。

而 `2(x + 3) = 2x + 5` 同样变形后得到 `6 = 5`，不可能成立，所以没有解。

```text
未知数消去后：
成立的恒等式 → 所有允许值都符合
不成立的等式 → 无解
```

不要看到 x 消失就自动写 x = 0，也不要为了继续计算而除以 0。

## 十五、代回原方程检验

检验时把所得值放回原方程，分别计算左右两边，尤其保留原来的括号、分母与负号。

例如 `3 − 2(x + 1) = 7` 得到 x = −3：

```text
左边 = 3 − 2 × [(−3) + 1]
     = 3 − 2 × (−2)
     = 7
右边 = 7
```

左右相等，结果通过检验。只代入最后一行 `x = −3`，不能检查前面是否正确展开或计算。

## 十六、完整演示：连续温度变化反求起点

某处初始温度未知，先下降 4°C，再升高 1.5°C，最后温度为 −3°C。设初始温度为 x°C。

```text
x − 4 + 1.5 = −3
x − 2.5 = −3
x = −3 + 2.5
x = −0.5
```

初始温度为 −0.5°C。

回到情境检查：下降 4°C 后为 −4.5°C，再升高 1.5°C 后为 −3°C，符合最后记录。

方程给出了数值，字母的含义确定了结果单位与解释。若未知量是完整物品件数，还要检查整数与非负条件；温度则允许负数和小数。

## 十七、小结

解方程利用相等关系，逐步把未知数单独留下。两边同时加减同一量，或乘除同一个已知非零数，保持相同的解。

处理负系数、括号、分数与小数时，先看清项与整体范围，再展开、合并或清除分母。未知数消去后，要判断剩余等式是成立还是矛盾。

最后把所得值代回原方程，并结合允许取值、单位和实际情境检验。计算结果与它表示的数量都要符合条件。
