# 分数加法与减法

一根绳子剪下 `1/2 m`，又剪下 `1/3 m`，两次剪下的长度合计是多少？二分之一米和三分之一米不是同样大小的份，不能直接把两个“1 份”合成“2 份”。

这一节把已经学过的分数加减和正负号规则结合起来，继续观察怎样统一单位、处理带分数，并选择合适的计算顺序。

## 一、先让每一份同样大

以 1 m 为一个整体，把它平均分成 6 份。原来的二分之一米是 3 份，三分之一米是 2 份：

```text
每格表示 1/6 m

1/2 m：[■][■][■][□][□][□]
1/3 m：[■][■][□][□][□][□]
合计：3 份 + 2 份 = 5 份
```

图中两行都以相同的 1 m 为整体，不是在重复计算同一段绳子，而是在表示两次剪下的长度。

```text
1/2 + 1/3
= 3/6 + 2/6
= 5/6
```

两次合计剪下 `5/6 m`。通分让我们用相同的分数单位计数，原来的长度没有改变。

## 二、同分母加减只改变份数

分母相同，每一份的大小相同，可以直接对份数进行加减。

```text
3/8 + 2/8 = 5/8
7/10 − 3/10 = 4/10 = 2/5
```

分母保持不变，因为每份的大小没有改变。结果如果可以约分，就写成最简形式。

带负号时仍以相同大小的份为单位，例如：

```text
(−3/8) + 1/8 = −2/8 = −1/4
```

负方向的 3 份与正方向的 1 份抵消后，剩下负方向的 2 份。

## 三、选择合适的共同分母

计算 `5/12 + 7/18`。12 和 18 的共同倍数可以是 36、72、108 等，其中最小的是 36。

```text
5/12 = 15/36
7/18 = 14/36

5/12 + 7/18 = 29/36
```

共同分母不一定要用两个分母的乘积。选择最小公倍数，往往能让分子和分母更小，便于计算。

如果一个分母是另一个的倍数，例如 4 和 12，可以直接用 12 作共同分母：

```text
3/4 − 1/12 = 9/12 − 1/12 = 8/12 = 2/3
```

## 四、先约分可能更方便

计算 `6/15 + 3/10`，先把 `6/15` 约成 `2/5`：

```text
6/15 + 3/10
= 2/5 + 3/10
= 4/10 + 3/10
= 7/10
```

约分和通分都保持分数值不变。先观察能否约分，可以减少后续通分的工作。

但不能跨过加号，把一个分数的分子与另一个分数的分母相约。例如 `2/3 + 3/5` 中，两个 3 属于不同的加数，不能直接消去。

## 五、两个负分数相加

计算 `(−2/3) + (−1/4)`。两个变化方向相同，绝对值相加，结果保留负号。

```text
(−2/3) + (−1/4)
= (−8/12) + (−3/12)
= −11/12
```

可以理解为从 0 连续向左移动八个十二分之一和三个十二分之一，总共向左十一个十二分之一。

负号不会改变通分方法。改写等值分数时，负号也要保留。

## 六、异号分数相加

计算 `(−5/6) + 3/4`，先通分：

```text
(−5/6) + 3/4
= (−10/12) + 9/12
= −1/12
```

负方向的 10 份与正方向的 9 份抵消后，剩下负方向的 1 份。

再看 `5/6 + (−3/4)`：

```text
5/6 + (−3/4)
= 10/12 + (−9/12)
= 1/12
```

不能因为算式中有负数，就认为结果一定为负。要比较正负两个部分的绝对值。

## 七、减法先转化为加法

计算 `1/3 − 5/6`，减去 `5/6` 相当于加上 `−5/6`：

```text
1/3 − 5/6
= 1/3 + (−5/6)
= 2/6 + (−5/6)
= −3/6
= −1/2
```

被减数小于减数时，差为负数。

如果减去的是负分数，就加上对应的正分数：

```text
1/3 − (−5/6)
= 1/3 + 5/6
= 2/6 + 5/6
= 7/6
= 1 又 1/6
```

括号让我们看清被减去的是整个负数。

## 八、两个负分数相减

计算 `(−3/4) − (−5/6)`：

```text
(−3/4) − (−5/6)
= (−3/4) + 5/6
= (−9/12) + 10/12
= 1/12
```

这一次得到正数。反过来计算：

```text
(−5/6) − (−3/4)
= (−10/12) + 9/12
= −1/12
```

交换减法中两个数的位置，通常会改变结果。这里两个差互为相反数。

## 九、带分数相加与进位

计算 `2 又 5/6 + 1 又 3/4`，可以分别合并整数部分和分数部分：

```text
整数部分：2 + 1 = 3
分数部分：5/6 + 3/4 = 10/12 + 9/12 = 19/12
19/12 = 1 又 7/12
```

分数部分合成了一个完整单位和七个十二分之一，把这个完整单位并入整数部分：

```text
2 又 5/6 + 1 又 3/4 = 4 又 7/12
```

也可以先化成假分数：`17/6 + 7/4 = 34/12 + 21/12 = 55/12`，再化成 `4 又 7/12`。

## 十、带分数相减与拆出一个整体

计算 `4 又 1/6 − 2 又 3/4`，先把分数部分通分：

```text
4 又 1/6 = 4 又 2/12
2 又 3/4 = 2 又 9/12
```

2 个十二分之一不够减去 9 个十二分之一，可以从 4 个完整单位中拆出 1 个，改写成 12 个十二分之一：

```text
4 又 2/12 = 3 又 14/12
```

现在分别相减：

```text
3 − 2 = 1
14/12 − 9/12 = 5/12
结果：1 又 5/12
```

拆出一个整体只是重新组合原来的数量，不会改变被减数的值。

## 十一、整数减去分数

计算 `3 − 5/8`，可以把 3 改写成 2 个完整单位和 8 个八分之一：

```text
3 − 5/8
= (2 + 8/8) − 5/8
= 2 + 3/8
= 2 又 3/8
```

也可以把整数化成同分母分数：`3 = 24/8`，再计算 `24/8 − 5/8 = 19/8`。

整数没有写出分母，但仍可作为分数参与通分。例如，`−2 = −10/5`。

## 十二、负带分数先看清整体

计算 `−(1 又 1/2) + 2/3`，负号作用于整个带分数。先化成负假分数更清楚：

```text
−(1 又 1/2) + 2/3
= (−3/2) + 2/3
= (−9/6) + 4/6
= −5/6
```

再看两个负带分数相减：

```text
−(2 又 1/4) − [−(1 又 1/2)]
= (−9/4) + 3/2
= (−9/4) + 6/4
= −3/4
```

先化成假分数、再转化减法，可以避免把负带分数的整数部分与分数部分错误地分开处理。

## 十三、连续加减统一分母

计算 `3/4 − 5/6 + 1/3`，三个分母的最小公倍数是 12：

```text
3/4 − 5/6 + 1/3
= 9/12 − 10/12 + 4/12
= (9 − 10 + 4)/12
= 3/12
= 1/4
```

合并分子时，每一项原来的正负方向都要保留。

分数加减属于同一级运算，可以从左到右计算。统一分母后，写成一个分子算式，能清楚地展示各项怎样合并。

## 十四、括号改变计算范围

比较 `5/6 − (1/2 + 1/3)` 与 `5/6 − 1/2 + 1/3`。

第一式减去的是整个和：

```text
5/6 − (1/2 + 1/3)
= 5/6 − (3/6 + 2/6)
= 5/6 − 5/6
= 0
```

第二式先减去二分之一，再加上三分之一：

```text
5/6 − 1/2 + 1/3
= 5/6 − 3/6 + 2/6
= 4/6
= 2/3
```

同样的三个数，因为括号不同，表达的关系和结果也不同。

## 十五、减去一个差

计算 `7/8 − (1/2 − 1/4)`，可以先算括号：

```text
7/8 − (1/2 − 1/4)
= 7/8 − 1/4
= 7/8 − 2/8
= 5/8
```

也可以去括号。减去整个差，要把括号内两项的符号都改变：

```text
7/8 − 1/2 + 1/4
= 7/8 − 4/8 + 2/8
= 5/8
```

去括号后的式子必须与原式等价，不能只删除括号而保留里面所有符号。

## 十六、转化为加法后灵活组合

加法可以交换加数的位置，也可以改变加数的组合方式。我们观察：

```text
5/12 + 7/15 − 5/12
= 5/12 + 7/15 + (−5/12)
= [5/12 + (−5/12)] + 7/15
= 7/15
```

先把减法改写成加相反数，再把互为相反数的两项放在一起，可以避免不必要的通分。

移动的是整个带符号的加数，`−5/12` 的负号不能丢失。减法本身没有交换律，不能随意交换被减数与减数。

## 十七、先凑成完整单位

计算 `3/8 + 5/6 + 5/8`，可以先把同分母的两项合起来：

```text
3/8 + 5/6 + 5/8
= (3/8 + 5/8) + 5/6
= 1 + 5/6
= 1 又 5/6
```

同样，`1/7 + 6/7`、`0.25 + 3/4` 都能凑成 1。计算前观察能否凑整、抵消或先约分，有助于选择更简便的方法。

简便计算的依据是等值转换和加法规律，不是随意改变原来的运算关系。

## 十八、用估算和逆运算检验

前面得到 `5/12 + 7/18 = 29/36`。两个加数都是正数，和应大于任何一个加数。

它们又都小于 `1/2`，所以和应小于 1。`29/36` 符合这些范围。

再用减法检查：

```text
29/36 − 7/18
= 29/36 − 14/36
= 15/36
= 5/12
```

对于减法 `a − b = c`，可以检查 `c + b` 是否等于 `a`。这些逆运算关系也适用于带负号的分数。

范围检查能发现明显不合理的结果；逆运算则帮助核对具体计算。两者结合更有用。

## 十九、完整演示：初始水位与两次变化

以水池的一条标记线为 0，高于标记线为正。初始水位在标记线下 `1/3 m`，先上升 `3/4 m`，再下降 `1/6 m`。

先分别记录位置和变化：

```text
初始位置：−1/3 m
第一次变化：+3/4 m
第二次变化：−1/6 m
```

最终位置的数值是：

```text
(−1/3) + 3/4 − 1/6
= (−4/12) + 9/12 − 2/12
= 3/12
= 1/4
```

最终水位在标记线上方 `1/4 m`。

也可以先合并两次变化：`3/4 − 1/6 = 7/12`，表示总共上升 `7/12 m`。初始位置是 `−4/12 m`，上升后到达 `3/12 m`，与结果一致。

总变化是 `7/12 m`，最终位置是 `1/4 m`。计算虽然都用分数加减，但两个结果表达的数量不同。

## 二十、小结

分数加减的基础是统一每一份的大小。同分母时合并份数，异分母时先通分；可以先约分或选择较小的共同分母，让计算更方便。

带分数可以分别处理整数和分数部分，也可以先化成假分数。涉及负带分数时，要把负号看作作用于整个数。减法转化为加相反数后，可以依据加法规律组合各项。

连续计算时保留每一项的符号和括号范围，最后约分，并用估算、逆运算或实际数量关系检查结果。
